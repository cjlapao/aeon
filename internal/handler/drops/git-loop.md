**Why no handler (A3, kept visible):** L3 settles the split — code owns
every identifier and every API call; prose stays a model concern. Opening a
pull request is a mechanical call plus a writing task, and splitting them
removes the identifier-integrity bug class, **including the recorded
branch-inheritance bug** (a previous loop's checked-out branch — and its open
PR — adopted as the new loop's feature branch). A handler doing both halves
would reintroduce it. The `BECOMES A CODE ACTION` section is S16's input;
every range mapped to an action S16 does not plan to build is written as a
**FINDING to raise now**, not smuggled in as an action name.
