# T6 · Crash recovery, `Run`, and daemon wiring

**Prefix:** AU · **Rules:** AU8, AU9, AU13 · **Depends on:** T5 (dispatcher, `execute`), T4 (`(*Daemon).eventStarter`, `StartFromEvent`); S38 (a component read for `ResolveRoot`)

## Goal

A daemon killed between *claim* and *start*, or between *loop commit* and *fire decided*, is reconciled at the next boot: every open claim
becomes `started`, `skipped`, `refused` or `could-not-say` — **never a second loop**. `Dispatcher.Run` reconciles once then drains on each
tick; `cmd/aeon/serve.go` starts it after loop recovery and joins it at shutdown; an end-to-end test shows an approved goal producing an
unattended loop with its kickoff.

## Steps

1. **`recover.go`** — AU13's table, in this order. Skeleton:
   ```go
   type Summary struct{ Open, Started, Skipped, Refused, CouldNotSay, Rerun int }

   func (d *Dispatcher) Reconcile(ctx context.Context) (Summary, error) {
       open, err := d.Store.OpenEventFires()
       if err != nil { return Summary{}, err }
       sum := Summary{Open: len(open)}
       for _, f := range open {
           if err := ctx.Err(); err != nil { return sum, err }
           decide := func(o, reason, loopID, slug string) error {
               return d.Store.DecideEventFire(f.ID, store.EventFireDecision{Outcome: o, Reason: reason, LoopID: loopID, LoopSlug: slug}, d.Clock())
           }
           tr, terr := d.Store.GetEventTrigger(f.TriggerID)
           ev, eerr := d.Store.ReadAutomationEvent(f.OutboxID)
           if errors.Is(terr, store.ErrNotFound) || errors.Is(eerr, store.ErrNotFound) { // row 5
               if err := decide(store.FireRefused, fmt.Sprintf("subject-missing: trigger %s / outbox %d no longer readable", f.TriggerID, f.OutboxID), "", ""); err != nil { return sum, err }
               sum.Refused++; continue
           }
           if terr != nil { return sum, terr }
           if eerr != nil { return sum, eerr }
           // row 1: the loop already exists -> complete the record
           cid := tr.ComponentID; if cid == "" { cid = ev.ComponentID }
           if cid != "" {
               if root, rerr := d.ResolveRoot(cid); rerr == nil {
                   slug := AutoSlug(tr.ID, ev.ID)
                   l, gerr := d.Store.GetLoop(store.Scope{LoopSlug: slug, ProjectRoot: root}) // field name as the repo has it after S38
                   if gerr == nil { if err := decide(store.FireStarted, "", l.ID, l.Slug); err != nil { return sum, err }; sum.Started++; continue }
                   if !errors.Is(gerr, store.ErrNotFound) { return sum, gerr }
               }
           }
           switch {
           case !tr.Enabled: // row 2
               if err := decide(store.FireSkipped, "disabled: disabled while the daemon was down", "", ""); err != nil { return sum, err }
               sum.Skipped++
           case tr.UpdatedAt > f.ClaimedAt: // row 3 (ISO-8601 UTC strings compare lexicographically)
               if err := decide(store.FireCouldNotSay, "trigger-edited-since-claim: the definition that justified this claim changed", "", ""); err != nil { return sum, err }
               sum.CouldNotSay++
           default: // row 4: the start is idempotent by slug, so re-run from the depth check
               if err := d.execute(ctx, tr, ev, f); err != nil { return sum, err }
               sum.Rerun++
           }
       }
       return sum, nil
   }
   ```
   `execute` records its own outcome; after the loop, `Summary` counts by what was decided (Rerun counts attempts; a test reads the fire rows for outcomes).
2. **`Run`** (append to `dispatcher.go`):
   ```go
   func defaultClock() time.Time { return time.Now() } // the ONLY wall-clock read in this package (grep test in T5 allows exactly this)

   func (d *Dispatcher) Run(ctx context.Context) error {
       if d.Clock == nil { d.Clock = defaultClock }
       if sum, err := d.Reconcile(ctx); err != nil {
           if ctx.Err() != nil { return ctx.Err() }
           d.Log.Infof("automation: reconcile failed: %v", err)
       } else if sum.Open > 0 {
           d.Log.Infof("automation: reconciled %d open fire(s): %+v", sum.Open, sum)
       }
       tick := d.Tick
       if tick == nil { t := time.NewTicker(d.pollEvery()); defer t.Stop(); tick = t.C }
       for {
           if _, err := d.Drain(ctx); err != nil && ctx.Err() == nil { d.Log.Infof("automation: drain failed: %v", err) } // retried next tick
           select { case <-ctx.Done(): return ctx.Err(); case <-tick: }
       }
   }
   ```
   `pollEvery()` returns `d.PollEvery` or 1 s. Errors are logged with `Infof`, **never fatal** (daemon pattern, `serve.go:188`).
3. **`daemon/automation.go`:**
   ```go
   // RunAutomation blocks until ctx ends. No store => nothing to dispatch (honest, like daemon.go's unwired seams).
   func (d *Daemon) RunAutomation(ctx context.Context) error {
       if d.store == nil || d.loopRunner == nil { return nil }
       disp := d.newDispatcher()
       if err := disp.Run(ctx); err != nil && !errors.Is(err, context.Canceled) { return err }
       return nil
   }
   func (d *Daemon) newDispatcher() *automation.Dispatcher {
       return &automation.Dispatcher{Store: d.store, Starter: d.eventStarter(), ResolveRoot: d.componentRoot, Clock: time.Now, Log: d.log, PollEvery: time.Second}
   }
   func (d *Daemon) componentRoot(id string) (string, error) { /* S38 component read -> its root path; ErrNotFound -> a sentence */ }
   ```
   (`d.log` is whatever `lifecycle.go` uses for `d.log.Infof`.)
4. **`serve.go`** — after the recovery goroutine block (`:187-203`), add:
   ```go
   autoDone := make(chan struct{})
   go func() {
       defer close(autoDone)
       if noRecover { return } // the debug flag that skips recovery also skips automation
       select { case <-recoveryDone: case <-recoveryCtx.Done(): return } // start only after StartLoops has run
       if err := d.RunAutomation(recoveryCtx); err != nil { ctx.Log().Infof("automation dispatcher stopped: %v", err) }
   }()
   ```
   and at shutdown, right after the existing `select { case <-recoveryDone: case <-time.After(shutdownGrace): }`:
   ```go
   select { case <-autoDone: case <-time.After(shutdownGrace): }
   ```
   No other change to `serve.go`.
5. **Write the tests** (below). Recovery tests simulate a crash by leaving a claim open: `s.ClaimEventFire(...)` **without** `DecideEventFire`, then constructing a **new** `Dispatcher` (the "restarted daemon") over the same store. "Loop exists" is simulated with `s.CreatePinnedLoop(store.NewLoop{Slug: AutoSlug(tr.ID, ev.ID), <scope>: "/ws/c1", StartedByKind: event_trigger, StartedByID: tr.ID, …}, "dev-loop", 1, "content", "{}")`.
   The E2E test (`daemon/automation_test.go`) uses `recoveryStore(t)`, `New(Options{Store: s})`, the inline gate blueprint (`blueprint_workspace_test.go` shows it), S38's functions to create a component whose root is `t.TempDir()`, a trigger with `Blueprint: <gate blueprint path>`, an approved goal, then `d.newDispatcher().Drain(ctx)`.
6. Run the suites (Commands).

## Do NOT

- Do not delete or re-claim a claim; do not decide a fire twice; do not retry a `could-not-say`.
- Do not start the dispatcher before `StartLoops` finished, and do not start it when `noRecover` is set.
- Do not call `time.Now()` outside `defaultClock` in `internal/automation`; the daemon passes `time.Now` as an injected value.
- Do not make a dispatcher/log failure fatal to the daemon.
- Do not re-run a claim whose trigger was edited or disabled since — the table says `could-not-say`/`skipped`.
- Do not add an `event` publish for fires in this task (follow-up AU16).
