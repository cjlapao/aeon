# T2 · Outbox writes inside S38's store functions

**Prefix:** AU · **Rules:** AU3, AU4, AU5 · **Depends on:** T1; S38 T6 (goal store: `DecideGoal`, goal create), S38 T7 (task store: `CreateTask` with `manual`, manual-task approval, `SetTaskStatus`)

## Goal

Each of the four automation events is written to `automation_event` **inside the same transaction** as the domain change that
causes it, by exactly one helper; loop tasks never emit; depth and cause are derived from the writing loop, never passed in. A
rolled-back domain write leaves no outbox row, and a failed outbox write rolls the domain write back.

## Steps

1. **Create `automation.go`** (package `store`). Exact skeleton:
   ```go
   package store

   import ("database/sql"; "errors"; "fmt")

   const (
       EventGoalApproved  = "goal.approved"
       EventTaskCreated   = "task.created"
       EventTaskApproved  = "task.approved"
       EventTaskCompleted = "task.completed"
   )

   // AutomationEvents is the closed set (AU3). It must equal the CHECK in the migration; a test says so.
   func AutomationEvents() []string {
       return []string{EventGoalApproved, EventTaskCreated, EventTaskApproved, EventTaskCompleted}
   }

   // ErrNotAutomatable: a loop task asked for an event. Loop tasks never emit (AU3).
   var ErrNotAutomatable = errors.New("store: automation events are for goals and manual tasks only")

   // AutomationEventIn is what a domain write knows. It has NO depth field on purpose (AU5).
   type AutomationEventIn struct {
       Event, SubjectKind, SubjectID                         string
       SubjectVersion                                        int
       ProjectID, ComponentID, GoalType, TaskType, SourceKind string
       Manual       bool   // task events only; must be true
       OriginLoopID string // the loop whose agent caused this write; "" = a person
   }

   type AutomationEvent struct {
       ID                                                    int64
       Event, SubjectKind, SubjectID                         string
       SubjectVersion                                        int
       ProjectID, ComponentID, GoalType, TaskType, SourceKind string
       Depth                                                 int
       CausedByTrigger, CreatedAt                            string
   }

   // txExec is satisfied by *sql.Tx. (If S38's function uses a gorm tx instead, STOP and report.)
   type txExec interface {
       Exec(query string, args ...any) (sql.Result, error)
       QueryRow(query string, args ...any) *sql.Row
   }

   // insertAutomationEvent is the ONLY writer of automation_event. It never opens a transaction and never publishes.
   func insertAutomationEvent(tx txExec, now string, in AutomationEventIn) error {
       if !isAutomationEvent(in.Event) {
           return fmt.Errorf("store: %q is not an automation event", in.Event)
       }
       if in.SubjectKind == "task" && !in.Manual {
           return ErrNotAutomatable
       }
       depth, cause := 0, ""
       if in.OriginLoopID != "" {
           var d int
           var kind, id sql.NullString
           err := tx.QueryRow(`SELECT automation_depth, started_by, trigger_id FROM loop WHERE id = ?`, in.OriginLoopID).Scan(&d, &kind, &id)
           if err != nil { // unknown loop => fail CLOSED: never reset depth to 0
               return fmt.Errorf("store: automation origin loop %q: %w", in.OriginLoopID, err)
           }
           depth = d
           if kind.String == "event" { cause = id.String } // only EVENT-started loops cascade; S20 fires ('trigger','webhook') are depth 0
       }
       _, err := tx.Exec(`INSERT INTO automation_event
           (event, subject_kind, subject_id, subject_version, project_id, component_id, goal_type, task_type, source_kind, depth, caused_by_trigger, created_at)
           VALUES (?,?,?,?,?,?,?,?,?,?,?,?)`,
           in.Event, in.SubjectKind, in.SubjectID, in.SubjectVersion, in.ProjectID, in.ComponentID, in.GoalType, in.TaskType, in.SourceKind, depth, cause, now)
       if err != nil { return fmt.Errorf("store: write the %s automation event: %w", in.Event, err) }
       return nil
   }

   func isAutomationEvent(e string) bool { for _, v := range AutomationEvents() { if v == e { return true } }; return false }
   ```

- Do not call `Daemon.publish`, `Events.Append` or open a second transaction from the helper.

- Do not change a function's behavior when it succeeds or fails for non-automation reasons; the only new failure is the outbox write.
