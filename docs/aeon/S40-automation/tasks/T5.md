# T5 · The dispatcher — cursor, match, claim, guards, limits, start, outcomes

**Prefix:** AU · **Rules:** AU5, AU6, AU8, AU11, AU12 · **Depends on:** T2 (outbox readers, cursor), T3 (triggers, fires, `Match.Matches`), T4 (`automation.Starter`, `Refusal`, `AutoSlug`); S38 T6/T7 (to seed events in tests through real store functions)

## Goal

`internal/automation` gains `Dispatcher.Drain`: one pass that reads the outbox after the durable cursor, finds every matching trigger,
claims each (trigger, event) pair **before** anything starts, applies depth → overlap → limits → target → start, and records exactly one of
the five outcomes with its reason — all driven by an **injected clock and a fake `Starter`, with no sleeps anywhere**.

2. **`dispatcher.go`** — types and `Drain`:
   ```go
   package automation

   type Dispatcher struct {
       Store       *store.Store
       Starter     Starter
       ResolveRoot func(componentID string) (string, error) // S38 component read (<VERIFY name>); wired in T6
       Clock       func() time.Time                         // REQUIRED; tests inject; no default to time.Now here
       Log         interface{ Infof(format string, args ...any) }
       PollEvery   time.Duration // used by Run (T6)
       BatchSize   int           // default 100
   }
   const cursorName = "dispatcher"

   func (d *Dispatcher) Drain(ctx context.Context) (events int, err error) {
       after, err := d.Store.AutomationCursor(cursorName)
       if err != nil { return 0, err }
       evs, err := d.Store.ReadAutomationEvents(after, d.batch())
       if err != nil { return 0, err }
       for _, ev := range evs {
           if err := ctx.Err(); err != nil { return events, err }
           trigs, err := d.Store.ListEventTriggersFor(ev)
           if err != nil { return events, err }
           for _, tr := range trigs {
               if err := d.fire(ctx, tr, ev); err != nil { return events, err } // store failure: stop, cursor NOT advanced
           }
           if err := d.Store.AdvanceAutomationCursor(cursorName, ev.ID, d.Clock()); err != nil { return events, err }
           events++
       }
       return events, nil
   }
   ```
3. **`fire` and `execute`** (exact order — AU8):
   ```go
   func (d *Dispatcher) fire(ctx context.Context, tr store.EventTrigger, ev store.AutomationEvent) error {
       nf := store.NewEventFire{TriggerID: tr.ID, OutboxID: ev.ID, SubjectKind: ev.SubjectKind, SubjectID: ev.SubjectID, Depth: ev.Depth}
       if !tr.Enabled {
           reason := "disabled"; if tr.DisabledReason != "" { reason += ": " + tr.DisabledReason }
           _, _, err := d.Store.RecordEventFire(nf, store.EventFireDecision{Outcome: store.FireSkipped, Reason: reason}, d.Clock())
           return err
       }
       f, fresh, err := d.Store.ClaimEventFire(nf, d.Clock())
       if err != nil || !fresh { return err } // already claimed: T6's Reconcile owns open claims
       return d.execute(ctx, tr, ev, f)
   }

   // execute is AU8 steps 3-7 for a CLAIMED fire. Reconcile (T6) calls it too.
   func (d *Dispatcher) execute(ctx context.Context, tr store.EventTrigger, ev store.AutomationEvent, f store.EventFire) error {
       decide := func(o, reason, loopID, slug, note string) error {
           return d.Store.DecideEventFire(f.ID, store.EventFireDecision{Outcome: o, Reason: reason, LoopID: loopID, LoopSlug: slug, CostNote: note}, d.Clock())
       }
       note := ""
       // 3. depth
       if ev.Depth > store.MaxAutomationDepth {
           return decide(store.FireRefused, fmt.Sprintf("depth-exceeded: event depth %d > %d (caused by trigger %q)", ev.Depth, store.MaxAutomationDepth, ev.CausedByTrigger), "", "", "")
       }
       // 4. overlap
       if slug, status, found, err := d.Store.OverlappingEventFire(tr.ID, ev.SubjectKind, ev.SubjectID); err != nil { return err } else if found {
           return decide(store.FireSkipped, fmt.Sprintf("overlap: loop %s is still %s", slug, status), "", "", "")
       }
       // 5. limits (AU11)   // S20 T7: TriggerAccess evaluates here (no code in S40)
       now := d.Clock()
       n, err := d.Store.CountRecentEventFires(tr.ID, now.Add(-time.Hour), f.ID); if err != nil { return err }
       if n >= tr.MaxRunsPerHour {
           return decide(store.FireLimited, fmt.Sprintf("max-runs-per-hour: %d started since %s, limit %d", n, now.Add(-time.Hour).UTC().Format(time.RFC3339), tr.MaxRunsPerHour), "", "", "")
       }
       if tr.MaxCostPerDayUSD != nil {
           sp, err := d.Store.EventTriggerSpend(tr.ID, now.Add(-24*time.Hour)); if err != nil { return err }
           if sp.Floor { note = "cost-floor" }
           if sp.USD >= *tr.MaxCostPerDayUSD { // a floor that already reaches the cap proves it
               return decide(store.FireLimited, fmt.Sprintf("max-cost-per-day: $%.2f known (floor=%v) >= $%.2f", sp.USD, sp.Floor, *tr.MaxCostPerDayUSD), "", "", note)
           }
           if sp.Unknown { note = "cost-unknown" } // cannot check the cap: runs/hour alone bounds this fire
       }
       // 6. target
       cid := tr.ComponentID; if cid == "" { cid = ev.ComponentID }
       if cid == "" { return decide(store.FireRefused, "no-target-component: the event names no single component; set component on the trigger", "", "", note) }
       root, err := d.ResolveRoot(cid)
       if err != nil { return decide(store.FireRefused, "workspace-invalid: "+err.Error(), "", "", note) }
       // 7. start
       res, err := d.Starter.Start(ctx, StartRequest{TriggerID: tr.ID, TriggerName: tr.Name, Blueprint: tr.Blueprint, WorkspaceRoot: root,
           Slug: AutoSlug(tr.ID, ev.ID), Event: ev.Event, SubjectKind: ev.SubjectKind, SubjectID: ev.SubjectID, SubjectVersion: ev.SubjectVersion,
           KickoffTemplate: tr.Kickoff, Depth: ev.Depth + 1})
       var ref *Refusal
       switch {
       case errors.As(err, &ref):
           if !store.ValidEventRefusedReason(ref.Reason) { // never trust an unclassified refusal
               return decide(store.FireCouldNotSay, "start-error: unclassified refusal "+ref.Reason+": "+ref.Sentence, "", "", note)
           }
           return decide(store.FireRefused, ref.Reason+": "+ref.Sentence, "", "", note)
       case err != nil:
           return decide(store.FireCouldNotSay, "start-error: "+err.Error(), "", "", note)
       }
       return decide(store.FireStarted, "", res.LoopID, res.Slug, note)
   }
   ```

- Do not estimate cost, substitute a default for unknown, or round a floor up to a "known".
- Do not retry a failed start, re-claim a fire, or decide a fire twice.

**Shipped 2026-10-28.** The dispatcher arrived as written — `Drain` (cursor → read → match →
fire → advance-per-event), `fire` (disabled recorded BEFORE claim; claim-before-start; loser
returns nil and says nothing), `execute` in AU8's exact order depth → overlap → limits → target

**Measured, not assumed:**

- The skeleton's `store.EventTrigger`/`store.EventFire` do not exist — T3 named the types
  `store.Trigger`/`store.Fire`; the dispatcher speaks those.
- **A pin rests `idle` until a runner takes it** (S39). The overlap test's fake starter first
  pinned loops and let them rest — and the guard correctly let every "overlap" through, because
  an idle loop is not still going. The fake now moves its pinned loop to `running`, the same way
  `startLoopWith` hands off; the guard then guards. A fake that cannot fail a guard is not a fake.
- **`Trigger.Admits` fails closed for a component-scoped trigger against an event with empty
  component** (T3's scope AND-match). The plan's phase "multi-component goal + ComponentID on
  the trigger → started" is therefore unreachable — the event never admits that trigger. The
  test is restructured honestly: the trigger-rooted start uses a SINGLE-component goal (the
  event names the same component, so Admits passes), and a new arm covers the plan's fallback —
  a trigger with NO component on a single-component event starts rooted at the EVENT's
  component (`cid = ev.ComponentID`).
- `MaxRunsPerHour` is validated 1–1000 at `CreateEventTrigger` — there is no zero-means-unlimited
  shadow, so the plain `n >= tr.MaxRunsPerHour` is the whole rule.
- `ListEventFires` is `ORDER BY id DESC` (newest first) — tests index the newest fire at `[0]`.
- `CreateProject` returns `ProjectWrite{Project, Refusal, Reason}` — read `p.Project.ID`.
- The store's own disciplines fired and were honoured, not silenced:
  `TestCostIsWrittenAndReadThroughOneFunctionEach` is a grep and matches `cost_state =` even
  inside a `CASE WHEN` read — `EventTriggerSpend` spells its comparisons `IN ('partial')` /
  `IN ('unknown')`, the very spelling the house costQuery (`runs.go:293`) uses. And
  `TestEveryExportedMethodIsNamedInTheSurfaceTable` demanded the new **S40 dispatch reads**
  row in `store.go` naming the dispatcher as consumer.
- The human doors carry the honest zero: a person's `DecideTask` approval of a task a depth-2
  loop filed emits **depth 0, cause ""** even though the write's task row carries
  `OriginLoopID` (T2's human-door rule) — pinned by `TestDepthAndCauseRideTheEmittingWrites`;
  the only depth-carrying event is the agent door's `task.created`.
