**Prefix:** AU · **Rules:** AU1, AU6, AU7, AU12 · **Depends on:** T1 (tables); T2 (`AutomationEvent`, `AutomationHead`); S38 T7 (task type list, for `task_type` validation)

## Goal

`internal/store` gains (a) a pure, closed **match grammar** (`ParseMatch`, `Match.Matches`, canonical form), (b) the **trigger
store** whose writes demand a human `Actor` and refuse anything else before any SQL, and (c) the **fire-record functions** with the
claimed-FROM decision and the closed outcome/reason vocabulary. No dispatcher, no daemon, no socket yet.

## Steps

1. **`trigger_match.go`.** Closed grammar (AU6). Skeleton:
   ```go
   type Match struct {
       Event                                          string
       Project, Component, GoalType, TaskType, SourceKind []string // each: sorted, de-duplicated; empty = key absent
   }
   var matchKeys = []string{"event", "project", "component", "goal_type", "task_type", "source_kind"}

   // ParseMatch reads the JSON form. Every refusal is ONE sentence that names the key.
   func ParseMatch(raw []byte) (Match, error) {
       var m map[string]json.RawMessage
       if err := json.Unmarshal(raw, &m); err != nil { return Match{}, fmt.Errorf("match: must be a JSON object: %v", err) }
       for k := range m { if !contains(matchKeys, k) {
           return Match{}, fmt.Errorf("match: unknown key %q (allowed: %s)", k, strings.Join(matchKeys, ", ")) } }
       // event: required string in AutomationEvents()
       // each other key: a string OR a list of strings (see strSet below); then normalise
       // then (&Match).Validate()
   }
   func (m Match) Validate() error   // event in closed set; applicability; value rules; task_type values in the task type list
   func (m Match) Canonical() string // json.Marshal of a struct with fixed field order and omitempty slices
   func (m Match) Matches(ev AutomationEvent) bool
   ```
   Rules `Validate` enforces (each its own error sentence, test each): `event` required and in `AutomationEvents()`; `goal_type` and
   `source_kind` only when `event` starts `goal.`; `task_type` only when it starts `task.`; each value 1–128 chars, no empty string;
   ≤16 values per key; `task_type` values ∈ the task type list. `strSet(raw json.RawMessage) ([]string, error)` accepts `"x"` or `["x","y"]`
   and rejects numbers, bools, objects, `null`. Normalise = trim nothing (values are literal), sort, de-duplicate.
   `Matches`: `ev.Event == m.Event`; then for each **non-empty** key, the event's field must be **non-empty and in the set**
   (an event field of `''` never satisfies a present key — AU6). Keys are ANDed; values within a key are ORed.
2. **Trigger types and the human lock** (`triggers.go`):
   ```go
   type Actor struct{ Kind, ID string } // Kind is "user" | "agent" | ...; only "user" may write triggers
   var ErrActorNotHuman = errors.New("store: triggers are written by a person")
   func requireUser(a Actor) error {
       if a.Kind != "user" || strings.TrimSpace(a.ID) == "" {
           return fmt.Errorf("%w; this actor is %q", ErrActorNotHuman, a.Kind)
       }
       return nil
   }
   type Trigger struct {
       ID, Name, Source, ProjectID, ComponentID, MatchJSON, Blueprint, Kickoff string
       MaxRunsPerHour int; MaxCostPerDayUSD *float64
       Enabled bool; DisabledReason string; FromOutboxID int64
       CreatedByKind, CreatedByID, CreatedAt, UpdatedAt string
   }
   func (t Trigger) Match() (Match, error) { return ParseMatch([]byte(t.MatchJSON)) }
   // Admits: scope (project/component columns) AND the match. '' scope columns admit anything.
   func (t Trigger) Admits(ev AutomationEvent) bool
   ```
3. **CRUD** (columns exactly as T1; table `event_trigger`):
   ```go
   type NewEventTrigger struct {
       Name, ProjectID, ComponentID string; Match Match; Blueprint, Kickoff string
       MaxRunsPerHour int; MaxCostPerDayUSD *float64
   }
   type EventTriggerEdit struct {
       Name, Blueprint, Kickoff *string; Match *Match
       MaxRunsPerHour *int; MaxCostPerDayUSD *float64; ClearMaxCost bool
   }
   type EventTriggerFilter struct{ ProjectID, ComponentID string; Enabled *bool }

   func (s *Store) CreateEventTrigger(a Actor, in NewEventTrigger) (Trigger, error)
   func (s *Store) UpdateEventTrigger(a Actor, id string, e EventTriggerEdit) (Trigger, error)
   func (s *Store) SetEventTriggerEnabled(a Actor, id string, enabled bool, reason string) (Trigger, error)
   func (s *Store) GetEventTrigger(id string) (Trigger, error)               // ErrNotFound
   func (s *Store) ListEventTriggers(f EventTriggerFilter) ([]Trigger, error)     // ORDER BY name
   func (s *Store) ListEventTriggersFor(ev AutomationEvent) ([]Trigger, error)
   ```
   - Every write begins `if err := requireUser(a); err != nil { return Trigger{}, err }` — **before** `s.w.Begin()`.
   - `CreateEventTrigger`: validate (`in.Match.Validate()`, name 1–80 chars, blueprint non-empty, `1 ≤ MaxRunsPerHour ≤ 1000`, cost nil or ≥ 0), then one tx:
     `from := MAX(id) FROM automation_event` (same tx), `id := newID()`, INSERT with `source='event'`, `created_by_kind='user'`, `created_by_id=a.ID`, `enabled=1`, `match_json = in.Match.Canonical()`.
     A duplicate `name` returns `fmt.Errorf("trigger %q already exists", name)` (detect the UNIQUE failure by string `UNIQUE constraint failed: trigger.name`).
   - `UpdateEventTrigger`: edits only the non-nil fields; re-validates the merged result; sets `updated_at`; never changes `created_by_*`, `from_outbox_id`, `source`.
   - `SetEventTriggerEnabled`: `enabled=false` **requires** a non-empty `reason` (sentence), stored in `disabled_reason`; enabling clears it; both bump `updated_at`. No-op changes (already in that state) still return the row, unchanged `updated_at`.
   - `ListEventTriggersFor(ev)`: `SELECT … FROM event_trigger WHERE source='event' AND from_outbox_id < ? ORDER BY id` then filter in Go with `Admits` (includes **disabled** triggers — the dispatcher records `skipped(disabled)`).
4. **Fire records** (`triggers.go`):
   ```go
   const (FireStarted = "started"; FireRefused = "refused"; FireLimited = "limited"; FireSkipped = "skipped"; FireCouldNotSay = "could-not-say")
   func EventFireOutcomes() []string // the five, in that order
   // EventFireReasons is AU12's closed list: outcome -> allowed reason codes (the text before the first ':').
   var EventFireReasons = map[string][]string{
       FireStarted: {}, 
       FireRefused: {"depth-exceeded","requires-unmet","blueprint-refused","no-target-component","workspace-invalid","subject-missing","kickoff-invalid"},
       FireLimited: {"max-runs-per-hour","max-cost-per-day"},
       FireSkipped: {"disabled","overlap"},
       FireCouldNotSay: {"start-error","trigger-edited-since-claim"},
   }
   var ErrEventFireDecided = errors.New("store: this fire already has an outcome")

   type NewEventFire struct{ TriggerID string; OutboxID int64; SubjectKind, SubjectID string; Depth int }
   type EventFireDecision struct{ Outcome, Reason, LoopID, LoopSlug, CostNote string }
   type Fire struct { ID int64; TriggerID string; OutboxID int64; Source, SubjectKind, SubjectID string; Depth int
       Outcome, Reason, LoopID, LoopSlug, CostNote, ClaimedAt, DecidedAt string } // Outcome "" = claimed, undecided
   type EventFireFilter struct{ TriggerID, Outcome string; BeforeID int64; Limit int }

   func (s *Store) ClaimEventFire(in NewEventFire, at time.Time) (f Fire, fresh bool, err error)
   func (s *Store) DecideEventFire(id int64, d EventFireDecision, at time.Time) error
   func (s *Store) RecordEventFire(in NewEventFire, d EventFireDecision, at time.Time) (Fire, bool, error) // claim+decide in ONE insert (skipped/disabled)
   func (s *Store) GetEventFire(id int64) (Fire, error)
   func (s *Store) OpenEventFires() ([]Fire, error)                // outcome IS NULL, ORDER BY id
   func (s *Store) ListEventFires(f EventFireFilter) ([]Fire, error)    // ORDER BY id DESC, Limit default 50, max 500
   func (s *Store) EventFireCounts(triggerID string) (map[string]int, error) // always all five keys, zero included
   ```
   - `ClaimEventFire`: `INSERT … (outcome NULL) ON CONFLICT(trigger_id, outbox_id) DO NOTHING`; `RowsAffected()==0` → `fresh=false` and return the existing row (select by the unique key).
   - `DecideEventFire`: first `validateDecision(d)` (outcome ∈ `EventFireOutcomes()`; reason code = text before the first `:` ∈ `EventFireReasons[outcome]`; `started` requires `LoopID != ""` and empty reason; `CostNote` ∈ `''|cost-unknown|cost-floor`).
     SQL: `UPDATE event_trigger_fire SET outcome=?, reason=?, loop_id=NULLIF(?,''), loop_slug=NULLIF(?,''), cost_note=?, decided_at=? WHERE id=? AND outcome IS NULL`.
     Zero rows → row exists? `ErrEventFireDecided` : `ErrNotFound` (claimed-FROM, S35 TD1's pattern).
   - Time arguments are formatted with the store's own `isoUTC(at)`; **these functions never read the store clock** (the dispatcher injects time).
5. **Write the tests** (below). Use `openTemp(t)` and fixed `time.Time` values; build `AutomationEvent` literals directly for `Matches`.
6. Run the suite (Commands).

- **`json.Unmarshal` lets `null` through as a silent no-op** on both the string and the list attempt — a bare `null` value would have become an empty string and refused with the *wrong* sentence (or worse, passed elsewhere). `strSet` checks `null` first, so the type refusal is what the author reads. (Found by the refusal table, which tests null explicitly.)
- **Absent ≠ empty, and the grammar says so in two places:** an absent key is a nil list, which `Matches` skips (matches anything) and `Validate` skips; an empty JSON list `[]` is refused at parse ("an empty list matches nothing, which is surely not what was meant"). The first draft ran every nil list through the value rules and every keyless match died — the fix is the distinction itself, not a bypass.
- **`Admits` ignores `enabled`** — deliberately: `ListEventTriggersFor` includes disabled triggers so the dispatcher can record `skipped(disabled)`; a store that filtered them out would make AU12's `skipped` unwritable from the store side.
- **Trigger ids are `"trg-"+newID()`** (house prefix like `tsk-`; the design froze the *columns*, not the id format — nothing parses the prefix, T5's tests use literal ids).
- **`EventFireReasons` widened? - **`DecideEventFire`'s closed vocabulary is special-cased exactly as AU12 reads:** `started` demands a loop id and an EMPTY reason (a started loop "has no reason to give"); every other outcome demands a reason whose code (text before the first `:`) is in its list; `cost_note` ∈ `''|cost-unknown|cost-floor`.
