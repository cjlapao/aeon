# T8 · The write surface and the human-only pins — `automation.trigger.create/update/enable/disable`

**Prefix:** AU · **Rules:** AU1, AU6, AU14 · **Depends on:** T7 (types, `Table` fields, fixtures dir); T3 (`store.Actor`, trigger writes, `ErrActorNotHuman`); S38 T15 (the actor stamp that `*.decide` uses); S39 T8 (kickoff template parser)

## Goal

Four human-only socket writes. Each derives its actor from the connection, **refuses anything that is not a `user` before touching the
store**, validates the match grammar, the blueprint (the same validation `loop.start` applies, without creating anything), the scope
ids and the kickoff template, and returns the stored `EventTriggerView`. Three grep-pinned tests prove no agent tool, handler or narrow-surface
action can reach a trigger write.

## Steps

1. **Actor** (`protocol/triggers.go`). If S38 T15 already provides one, reuse it. Fallback:
   ```go
   type Actor struct{ Kind, ID string } // "user" is the only kind that may write triggers (AU1)
   // On Table: ActorFor func(ctx context.Context, sess *Session) Actor   // wired by the daemon from the peer credential; nil => refuse

   func (t *Table) triggerActor(ctx context.Context, sess *Session) (Actor, error) {
       if t.ActorFor == nil { return Actor{}, <S38 refusal>("triggers are written by a person; no identity is available on this connection") }
       a := t.ActorFor(ctx, sess)
       if a.Kind != "user" || strings.TrimSpace(a.ID) == "" {
           return Actor{}, <S38 refusal>(fmt.Sprintf("triggers are written by a person; this actor is %q", a.Kind))
       }
       return a, nil
   }
   ```
   (`<S38 refusal>` = the error T0-Q6 recorded; if none, `ErrBadParams{Err: fmt.Errorf(...)}`.) In the daemon, wire `table.ActorFor` from `d.peer(sess.ConnID)`: `uid, _, _ := d.peer(connID)` → `Actor{Kind: "user", ID: "uid:" + strconv.Itoa(uid)}` — the connecting process's user. **No path in the daemon ever constructs `Kind: "agent"`** (the type can carry one for the refusal test).
2. **Write types and seam:**
   ```go
   type EventTriggerCreateParams struct {
       Name string `json:"name"`; ProjectID string `json:"projectId,omitempty"`; ComponentID string `json:"componentId,omitempty"`
       Match json.RawMessage `json:"match"`; Blueprint string `json:"blueprint"`; Kickoff string `json:"kickoff,omitempty"`
       MaxRunsPerHour int `json:"maxRunsPerHour"`; MaxCostPerDayUSD *float64 `json:"maxCostPerDayUsd,omitempty"`
   }
   type EventTriggerUpdateParams struct {
       ID string `json:"id"`; Name *string `json:"name,omitempty"`; Match json.RawMessage `json:"match,omitempty"`
       Blueprint *string `json:"blueprint,omitempty"`; Kickoff *string `json:"kickoff,omitempty"`
       MaxRunsPerHour *int `json:"maxRunsPerHour,omitempty"`; MaxCostPerDayUSD *float64 `json:"maxCostPerDayUsd,omitempty"`; ClearMaxCost bool `json:"clearMaxCost,omitempty"`
   }
   type EventTriggerEnableParams struct{ ID string `json:"id"` }
   type EventTriggerDisableParams struct{ ID string `json:"id"`; Reason string `json:"reason"` }
   type EventTriggerWriter interface {
       CreateEventTrigger(a Actor, p EventTriggerCreateParams) (EventTriggerView, error)
       UpdateEventTrigger(a Actor, p EventTriggerUpdateParams) (EventTriggerView, error)
       EnableEventTrigger(a Actor, id string) (EventTriggerView, error)
       DisableEventTrigger(a Actor, id, reason string) (EventTriggerView, error)
   }
   ```
   Handlers (copy `handleProjectUpdate`): `decodeParams` → trim/validate required fields → `a, err := t.triggerActor(ctx, sess)` **before** any other work that touches state → `if t.TriggerWrites == nil { return nil, ErrStoreUnavailable }` → call the seam. Order is part of the contract: **actor check first**, so an agent learns nothing about validity. Methods: `automation.trigger.create`, `automation.trigger.update`, `automation.trigger.enable`, `automation.trigger.disable` (consts `MethodAutomationTriggerCreate` …), all `RequiresInitialize: true`. Add fields `TriggerWrites EventTriggerWriter` and `ActorFor` to `Table`.
3. **`loop.CheckBlueprint` — a pure extraction.** In `pin.go`, move the part of `Start` from `blueprint.Resolve(name)` through the `futureHandlerRefusal` check into

   ```go
   func checkBlueprint(name, mode string) (bp blueprint.Blueprint, raw []byte, err error) // returns PinRefusal / resolve errors exactly as Start did
   func CheckBlueprint(name, mode string) error { _, _, err := checkBlueprint(name, mode); return err }
   ```
   `Start` then begins `bp, raw, err := checkBlueprint(name, in.Mode); if err != nil { return LoopState{}, err }` and continues with `InitialState(bp)`. **No behavior change**: the existing `internal/loop` tests (pin, refusals, future-handler door) pass untouched. `pin_check_test.go`: `TestCheckBlueprintRefusesWhatStartRefusesAndCreatesNothing` — an unknown name and an invalid YAML each give the same `PinRefusal`/error text as `Start`; a valid standard blueprint (`"two-step"`) returns nil; no loop row is created (store untouched).
