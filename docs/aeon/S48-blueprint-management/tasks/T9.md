# T9 · The `blueprint_save` proposal kind

**Prefix:** BP · **Rules:** BP9 · S35 TD1/TD3/TD4 · S37 T1 / S46 T6 (the rebuild precedent) · **Depends on:** T6, T8 and **S45 T1/T5** (the `internal/desk` registry and the generic `proposal.commit`).

## Goal

Agents can *propose* a blueprint (new or changed) as an **inert** proposal; a person reviews and commits it through S45's generic commit. The closed `proposal.kind` enum gains **one** kind — the "design revision" S35 TD1 requires — by the established table rebuild.

- `aeon/internal/desk/` (S45) — register `blueprint_save`: payload `{name, content, createOnly?, note?}` (closed shape; ≤ 1 MiB + 8 KiB envelope):
  `Validate`: **`blueprint.Analyze`** with the write path's options + `id == name` + size + grammar + (`createOnly` ⇒ name free); a payload refused by `proposal.create` is refused by `proposal.commit` for the same reason (S35 TD3 — one function). `AlreadyApplied`: the stored `content_hash` equals the payload's. `Apply`: **T6's save path** with actor = the **committing person** (never the proposer), `op` = `create`/`save`, `note` = the proposal's note. The effect func is supplied to `desk.Seams` by the daemon/cmd wiring (`internal/desk` imports neither the store nor the daemon; the existing seam pattern).
- `aeon/cmd/aeon/proposal_validators.go` / `proposal.go` — the CLI's per-kind arms delegate to `desk` for the new kind (S45 T1 pattern); `aeon proposal list/commit/reject` handle it with no special case beyond the preview.
- `internal/protocol/proposals.go` — **no edit**; the existing `ProposalRow` carries the payload; **preview** for this kind (S45 T5's `proposal.get` preview hook): the `Diff` (T2) against the current content (or "new blueprint"), the `Report` summary, and `Lint` advisories — computed read-only, advisory (AA4).

## Behaviour

1. **Inert:** a `blueprint_save` proposal changes nothing; `blueprint.list/show/usage` and `loop.start` are byte-identical with proposals of every kind present (the S35 arbiter pattern, extended to blueprints).
2. **Commit is S45's generic commit** (digest-bound, effect-then-flip with crash-safe retry, before/after = the diff and the new revision number, reject needs a reason). No new socket method.
3. **Created by an agent** carries `created_by` kind `agent` (the stamped identity, T0/S45 T0 recorded how); the UI shows the badge.
4. A proposal whose blueprint no longer validates at commit (an agent was deleted meanwhile) is refused at commit naming the report — `applied_error` set, row stays `proposed` (S35 TD4).
5. The per-agent open-proposal limit (S45/S46's named constant) applies.
