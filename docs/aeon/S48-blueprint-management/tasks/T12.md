## Behaviour

**List.** `blueprint.list` (filters sent as params: origin, q — daemon-side): name, **origin badge** (`Shipped`/`Yours`), version, revision, **`Edited` badge** when `divergedFromShipped` (and **no** badge when the field is absent — unknown is not "unedited"), usage count, last changed by/when (`RelativeTime`). Empty ⇒ the daemon's statement.
**Detail drawer / editor** (`blueprint.show`): the YAML editor over the stored text; **Validate** (`blueprint.validate`, text) and **Lint** (`blueprint.lint`, text) run on demand and show the three-state report and the advisories **side by side**, advisories labelled "as of <evaluatedAt>" and showing the verdict sentence verbatim; **Save** ⇒ `blueprint.save {name, content, note}`; an invalid result shows the report verbatim and **keeps the draft**; success shows "saved as revision N" from the response; a `changed:false` shows "no changes". The editor never writes the file system.
**Duplicate:** a name field ⇒ `blueprint.duplicate` (comments preserved by the daemon); on success opens the copy.
**Delete:** `useConfirm` naming the blueprint; the daemon's refusal (system / referenced) is shown **verbatim with every reference** (each links to the trigger/queue view if it exists — S49 — else shown as text); started loops are reported unaffected.
**Revisions tab:** `blueprint.history` list (rev, op chip, actor, note, when); select two ⇒ `blueprint.diff` rendered in `DiffView` (unified diff, monospace, add/remove colouring **plus** `+`/`-` markers so colour is not the only cue); **Revert** ⇒ `useConfirm` ⇒ `blueprint.revert` (a new revision); for a system blueprint a "Compare with shipped" action (`diff … shipped`) and **"Restore shipped"** (`seed.restore`, with confirm and the diff shown first — S43-extra's door; hidden if that method is not registered).
**Usage tab:** `blueprint.usage`: referencing triggers/schedules/open queue items (counts + rows), agents/actions/skills used (agents link to the agent view, S43), started-loops count.
**Proposals:** S45's desk filtered to `blueprint_save` (preview = diff + report + advisories; commit/reject via the generic methods with the before/after confirm; reject needs a reason; the "proposed by an agent" badge).
**Cross-cutting.** Offline/reconnecting ⇒ writes disabled with the kit affordance; reads show last data; after any write the affected rows come **from the response**, never optimistically; no `localStorage` for blueprint data; no `fetch`; no client-side YAML editing, diffing, validation or reference extraction; i18n parity; no new dependency.
