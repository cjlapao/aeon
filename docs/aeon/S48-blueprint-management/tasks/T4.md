# T4 · Adopting existing files

**Prefix:** BP · **Rules:** BP3 · **Depends on:** T3.

## Goal

An existing installation's blueprints — pristine standard copies, **edited** standard copies and custom files — are carried into the database **once, per file, losslessly**; invalid files are reported, never dropped; the files are never touched.

## Files

- `aeon/cmd/aeon/blueprint_adopt.go` — **new** (cmd/aeon wires it; the logic is `internal/blueprint` + store): `adoptFiles(ctx, st, dir) (AdoptReport, error)`:
  1. Walk `<store dir>/blueprints/`: regular `*.yaml` only (no symlinks, no subdirectories), name matches the grammar; others are **ignored and listed** in the report (`skipped`, with the reason).
  2. For each file: read (≤ 1 MiB), `sha256`; `ImportByHash` exists ⇒ `already-imported` (idempotent). Else `blueprint.Analyze(raw, same options as save)`; `!OK(false)` ⇒ **not imported**: one `blueprint_import` row (`refused`, the diagnostics rendered ≤ 4096) — never silent; `doctor` lists them.
  3. Valid ⇒ classify: **(a) pristine** — standard name and the hash equals the **current embedded** bytes or any `pristineUpgrades` hash ⇒ `origin='system'`; **(b) edited standard** — standard name, other content ⇒ `origin='system'` **with the user's content** (BP6); **(c) custom** ⇒ `origin='user'`.
  4. One transaction per file (`BlueprintPutTx`: row + `blueprint_revision` `op='adopt'` actor `{system,startup}` + `blueprint_ref` from `References` + `ImportInsertTx` `imported`).
  5. Name collision between a file and an existing row ⇒ **skipped** with the reason (never merge/overwrite).
  Files are **never** written, renamed or deleted. The pristine-hash list is read from `blueprint` (a small exported accessor over `pristineUpgrades`, kept **until T5 retires the table** — T5 moves the hashes into the adoption classifier's own constant with its test).
- `aeon/cmd/aeon/serve.go` — call `adoptFiles` after migrations and **before** the seed (T5) and before loops are accepted; log one line per outcome class (`blueprints: adopted N (P pristine, E edited, C custom), refused R, skipped S`).
- `aeon/cmd/aeon/doctor.go` — a `blueprints` line: `database authoritative (N blueprints)` / `R files refused at adoption (aeon blueprint …)` / `files differ from what was imported (the database wins)`; **never** modifies anything.
- No `blueprint.importFile` daemon method (BP3: the daemon never reads arbitrary paths); explicit import is the CLI's `save --file` (T11).

## Behaviour notes

- **Edited standard copies matter most:** an operator's customized `dev-loop` must survive upgrade intact. It becomes a system row holding *their* text; T5's seed sees `ledger none + live row present + content ≠ shipped` ⇒ **conflict (skipped, reported)** — it is **never overwritten**; `seed.restore` is the explicit way back.
- A pristine **older** copy (hash in the table) becomes a system row; T5's seed then performs the versioned **update in place** (replicating today's `upgradePristineStandard`).
- Adoption order within the directory is by name for determinism.

## Tests

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestAdoptPristineCurrentStandardIsSystemRow` | content equals embedded; `origin=system`; revision `adopt`; refs filled; ledger row | pristine mis-classified |
| `TestAdoptPristineOlderStandardIsSystemRowAndMarkedForUpdate` | each `pristineUpgrades` hash adopted as system (then T5 updates it) | an old pristine treated as edited |
| `TestAdoptEditedStandardKeepsUserContent` | system row holds the edited bytes exactly; never replaced by embedded | **operator's edits lost** |
| `TestAdoptCustomIsUserRow` | `origin=user` | provenance wrong |
| `TestAdoptInvalidFileRefusedPerFileWithDiagnostics` | no row; one `refused` ledger row with diagnostics; others still imported; `doctor` line | a bad file blocks all / vanishes |
| `TestAdoptIsIdempotentByHash` | second run writes nothing | double adoption |
| `TestAdoptNeverTouchesFiles` | bytes, mtime and inode unchanged for every file (incl. refused ones) | file mutated |
| `TestAdoptIgnoresSymlinksAndSubdirsAndListsThem` | not imported, reported | path abuse / silent skip |
| `TestAdoptNameCollisionSkips` | existing row untouched | overwrite |
| `TestAdoptedBehaviourEqualsFileBehaviour` | T3 goldens produced from adopted rows equal the file-era goldens | adoption changed behaviour |
| `TestAdoptRunsBeforeSeedAndBeforeLoops` | start-order test with a fake seed and a fake loop acceptor | ordering broken |
| `TestAdoptOneTransactionPerFile` | forced failure on file N leaves files <N imported and N untouched | partial file import |

## Definition of done

- [x] Pristine/edited/custom adopted per file; invalid reported per file; files untouched; idempotent by hash.
- [x] An operator's edited standard blueprint survives intact; behaviour identical before/after adoption.
- [x] Runs after migrations, before the seed and before loops; `doctor` reports refusals and drift.

## Do NOT

- Do not modify, rename or delete a file; do not overwrite or merge into an existing row; do not drop an invalid file silently.
- Do not add a daemon method that reads an arbitrary path; do not treat an edited standard copy as pristine.
