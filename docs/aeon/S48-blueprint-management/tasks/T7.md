# T7 · Reads: details, usage, history, revision, diff, lint

**Prefix:** BP · **Rules:** BP7, BP8, BP11, BP12 · P34 · **Depends on:** T3 (lint's policy half needs S47 `toolcatalog`; with a fake `ToolState` the rest is independent).

## Goal

The list becomes a **list with details**, and a person (or the UI) can ask: what uses this blueprint and what does it use, what changed, what is the difference between two revisions or against the shipped version, and what would policy say about its steps today.
All read-only, all daemon-side.

## Files

- `aeon/internal/protocol/blueprint_manage.go` (extend T6's file — **or a new `blueprint_read.go` if T6 has not landed**): handlers and wire types:
  - `blueprint.list {origin?, q?}` → **additive**: still `{names}` (compat) **plus** `{blueprints: BlueprintSummary[]}`, `BlueprintSummary{name, origin, version, revision, contentHash, divergedFromShipped, updatedAt, updatedBy, usedByCount}`; `q` = case-insensitive substring on the name; filters daemon-side. `divergedFromShipped` = system row whose hash ≠ the shipped record's hash (from the seed ledger via the T5/S43-extra seam; `false` for user rows; `unknown` is not a value — if the seed engine is unwired the field is **omitted**, never `false`).
  - `blueprint.show {name}` → keeps `name`, `content`, `path:""`; adds the summary, `report` (`Analyze` on the stored content, `Mode: "standard"`), `references` (from `blueprint_ref`).
  - `blueprint.usage {name}` → `{triggers: [...], schedules: [...], queueItems: [...open only...], loopsStarted: N, agents: [...], actions: [...], skills: [...]}` — referencing triggers/schedules/queue items from `BlueprintReferences` (T1), agents/actions/skills from `blueprint_ref`; **a blueprint nothing uses returns empty arrays, not an error**.
  - `blueprint.history {name, limit?}` → `{revisions: [{rev, version, op, note, actorKind, actorId, occurredAt, contentHash}]}` (no content); unknown name with history ⇒ still answers (deleted blueprints' history stays readable); unknown with none ⇒ `ErrBlueprintUnknown` naming nearest names.
  - `blueprint.revision {name, rev}` → the revision incl. `content`.
  - `blueprint.diff {name, a, b}` → `{diff: string, aLabel, bLabel, equal: bool}`; `a`/`b` ∈ a revision number, `"current"`, or `"shipped"` (system blueprints only; refused with a named sentence for user blueprints) — computed by **`blueprint.Diff`** (T2) on the stored bytes.
  - `blueprint.lint {name?|content?}` → `{advisories: Advisory[], evaluatedAt}` via `blueprint.Lint` with a `ToolState` adapter over **S47's `toolcatalog.Effective`** (policy set read fresh, `At` injected at the adapter); if `toolcatalog` is unwired, `advisories:[]` with `unavailable:"the tools catalog is not wired — policy advisories are unavailable"` (an explicit state, never an empty "all clear").
  `blueprint.fields`/`blueprint.validate` unchanged.
- `aeon/internal/daemon/blueprint_read.go` — adapters (no cache); `aeon/internal/protocol/method.go` — five consts (usage, history, revision, diff, lint) in a labelled block; `RequiresInitialize`, not `Debug`; conditional on the seam; `errors.go` — `ErrBlueprintUnknown` (T6's if landed); contract chain.

## Behaviour notes

1. **Reads write nothing** (spy-pinned), take no actor, cache nothing.
2. **Lint is advisory** — it never changes `Report.OK`, `save`, or `validate`; every advisory carries its evaluation instant and the verdict sentence **verbatim**.
3. **Diff against `shipped`** uses the system record's content (the embedded bytes the seed would apply), so a person can see exactly how their edited `dev-loop` differs from what ships.
4. **MC2 is not relevant** (blueprints are not private between agents; the agent reads in T10 are the same data).
