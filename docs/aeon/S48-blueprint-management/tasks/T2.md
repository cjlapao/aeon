# T2 · `internal/blueprint`: references, text duplicate, diff, lint, and the `Source` seam types

**Prefix:** BP · **Rules:** BP2, BP7 (diff), BP8, BP11, BP12 (duplicate) · **Depends on:** T0. Parallel-safe with T1.

## Goal

The pure logic every later task needs, with **no I/O and no new imports** (`internal/blueprint` stays store-free, policy-free, tools-free): extract references from a blueprint, duplicate a blueprint **textually** preserving comments,
diff two texts, compute lint advisories through a small interface, and define the `Source` seam. Nothing here changes `Analyze`'s verdicts.

## Files (new, in `aeon/internal/blueprint/`; existing files **not edited**)

- `refs.go` — `type Ref struct{ Kind, Target string }` (`agent|converse|skill|action|resolver`); `func References(bp *Blueprint) []Ref`: `Step.Agent` (lanes, ladders), `Blueprint.Converse`, `Step.Skill` (the **callee** part of `callee/skill-id`), `Step.Action`, resolver tags found in `Params` (the same extraction `Analyze` already performs — **reuse its helper where one exists, else mirror its tag rules and test equality** with `Analyze`'s own agent/action lookups); sorted, deduped.
- `duplicate.go` — `func Duplicate(src []byte, newName string) ([]byte, error)`: rewrite **only** the top-level `id:` scalar to `newName` and the top-level `version:` scalar to `1`, **preserving every comment and all other bytes** (a line-oriented edit guarded by a `yaml.Node` parse that proves the two keys are top-level scalars; refuse if they are anchors/aliases/multi-line). Replaces the client-side YAML re-serialization.
- `diff.go` — `func Diff(a, b []byte, aLabel, bLabel string) string`: a unified diff (a small LCS implementation, ~80 lines, **no dependency**), stable output, `""` when equal.
- `lint.go` — `type ToolState interface{ State(agent, tool string) (state, reason string, ok bool) }`, `type Advisory struct{ Lane, Step, Agent, Tool, State, Reason, EvaluatedAt string; Kind string }`, `func Lint(bp *Blueprint, ts ToolState, at time.Time) []Advisory`: for each model step with an agent, each tool implied by its `Emits` (entity name → the catalog tool name via a table in `internal/blueprint` mirroring `internal/records` names — **assert against the catalog in a test in a package that may import both**), query `ts`; states `granted_denied | granted_no_rule | not_granted` ⇒ advisory with the reason **verbatim**; unknown agent ⇒ no advisory (that is `Analyze`'s job); `at` injected, rendered RFC3339 UTC.
- `source.go` — the seam types only: `type Source interface{ Get(name string) ([]byte, bool, error); Names() ([]string, error); Standard() []string }` and `type embeddedSource` (reads the existing `standards` embed FS; names = the embedded files) used by tests and the offline validate path.
- `*_test.go`, `testdata/`.

## Rules (each a test)

1. **References equal `Analyze`'s view:** for every standard and fixture blueprint, the agents/actions/skill callees found by `References` equal those `Analyze` resolves (one extraction, two uses).
2. **Duplicate preserves everything else:** `Duplicate(src, "copy")` differs from `src` in exactly the two lines; comments, ordering, blank lines, CRLF/LF and the trailing newline are byte-preserved; the result passes `Analyze` and `Parse(...).ID == "copy"`, `Version == 1`; anchors/aliases on `id`/`version` are refused.
3. **Diff is a real unified diff:** applying hunks to `a` yields `b` (a round-trip test); identical ⇒ `""`; deterministic.
4. **Lint is advisory only:** `Lint` never returns an error and never alters a `Report`; a table of states ⇒ advisories (allowed ⇒ none; ask ⇒ none; denied/no_rule/not_granted ⇒ one each with the verbatim reason); `EvaluatedAt` equals the injected instant.
5. **No new imports:** the package's import list is unchanged from T0's baseline (`go/parser` test); `embeddedSource` is the only user of the embed FS besides existing `standard.go`.

- **Rule 1 (references equal `Analyze`'s view):** `TestReferencesEqualAnalyzeForAllShippedAndFixtures` runs over all 11 shipped standards + `code-action.yaml` + `verify-run-fixture.yaml`. It compares `References` against an **independent generic-YAML walk** (not `References`' code, so the equality is not a tautology) and against `Analyze` handed exactly the agents `References` surfaced (a missed name fires `unknown-agent`). Deviation: `verify.run` is added to the closed action set for the fixtures (it postdates the `s16ActionSet` mirror; `verify.run` is a real registered action, so the mirror's own drift test does not cover it — added here, `s16ActionSet` untouched).
- **Resolver mirror:** `resolverNames = {"by-tech-tag"}` mirrors `handler.resolvers`; `TestResolverNamesEqualTheRegistry` pins it against `handler.Resolvers()` from the test side (the `s16ActionSet` precedent). The independent walk treats a step whose `agent:` is `by-tech-tag` as a resolver, matching `References` — `References` must NOT count a resolver name as an `agent` ref (T0's `IsResolver` exclusion).
- **Duplicate is text, not (de)serialization:** `Duplicate` byte-splices only the top-level `id:`/`version:` scalars at the positions the `yaml.Node` parse reports, after proving both are unanchored single-line plain-or-quoted scalars (anchors/aliases/block/flow/missing/duplicate-key all refused — `TestDuplicateRefusesAnchoredOrMultilineKeys`). It splices the later position first so edits can't shift each other, then re-`Load`s the result and refuses to return anything that does not load as `ID==newName, Version==1`. Comments, ordering, blank lines, CRLF and the trailing newline survive byte-for-byte (the CRLF case asserts `\r\n` count == `\n` count). `TestDuplicateResultValidates` duplicates every shipped standard and checks it still passes `Analyze` with the real registries.
- **Diff is a real unified diff:** `lcsOps` is a classic LCS table over the middle after common prefix/suffix trim, delete-before-insert on ties (deterministic — `TestDiffIsDeterministic` runs it 20×). A size guard (`len(a)*len(b) > 4M`) falls back to wholesale middle-replacement rather than a quadratic stall — still valid unified-diff. `TestDiffRoundTrips` re-parses the emitted hunks with a test-side applier (independent of `Diff`) that honours `@@ -x,y +u,v @@` headers and `\ No newline at end of file`, and asserts re-application yields `b`. Equal inputs give `""`. A `\0\0no-final-newline` sentinel makes a missing final newline a real one-line change so it round-trips (otherwise an otherwise-equal file differing only in its final newline would diff to `""`).
- **Lint is advisory, dated:** `Lint` never returns an error, never touches a `Report` (`TestLintNeverTouchesReport` asserts the `Analyze` diagnostics are unchanged across three `Lint` calls and no `not_granted` leaks into a diagnostic). Only `granted_denied|granted_no_rule|not_granted` produce advisories; `allowed`/`ask`/unknown/`nil` ToolState are silent. The reason rides **verbatim**; `EvaluatedAt` is the injected instant rendered RFC3339 **UTC** (`at.UTC().Format(RFC3339)`, pinned to `2026-11-02T17:00:00Z` from an EST instant). Entity→tool goes through the **existing** `EmitTool`/`emitTool` table (T2 reuses it, does not add a second — no new table); `attach` is added when an emit has attachments. `TestEmitsToolNamesMatchTheRecordsCatalog` (this package, which may import `records`) checks the entity tools and `attach` are real `records.Catalog()` names.
- **Deviation — `time` is a new import:** rule 5 says the import list is unchanged from baseline, but `Lint(bp, ts, at time.Time)` (mandated by the task's own signature) needs `time`. `time` is stdlib and inert (no policy/tools/store/handler/network). `TestBlueprintPackageImportsUnchanged` pins the exact production set — the three pre-existing internal deps (`store`/`errs`/`paths`, all T0-recorded) are grandfathered in the pin and `time` is the only T2 addition — so the pin is checkable, not remembered. This is the sole way to honour both the `Lint` signature and "no new dependencies"; recorded here per §4a.
- **`Source` seam:** `Get/Names/Standard` interface + `embeddedSource` (reads the `standards` embed FS only, no disk/store/env). `TestEmbeddedSourceNamesMatchEmbedFS` pins `Names()` to the embed directory listing and `Standard()` to `StandardNames()`; bad names are `(nil,false,nil)` — never an FS probe.
