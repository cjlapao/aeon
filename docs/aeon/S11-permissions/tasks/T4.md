# T4 — `Evaluate` — pure, total, first-match

## Why this exists

**It is consulted on every `bash` call, and a policy decision that can fail open is not a guard** (G1).

## Scope

```go
type Policy struct {
    Agent string     // whose policy this is (G13, O1)
    Rules []Rule     // ORDERED. First match wins (G2)
}

type Rule struct {
    Pattern string
    Verdict Verdict  // allow | deny | ask
}

type Decision struct {
    Verdict Verdict
    Rule    string   // the pattern that decided (G11)
    Agent   string   // whose policy (O1)
    Segment string   // which segment, when splitting decided it (G8)
}

// Evaluate is pure and total. No I/O, no clock, no environment.
func Evaluate(p Policy, cmd string) Decision
```

### Ordered, first match wins (G2, D6)

`Rules` is a **slice**, not a map. v1's format is a YAML *mapping* whose correctness depends on key order that the
YAML spec does not guarantee — an array makes ordering part of the format rather than a parser behaviour.

`golang-engineer-loop`'s real block is the shape that proves this matters: `"*": allow` followed by eight denials. Read
in the wrong order, every one of those denials is dead.

### Unmatched denies; empty denies (G3, G4, D7)

**A guard whose default is permit is not a guard.** `"*": allow` is how a policy opts into permissiveness —
explicitly, as a rule someone wrote.

An empty policy denies everything. Unreachable in practice and the only safe answer.

### The verdict carries its rule **and its agent** (G11, O1, D9)

"Denied" is unactionable. "Denied by `git push*`" tells the user what to change — but with the same pattern carrying
**different verdicts in different agents** (`gh pr merge*` is allow, ask **and** deny across the corpus), it is
ambiguous about **whose** `git push*`. The agent is what tells someone where to go and change it.

### The evaluator never asks (G6)

It **returns** `ask`. The caller resolves it — T6. A pure function cannot suspend a step, and putting the resolution
here would make the guard depend on whether a human is available, which is the reproducibility problem G14 exists to
avoid.

### Total (D8)

Every input produces a `Decision`. No error return, no panic path. A fuzz seed of malformed commands and policies —
an empty command, a command of only separators, a pattern of only `*`, a rule with an empty pattern, 10,000 rules —
each yields a `Decision`.

**A `Decision` is not an error type.** A denial is a domain outcome (S4's DB19), and the caller must be able to tell it
from a disk failure.
