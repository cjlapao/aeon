**Prefix:** CT · **Rules:** CT9 · standing rule 2 · P6 · **Depends on:** T4 (rebases on T5 for the twins). Parallel-safe with T5, T7.

## Goal

Agents manage the tree with the same operations a person has (one definition, two doors). The project tools go; the
component tools gain the tree; every `project_id` in a schema becomes `root_id`.
