# T7 · Automation and triggers: `root` replaces `project`

**Prefix:** CT · **Rules:** CT11 · **Depends on:** T4. Parallel-safe with T5, T6.

## Goal

Event triggers and the automation outbox speak roots. A trigger that matched a project before the slice matches the
same events after it (the ids are the same or mapped); a trigger authored after the slice uses the key `root`.
Nothing about who may author a trigger changes (S40 AU1's three locks are untouched).
