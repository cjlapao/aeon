# T4 · The store speaks the tree: operations, effective settings, telemetry

**Prefix:** CT · **Rules:** CT1–CT4, CT6, CT7, CT10 · **Depends on:** T3. **Merges with T2 and T3.**

## Goal

`internal/store` reads and writes the new schema: tree operations with their refusals, one effective-settings
resolver, subtree telemetry, root-attached epics/goals/tasks — and the project API is gone. Every T1 store golden is
either byte-identical or changed exactly as its header said.

## Files

- **Delete:** `store/projects.go` (+ its tests' project-only cases move to tree tests), `UpsertComponent`
  (`loops.go:451-497`, dead) and its test (`loops_test.go:324`), `CountComponentsInProject`.
- `store/components.go` — rewrite:
  - `Component` gains `ParentID string`, `ArchivedAt string`, `Kind string` (`project|component`, derived),
    `ChildCount int`, `Empty bool`; `Root` may be empty; `ProjectID` removed. Inheritable fields become pointers
    (`*string`, `*int`) on the **own** value; `Effective` carries resolved values + sources.
  - `NewComponent{…, ParentID}`; `ComponentEdit{…, Inherit []string}` (no `ProjectID`, no parent change).
  - `CreateComponent` — no implicit project; parent rules (CT2) as `ComponentRefusal` values with sentences (the
    `ProjectRefusal` discriminated-result shape, DB19); child requires a root.
  - `UpdateComponent` — no parent change; `Inherit` clears overrides on a child (refused on a root: "a root's
    settings have nothing to inherit from").
  - New: `PromoteComponent`, `AttachComponent`, `DetachComponent`, `ArchiveComponent`, `RestoreComponent` — each one
    transaction, each moving telemetry (CT7) where the tree changes, each keeping CT3's invariant.
  - `ReadComponent`, `ListComponents(ComponentFilter{ParentID, RootsOnly, IncludeArchived})`, `ComponentForRoot` —
    `LEFT JOIN component_root`; `Kind`/`ChildCount`/`Empty` computed in the query.
  - `ListChildren(rootID)`; `RootOf(id) (string, error)` (the parent or itself).
- `store/effective.go` — **new**: `EffectiveComponent(id)` and `EffectiveForRoot(path)`; the **only** code that reads
  the five inheritable columns. `ComponentQueueSettings`/`SetComponentQueueSettings` (`queue.go:310,326`) and
  `ComponentMaxParallelAgents`/`SetComponentMaxParallelAgents` (`parallel_agents.go`) call it (set on a child writes an
  override; T0 decides whether the two setters survive or fold into `UpdateComponent` — they have no non-test caller).
- `store/telemetry.go` — `resolveTelemetryScope` returns `(componentID, parentID)`; `bumpTelemetryRollups(tx, s,
  componentID, parentID, d, now)` bumps node, parent (if any and ≠ node) and workspace once each;
  `transferRollups(tx, child, fromParent, toParent)` replaces `transferProjectRollups`; `recomputeCostState(tx, id)`
  replaces `recomputeProjectCostState`; `ProjectTelemetry` deleted; `ComponentTelemetry` returns `ChildCount`.
- `store/epics.go`, `store/goals.go` — `ProjectID` ⇒ `ComponentID` (a root); refusals "epics and goals belong to a
  root component — X is a child of Y"; `GoalFilter.RootID`; `insertGoalComponents` checks each member is the root or
  its child.
- `store/tasks_board.go:60` — root filter (CT10); `TaskFilter.Root`.
- `store/automation.go` — `componentProject` ⇒ `componentRoot` (`RootOf`); `AutomationEvent.RootID`.
- `store/triggers.go`, `store/trigger_match.go` — `RootID`; match key `root` (CT11); the old key refused.
- `store/store.go` — comments naming the implicit project (`:223,233`) corrected.
