# T9 · The app: compatibility pass on the new contract

**Prefix:** CT · **Rules:** CT14 · **Depends on:** T5, T7 (final `contract.ts`).

## Goal

The app compiles, lints and passes its tests on the regenerated contract, **with no new design**. Anything that read
a project now reads a root; anything that showed a group now shows a root with children. The real tree UI (folders,
the project marker, promotion) is the next piece of work and is deliberately not here.

## Files (from T0's UI inventory; re-derive)

- `features/projects/ProjectsScreen.tsx` — `project.list` ⇒ `component.list {rootsOnly:true}`; `project.show` ⇒
  `component.show`; `project.create` ⇒ **removed from this screen** (creating a pure project is `promote`; the
  screen keeps its "new component" path if it has one — VERIFY); `implicit` reads removed.
- `features/projects/layers.ts` — `visibleLayers`: the "one implicit group folds" rule becomes "roots are the top
  level; a root with `kind:'project'` shows its children" — same function signature if possible; `ProjectRow.implicit`
  removed.
- `app/PageLayout.tsx`, `features/home/pages/HomeScreen.tsx`, `features/components/ComponentsScreen.tsx`,
  `ComponentsDashboard.tsx` — `projectId` reads ⇒ `parentId`; `ComponentGroup` grouping by `parentId`.
- Bench: `TelemetryPage.tsx` (drop the project tier; the move control ⇒ `component.attach`/`detach`),
  `ParallelAgentsPage.tsx` (`effective.maxParallelAgents.value`; writing a cap on a child writes an override),
  `AutomationPage.tsx` and `lib/protocol.ts` (`projectId` ⇒ `rootId`; `EventTriggerView`).
- Tests under `ui/test/` from T0's list (`projects-screen`, `layers`, `bench-telemetry`, `product`, `parallel-agents`,
  and the `component.list`-only ones) updated to the new shapes.
- i18n: any string that says "group"/"implicit" in the touched screens is changed in **both** `en.json` and `pt.json`.
