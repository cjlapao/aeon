# T8 · The CLI: `aeon component`, removal of `aeon project`, renamed flags

**Prefix:** CT · **Rules:** CT13 · standing rule 1 · P5 (client half) · **Depends on:** T5, T7.

## Goal

The CLI gains the component verb it never had, as a pure client of T5's methods; `aeon project` and
`aeon telemetry project` are removed with a fixed redirect line; flags that took a project take a root.

## Files

- `cmd/aeon/component_verbs.go` — **new**: `list`, `show`, `create`, `update`, `promote`, `attach`, `detach`,
  `archive`, `restore` (flags per CT13). Every verb dials the socket (`dial(*want)`, `addProtocolVersionFlag`) and
  prints what the wire said; `--json` prints the wire result verbatim. Human output for `list` is a two-level tree
  (roots, children indented; `project` marker on roots with children; `empty` and `archived` tags; effective settings
  with `(inherited)` where `source=root`). The CLI re-validates nothing.
- `cmd/aeon/project_verbs.go` — **deleted**; `main.go:83` `case "project"` prints the CT13 line to stderr and exits 2;
  `case "component"` dispatches the new file; usage text updated.
- `cmd/aeon/telemetry.go` — `project` verb ⇒ the same redirect line; `component` verb unchanged (subtree semantics in
  its help text).
- `cmd/aeon/goal.go` (`--project` ⇒ `--root`, `:72,189`), `cmd/aeon/task.go` (`--project` ⇒ `--root`, `:61`): the old
  flag is refused with "`--project` was replaced by `--root` (component tree)".
- `cmd/aeon/component_parity_test.go` — **new**: every `component.*` method has a verb and every verb names its method
  (the P5 parity test, both directions).
