## Why this exists

Six handlers whose judgement is of one kind — implementing against a task spec in a particular stack — grouped so a
reviewer holds one kind of judgement at a time (R6). T4 established the pattern; this applies it at volume.

**File count exceeds R8's twelve by construction**: six bodies plus six drop records is twelve files, plus the
directory. Stated rather than justified away.

## Scope

Six rewrites, following T4's pattern exactly: body, front matter translation (A19, A20), drop record with all five
sections, and **one real run each** (O7).

| Handler | Domain to preserve |
| --- | --- |
| `sql-engineer` | Migration safety, when a change is irreversible, index and query judgement, dialect differences |
| `react-typescript-engineer` | Component boundaries, hook rules, state-versus-props judgement, type-level conventions |
| `vue-typescript-engineer` | Composition API idiom, reactivity pitfalls, SFC conventions |
| `websocket-engineer` | Reconnection, backpressure, message framing, presence — the failure modes that only appear under load |
| `tauri-react-engineer` | The Rust/web boundary, capability declarations, what belongs in the shell versus the webview |
| `tauri-vue-engineer` | The same boundary, Vue side |

### The trap specific to this batch

**Six similar handlers invite a shared preamble that nobody wrote.** The originals each carry their own phrasing; a
rewrite that factors out "common implementer guidance" into identical paragraphs across six files has **invented
content** (A17) and lost whatever each original said differently.

If six bodies genuinely want the same paragraph, that is a finding to raise — not a refactor to perform quietly. The
drop records must show each handler's kept content traced to **its own** original.

### The other trap

`tauri-react-engineer` and `tauri-vue-engineer` are the handlers whose domain is closest to **Aeon's own app** (S9).
Their guidance about the Rust/web boundary is real domain and must not be rewritten into advice about Aeon specifically
— they are general-purpose handlers that a user's Tauri project will also use.
