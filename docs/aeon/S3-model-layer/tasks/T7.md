## Context

One of the two tasks this slice exists for. The outbound half is a mapping table; the inbound half is where the
correctness lives.

**Fragments are keyed by array index, and the id arrives once.** A tool call streams as
`choices[0].delta.tool_calls[]` entries each carrying an `index`. The `id` and `function.name` appear on the
**first** fragment for that index; later fragments carry only `function.arguments` string pieces. Accumulating
by anything else — by id, most plausibly — loses every fragment after the first, and the symptom is a tool call
with empty arguments that the model then retries differently.

**Arguments accumulate as a string and are unmarshalled once, at the end.** Partial JSON is not parseable, so
parsing per fragment is wrong. And a model *does* sometimes emit malformed arguments — a normal event, not an
exceptional one — so it becomes a `tool_result` with `IsError: true` rather than an error that kills the call.

**Absent usage stays absent** (M9). A `Usage` with nothing set is the correct output for a gateway that omits
it; a `Usage` of zeroes is a lie that reaches the UI as `$0.00` at S9.

**The output-cap field name comes from the route**, not a constant. OpenAI deprecated `max_tokens` for
`max_completion_tokens`; hardcoding either breaks half the routes, and S18's compatible gateways mostly accept
only the older name.

**Read first:** `sse.go` (T3); `registry.go` (T5) for `Delta` and `Finalise`; T6's OpenAI fixtures; the plan's
Q3 answer on which cap name the target model accepts.

## What to do

**1. `ToWire`** — `POST {baseURL}/chat/completions`, `Authorization: Bearer`, `Content-Type: application/json`,
and nothing else in the headers.

Map: `system` stays in the array; a `tool`-role message becomes one wire message per `tool_result`; `text`
blocks join; **`thinking` blocks are omitted** on this provider, whose reasoning content is opaque and not
replayable; `tool_use` blocks become `tool_calls` entries with `Input` **marshalled to a string**.

`stream: true` always. The output cap under the route's field name, always present (M16). `temperature` only
when set. `tools` as `{type:"function",function:{name,description,parameters}}` — `Parameters` forwarded as raw
JSON (M22). `Route.ExtraBody` merged **last**.

**Assert the exact key set** in a test. That is what catches a canonical field silently reaching the wire
(D14).

**2. `FromWire`** — walk `choices[0].delta`:

- `content` → a `text` delta
- `tool_calls[]` → accumulate into a map keyed by **`index`**, recording `id` and `name` on first sight and
  appending argument fragments to a buffer. **Yield nothing yet.**
- `finish_reason` → buffers are complete: unmarshal each, yield a complete `tool_use` delta, then `stop`
- an unmarshal failure → yield the `tool_use` with empty `Input` and record that a `tool_result` with
  `IsError: true` is owed. **Do not fail the call.**
- `usage` on any chunk → accumulate, mapping `prompt_tokens`→input, `completion_tokens`→output,
  `prompt_tokens_details.cached_tokens`→cacheRead, `completion_tokens_details.reasoning_tokens`→reasoning.
  **Only set a field when the source is present** — a `?? 0` equivalent here is the bug.
- anything unrecognised → increment `dropped` (M4)

**3. The test that matters**: collect **every** delta and assert each `tool_use` has a non-empty `ID`, a
non-empty `Name` and non-nil `Input`. That is what makes M8 real rather than intended.
