## Context

Small, pure, and load-bearing far out of proportion to its size. It is the **only** place raw usage is seen, so
it is the single point where "we do not know what this cost" either survives or becomes `$0.00`.

The three states are not a nullable number with extra steps:

- **`known`** — every field the route prices was present.
- **`partial`** — some present, some absent. The number is a **floor**, and `Missing` names which fields were
  absent so the UI can say why.
- **`unknown`** — nothing usable, with a reason distinguishing *the provider sent no usage* from *we have no
  price for this route*. Different problems, different fixes, and a user who cannot tell them apart
  investigates the wrong one.

The rule that makes it correct is negative: **absent is never zero.** A `Usage` with no `CacheRead` is not a
request with zero cache reads; it is one whose cache behaviour was unreported.

**Prices are USD per million** (M25). Write the arithmetic once and test it against a worked example with
realistic numbers — an off-by-1e6 here is invisible in review and produces costs that look plausible.

**Read first:** `types.go` (T1) for `Usage`, `Cost` and `Route.Prices`;
`docs/_archive/aeon-v1-horizontal/01-model-layer/tasks/T10.md`, which this ports nearly directly.

## What to do

**1. `func ComputeCost(u Usage, p *Prices) Cost`**, in this order:

- `p == nil`, or no priced field → `unknown`, reason `no-price-for-route`
- `u` has no field set → `unknown`, reason `provider-omitted-usage`
- otherwise, per priced field, check presence:
  - all present → `known` with `USD`
  - some present → `partial` with `USDAtLeast` and a non-empty `Missing`
  - none present → `unknown`, reason `provider-omitted-usage`

`usd = Σ (tokens / 1_000_000) × price`.

**2. Do not round.** Return the full float; presentation rounding is the CLI's and the UI's, and rounding here
makes rollups drift as they accumulate.

**3. `stream-aborted-early` is not produced here** — it is `client.go`'s to set when a stream was cut before any
usage arrived. Say so in a comment, so the reason set does not look incomplete to the next reader.

**4. `Missing` lists priced fields only.** An unpriced field that is absent is not missing information — it is
information nobody asked for.

**5. The negative test is the important one.** Assert that a `Usage` with no fields and a fully priced route
returns `unknown`, and assert **explicitly** that it does not return `known` with `USD == 0`. That assertion is
the regression test for the failure this whole design exists to prevent, and it is one line.
