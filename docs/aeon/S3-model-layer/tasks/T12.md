## Context

Every test in this slice runs against recorded fixtures with no network (D15). That is right — deterministic,
fast, free — and it means **nothing automated has ever spoken to a provider.** Fixtures go stale, a redaction
can mangle a byte, and a capability nobody probed can be wrong.

**This demo must be walked with real keys for both providers.** Its central step runs the same prompt against
Anthropic and OpenAI and expects the same shape of output — which looks redundant and is the slice's whole
claim. Two wire formats disagree about seven things and none of it should be visible; a walk against one
provider proves the adapter and nothing about the format.

**`aeon-model.md` already exists** as a draft from the superseded slice, with `QAM-` ids. **Amend it, do not
rewrite it.** Case ids are stable and append-only — that is the schema rule `qa-engineer-loop` enforces when it
curates the folder on a PASS run, and several of its cases are still exactly right.

**Read first:** `DEMO.md` in full; `docs/test_suites/aeon-model.md` as it stands; T6's manifest for which
fixtures are hand-written — those are the ones a human most needs to verify.
