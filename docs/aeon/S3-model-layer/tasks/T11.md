> ## Notes — done 2026-10-15
>
> ### `costLine` is a function rather than a format string, and that is the point
>
> The three states are the design's centrepiece, and **the way they get lost is a client that formats `usd`
> and hopes.** So: `known` prints the figure; `partial` prints **"at least"** and names the missing fields;
> `unknown` prints **"not reported"** with the reason as a *sentence* rather than a code. A fourth branch
> handles a state this binary does not know — saying so rather than rendering it as one of the three, because
> guessing which would be a lie.
>
> Tested as: no two states render identically, and an `unknown` never contains `$0.00` or a bare dash. Plus
> `formatUSD` at six decimals, because one token of a cheap model is ~$0.000003 and two decimals would print
> a real cost as free.
>
> ### `Ctrl-C` cannot print the cost, and says where it is instead
>
> The task asks for a cost line after an interrupt. **The client has stopped listening by then** — the
> daemon emits `ask.done` (M15) but there is nobody on the socket to receive it. Inventing a figure would be
> worse than pointing at the real one, so the CLI says the daemon is still accounting and names
> `aeon watch --kinds ask.done`. Recorded as finding 5 in the demo.
>
> ### `--show-transcript` cannot show a signature, and says so
>
> A signature is replay metadata and never reaches a client. The transcript prints with an explicit note that
> the thinking block carries none and is **for reading rather than replaying** — rather than emitting a block
> that looks complete and would be rejected on replay. This also makes the demo's step 6 impossible as
> written (finding 7).
>
> ### Tests run against a real daemon **and a replayed provider**
>
> `scripts/fixture-server` replays a committed fixture as a provider, so the daemon, protocol, adapters, SSE
> reader, cost arithmetic and CLI are all real and **no credential is needed**. Added for the tests and it
> turned out to matter more for the demo: a walk requiring a key and a spend is a walk nobody does.
>
> The test fixture **strips** `ANTHROPIC_API_KEY` and `OPENAI_API_KEY` from the environment rather than
> merely not setting them — a developer's real key would otherwise make these tests call a provider, passing
> on their machine and failing in CI.
>
> Incremental arrival is asserted **on arrival**, by recording when each write lands while the replay server
> pauses between frames. A content assertion cannot tell streaming from buffering.

## Context

The first thing a person can run that feels like the product.

**The cost line is the slice's honesty made visible**, and it is the easiest thing here to get wrong in a way
nobody notices. Three states, three renderings:

```
anthropic-sonnet · in 24 · out 31 · $0.000516 (known)
some-route       · in 1204 · out 88 · at least $0.0041 (partial — missing: cacheRead, cacheWrite)
local-unpriced   · in 3 · out 12 · not reported (no price configured for this route)
```

**Never `$0.00` for `unknown`, and never a bare dash.** The reason is what tells a user whether to add prices
or configure a gateway — different problems with different fixes — and a formatter that collapses them undoes
what T4, T7, T8 and T9 all preserved.

**`aeon ask` must subscribe before it calls** (M23). Subscribe, get the id, pass it. A CLI that called first
and subscribed after would drop the opening deltas, and the fix — buffering — is the thing O5 makes a separate
mode precisely so it cannot happen by accident.

**Text must appear incrementally.** If the whole reply arrives after a pause, something buffered — and S5's
tool output, S6's questions and S9's live view all ride this path, so a buffering bug here is one met four more
times.

**Read first:** `internal/protocol/client.go` (S2 T6) for the client; `ask.go` (T10); the three-part error
rendering from S2.

## What to do

**1. `ask.go`** — subscribe to `ask.*` filtered to the `askId` once known, call `ask` with the subscription id,
and print deltas as they arrive. Flags: `--route`, `--max-tokens`, `--temperature`, `--show-transcript`.

**2. Render the cost line** in three forms, exactly as above. `known` prints the figure; `partial` prints
**"at least"** and names the missing fields; `unknown` prints **"not reported"** and the reason.

**3. `Ctrl-C`** cancels the `ctx`, prints what arrived, and **still prints a cost line**. Those tokens were
spent.

**4. `--show-transcript`** prints the canonical `Message` slice as JSON, so a human can see a signed `thinking`
block and feed it to `debug roundtrip`.

**5. `debug roundtrip --file`** — read a transcript, run it through `ToWire` and back, and report whether it is
identical, with the `thinking` signature's length. This is the demo's step 6 and the human-visible form of T8's
fidelity test.

**6. Errors render in three parts** — S2's shape, so a failure says what to do rather than printing a code.

**7. Tests against a real in-process daemon on a temp socket**, not a mock of the protocol. A CLI tested against
a mock of its own protocol tests nothing about the protocol.
