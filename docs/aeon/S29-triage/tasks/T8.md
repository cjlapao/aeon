# T8 — `TriagePage.tsx`

## Why this exists

The surface that proves R4's guard to a person looking at the screen: validation state and priority, as
two fields, never collapsed into one.

## Scope

**1. Add `"triage"` to `BENCH_TABS`**, pointing at `/bench/triage`, matching the existing pattern.

**2. A list view**: title, validation state, priority state + label, filed-by, with `unvalidated` and
`could-not-tell` rendered as visibly distinct states — not merely different-colored dots standing in for
text.

**3. A duplicate-suggestion panel** on a bug's detail view: shows `suggest-duplicates`' candidates, each
with an explicit "confirm as duplicate" action — the UI never auto-applies a suggestion, matching T4's
suggest-only discipline at the surface a person actually interacts with.

**4. A file form** for the human path, and a note that agents file through a separate tool
(`file_bug`) this page does not expose directly — the same "say what it does not do" instinct every bench
page in this plan uses.
