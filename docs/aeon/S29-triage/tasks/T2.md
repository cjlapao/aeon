# T2 — `internal/triage`: the core package

## Why this exists

Every other task calls into this package rather than touching `bug` rows directly.

## Scope

**1. `Bug` and the two status types** (`types.go`): the Go mirror of T1's row shape.

**2. Validation-state transitions** (`transitions.go`): `unvalidated → reproduced`, `unvalidated →
not-reproduced`, `unvalidated → could-not-tell` — and **nothing transitions back to `unvalidated`**, ever
(a re-attempt after `could-not-tell` produces a new attempt record, D3, not a reset of the bug's own state
— confirm this reading in this task's Notes rather than let it be assumed implicitly).

**3. `SetPriority(bug, state, label)`**: independent of validation state entirely — callable at any
validation state, including `unvalidated` (D2: the two fields never gate each other).

**4. `Create`**: always starts at `validation_state: 'unvalidated'`, `priority_state: 'unknown'` — D7's
self-filing default, with no caller-supplied override of either.

## Validation

- [ ] `TestUnvalidatedNeverCollapsesIntoCouldNotTell` — a freshly created bug and a `could-not-tell` one are

- [ ] `TestPriorityAndValidationRenderAsSeparateFields` — D2 as a property: setting one never implicitly
      changes the other, tested across every combination of starting states
