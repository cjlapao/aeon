# T7 — CLI and socket

## Why this exists

The human-facing counterpart to T3's `file_bug` tool, and the surface over T4's suggest-only duplicate
check — combined (CLI + socket) the same way `S26-roadmap`'s and `S28-memory`'s own small surfaces were.

## Scope

**CLI verbs**: `aeon triage file --title … --body …` (the human path alongside `file_bug`'s agent path,
both landing in the same `Create`) · `list [--validation …] [--priority …]` · `show <id>` · `set-priority
<id> --state known|assumed|unknown [--label …]` · `suggest-duplicates <id>` (read-only, T4) ·
`confirm-duplicate <id> --of <other-id>` (the only write path to `duplicate_of`).

**Socket methods**: `triage.file`, `triage.list`, `triage.show`, `triage.setPriority`,
`triage.suggestDuplicates`, `triage.confirmDuplicate` — same calls into `internal/triage` underneath.

**Every rendering shows validation state and priority as two separate fields, side by side** — never one
combined badge (R4's named risk, guarded here directly).
