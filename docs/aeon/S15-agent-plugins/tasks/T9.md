hardest step in the plan to walk honestly.

**§6 — revoke mid-Task.** The refusal path executes **only in a race**: the Task must genuinely be in
flight when the revoke lands. **If the Task completes first, the step passes and proves nothing.** Confirm
the timing, and record how.

**§7 is its deliberate contrast** — a *disabled* agent's Task completing. **If §6 and §7 behave the same,
AP12 is broken** and the demo is the only place that would show it.

**§1 — the consent screen.** Read the rendered text as an operator would. **Does it read as "this agent
has these capabilities"?** If so, that is a finding, even if every test passes — the tests check the words
and the shape, and the failure here is a reading.
