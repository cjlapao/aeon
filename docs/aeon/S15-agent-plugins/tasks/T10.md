## Why this exists

**A slice is done when someone else can follow `DEMO.md` and watch it work** — and since the 2026-10-25
amendments (the bench demo-runner spec, exercised by S14's T12), *watch it work* includes **in the app**.

Three ways this panel can appear to pass while lying, all pre-empted by S14's QAC-25:

**A management button.** R6: import, enable, disable and revoke over any socket a caller can drive hand
over the means to install the thing that bypasses the guards. **The panel has no management verb at all** —
the live half reads `agent.plugins` and nothing else; anything that mutates is CLI, and the greyed rows
carry the operator's command instead of a button.

**A consent UI in disguise.** The consent screen with an approve-flow is S9's. The panel **displays** the
recorded REQUESTS text — exactly what the CLI printed at import — with the word, with "none of these are
granted yet", and with no control that grants anything. A grant is `aeon policy add`, by an operator,
deliberately (MC4).

**A replay dressed as live.** In-flight revocation, the disable contrast and the first-party claim cannot
be conjured from a fake daemon — they are **labeled REPLAY** rows citing the Go tests that actually prove
each envelope, names grep-verified against the suites at the time of writing.
