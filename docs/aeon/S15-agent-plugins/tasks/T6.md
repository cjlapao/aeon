# T6 — `provenance.go`: first-party is ours to set

## Notes — built 2026-10-25

**The field is set where the code lives, and nowhere else.** `FirstParty` true is manufactured only by
`plugin.Agents()` from `handler.RegisteredBodies()` — the compiled 25 — and the import path sets `false`
unconditionally. The claim is read from the manifest **only to be recorded** (`ClaimedFirstParty`) and
reported: `ProvenanceLine` renders "PACKAGE CLAIMED FIRST-PARTY — IGNORED", because an ignored claim
nobody can see is an ignored claim nobody investigates. Both spellings (`first_party`, `firstParty`) are
caught; the behavioural half is asserted too — an enabled claimer is treated exactly like any enabled
import and a disabled one exactly like any disabled import, through the same gate as everyone else.

**AP9 is pinned three ways, not one:** behaviour (the claim moves nothing), grep (the field's name may
appear in NO struct tag that reads package input — manifest, card, policy; it is read only through
untyped map keys where it can be seen and cannot be honoured), and construction (the plugin package
imports `internal/label` nowhere and builds no region — the "no fourth implementation" test).

**S14's Q3 recorded as answered** in `docs/aeon/S14-agent-services/design.md`: first-party results stay
unlabelled, and "first-party" is read from the **registry only** — the boundary moved from compile-time
fact to registry fact without moving into package reach.

**Deviation, reasoned (files_expected said `plugin/provenance_test.go` alone):** the end-to-end

## Why this exists

**One field, and it is the one an imported package must never control.**

```go
FirstParty bool   // SET BY THE REGISTRY. Never read from the package.
```

**Because a package that could claim first-party would skip AS12's untrusted labelling** — and that
labelling is the single thing standing between a stranger's prose and an unlabelled prompt.

It is also the kind of field that gets read without thinking: it is in the metadata, it has the right name,
and unmarshalling it is one line. **So the test is that a claiming package is ignored**, not that we
remembered not to read it.

**This answers S14's Q3**, which asked where "first-party" is read from given that S15 makes it a registry
property rather than a compile-time fact.

**Read first:** S14's AS12 and its `untrusted.go` — **reuse the labelling, do not write a fourth**; S14's
Q3; AP9.

## Scope

**1. `Provenance`**: where it came from, when it was imported, and `FirstParty` — **set by the registry.**

**2. A claiming package is ignored, visibly.** Not silently: `aeon agent list --provenance` shows
*"package claimed first-party — ignored"*, because a package that tried is worth knowing about.

**3. An imported agent's results are labelled** through S14's mechanism (AS12). Assert end to end: import,
invoke, and check the **assembled prompt** carries the label.

**4. The flag is never unmarshalled from package metadata.** Assert by grep — the field must not appear in
any struct tag that reads package input.

**5. Record S14's Q3 as answered** in `docs/aeon/S14-agent-services/design.md`. A real edit to another
slice's design, assigned here because this is where the answer lives.
