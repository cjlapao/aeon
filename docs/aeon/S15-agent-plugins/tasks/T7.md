# T7 — `aeon agent`: the state transitions

## Notes — built 2026-10-25

**The CLI is a second process, and being a second process taught the design two things the library tests
could not:**

1. **Revoke cannot require the package.** T3's `move()` insisted the verb speak only of agents THIS
   process holds the package for — correct for `enable` (an unread prompt must never run) and fatal for
   `revoke`, whose most urgent case is the vendor's directory that is already gone. Split: **stopping
   needs the row alone** (durable-only path, no in-memory copy to move); **starting needs the package**,
   and `plugin.Rehydrate(pkgPath, set, at)` now reads it without writing anything (no record, no
   transition — re-reading a disk is not an event in a life), re-running AP3's check on the re-read so a
   package that grew a request after install is caught before a verb trusts it.
2. **The gates had a restart hole.** They consulted the in-memory map first and allowed anything it did
   not know — after a daemon restart the map is empty and a REVOKED agent would have been invocable.
   Both gates now read the durable record even when the map is silent (a ledger present but a row
   absent stays "not plugin-managed"; a ledger ABSENT refuses rather than guesses — fail closed).

**R6 drawn in the wire, not just the table**: the socket carries exactly `agent.plugins`, and it is
answered by `Table.Plugins` — an **entry-point** seam, not `Table.Agents`. The agent-services package is
swept forbidden from importing `internal/plugin`, so it could not answer the read even if it wanted to;
S14's dispatch-parity pin was AMENDED to say so out loud (enumeration ∖ {agent.plugins} = Handles, and
Handles must NOT contain it) rather than subtracted in silence. Params are refused: a filter would let a
reader probe for agents it was not shown.

**PL15 stayed a one-file rule when S10's own sweep said it should**: `TestNoPolicyAuthoringReachesTheNarrowSurface`
caught `agent.go` calling `boundary.Add` for the carried denials within one full-suite run. The fix was
ROUTING, not exemption — `StoreCarriedPluginDenial` lives in `policy.go` (the file the pin names) and
prints each row's fate, stored or refused, because a silently unstored denial is a hole the consent never
mentioned. The boundary still enforces PL1; a package cannot author its own permissions twice.

**A CLI trap worth recording**: `aeon agent revoke groot --reason "…"` is the shape people type, and Go's
flag package STOPS parsing at the first positional — `--reason` would have been silently lost into argv,
and a silently lost reason is exactly the column AP4 says survives. `cmdAgentRevoke` extracts `--reason`
before positional parsing; the missing-reason refusal names the flag and the future reader ("the operator
who wonders next month why groot-translator stopped").

**AP10 as grep AND behaviour**: no `net/http` in the CLI verb files nor any plugin source; `https://…` and
`git+ssh://…` are refused naming the fetch (before any disk is touched, via T2's check); `update` is not a
verb and its refusal says "no update, no fetch, no marketplace".

`make check-protogen` passes; the regenerated `contract.ts` carries exactly the +17 lines of
`agent.plugins` (verified: their work-in-flight fixtures contributed nothing — the diff is purely mine).
Counts dated 2026-10-25, measured `grep -c '^--- PASS'`: `cmd/aeon` **149** (142 + 7),
`internal/protocol` **211** (registration, want-list, enumeration and fixture all agree), `internal/plugin`
**40**, `internal/agentsvc` **90** (race clean), `internal/store` **258**.

## Why this exists

The surface for everything this slice does — and **the place AP10 and R6 are enforced.**

**Nothing fetches** (AP10). `import` takes a **path**. No marketplace, no auto-update, no dependency
resolution — each is a path by which code arrives without anybody deciding, which is what MC3 refused for
MCP servers for the same reason.

**And no plugin management on the narrow surface.** R6's reasoning exactly: exposing enable, disable or
import over HTTP or MCP would hand a caller the means to install the thing that bypasses the guards. **Read
is fine; managing is CLI and app only.**

**Read first:** `consent.go` (T4), `revoke.go` (T5), `provenance.go` (T6) — this surfaces them and
reimplements none; S10's T10 for the precedent on keeping authoring off the narrow surface.

## Scope

**1. Five subcommands.**

| | |
| --- | --- |
| `import <path>` | runs the check, **prints the consent, and does not enable** |
| `list` | state, provenance and grant count; `--all` includes revoked |
| `enable` | disabled → enabled |
| `disable` | enabled → disabled |
| `revoke --reason` | terminal, and the reason is **required** |

**2. `import` prints consent and stops.** The three-step path (AP2) is visible in the CLI's behaviour, not
just in the library.

**3. A URL is refused**, with the reason. Assert by grep that there is no HTTP client in this package and
no auto-update path.

**4. Every transition is recorded with its reason**, through T3.

**5. Nothing here reaches the narrow surface.** Assert by grep over S19's action table: no import, enable,
disable or revoke.

**6. No credential handling.** Noted because a package path is free-form and somebody will eventually point
it at something with a token inside — **this command neither reads nor prints package contents beyond the
manifest and the card.**
