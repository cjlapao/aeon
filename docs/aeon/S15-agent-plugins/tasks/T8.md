# T8 — The level-0 invariant: the layer is deletable

## Notes — built 2026-10-25

**How "the whole suite passes with no imported agents" is run, reproducibly** — no flag, no build tag, no
skip, in three mechanical parts:

1. **Linkage, asserted:** a test binary can execute what it links; the sweep (`TestNoUnconditionalImportOfPlugin`,
   counting TEST files too) pins the module's importer set to exactly {`cmd/aeon`, `internal/plugin`}. The
   other twenty-four packages' suites therefore run with the layer unlinkable every time `make test-race`
   runs — that command IS the no-imported-agents run, and the sweep is what stops the claim rotting.
2. **Level 0, executed:** this package's own suite runs level-0 — `TestRegistryEmptyIsNormalState` and
   `TestThe25BodiesUnaffected` both start from `Reset()`: zero imports is the DEFAULT state under which the
   assertions run, not a special fixture. An unwired daemon (no ledger, no loader) is inert: gates allow
   what they cannot judge, and `Refusals` says UNAVAILABLE rather than "nothing was refused" (P31).
3. **Deletability, measured:** with the layer's directory deleted, everything but the seam builds — the
   runtime set (`daemon loop store protocol agentsvc runtime`) is vet-green and imports nothing from the
   layer (part 1 is the machine-checked version of that). The red lines are exactly four files:
   `grep -l internal/plugin cmd/aeon/*.go` → `agent.go agent_test.go agent_gate_test.go agent_services.go`
   (+ the one `case "agent"` line in `main.go`). Same shape as S14's entry-point red lines.

**The sweep caught my own T5 within one run** — the honest kind of catch. The real-async-Task gate tests had
been moved INTO `internal/agentsvc` (the S14 sweep allowed the layer to link itself, and I reasoned the
racing tests belonged with the racing machinery). But T8's invariant is DELETABILITY: `rm -r internal/plugin`
must leave `internal/agentsvc` building, and `revoke_gate_test.go` made that false. The tests now live in
`cmd/aeon/agent_gate_test.go` — the one package both sweeps allow to link both halves, and the honest home
for anything where layers meet. `internal/agentsvc` is back to 83 tests linking nothing from this slice.
The T5 Notes carry an erratum. (The S14 lesson — "never leave a helper binary importing the layer inside the
module" — re-earned, one slice later.)

**The 25, checked the way the claim is made:** `handler.RegisteredBodies()` identical before and after an
import arrives; the one body run through `runtime.DefaultHandler(h.SystemPrompt, runtime.DefaultGrantNames())`
(read/list/write, named handler — S13's expectation, at the level a provider-less test can reach: the
PRIMATIVE and its grant set, not a live model call); `Dispatch` refuses to route a compiled body (the
first-party half does not go through the plugin door); and the gate refuses a compiled body nothing — AP1
betrayed would read exactly like that refusal.

**No feature flag, by grep:** no `os.Getenv`/`LookupEnv` and no `//go:build` anywhere in the layer's
non-test source — absent state works through absence, not through a switch that drifts into a default.

Counts dated 2026-10-25, measured `grep -c '^--- PASS'`: `internal/plugin` **45** (+5; race clean),
`cmd/aeon` **155** (149 + the 6 moved real-Task tests; race clean), `internal/agentsvc` **83** (back to its
S14 baseline — it links nothing from S15), `internal/protocol` **211**, `internal/store` **258**.

## Why this exists

**Third time, same discipline** — S22 earned it for retrieval, S12 reused it for tools, S14 for services.

> The whole suite passes with no imported agents (AP11).

**And the specific form that matters here: the 25 first-party bodies must not acquire a dependency on
plugin machinery.** They were written at S13 and they are the product's floor. If importing becomes
load-bearing for them, AP1's *"same object, different source"* has quietly become *"everything is a
plugin"* — and the simplest deployment now needs the most complex path.

**Read first:** S12's and S14's `absent_test.go` for the pattern; AP1, AP11.

## Scope

**1. Run the whole suite with no imported agents.** Not this package's tests — everything else.

**2. The 25 are unaffected.** Pick one, run it, assert the result matches S13's expectation **with the
plugin tables empty.**

**3. No package imports `plugin` unconditionally.** Assert by grep.

**4. No feature flag.** Deletability means *absent state works*, not *a switch exists*.

**5. An empty plugin registry is a normal state**, not an error or a warning — `aeon agent list` with
nothing imported says so plainly, the way `aeon policy list` says the default is deny.
