## Context

Three methods, and one of the tests is the whole reason versioning exists.

**Refusing a client that asks for too much is the obvious half.** It gets written. The other half — **serving
a client that asks for an older version the daemon still supports** — is what keeps an editor extension
working across a daemon upgrade, and nothing else in the slice exercises it. A daemon that only knows how to
refuse has version *checking*, not version *negotiation*.

**`initialize` is mandatory and first** (T7). Anything else on an uninitialised connection returns `-31001`.
And **exactly one place decides** whether a connection has initialised (I3): a second check drifts, the looser
one wins, and T7 quietly becomes a suggestion.

**Unknown fields are ignored, in both directions** (T3, D3). This looks trivial and it is the single property
that makes the next fifteen slices additive. Test it on the way in *and* on the way out — a Go client that
rejects an unknown result field is as broken as a daemon that rejects an unknown param, and only one of those
is obvious.

**A malformed frame keeps the connection open** (O6). Dropping it makes a client's minor bug look like a
daemon crash, which is a support conversation about the wrong component.

**Read first:** `version.go` and `errors.go` (T1); the transport interface T1 recorded; `cmd/aeon/serve.go`
from S1 for the accept path.

## What to do

**1. `method.go`** — the method table: name → handler. Five entries. An unknown method returns JSON-RPC's own
method-not-found, not an Aeon code — it is a protocol-level condition, not an Aeon one.

**2. `handshake.go`** — `initialize`:

- client sends `clientName`, `clientVersion`, `protocolVersion` (the version it **needs**)
- daemon answers `protocolVersion` (the version it will **speak**), `daemonVersion`, `capabilities`
- needs higher than `PROTOCOL_VERSION` → refuse, **naming both numbers** in `data.what`
- needs lower but still supported → answer with **that** version and record it on the connection
- `capabilities` is a list of strings; an unknown name in the client's expectations is ignored (O5)

**3. Connection state** — one place holds "initialised, at version N" (I3). Every other handler consults it
and none re-derives it.

**4. `ping`** returns a result with no fields beyond what the client needs to measure a round trip.
**`version`** returns the daemon version and the **negotiated** protocol version, so the CLI can print
"negotiated" honestly.

**5. Wire it into the accept path** in `internal/daemon/serve.go`, over the transport T1 recorded. This file is
the only one in the slice that knows about transports.

**6. Malformed frames** → JSON-RPC parse error, connection stays open (O6).
