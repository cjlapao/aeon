> ## Notes — done 2026-10-15
>
> ### One deviation, and it is the T6/T11 contradiction
>
> T6 puts `client.go` in `internal/protocol`; T11 and I1 forbid that package from importing anything
> transport-related. **Taken literally both cannot hold** — a client that dials needs `net`.
>
> Resolved by splitting along the seam T11 is actually about: the **sequencing** is the protocol's
> (handshake first, correlate by id, demultiplex notifications) and the **connecting** is the transport's.
> `protocol.NewClient` takes an `io.ReadWriteCloser`; `cmd/aeon/dial.go` — which imports `net` — opens it.
> Two things follow that are worth more than the tidiness: S19 reuses this client unchanged over HTTP and
> stdio, which is the promise T11 was made for; and every client test runs over an in-memory `io.Pipe`, so
> **"the client performs initialize before any other call" is asserted on the wire** against a recording
> fake rather than by reading the code.
>
> ### `dial` reuses S1's resolver rather than adding a third
>
> `localrpc.EndpointPath()` answers only inside the daemon process, so a client needs the derivation —
> and `internal/endpoint.Path()` already is it. Two resolutions of one path would disagree eventually, and
> the symptom would be a client staring at a socket nobody serves.
>
> ### Tests run against a REAL daemon, as a subprocess
>
> `TestMain` builds the binary once; each test starts `aeon serve` on a socket in a fresh temp directory
> (I5 — never the real endpoint). 11 cases against the shipped dispatch and the real transport, including
> `debug subscriptions` showing the registry empty after a watcher is killed. A CLI tested against a mock of
> its own protocol tests nothing about the protocol.
>
> **A practical note for anyone writing one of these:** keep the temp directory name short. A unix socket
> path is capped near 108 bytes, and `t.TempDir()` under a long test name overflows it — which surfaces as
> `invalid argument` from bind and reads as a permissions problem.
>
> ### Three defects the walk found, all now fixed
>
> `peerPid=1.130661e+06` (a `float64` through `%v`, making the one field meant for a `kill` command
> unusable), `filter=map[]` (Go's map syntax on the wire's JSON), and "1 connections". Small, and the kind
> of small that makes output look unmaintained.
>
> ### A finding wider than this task
>
> The framework's **Windows named-pipe transport is `ErrPlatformNotImplemented`** — deferred upstream
> because CI builds Linux only. So `serve` cannot run on Windows at all, and the six-target build produces
> Windows binaries that run `version` and `--vectors` and nothing else. `dial` says so by name rather than
> handing `net.Dial` a network it does not know. Recorded in `aeon/docs/BUILD.md` and as QAP2-12.

## Context

The first clients, and the first things a person can actually run.

**`aeon watch` is the demo's centrepiece** and the only way to see subscriptions work without a UI. It prints
its subscription on connect — id, kinds, starting seq — because a client that silently waits is
indistinguishable from one that subscribed to nothing, which is exactly the failure O1 guards against.

**`--protocol-version` exists so refusal can be demonstrated.** It is a debugging flag, not a feature: it lets
the demo prove the daemon refuses a client asking for too much, which is otherwise unobservable until the
first real version bump.

**`debug subscriptions` exists so D6 can be shown**, not just tested. A registry that empties is a claim; a
command that prints it empty is a demonstration.

**The client library is `internal/protocol/client.go`** and it must go through the same types and honour the
same handshake rule as any third party would. A CLI that shortcuts `initialize` because it knows the daemon
would prove nothing about the protocol.

**Read first:** `types.go` and the fixtures (T1, T5); `cmd/aeon/main.go` from S1 for the verb dispatch;
`docs/_archive/aeon-v1-horizontal/13-cli/tasks/T2.md` for the three-part error rendering.

## What to do

**1. `internal/protocol/client.go`** — dial, `initialize`, call, subscribe, close. It performs the handshake
**first**, always, and exposes the negotiated version so `version` can print it honestly.

**2. `ping`** — round trip, printing the elapsed time. `pong · 0.8ms`.

**3. `version`** — the client version, the **negotiated** protocol version marked as such, and the daemon
version. Marking it negotiated matters: a bare number reads as a constant.

**4. `watch`** — subscribe and stream. Flags: `--kinds` (repeatable or comma-separated), `--project`,
`--after`. On connect, print the subscription line. Then one line per event: `seq`, `kind`, and a compact
payload.

**5. `debug subscriptions`** — list the registry: connection, subscription id, filter, current seq.

**6. Render errors in three parts** — every failure goes through the shape T1 defined, so a user sees what
happened, what it means and what to do rather than a code.

**7. Tests against a real in-process daemon on a temp socket** (I5), not a mock. A CLI tested against a mock
of its own protocol tests nothing about the protocol.
