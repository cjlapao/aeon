## Why this exists

S8's `aeon loop show` prints the ladder's **shape**; this renders it. And it must answer the question S8 identified
as the first anyone asks of a ladder: **why did this not run?**

## Scope

### The shape, not a list

Lanes in order; an iterating lane's items nested beneath it; each step's state, artifact and cost.

```
  clarify      ok           prompt.md            $0.0104
  discovery    not-needed   when: mode != simple
  plan         ok           plan.md, tasks/      $0.1832
  plan-gate    waiting      approve-plan
  build        running      iterate: tasks (3)
    task-1     ok           3 steps              $0.4210
    task-2     running      verify
    task-3     pending
  qa           pending      when: flags.integration_surface
                                          total  at least $0.6146
```

A flat list of steps loses the nesting, and the nesting is what makes an iterating lane comprehensible.

### Three states that are not the same (D13, S8's O8)

| State | Means | Must not read as |
| --- | --- | --- |
| `pending` | still to come | — |
| `not-needed` | its `when` was false — **shown with the condition** | `pending` |
| `skipped` | a mode-driven skip | `not-needed` |

**A bypassed lane rendered as `pending` reads as "still to come" for something that will never happen.** That is the
specific failure, and printing the condition beside it is the answer to "why did this not run" — which is why the
condition is part of the requirement and not a tooltip.

### `blocked`, with its reason (S8's O4)

S8 made `BlockedReason` structured — `kind`, `detail`, `action`, `slice` — precisely so this screen could render
kinds distinctly. **Use the structure; do not parse the prose.**

An unimplemented code action must read as *"not built yet — arrives at S16"*, not as a failure. Those are different
situations and only one of them is a problem with the loop.

### Cost (T4, D2)

Per step, per item, per lane, and a total. **A total over a `partial` step is itself a floor.** A confident total
over an uncertain part is the same error one level up, and a total is what someone quotes.

### The pinned blueprint

A way to see it — the stored text, byte-identical (S8's L6). Someone asking "why is this loop not doing what the file
says" needs to see what it actually pinned, and that question will be asked.

### Live (U3, D12)

`loop.advanced`, `loop.skipped`, `loop.waiting`, `loop.blocked`, `loop.finished` each move the ladder. No refetch, no
interval.

### Layout (O8)

**No horizontal scroll at 1024px.** This is the widest content in the app and a ladder that overflows is one nobody
reads.
