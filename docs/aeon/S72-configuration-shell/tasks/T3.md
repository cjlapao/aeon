### Deviations and decisions

1. **Internal components renamed** for the new file names: `ListPanel→AgentList`, `ViewPanel→AgentViewPanel`, `CreatePanel→AgentCreatePanel`, `ImportPanel→AgentImportPanel`, `ExportPanel→AgentExportPanel`, `DuplicatePanel→AgentDuplicatePanel`, `EditPanel→AgentEditForm`, `DeletePanel→AgentDeletePanel`, `MigratePanel→AgentMigratePanel`. All were module-private (no importer outside the file), every `data-testid` is unchanged, and no test referenced the old names. The page's own export name, `AgentManagementPage`, survives in the bench wrapper.
2. **`agents.ts` uses `createElement`, not JSX**, because the requested filename is `.ts` and this folder's page modules are `.ts` (`pages/_fixture.ts` does the same). Semantics are exactly `<Suspense fallback=…><LazyAgentManagement controller live canWrite /></Suspense>`.
3. **`AgentManagementProps` is `{controller?, live?, canWrite?}` and the component does not read them.** The bench page used none of its context today (the bench ctx is `{connected}`), so "used exactly as the bench page does today" means: accepted, unused, zero new calls. Documented at the declaration. The props are **required-in-signature, all-optional-in-type** because a fully optional parameter makes `React.lazy`'s `createElement` overload fail to infer props (measured: TS2769).
4. **`frame` left at the default `"titled"`.** The page renders its `h2` inside its own header row rather than a titled panel, so the frame's `h1` + breadcrumb and that `h2` are a hierarchy, not a doubled heading — but this is R1's judgement and **T4 should confirm it in the browser walk** and flip `frame: "bare"` if it reads as a double header.
5. **Header comment split with the code it describes**, and two phrases made true now that there are two doors: "the bench page for the agent-management daemon methods" → "this feature, for …", and "The page is a CRUD bench" → "The page is a CRUD surface". Every user-visible string is byte-identical.
6. **The three `test-bench/lib` imports stay** (`useFact`, `FactHandle`, `FactCell`) per CF9, noted in `AgentList.tsx`'s own comment.
7. `plan.md`'s step "Add the line to `registerAll.ts`" was overridden by the task's coordination rule — see the one line above.
