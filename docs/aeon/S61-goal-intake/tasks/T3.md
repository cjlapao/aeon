# T3 · Templates and `internal/scaffold`: renderer, path guards, the `templates.scaffold` seed set

**Prefix:** GI · **Rules:** GI9, GI14, GI15 · P2, P8 · **Depends on:** T1, S43-extra T3 merged. Parallel-safe with T2.

## Goal

Everything that turns a template into files safely: the closed renderer, the new-path-only writer with its guards, and
the seeded starter templates. No git and no network here (T4 adds them).

## Files

- `aeon/internal/scaffold/render.go` — `Render(t Template, v Vars) ([]File, error)`; `Vars{Name, Slug, Description,
  Stack []string, DefaultBranch}` is the **only** variable set; `text/template` with `missingkey=error`, a function map of
  exactly `lower, upper, join`; limits 200 files / 512 KiB total / 128 KiB per file; every `File{Path, Mode, Content}`
  path validated (relative, `Clean`ed, no `..`, no `.git` segment, no NUL, ≤ 255 bytes, no duplicates, case-fold
  duplicates refused); mode ∈ {0644, 0755}.
- `aeon/internal/scaffold/plan.go` — `Plan(targetDir, files) (Preview, error)`: path-escape checks **without touching the
  disk** beyond `Lstat/EvalSymlinks` of the parent; `Preview{Files[{path,mode,size,sha256}], Create: [dirs]}` — the exact
  thing `intake.plan` shows and the digest covers.
- `aeon/internal/scaffold/write.go` — `Write(targetDir, files, ledger) error`: creates dirs 0755, files with `O_CREATE|
  O_EXCL|O_WRONLY`, re-`Lstat`s each path (refuses a symlink), records **what it created** in `ledger` so cleanup removes
  only that; `Cleanup(ledger)` removes created files then created (now empty) directories, never a pre-existing one.
- `aeon/internal/scaffold/guard.go` — `CheckTarget(target string, known TargetFacts)` per GI9: absolute, no `..`, parent
  exists/is a dir (`EvalSymlinks`), target absent or an empty directory, not equal to / containing / inside any registered
  component root (`TargetFacts.ComponentRoots` from a seam), not `$HOME`, not the state dir, under `intake.workspaceRoot`
  when the setting is set (seam). Each refusal a sentence.
- `aeon/internal/daemon/templates_seed.go` + `aeon/internal/seed/decl_templates.go` — P8: `Source()` returns the three
  templates (`minimal`, `go-service`, `node-ts`) verbatim from embedded files under
  `aeon/internal/scaffold/templates/<slug>/…`; per-record `Version`; an `Applier` writing through `store.SaveTemplate`
  (actor `{system, seed}`); class **inert**; `origin='system'`; operator rights `{Edit, Remove=false}` (no delete exists).
- Template bodies: README with `{{.Name}}`/`{{.Description}}`, an `AGENTS.md` skeleton (project conventions section with
  **empty headings to fill**, no invented rules), `.gitignore`, a generic CI workflow file with **no secrets and no
  external actions beyond a pinned checkout** (T0 decides the checkout pin from the repo's own workflows; if none exists
  the CI file is omitted from the template rather than invented).

## Definition of done

- [x] Closed renderer, new-path-only writer, guards with the escape matrix; three seeded templates, version-guarded and
      content-scanned; preview == written.

## Do NOT

- Do not allow a template to run code, read the environment or include a host path. Do not write into an existing
  non-empty directory. Do not add a dependency. Do not delete a directory this run did not create.

Decisions and deviations:

1. **Seed package shape (spec's `templates_seed.go` + `internal/seed/decl_templates.go`
   is the cycle the spec could not see):** one package
   `internal/scaffold/seed` (package `scaffoldseed`), init-declared, daemon
   function-mounts the store-backed applier in `NewSeedEngine` (mounted ABOVE
   the corpus rebuild block, the watchdog reason). The retroseed ruling
   (verbatim precedent, S63 T3) applies exactly: an `internal/seed` decl file
   would import this package, which imports `internal/seed`.
2. **Migration 98 — the actor CHECK T1 got wrong for GI14:** GI14 says the
   applier writes with actor `{system, seed}`; T1's
   `scaffold_template_revision` CHECK admitted only the records-tier trio, so
   the seed's honest author was unsavable. Fixed by an ADDITIVE migration
   (shipped entries are immutable): a copy-guard rebuild widening the CHECK
   to `('user','agent','trigger','system')`, rows untouched, the append-only
   pair recreated byte-identically. `validTemplateActor` (store) is the
   four-kind rule for template saves ONLY — charter revisions and the rest of
   the records tier keep the strict trio; the reasoning lives in the Go
   comment and the migration header. Counts paid in the same commit:
   53 files/98 applied (`backup_run_test`), `bkDatabaseLine` 97→98, the
   `backup_cli_test` wire literal (dated comment), `dbinfo.golden` schema
   line, `fingerprint.golden` one CHECK line.
3. **Fingerprint honesty, caught by the doctor-up golden:** a freshly laid
   `minimal` row reported `1 diverged` — the store round-trips `"[]"` to an
   empty slice while the record marshals absent tags as null, and the rebuild
   hashed the two spellings apart. `Applier.Fingerprint` normalizes
   empty→nil (the report must not lie about bytes that never moved); the
   normalization is pinned by a live-fingerprint==record-hash assertion inside
   `TestFreshStoreSeedsEverythingWithSystemOrigin`, so the next unfaithful
   rebuild is a test failure, not a doctor surprise.
4. **CI pin rides the repo's own workflows (T0's fact):** `actions/checkout@v7`
   (tag, not SHA — the house convention here), and only that external action;
   the scan test asserts exactly two `uses:` lines across the shipped CI
   files. The documented placeholder set is NONE: the scan bans every URL, so
   the CI files reference the action by name and no URL ships anywhere.
   `actions/checkout` IS the whole external surface; the go/node steps are
   plain `run:` lines against tools ubuntu-latest ships.
5. **Content scan shipped clean:** no `/Users/`, `/home/`, `C:\`, `ghp_`,
   `sk-`, `AKIA`, 40+ base64 runs, `secrets.`, no URLs (the URL-ish regex
   fires on nothing — zero URLs is stricter than any placeholder budget).
6. **`go:embed all:templates`** — plain `//go:embed templates` silently skips
   dotfiles, which is every `.gitignore` and the whole `.github/` tree; the
   `all:` prefix is what makes the shipped set actually ship them.
7. **Preview truth across umask:** `Write` chmods each file to its previewed
   mode after `O_EXCL` create (OpenFile's mode rides the umask; the preview
   promised an exact mode).
8. **Guard order and absent targets:** identity refusals (HOME itself, state
   ground, component same/inside/ancestor) run BEFORE the empty-dir sentence,
   so `$HOME` gets the sentence that names the law; `Plan` resolves the
   PARENT (the target itself may lawfully not exist yet — it is the thing
   being created) and re-checks every component for symlinks at both plan and
   write; `resolveGround` compares REAL paths for absent targets too.
9. **Test names vs the spec table:** the behaviors are the spec's with clearer
   names — `TestVarsAndFunctionsAreClosed`+`TestUnknownVariableIsRefused`
   (closed variables), `TestSizeCaps`/`TestModesAreTheClosedPair`/
   `TestDuplicateAndCollidingPathsRefused` (limits),
   `TestWriteRefusesWhatAppearedAfterThePlan` (never-overwrites + the planted
   symlink swap, with an after-the-fact check that nothing escaped),
   `TestLedgerCleanupTakesBackOnlyItsOwn`,
   `TestDeletedTemplateRowIsRefusedByTheSchema` (the never-resurrected law in
   its stronger form: GI14 gave the table NO delete door at all — T1's
   trigger — so an out-of-band vanishing has no SQL road; the test proves the
   trigger fires and an ordinary apply never re-lays applied rows),
   inert-only = class/operator/Retire test + the boot-apply witness in the
   doctor-up golden. `{{.Name | exec}}` replaced an `html` probe mid-task:
   `html`/`js`/`urlquery` are text/template built-ins — the closure claim is
   about OUR map (lower, upper, join) and data-only built-ins grant no power.
