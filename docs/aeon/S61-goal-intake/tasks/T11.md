# T11 · The wizard descriptor and the UI spec (no UI code)

**Prefix:** GI · **Rules:** GI17, standing rule 4 · P7 (spec half) · **Depends on:** T7. Parallel-safe with T8–T10.

## Goal

Everything the app needs to build the new-project wizard **without typing a vocabulary, a sentence or an authority
statement**, proved from the daemon side, plus the written spec. No React is added; the existing UI is untouched.

## Files

- `aeon/internal/protocol/intake.go` — `intake.vocabulary` result finalised (T7 stubbed it): `{publish: [{value, label key,
  statement?}], remoteCreateEnabled bool, remoteCreateReason?, templates: [{slug, title, stackTags, version, origin}],
  caps{components, epics, goals, items, charterBytes}, workspaceRoot?, routeAvailable bool}`; `statement` is the
  **daemon's own confirmation text** (what will be created, where, whether it is public) — the UI renders it verbatim.
- `aeon/internal/protocol/intake.go` — `intake.preview` is `intake.plan`'s read with the same digest (no new method; the UI
  spec names `intake.plan`).
- `aeon/ui/src/proto/contract.ts` — regenerated by `make protogen` only (never by hand).
- `docs/aeon/S61-goal-intake/ui-spec.md` — the spec (already written at planning time); this task **re-reads it against the
  real method results** and edits it where a field name differs, recording each edit in Notes.
- `aeon/ui/test/intakeRpc.guard.test.ts` — **new, test-only, no component**: the P7 guard scaffolding the future screen
  inherits — extracts every method literal under `ui/src/features/**/intake*` (none yet ⇒ the test asserts it finds **0**
  today and has a documented switch to "≥ 1 per tab" that the wizard task flips), with a canary that flags a bogus method
  literal. The "found 0" case is an explicit, named "no wizard yet" assertion (it fails the moment a wizard file appears
  without the switch being flipped), so it is never vacuous; the canary half always runs.

## Definition of done

- [x] Descriptor complete with daemon-authored statements; spec matches the contract; guard scaffolding in place; no UI
      component or dependency added.

## Do NOT

- Do not build the wizard. Do not add a dependency. Do not hardcode a template name, publish value or sentence anywhere in
  `ui/src`. Do not edit `contract.ts` by hand.
