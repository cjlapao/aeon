# T10 · The CLI: `aeon charter`, `aeon template`, `aeon intake`

**Prefix:** GI · **Rules:** standing rule 1 · P5 (client half) · **Depends on:** T7. Parallel-safe with T8, T9, T11.

## Goal

Every daemon method of this slice has a CLI verb, as a pure client; the CLI re-validates nothing. (No direct-store
door: none of these verbs works offline — there is no loop, no conversation and no filesystem effect without a daemon,
and `intake.commit` must not run in a second process; recorded deviation from P5's offline fallback.)

## Verbs

- `aeon charter list [--json]`, `show ROOT [--revision N] [--json]`, `history ROOT [--limit N]`, `save ROOT --file PATH
  [--note T]` (reads the body JSON from a **file path**; `-` for stdin is refused — a body is not a secret but the rule
  "no stdin payloads for authority writes" keeps parity with S45), `vocabulary`.
- `aeon template list [--stack TAG] [--origin system|user] [--json]`, `show SLUG [--files]`, `save --file PATH [--note T]`.
- `aeon intake start --name N`, `list`, `status ID [--json]`, `plan ID --proposal P [--target PATH] [--json]`,
  `commit ID --proposal P --digest D --target PATH [--publish none|private|public] [--owner O] [--confirm-public]`,
  `abandon ID`, `vocabulary`.
- `commit` flow: calls `intake.plan` first and **prints the daemon's statement and file list**; `--digest` must be supplied
  (the verb refuses to run without it — it forces a `plan` first; `--yes` is a seatbelt only where S45 uses it, here:
  required for `--publish private|public`). A refusal prints the daemon's sentence verbatim; `--json` prints the wire result
  verbatim. `--publish` values and all closed sets come from `intake.vocabulary` for `--help` (generated, never typed
  twice).
- No flag accepts a secret value; no flag takes a token, key or password (`TestNoSecretFlags` greps the new verbs).

## Files

`aeon/cmd/aeon/charter.go`, `template.go`, `intake.go` (each a dial-and-print client, `addProtocolVersionFlag`), `main.go`
(usage text and three `case`s only), `aeon/cmd/aeon/intake_parity_test.go`.

## Commands

P10, `./cmd/aeon/ -run 'Charter|Template|Intake|Parity|NoSecret' -count=1 -v`; build and run `"$ROOT/.tmp/aeon" charter list`
against a dev daemon.

## Definition of done

- [ ] Verbs for every method; parity both ways; digest and yes enforced; no secret flag; help generated.

## Do NOT

- Do not open the store from these verbs. Do not accept a secret, token or stdin payload for writes. Do not re-validate.
