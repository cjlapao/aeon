# T8 · Agent tools: reads and propose-only twins

**Prefix:** GI · **Rules:** GI17 · standing rule 2 · P6 · **Depends on:** T7. Parallel-safe with T9, T10, T11.

## Goal

Agents can see charters, templates and intake status, and can **propose** a charter or an intake plan — nothing more.
Seven catalog specs, each with a socket twin, a parity test both ways, registered **not granted**.

## The seven specs (`internal/records/catalog.go`, additive, data only, **no import added**)

| Tool | Twin | Class | Mutates |
| --- | --- | --- | --- |
| `charter_list` | `charter.list` | safe | no |
| `charter_show` | `charter.get` | safe | no |
| `template_list` | `template.list` | safe | no |
| `template_show` | `template.get` | safe | no |
| `intake_status` | `intake.status` | safe | no |
| `charter_propose` | `charter.propose` (new twin) | detectable | **yes** |
| `intake_propose` | `intake.propose` (new twin) | detectable | **yes** |

Schemas are `additionalProperties:false`. `charter_propose` input `{root_id, body, note?, reason}` (body = GI2 schema);
`intake_propose` input = GI7's payload **minus** `intakeId` (the daemon stamps it from the calling loop's identity —
the loop's intake row) and **with no path/option/identity/status/kind field**. Descriptions ≥ 40 chars; each says the
proposal is inert until a person commits it and that charter/plan text is data.

## Behaviour

1. `charter.propose`/`intake.propose` are **records-service** actions (not the human authoring service): they run the same
   `desk.Validate` as `proposal.create` and the same `ProposalStore.CreateProposal`; `source`/`created_by` stamped by the
   service from the agent identity.
2. Inert: after a propose, `charter.get` and every table of T1 are byte-identical.
3. An agent whose loop is not an intake loop calling `intake_propose` ⇒ refusal "this tool works only inside an intake
   session" (identity check — the loop's slug resolves to an `intake` row).
4. Per-agent open-proposal limit (S45's constant) and payload ≤ 128 KiB.
5. No spec twinned to `charter.save`, `template.save`, `intake.start`, `intake.commit`, `proposal.commit/reject` (T7's guard
   is re-run with the specs present).
6. `DefaultGrant()` unchanged; the seven are registered, not granted. `TestRegistryExactNames` (both want lists) +7,
   counted and dated from T0's real count; `testdata/rerun_classes.json` updated.
