# T9 · The `intake-architect` agent, the `goal-intake` blueprint, `intake.start` and the scratch workspace

**Prefix:** GI · **Rules:** GI6, GI15, GI18, GI20 · P8 · **Depends on:** T7, S43-extra merged, S48 merged.
(Adopting-slice work: S43-extra's and S48's own sets are not edited — this slice declares its own, GI15.)

## Goal

The conversation that produces a plan: a seeded agent and blueprint, `intake.start` creating the intake row and scratch
workspace and starting the loop, with the daemon as the only thing that links loop → intake.

- `aeon/internal/handler/bodies/intake-architect.md` — **new** body. Frontmatter `tools: [read, glob, grep, question,
  todo, write, charter_show, template_list, template_show, component_list, goal_list, intake_status, charter_propose,
  intake_propose]`; `policy-agent: intake-architect`; handoff fields mirror `brainstormer`'s. Body text (shipped

  desk's reject path. (GI6's derived `abandoned` state.)

## Behaviour (each a test)

1. `intake.start` on a daemon with no route ⇒ refusal naming `aeon routes set` (GI16).
2. The loop runs in the scratch directory (P-A proved in T0); the agent can `write` there, cannot reach the target path
   (it does not exist and is not offered); the intake agent's bash is absent from its tools.
3. A seeded `goal-intake` blueprint **validates clean** (`blueprint.validate`), has no `code-action` step, and no step names
   a person-door action (`unknown-action` would fire).
4. `agents.intake` and `blueprints.intake` apply at daemon start (inert), are idempotent, diverged rows are never
   overwritten, removal never resurrected, and startup never reaches a guard set.
5. The tool allow-list is exactly the listed one (no `bash`, no `goal_create`, no `component_create`): an agent-body test.

**`intake.abandon` — the fifth human door.** New surface row (`SurfaceWrite`, human-door-only), the

person's own actor and rejects every open `intake_plan` proposal through the desk's reject path with
the person's stamp and reason. `charter_save` proposals deliberately **outlive** the session — a
charter draft is a candidate document, not the session's property; the comment in the code says so
(the spec's "open proposals" is read as the plan's open proposals; named deviation). An intake whose
loop already ended (waiting, blocked or terminal) closes honestly: `loop.Stop` refuses a loop that is
not running, and an interview spends most of its life `waiting` on an unanswered question — only a
live, running loop refuses an abandon, and then `loop.stop`'s own words name what stands in the way.
