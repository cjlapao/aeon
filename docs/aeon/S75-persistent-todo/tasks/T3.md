# T3 · The read, the person's close, the CLI

**Rules:** TD6, TD8. **Depends on:** T1, T2.

## Steps

1. `internal/protocol/loop_todos.go`: `loop.todos {loop}` (read) and `loop.todos.close {loop}` (write, human door only). Follow an existing read+write pair under `loop.` for the registration, the surface table entries (`SurfaceRead` / `SurfaceWrite` with `HumanDoorOnly: true` on the close), the actor rule (an agent actor is refused with the typed refusal the other human-only doors use), and the seam in `Table` (a small interface the daemon implements over the store; the protocol package imports no store).
2. Answers per TD6: an unknown loop is the typed not-found; a loop with no list is `{active:false, items:[]}` plus a `statement`.
3. Amend by name the guards that count methods (`TestTheMethodTableHasExactlyTheExpectedMethods`, the surface completeness test, any `loop.`-namespace fence) and add conformance fixtures for both methods; regenerate the TS contract with `go run ./tools/protogen`.
4. CLI: `aeon loop todos <loop> [--json]` and `aeon loop todos close <loop>`; add the verbs to the CLI table and keep the CLI-parity guards green. Daemon first, CLI second.
5. Tests: read active, read closed, read none, close by person, close refused for an agent actor, close of an already closed list.

## Definition of done

- Both methods answer on a running daemon (note the exact output in Notes) and the CLI prints the list.
- Protocol, cmd and surface suites pass for the touched tests.

## Do not

- Do not let an agent call `loop.todos.close` (it has no door; the actor check is the proof).
