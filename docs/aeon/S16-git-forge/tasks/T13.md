## Why this exists

**A slice is done when someone else can follow `DEMO.md` and watch it work** — and since the 2026-10-25
amendments (the bench demo-runner spec, exercised by S14's T12 and S15's T10), *watch it work* includes
**in the app**. The Test bench → Demos tab gains a sixth feature panel: **Git · forge (S16)**.

Three ways this panel can appear to pass while lying — the S14/S15 pattern, sharpened by what makes S16
different (these actions are **visible to other people**, and one class cannot be undone by another
action):

**An approve button in disguise.** The ask prompt is the whole §3: `forge.merge` stops and asks because a
human must decide. A panel button that answers `question.answer` **from the demo tab** turns the demo into
a click-through that approves the irreversible thing. **The panel reads asks and never answers them** —
answering is S9's answer path, from someone who means it; the panel renders the prompt verbatim with its
effect class and the operator's commands around it.

**A fabricated PR.** No fake daemon opened a pull request. A row that reads "PR #15 opened" without a
labeled replay and a citation is invented outward-effect — the first slice where that fabricates *other
people seeing something*. Every success-shaped row is **labeled REPLAY**, citing the Go test that proves
its envelope; the fake-daemon call log is the whitelist assertion.

**A governance gap at the surface.** §3's whole point is that both routes reach a human. The panel must
render `aeon action check forge.merge` and the `gh pr merge` policy verdict **side by side, verbatim** —
re-cased or paraphrased refusals are the second truth.

**Read first:** `tasks/T12.md` (the walked DEMO, findings and the owed GitHub record); `DEMO.md` §9; the
S15 panel (`DemosPage.tsx`'s plugins panel) and `ui/test/bench-plugins-s15.test.tsx` for the fake-daemon
discipline — including the known trap that a refusal must be **thrown as the JSON-string wire form** (a
plain `Error` loses `code` through `toRpcError`); `docs/test_suites/aeon-loop.md` QAC cases as the contract
template.
