# T1 · `bug_change`, the `filed_by` → slug migration, actor+audit threading

**Prefix:** TM · **Rules:** TM2, TM3 · **Shapes:** P2, P3 · **Depends on:** T0 and **S43** (slugs).

## Files

- Migration `<ts>_bug_change.sql`: `CREATE TABLE bug_change (id INTEGER PRIMARY KEY AUTOINCREMENT, bug_id INTEGER NOT NULL, op TEXT NOT NULL CHECK (op IN ('file','update','priority','duplicate','validate','handoff','transition')), summary TEXT NOT NULL CHECK (length(summary) BETWEEN 1 AND 1024), actor_kind TEXT NOT NULL CHECK (actor_kind IN ('user','cli','agent','system')), actor_id TEXT NOT NULL CHECK (length(actor_id) BETWEEN 1 AND 256), occurred_at TEXT NOT NULL, CHECK (actor_kind <> 'agent' OR op = 'file'));` + index + append-only triggers (fallback per T0). The CHECK is the database net for "an agent may only file".
- `store/bug_change.go` (SQL only: `BugChangeInsertTx`, `BugChangeList`); existing write functions (T0 item 1) take an `actor` and a tx-variant writing the audit row **in the same transaction**; reactor transitions use `{system, reactor}`.
- **The `filed_by` migration** (own file `<ts>_bug_filed_by_slug.sql`, or a Go migration step if resolution needs the agent table — T0 decides): `UPDATE bug SET filed_by = (SELECT slug FROM agent WHERE agent.name = bug.filed_by) WHERE filed_by <> 'person' AND filed_by IN (SELECT name FROM agent)`; **any remaining non-`'person'`, non-slug value refuses the whole migration** (checked first, in one statement, naming every value) — never a partial rewrite; a value already equal to a slug is skipped (idempotent). New filings store `'person'` or the stamped slug.
- Handlers: existing writes take the session actor (`table.ActorFor`; unresolvable ⇒ named refusal); `triage.file` derives `filed_by` from the actor and **rejects a `filedBy`/`actor` param** (the one intentional wire change if T0 found such a param — listed with the fixture diff).

## Tests

Migration fresh/upgrade (dynamic `len-1`), append-only, CHECK incl. `actor_kind='agent'` ⇒ `op='file'` only; `TestEveryTriageWriteWritesExactlyOneAuditRow` (all six ops, reactor as `system:reactor`, none for refusal/no-op/read); audit+write one transaction; summaries fixed templates (hostile titles absent); `TestFiledByMigrationResolvesNamesToSlugs`, `…RefusesTheWholeMigrationNamingUnresolved`, `…IsIdempotent`, `…LeavesPersonUntouched`; `TestFileDerivesFiledByFromTheActorAndRejectsAParam`; D1/D2/D5/D6 tests and S29 fixtures/goldens unchanged.

## Do NOT

Change a state, edge or priority rule; allow an agent actor on any op but `file`; backfill a guessed slug; put user text in a summary; edit `schema.go`.
