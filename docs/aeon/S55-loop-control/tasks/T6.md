## Schema

```sql
CREATE TABLE budget (
  id             TEXT PRIMARY KEY,
  scope          TEXT NOT NULL CHECK (scope IN ('workspace','component','epic','loop')),
  subject_id     TEXT NOT NULL,
  window         TEXT NOT NULL CHECK (window IN ('lifetime','day')),
  usd_cap        REAL    CHECK (usd_cap IS NULL OR usd_cap >= 0),
  tokens_cap     INTEGER CHECK (tokens_cap IS NULL OR tokens_cap >= 0),
  wall_ms_cap    INTEGER CHECK (wall_ms_cap IS NULL OR wall_ms_cap >= 0),
  steps_cap      INTEGER CHECK (steps_cap IS NULL OR steps_cap >= 0),
  unknown_policy TEXT NOT NULL DEFAULT 'proceed' CHECK (unknown_policy IN ('proceed','stop')),
  warn_pct       INTEGER CHECK (warn_pct IS NULL OR warn_pct BETWEEN 1 AND 99),
  enabled        INTEGER NOT NULL DEFAULT 1 CHECK (enabled IN (0,1)),
  origin         TEXT NOT NULL DEFAULT 'user' CHECK (origin IN ('user','migrated')),
  created_at     TEXT NOT NULL,
  updated_at     TEXT NOT NULL,
  CHECK (usd_cap IS NOT NULL OR tokens_cap IS NOT NULL OR wall_ms_cap IS NOT NULL OR steps_cap IS NOT NULL),
  CHECK (scope <> 'workspace' OR subject_id = 'workspace'),
  UNIQUE (scope, subject_id, window)
);
CREATE TABLE budget_event (
  id INTEGER PRIMARY KEY AUTOINCREMENT, budget_id TEXT NOT NULL, at TEXT NOT NULL,
  kind TEXT NOT NULL CHECK (kind IN ('created','changed','removed','raised','hit','warned')),
  actor_kind TEXT NOT NULL CHECK (actor_kind IN ('user','cli','system')), actor_id TEXT NOT NULL DEFAULT '',
  loop_id TEXT NOT NULL DEFAULT '', dimension TEXT NOT NULL DEFAULT '',
  old_value REAL, new_value REAL, spend_floor REAL, exact INTEGER
);   -- append-only triggers as T2; no FK (history outlives the budget); no user text columns
```

Epic backfill (same migration): `INSERT INTO budget (id,scope,subject_id,window,usd_cap,origin,…) SELECT 'bud-'||id,'epic',id,'lifetime',budget_usd,'migrated',… FROM epic WHERE budget_usd IS NOT NULL` plus one `created` event row per backfilled budget (`actor_kind='system'`, `actor_id='migration'`). A copy guard (`CHECK (moved = total)`) proves the row counts match. The `epic.budget_usd` column is **not** touched.

## Store functions

- `CreateBudget/UpdateBudget/RemoveBudget(actor, …)`; **a `removed` row is deletion of the budget row only** (the audit stays); returns `BudgetRefusal{Kind, Detail}` for: no dimension set, negative, a subject that does not exist (component id / epic id / loop id checked against its table — **no FK**, a store check), duplicate (scope, subject, window), `workspace` with another subject.
- `ApplicableBudgets(loopID) ([]Budget, error)` — loop-scope + epic (via loop→goal→epic) + component **and its root** (S44-extra `RootOf`) + workspace; disabled rows excluded.
- `SpendFor(b Budget, now time.Time) (Spend, error)` — dimension by dimension per LC9's source table: lifetime USD for component/workspace from `component_telemetry`/`workspace_telemetry` rows (a root's row is the subtree total, S44-extra CT7), everything else from aggregates (`step`/`step_turn`) using the `EventTriggerSpend`/`costQuery` pattern. `Spend{USDAtLeast, USDPartial, USDUnknown int, Exact bool, Tokens *int64, TokensUnknown int, WallMs int64, Steps int}` — **an unknown is a count, never a zero** (P31).
- `SpendSeries(groupBy, since, until, rootID)` for `spend.report` (T8): `day|trigger|component|epic|route` buckets.
- Budget audit: every changing write appends one `budget_event`; reads and no-op updates append nothing.
