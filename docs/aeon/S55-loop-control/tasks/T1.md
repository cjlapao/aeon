**Prefix:** LC · **Shape:** P2 (Phase A only) · **Rules:** LC1, LC6, LC13, LC19, LC24 · **Depends on:** T0.

## Goal

Pin today's behaviour **on the untouched code** so later tasks prove what they changed and what they did not: the loop status vocabulary and its pin tests, the stopped-step parking path, the exhaustion/escalation path, `blocked` reasons, cost reads, the `loop.show` view, shutdown behaviour of an in-flight step, and the epic budget.

## Files to create

- `aeon/internal/loop/lc_golden_test.go` — engine goldens over an in-memory store with fake `Deps`:
  - `TestVocabularyIsExactlySixStatuses` — drives a loop through every path (start, gate, stop-park, block, done, abort, converse-idle) and asserts the set of `status` values ever written is `{running, waiting, blocked, done, aborted, idle}` (the pin T3/T7/T9 must keep).
  - `TestStoppedStepParksLoopWaiting` — the S31 path (`advance_stopped_test.go:39` is the model; copy its harness, do not edit it): reason `stopped`, `QuestionID 0`, event payload bytes.
  - `TestExhaustionAttendedAsksContinueAbort` / `TestExhaustionUnattendedCollapsesToBlock` — the S17 path with the exact sentences (`escalate.go:62-64,105-137`).
  - `TestAbortGateEndsAbortedWithRunCancelled` — gate `abort` → `OnAbort` lane → `aborted`; run row state `cancelled`.
  - `TestStepBlockedByMaxIterationsBlocksLoopStepBlocked` — `exceeded MaxIterations` → loop `blocked`, `BlockedReason.Kind "step-blocked"` (so LC9's new in-step path is a *different* typed cause).
- `aeon/internal/daemon/lc_golden_test.go` — daemon/wire goldens: `loop.show` view bytes (before the `control` block exists), `loop.answer` routing for a gate and for an action ask, `step.stop`/`step.continue` results, `notifyHintFor` for the three kinds, and the **shutdown behaviour characterization**: start a loop with a fake long-running model step, call the daemon's shutdown path the way `serve.go` does (the test helper, not the real signal), and record what the step row looks like afterwards (expected today: left `running`; runner ctx never cancelled). This golden is what T4 deliberately changes.
- `aeon/internal/store/lc_golden_test.go` — `LoopCost`/`RunCost`/`EventTriggerSpend` over a fixture with known/partial/unknown steps (the P31 numbers), `component_telemetry`/`workspace_telemetry` rows after recording turns, `epic` round-trip including `BudgetUSD` (`epics_test.go:5` pattern), and `step.pause_reason` round-trip for `user`.
- `aeon/internal/records/lc_golden_test.go` — `epic_create/update` with `budget_usd` result bytes (T8 changes the *source* of the value, not the view).
- `aeon/cmd/aeon/lc_golden_test.go` — CLI goldens for `aeon loop show`, `aeon telemetry component|workspace`, `aeon answer` over a test daemon.
