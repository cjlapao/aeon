# T10 · Agent tools: reads and `loop_request_stop`

**Prefix:** LC · **Shape:** P6 · **Rules:** LC5, LC15 · standing rule 2 · S38 OL2/OL3/OL10 · **Depends on:** T5, T8, T9. Parallel-safe with T11.

## Goal

Agents can **see** loop control state, budgets, spend and watchdog rules (list-with-details), and can **ask a person** to stop a loop — and can do nothing else. Specs live in the S38 records catalog (one definition, two doors), registered, **not granted**.

## The specs (`internal/records/catalog.go`, data only, families `loopcontrol`, `budget`, `watchdog`)

| Tool | Socket twin | Class | Mutates | Notes |
| --- | --- | --- | --- | --- |
| `loop_control_state` | `loop.control` | safe | no | eligibility, open requests, cap-hit, last events — own-view: an agent sees **its own loop** unless the person door is used (MC2 privacy rule; T0 names how `Identify` scopes it) |
| `budget_list` | `budget.list` | safe | no | rows + effective status + spend vs cap |
| `budget_show` | `budget.show` | safe | no | incl. worst-case overshoot note |
| `budget_effective` | `budget.effective` | safe | no | what would apply to the agent's own loop |
| `budget_spend` | `spend.report` | safe | no | spend over time/trigger/component/epic/route |
| `watchdog_list` | `watchdog.list` | safe | no | rules with last-fired |
| `loop_request_stop` | `loop.requestStop` | detectable | **yes** | creates an inert `loop_control_request` |

**Deliberately absent:** any tool twinned to `loop.stop|resume|cancel|raise|control.dismiss`, `budget.set|remove`, `watchdog.set|setEnabled|remove` (a positive "no decision tool exists" test lists them, T5/T8/T9 guards re-run). An agent cannot set, raise or disable a cap (OD10), nor halt another loop.

## `loop_request_stop` (the one write)

Schema `additionalProperties:false`: `{loop_id, reason}` — `reason` required, 1–512 bytes; **no** identity, status, kind or actor fields. The records service stamps `by_agent` (slug), `by_step_id` and refuses a `loop_id` other than the caller's **own** loop unless the agent's grant explicitly names others (default: own loop only — a third-party agent cannot flag the whole workspace). Creates the row through `store.AddControlRequest` (T2), emits `loop.stop.requested` (notify hint: warning), **never touches loop state** (the inertness test). Limits: 5 open per loop, 20 per agent (named constants in `internal/store`, counted refusals naming the limit and the way to see the open ones).
