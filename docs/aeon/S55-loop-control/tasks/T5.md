# T5 · Socket doors and the P4 guard amendment for loop control

**Prefix:** LC · **Shape:** P4 · **Rules:** LC2–LC5, LC16, LC20 · P34 · **Depends on:** T3.

## Goal

Stop, resume, cancel and the stop-request desk are socket methods — daemon first — on the person's 0600 + peer-credential surface, and are provably absent from every non-human door. The contract chain (conformance, handshake, protogen) is regenerated.

## Methods (all `RequiresInitialize`, none `Debug`, absent when their service is nil — V13)

| Method | Params | Result |
| --- | --- | --- |
| `loop.stop` | `{id, reason?}` | `LoopStopResult{loopId, stopped, status, parkedSteps[], note}` |
| `loop.resume` | `{id, message?}` | `LoopResumeResult{loopId, resumed, status, how:"step"\|"runner", refusal?}` |
| `loop.cancel` | `{id, reason}` (1–512 bytes) | `LoopCancelResult{loopId, status:"aborted", runState:"cancelled", skippedAbortLane:bool}` |
| `loop.control` | `{id}` (read) | `{eligibility{stop,resume,cancel,raise}, openRequests[], capHit?, events[last N]}` |
| `loop.requestStop` | `{loopId, reason}` (agent twin only — registered through the records catalog in T10; the socket twin lives here) | `{requestId, status:"open"}` |
| `loop.control.requests` | `{loopId?, status?}` (read) | `{requests[]}` |
| `loop.control.dismiss` | `{requestId}` | `{requestId, status}` |

`loop.raise` arrives in T8. Refusals ride `ErrLoopControlRefused` (T0's block) with the three-part data (what / why / do); `ControlRefusal.Kind` is machine-readable in `data.kind`.
