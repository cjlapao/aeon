## Notes

- **The walk was two daemons and no provider, on purpose** (throwaway
  `XDG_STATE_HOME`, §6 made executable): with no routes the engine blocked
  every materialized loop at its first step, which drove the queue's real
  terminal-event machinery — the honest failure walk, not a scripted one.
  The lane is named in the record as §4b demands. Components came through the
  app's own door (`component.create` over the socket; there is no CLI verb),
  and `queue.advance` was walked as raw JSON-RPC frames after `initialize` —
  the CLI has no advance verb by its own spec (T6 lists six), so the socket
