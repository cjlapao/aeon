# T5 — sizing

## Why this exists

`sizingMode: skill` (brief D7) needs a real dispatch target. This task builds it the way `design.md` CG5
insists: a sizing run is an ordinary step, assigned a handler through the registry exactly like any other
body, with one extra tool.

**Read first:** `internal/tools/todo.go` for the shape of a small native tool (`Tool{Class, Spec}`,
`model.ToolSpec`), and one existing `internal/handler/bodies/*.md` file for the handler frontmatter shape
(`name`, `description`, `temperature`, `tools`, `policy-agent`, `handoff`). `report_size` follows the first;
the new `sizing-estimator.md` body follows the second.

## Scope

**1. `report_size` tool** (`internal/tools/report_size.go`): one call, one shape — `{sizeMin, sizeMax,
sizeBasis}` (D8: a range with its basis, never a bare number). Called more than once in a run is refused —
D9 says "reports through one native tool, called once," and this task enforces that as a tool-level
refusal, not a convention the handler's prompt merely asks for.

**2. `sizing-estimator.md` handler body**: minimal toolset — `read`, `glob`, `grep` (to actually look at
the work before estimating), `todo`, and `report_size`. **No `write`, `edit`, `bash` or `webfetch`** — a
sizing run estimates, it does not touch the repository. `handoff` declares `size_min`, `size_max`,
`size_basis` so `StepHandler.HandoffSchema` carries the declaration to the model (D12's handoff discipline,
already built).

**3. Register the body** in `registeredBodies` (`internal/handler/registry.go`) — a one-line addition, the
documented two-file-ish shape this project already uses for widening a registry (B11's spirit, applied to
handlers rather than framework services).

**4. Wire the result**: when the sizing step's handoff reports successfully, call `internal/queue`'s
`Transition(item, StatusReady)` with the reported `size_min`/`size_max`/`size_basis` written onto the row.
On a failed or abandoned sizing run, `Transition(item, StatusPending)` — CG5's documented edge — so the item
is eligible to be sized again rather than stuck in `sizing` forever.
