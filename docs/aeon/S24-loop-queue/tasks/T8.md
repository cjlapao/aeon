# T8 — `QueuePage.tsx`

## Why this exists

§4b's cumulative-demo rule needs a running surface to walk against; this is it, built the way `PolicyPage.tsx`
and `AskPage.tsx` already establish the pattern — the generic `rpc()` bridge, no new Tauri command.

## Scope

**1. Add `"queue"` to `BENCH_TABS`** in `ui/src/app/routes.ts`, pointing at `/bench/queue`, same shape as
the existing eleven entries.

**2. `QueuePage.tsx`**: an ordered list (position, status, goal, blueprint), an append form (blueprint
picker, goal text, optional `tech`/`with` entries, attended toggle defaulting to the project's declared
default — never defaulting to "whoever is watching this page"), settings toggles for `queueAdvance`/
`sizingMode`, and a remove action per pending/ready row.

**3. Render every one of the seven statuses distinctly** — `pending`/`sizing`/`ready`/`running`/`done`/
`blocked`/`cancelled` each get their own visual treatment, not three colors doing double duty for seven
states. Size renders as `min–max (basis)` when present, and an explicit "not sized yet" state when absent —
never a blank cell, which would read as zero.

**4. Say what it does not do** (§4b's standing rule): the page notes that `queueAdvance: ask`'s gate
question appears in the existing question/thread surface, not inline on this page — this bench tab shows
queue state, it does not re-implement the app's question-answering UI.

## Validation

- [ ] vitest: all seven statuses render with distinct, asserted (not merely visually different) markup
- [ ] vitest: an unsized `ready`-eligible item (manual mode) and a sized one both render correctly — the
      size field's three states (`known` range / `unknown` — none reported yet / not applicable in manual
      mode before `set-size`) are not collapsed into two
- [ ] no `localStorage`, no echoed credential — not applicable to this page's data, confirmed by the
      existing standing test rather than assumed
- [ ] the append form calls `queue.append` through the generic `rpc()` bridge; no new Rust command appears
      in `src-tauri`
