# T5 — the CLI verbs

## Scope

`aeon skills list|get|validate|install|remove|help` — a thin client
(P34) of the five socket methods. Printers split from the verbs so the
answers are testable with canned structs; the client must open no store
and run no git.

## Acceptance

* Malformed asks refuse before any dial (no source, no name, two names).
* Refusals print in three parts with the daemon's sentence verbatim
  (the shared `*protocol.Error` path does this; the verbs add nothing).
* The client file opens no store, spawns nothing (`TestSkillsClientOpensNoStore`
  parses its own imports and text).

## Notes (2026-10-31, built)

`cmd/aeon/skills.go` + `cmd/aeon/skills_test.go`; dispatch + help line
in `main.go` beside `settings`. Two deviations from the first draft,
both caught by the LIVE walk (T7), recorded because a canned-struct
suite would never have caught them:

* **Trailing flags were silently lost.** `skills install <src> --force`
  parsed as source + TWO positionals: `flag.Parse` stops at the first
  positional, so `--force` rode along as a name and the verb refused
  "needs one source". `skillsSeparate` now pre-splits argv — positionals
  and flag-arguments — honouring `--`, `=`-form, and the three
  space-separated value flags (`ref`, `subpath`, `path`) so a bool never
  swallows the next token. Pinned by `TestSkillsSeparateKeepsTrailingFlags`
  (including `--ref` without a value, and a folder literally named
  `--weird-folder-name` after `--`).
* **`get --path` was missing from the CLI** although the wire had
  `path` since T3 — and the path is the ONLY address a shadowed copy
  has (the bench page uses it; the CLI had no way). Added: a name OR
  `--path`, never both (refused before dialing,
  `TestSkillsGetRefusesNameAndPathTogether`).

Also learned from the walk: the miss answers through `ErrInvalidScope`
naming the target in `what` — the family's `means` sentence is about
scopes generally, which reads beside the skills-specific `what` like
boilerplate. Left as-is deliberately: it is the shared scope-family
answer and the `what` is the one that names the thing.

Validation (2026-10-31): `go test ./cmd/aeon/ -run Skills -count=1` —
ok, 13 tests (printers ×5, malformed-refuse, separator, path-or-name,
V13 guard ×2, store-blindness, + the fake-catalog guards).
