## Findings

* **The box's ssh is broken for git even over https**: every clone —
  CLI-direct or daemon-side — dies with `Bad owner or permissions on
  /etc/ssh/ssh_config.d/20-systemd-ssh-proxy.conf` (a root-owned
  symlinked system config ssh refuses). Pre-existing on this machine,
  unrelated to S65; the walk worked around it with
  `GIT_SSH_COMMAND='ssh -F /dev/null'` in the DAEMON environment. An
  operator hitting it gets a -31821 naming exactly that sentence —
  verified as the walk's step-13 shape.
* **`Revealed` can never fire under the shipped root order** (user
  first ⇒ the user copy always wins ⇒ removing a managed copy never
  uncovers anything). It stays because the engine's contract holds for
  any root order and its test proves the answer when it can fire; under
  the production order it is honestly always `false`.
* The worktree needed the `ui/node_modules` symlink (T6 Notes) — worth
  knowing before the next UI slice lands in a worktree.
