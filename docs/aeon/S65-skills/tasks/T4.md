# T4 — the wiring

## Scope

`daemon.Options.Skills *skills.Service`; `New` copies it into
`Table.Skills` (only when non-nil — a typed nil assigned into the
interface would register five doors that all refuse) and calls
`RegisterSkills()`. `cmd/aeon/serve.go` builds the one service, treats a
construction failure as "the catalog is absent" (V13), and runs the
startup scan whose counts are logged — never fatal: skills are what the
daemon can SEE, not what it needs to run.

## Acceptance

* No seam ⇒ no methods (V13), asserted at the table level.
* The five never appear on the narrow surface — not in `Actions()`, not
  as a literal in `internal/narrow` or `internal/agentsvc`, not in the
  agent projection's method list — guarded with a meta-test proving the
  guard can fail.
* A disk that will not answer at boot does not stop the daemon.
