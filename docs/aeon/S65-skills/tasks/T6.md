# T6 — the app

## Scope

`ui/src/lib/skills.ts` (wire types + `listSkills/getSkill/validateSkills/
installSkill/removeSkill` + the `useSkills` hook) and
`features/test-bench/pages/SkillsPage.tsx` (registry-registered, order
4500, `needsConnection: true`), pinned by `test/bench-skills.test.tsx`.
No new Tauri command; no browser storage; contract via `make protogen`.

## Acceptance

* Registration proves itself end to end (registry lookup, not a hand
  array).
* Three statuses, three renderings; issues beneath; both roots named
  with their paths; a shadowed row says what shadows it.
* The user row provably has no remove affordance; the managed row does,
  and remove sends exactly `{name}`.
* Expanding loads the body through `skills.get`; a cut body says it was
  cut AND that the disk holds the whole file.
* The install form sends the typed locator verbatim (no client-side
  "fixing"), and a refusal's sentence renders in full — the page does
  not pretty it.
