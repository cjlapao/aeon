# T2 — the installer and the remover

## Scope

`Install(ctx, InstallRequest)` and `Remove(name)` on the one Service:
source resolution (folder-vs-GitHub), the locator grammar, candidate
selection, staging placement, force/trash semantics, managed-only
removal. `ErrRefused` carries the installer's sentence. `Clone` is an
injected seam (`CloneBudget` 60 s); the default is
`git clone --depth 1 --quiet [--branch ref]` — git CLI, already a
project dependency, under a named budget.

## Acceptance

* GitHub grammar pinned by table: `owner/repo`, `owner/repo@ref`,
  `owner/repo/sub`, full URLs with `/tree/ref/sub`, ssh form, trailing
  `.git`, double-ref markers refuse, empty `/tree/` marker refuses.
* Candidate selection refuses AMBIGUITY and lists the candidates rather
  than guessing.
* Nothing half-installs: frontmatter validated against the FINAL folder
  name before placement; symlinks and non-regular files refused in the
  tree; caps enforced during the staged walk; placement is a `rename`
  from `.staging-*` inside the managed root.
* Overwrite refuses without `force`; forced replace trashes the old
  folder (`.trash-<name>-<ns>`), never deletes it.
* `Remove` is managed-only; a name that lives only in the user root
  refuses with the sentence naming the user root; removing a shadowing
  copy reports `Revealed`.
* A skill's scripts are NEVER executed — proven, not asserted in prose.

## Notes (2026-10-31, built)

`aeon/internal/skills/install.go` + `install_test.go`. Decisions made
while building, each with a test:

* **Pre-placement validation names the destination folder, not the
  checkout.** The first version judged the source folder's name, so a
  checkout `my-pdf-thing` holding `name: pdf` was refused for a mismatch
  that would not exist where it lands. Now `finalName = fm.Name` is
  validated before staging and re-checked at the destination.
* **The ssh form's `@` is not a ref marker.** Tracking `sshForm`,
  `hadTree`, `hadAt` separately keeps `git@github.com:o/r.git` accepted
  while `o/r@` and `…/tree/` still refuse; the double marker
  (`/tree/x@y`) refuses as "names a ref twice".
* **Trailing `/tree` (no ref, slash eaten on paste) is refused** as the
  same empty marker — caught by the grammar table after the Trim order
  initially hid it.
* `--ref` beside a locator that already names a ref refuses rather than
  silently dropping one side.
* The never-executed proof is a real test: an installed `scripts/*.sh`
  keeps its exec bit and the test asserts no process ever ran it; and
  `TestRealGitCloneAgainstLocalOrigin` stands up a bare origin, commits,
  pushes `main`, and clones it through the DEFAULT clone (skips only
  when `git` is absent from the box).
