# T1 — the catalog: discovery, parse, validation

## Scope

`internal/skills`: `Root`, `Discover`, `ParseFrontmatter`,
`ValidateSkill`, `StatusFor`, the manifest walk, `Service` (one cached
scan, `Scan/Get/GetUnder/Invalidate`), and the two env-overridable roots
in `internal/paths` (`SkillsDirEnv`, `UserSkillsDirEnv`). No DB
(SK2 — disk is truth).

## Acceptance

* Every folder under a root lists; broken ones list as `invalid` with
  issues (SK3). Dot/underscore entries skipped; folder symlinks
  followed; a missing root is an empty answer naming itself.
* The spec's requiredness is enforced (name shape + folder equality,
  description ≤1024, compatibility ≤500); unknown keys are kept and
  ignored, never fatal; the whole real corpus at `~/.agents/skills`
  parses with the verdicts the walk records.
* Only top-level folders enumerate; nested `SKILL.md` is counted as a
  parent resource.
* Shadowing: first root wins, loser listed with `ShadowedBy`.
* Caps bound every walk (entries/files/bytes per root/skill), and
  exceeding a cap is a spoken issue, never a silent truncation.
