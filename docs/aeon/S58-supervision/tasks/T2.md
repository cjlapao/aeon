# T2 · The attention core: sources, items, severity, doors, `inbox.list` / `inbox.summary`

**Prefix:** SV · **Rules:** SV1, SV2, SV13 · P34 · **Depends on:** T1 (and S44-extra's `rootId` — T0 records the state; if unmerged, code against the store's component read behind one seam).

## Goal

The daemon can answer "what needs a person" from live state, with the reason, the age, the severity and the exact door, and says which sources it consulted. Nothing is cached or stored.

## Files

- `aeon/internal/attention/` — **new package** (standard library + `internal/store` read accessors + `internal/protocol` types; no SQL):
  - `source.go` — `Source`, `Query{RootID, Severity, Kinds, IncludeAcked, Limit}`, `Item`, `SourceStatus`; a `Registry` with `Register(Source)` (duplicate name panics at init) and `Evaluate(ctx, q)` that runs **every** source, collects items, and records per-source status (`reporting|failed`); an unregistered *known* name (the list `budget, stuck, gates, scheduler`, a closed slice in code naming the sibling slices' sources) reports `not-wired`.
  - `severity.go` — the closed severity vocabulary and order (SV2) and `Less(a, b Item)` (severity, then older `since` first, then key).
  - `doors.go` — the door-template table (kind → `{Method, Sentence(items)}`), **data with a golden**; a `Generic(kind)` fallback used when the named method's slice is not wired.
  - `questions.go` — `QuestionsSource`: unanswered rows (the `AwaitingSQL` shape, but returning ids, kind, options, asked_at); one item per question; `reason` = "waiting for your answer" (fixed) and `prompt` carried in the **local-only** field; door = `answer` with the closed options from the row.
  - `blocked.go` — `BlockedSource`: loops `status='blocked'`; `reason` = `LastReason` verbatim; `kind` = `blocked.<reasonKind>` classified per T0's decision (SV-D12), falling back to `blocked.other` — never a guess; door per SV2.
  - `stopped.go` — `StoppedSource`: loops `waiting` with `LastReason="stopped"` and no `QuestionID`; door `step.continue {stepId}`.
  - `scope.go` — `RootScope(ctx, rootID)`: a root's tree = itself + children (store read from S44-extra); a child id scopes to the child; an unknown id is a typed refusal.
- `aeon/internal/store/attention_read.go` — **new** (SQL half): `PendingQuestionsForScope`, `BlockedLoopsForScope`, `StoppedLoopsForScope` — each returns ids/slugs/statuses/timestamps and the stored reason text; `LatestAcks` is T1's.
- `aeon/internal/protocol/inbox.go` — **new**: `InboxListParams{rootId?, severity?, kinds?, includeAcked?, limit?}`, `InboxListResult{items, sources, evaluatedAt}`, `AttentionItem`, `InboxSummaryParams/Result`, `InboxStore` interface; handlers; `MethodInboxList`, `MethodInboxSummary` constants + `t.register` (RequiresInitialize; not Debug; absent when the service is nil — V13).
- `aeon/internal/daemon/inbox.go` — **new**: wires the registry with the three sources + the store; the **sibling seams** (`RegisterAttentionSource(attention.Source)` exported for S55/S57/S27 to call from their own files).
- `aeon/internal/protocol/errors.go` — `ErrInboxScope` (unknown root/loop) in T0's block; one conformance fixture per refusal family.
- Contract chain: conformance fixtures (`inbox/list.json`, `inbox/summary.json`, one with a `not-wired` source), handshake want-list lines, `make protogen`.

## Behaviour

1. `inbox.list` returns items sorted by `Less`, limited (default 100, max 500), with `sources[]`. An item whose key is acked/snoozed (T3) is excluded unless `includeAcked`; `acked` is attached when included.
2. A **failed source** (a store error) yields `sources[i].state="failed"` and the other sources' items still return; the call does not error.
3. `ageSeconds` is computed at read from `since`; nothing is persisted.
4. Scope: `rootId` omitted ⇒ every root; present ⇒ the tree (SV1).
5. **Own-view** is T6's concern for agents; here every item is returned to the human door.
