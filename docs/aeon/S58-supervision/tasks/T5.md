# T5 · Channels, the dispatcher, the delivery log, the `nettest` invariant

**Prefix:** SV · **Rules:** SV6, SV7, SV8, SV12, SV14 · P3, P4 · **Depends on:** T3, T4.

## Goal

A person can configure a **signed webhook channel**; matching events reach it through a bounded, SSRF-safe dispatcher with a closed envelope, dedup, rate limit and quiet hours; every outcome is logged honestly; and with no channel the daemon contacts **nothing new**. This is the slice's authority task: the guards (SV7's three locks) land in the same commit as the methods.

## Files

- `aeon/internal/notify/channel.go` — **new**: channel domain: `Validate(ChannelInput)` (https only; `http` accepted **only** with `allow_private=1` and a loopback/private host; no userinfo; ≤ 2 KiB; parseable; the host must be non-empty; name ≤ 80 bytes) returning typed refusals with the daemon's sentence; `Service` (create → **disabled**, update, enable, disable, archive(reason), setSubscription, test) — each writes its row and its `notify_change` in **one transaction**, actor from `table.ActorFor`; `Enable` additionally requires `secret_ref` to resolve in the secrets store (`secret-missing` refusal otherwise: "the channel has no secret — set one with --secret-file").
- `aeon/internal/notify/secretref.go` — **new**: `SecretRef` = `secret:notify/<channelId>`; `type SecretStore interface { Put(ref string, value []byte) error; Get(ref string) ([]byte, error); Delete(ref string) error }` implemented over `internal/secrets` per **T0's recorded API** (route-key precedent, `daemon/memory.go:680-735`: write to the store **first**, the row carries only the ref). `ReadSecretFile(path)` reads ≤ 4 KiB, trims one trailing newline, refuses a world/group-readable file (mode must be 0600 or stricter — the cursor-key rule's spirit), refuses an empty file, and **zeroes its buffer** after `Put`. The value never enters a log line, an error string, a result or an audit summary (a redacting `String()` on the holder type, S19 T2's `Key` shape).
- `aeon/internal/notify/envelope.go` — **new**: the closed `Envelope` struct (SV6) with a fixed JSON key order, `Build(ev ResolvedEvent) Envelope` taking **only** the closed `ResolvedEvent{Seq, Kind, Variant, Severity, RootSlug, LoopSlug, LoopID, Title, At}` — there is no path from a wire `Item` or event payload into it; `Marshal` enforces ≤ 1 KiB (a longer title is truncated at a rune boundary, never dropped); `Sign(secret, body) string` = HMAC-SHA256 hex (mirror of `trigger.VerifyWebhookSignature`, `trigger/webhook.go:95-108`, with a round-trip test against that verifier).
- `aeon/internal/notify/dial.go` — **new**: the **SSRF-safe transport**: `http.Transport` with `DialContext` that resolves, then iterates the addresses and refuses any that is loopback, link-local, private (10/8, 172.16/12, 192.168/16, fc00::/7), CGNAT (100.64/10), multicast, unspecified, or the metadata addresses (169.254.169.254, fd00:ec2::254) — **on the dialled IP** — unless the channel's `allow_private=1`; `CheckRedirect` returns `http.ErrUseLastResponse` (**no redirect followed**); `DisableKeepAlives`, no cookie jar, `TLSClientConfig.MinVersion = TLS12`, `Timeout 10s`; the proxy env is **ignored** (`Proxy: nil`) so an environment proxy cannot reroute a channel.
- `aeon/internal/notify/dispatcher.go` — **new**: `Dispatcher` with `Submit(ResolvedEvent)` (non-blocking; a bounded queue of 256, **drop-oldest** with an `suppressed-overflow` row), N=2 sender goroutines, per (channel, subscription) pipeline: filter (root scope = the event's root or any ancestor/child in the tree; `min_severity`; `kinds`) → disabled/archived check → **dedup** `(channelId, attentionKey)` 10 min → **rate** (`RecentDeliveryCount` against `max_per_hour`; over ⇒ `suppressed-rate`, and **one** summary delivery per hour reporting the suppressed count) → **quiet hours** (`quiet_start/end` + IANA zone; over-midnight windows; DST-safe via `time.In(loc)`) ⇒ `suppressed-quiet` → send with ≤ 3 attempts (1 s / 4 s; only transport, timeout, 5xx, 429 with `Retry-After` ≤ 60 s) → log. Response body read ≤ 4 KiB and discarded. `error_kind` mapping is a closed table (`transport|timeout|status|refused-address|secret-missing|url-invalid`). The dispatcher **never** returns an error to its caller and never blocks it.
- `aeon/internal/daemon/notify_wire.go` — **new**: `table.OnEvent` calls `Resolver.HintFor` (T4) and, in the **same** place after `Append`, `Dispatcher.Submit(...)`; daemon start sends the **digest** (SV-D6): if `attention.Evaluate` returns items, one `inbox.digest` envelope per enabled channel (kind `inbox.digest`, `count` only), recorded like any delivery.
- `aeon/internal/protocol/notify_channel.go` — **new**: `NotifyChannelCreateParams{name, url, secretFile, allowPrivate?, subscriptions?[]}`, `…UpdateParams{id, name?, url?, secretFile?, allowPrivate?}`, `…EnableParams/DisableParams/ArchiveParams{id, reason}` , `…TestParams{id}`, `NotifySubscriptionSetParams{channelId, rootId?, minSeverity, kinds?, quietStart?, quietEnd?, quietZone?, maxPerHour?}`; views `NotifyChannelView{id, name, kind, host, enabled, allowPrivate, secretPresent, subscriptions[], createdAt, lastOutcome?, consecutiveFailures}` — **`url` is never returned, only `host`**, and `secretFile` is never echoed. Reads `notify.channel.list/show`, `notify.delivery.list`. Methods are registered only when the service is wired; **every write method refuses an `agent` actor and an unresolvable actor** (ErrBadParams, "configuring where Aeon sends data is a person's act"). Error code `ErrNotifyChannelRefused` (reason in `what`, three-part data) in T0's block; fixtures per refusal family; handshake; `make protogen`.
- `aeon/internal/nettest/` — **extend** (data, not behaviour): `AllowedHosts(configured routes, forges, channelHosts)`; a doc comment stating SV14's sentence.
- **Guards land here** (P4, the T9 task consolidates and documents): `aeon/cmd/aeon/notify_channel_guard_test.go` — **new** sibling guards: positive half (`TestChannelWritesAreAHumanDoor`: the set `{notify.channel.create, update, enable, disable, archive, test, notify.subscription.set}` registered, `RequiresInitialize`, not `Debug`, absent when nil), negatives (below), canary `TestChannelGuardsHaveTeeth`.

## Behaviour notes

1. **A channel is created disabled**; enabling is a separate act that checks the secret resolves. `test` sends one fixed envelope (`event:"test"`), is logged as a delivery with `attention_key = "test"`, and is refused for a disabled/archived channel.
2. **Failure honesty:** `notify.channel.list` shows `lastOutcome` and `consecutiveFailures`; a channel is **never auto-disabled** (a person decides); `aeon doctor` (T6) flags ≥ 3 consecutive failures.
3. **Daemon down** is unknowable, not a row (SV8): the start-up digest is the compensation; stale per-event messages are never replayed.

## Definition of done

- [ ] Channels creatable only on the human door; created disabled; secret by reference proven absent from DB bytes and logs; env proxy ignored; SSRF/rebinding/redirect refusals proven.
- [ ] Closed envelope with a sentinel test; signature verified against the inbound verifier; dedup, rate, quiet hours, bounded retries; dispatcher cannot slow a loop.
- [ ] Delivery log append-only and honest; zero-channel and one-channel `nettest` tests permanent; the three locks tested with canaries.

## Do NOT

- Do not accept a secret value as a flag, param, stdin or prompt; do not return a URL (host only) or a secret; do not follow redirects; do not honour proxy env; do not retry a 4xx; do not auto-disable a failing channel; do not replay missed events; do not seed a channel; do not give an agent, a loop, the narrow surface or the records catalog any channel write; do not let the envelope builder read a wire `Item`.
- Do not add a second channel kind here.

**Deviations from the spec (all deliberate):**
1. Envelope `"id"` is the dispatcher-minted DeliveryID `channelSeq` (`notify.channel.test` mints `…-test-<stamp>`, the digest `…-digest-<stamp>`) — the class resolver does not mint ids.
2. The rate summary is a synthetic `rate.summary` ("At least N …", N counted from the ≤50-row page — the honest floor), and its once-per-hour guard reads the **delivery log**, not process memory, so a restart cannot shout twice in an hour.
3. **Dedup claims at the check** (not post-send): two senders could otherwise double-deliver one fact; at-most-once it is — a send that then fails is not retried by the sibling inside the window (recorded `failed`; the next event with that key arrives after the 10-min window or is genuinely new).
4. `DispatcherOptions.Sleep` seam (default `time.Sleep`) — the ladder is proven with recorded waits, not real seconds.
5. `Dispatcher.Submit` after `Stop` drops with one log line (the daemon is leaving; sending on a closed queue would panic); `Stop` is idempotent.
6. `CheckRedirect` lives on `http.Client`, not the Transport (the spec said transport) — the client is assembled per send over the guarded transport.
7. `maxPerHour=1` refused (floor 2): a ceiling of 1 makes the rate summary un-sendable — the summary is itself a send.
8. No separate set-secret verb: `notify.channel.update` carries `secretFile`; archive keeps the secret file (retirement, not deletion; the delivery log has **no FK** so an archived channel's history answers only behind `includeArchived`).
9. Overflow rows are one-per-enabled-channel — "this event will not reach you" is a fact per channel.
10. `Resolver.Resolve` reads the loop pin whenever `loopId` is present (the envelope carries slugs even when no template asks; one pin read serves wire and envelope).
11. The spec's `notify_wire.go` is `resolveForPublish` in `notify_channels.go` + the `publishWithNotify` call instead — the daemon method lives where its seams are, and a local param named `notify` shadowing the package in lifecycle.go is exactly why.
12. `TestSecretNeverAppearsAnywhere` covers: every `Secret`-holder rendering (all refuse), the wire results (host-only views proven), the raw store file bytes (walked in `TestDeliveryLogHasNoBodyURLOrResponse`), and the delivery rows; the daemon log-capture half rides on `record()` never receiving secret/url/response values by construction.
13. `TestDeadReceiverNeverSlowsALoop` is paid by `TestDispatcherNeverBlocksOrErrorsTheEventPath` (Submit bounded under a full, undrained queue) + the senders' isolation; the full-loop-under-nettest permanent assertion belongs to T9/T10's demo walk (nettest recorder exists; the channel-plane wiring through it is one integration step there).
14. `TestTLSOnlyAndMinVersion` asserts the transport config (MinVersion TLS1.2, Proxy nil, no keep-alives); a literal TLS-1.0 server handshake refusal is Go's `crypto/tls` own refusal — not re-proved.
15. The digest event carries `severity:"info"` and NO kind (it is about no single thing); the test envelope carries `kind:"test"` too (receivers sort on one field).
16. `method.go` stands at 2,072 lines — a pre-existing SIZE1 violation (recorded at adoption 1,717); T5 added 12 lines and did not split it (splitting the method table is its own cohesion task; named as standing debt, not hidden).
