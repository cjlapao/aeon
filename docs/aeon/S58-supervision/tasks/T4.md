# T4 · The event-class table: `notify.events` seed set and the resolver

**Prefix:** SV · **Shape:** P2 + P8 · **Rules:** SV4, SV5, SV9, SV12 · **Depends on:** T1; **S43-extra T3** (the seed engine). Parallel-safe with T2/T3.

## Goal

The three-case `notifyHintFor` switch becomes a lookup over a **seeded inert record set**; today's three hints stay **byte-identical**; `question.asked` and the `blocked` reason variants are added; templates can carry only ids and enums; the hint gains `attentionKey` and `deepLink`.

## Files

- `aeon/internal/notify/classes.go` — **new** package `notify` (store accessors + `protocol`): `Resolver{store}` with `HintFor(kind string, payload any) *protocol.NotifyHint`:
  1. derive `variant` (the `loop.blocked` reason kind from the payload per T0's decision; empty otherwise);
  2. `GetNotifyClass(kind, variant)`, else `(kind, '')`, else `nil`; a disabled row ⇒ `nil`;
  3. `Render(template, Values)` with the **closed placeholder set** `{rootSlug} {loopSlug} {reasonKind} {severity} {count}`; a template with any other `{…}` is refused at **write** time by `ValidateTemplate` (so nothing invalid is persisted) and renders nothing at read time if one slips through (belt and braces);
  4. attach `attentionKey` (the SV1 key the inbox would give the same subject — a pure function shared with `internal/attention`) and `deepLink` (SV9 forms).
  No cache (N8): one indexed read per event.
- `aeon/internal/notify/placeholders.go` — `Values` is built **only** from ids/slugs/enums: `rootSlug` (the component slug, `^[a-z0-9]+(-[a-z0-9]+)*$`-validated again at render), `loopSlug`, `reasonKind` (closed), `severity` (closed), `count`. There is **no field** on `Values` that can hold a name, prompt, goal or message — the type system carries SV6.
- `aeon/internal/daemon/lifecycle.go` — `notifyHintFor` is replaced at its single call (`daemon.go:641-650`) by `d.notify.HintFor(kind, payload)`; the old function is **deleted** (no fallback to the old switch — P2's two-truths rule). The `question.asked` emitters stay as they are.
- `aeon/internal/protocol/types.go` — `NotifyHint` gains optional `AttentionKey string json:"attentionKey,omitempty"` and `DeepLink string json:"deepLink,omitempty"` (additive; `protogen` regenerates `contract.ts`).
- `aeon/internal/seed/decl_notify.go` + `aeon/internal/notify/notifyseed/` — **the seed set `notify.events`** (class **inert**, P8): `Source() []seed.Record` (content verbatim, per-record `Version` guarded by a golden — "content changed but version did not — bump it"), an `Applier` (`Upsert/Fingerprint/Retire/GuardAffecting=false/Operator`) writing through the notify store's **one write path** (the same function `notify.class.update` uses), `origin='system'`, operator rights `{Edit: enabled/tone/templates (validated), Remove: disable}`. Records: `loop.finished`, `loop.blocked`, `loop.waiting` (**exact current titles/tones; empty bodies**), `question.asked` (info), and `loop.blocked` variants `action-denied`, `step-blocked`, `exhaustion`, `model-error`, `runner-error`; `loop.waiting` variant `stopped` (kind `loop.waiting`, reason `stopped`). T0 trims the list to the kinds an emitter really produces.
- **Dedup of the same moment** (a question both `loop.waiting` and `question.asked`): the resolver returns a hint for both; the **dedup is the consumer's** (`attentionKey`, app + dispatcher), not the resolver's — recorded in Notes.
- `aeon/internal/daemon/notify_classes.go` — **new**: the human-door `notify.class.update {kind, variant, enabled?, tone?, title?, body?}` and reads `notify.class.list`, `notify.vocabulary` (SV13). Write = `ValidateTemplate` → one transaction: row update + `notify_change` (`subject_kind='class'`, fixed-template summary) — an edited **system** row becomes `diverged` in the ledger (never overwritten by re-seed). Protocol file `internal/protocol/notify_class.go`; constants; V13; fixtures; handshake; `make protogen`.

## Commands

## Definition of done

- [ ] Resolver replaces the switch with byte-identical hints for the old three; new rows seeded inert; templates cannot carry user text; no cache; `notifyHintFor` deleted.
- [ ] Hint carries `attentionKey`/`deepLink`; class edits are human-door, audited, divergence-safe.

## Do NOT

- Do not keep the old switch as a fallback; do not add a placeholder that can hold free text; do not cache rows; do not seed rows for kinds no emitter produces; do not edit another slice's seed file (siblings add `notify.events.<area>` sets in their own files).
