# T1 · `internal/seed`: sets, records, the registry, canonical hashing, the pure plan

**Prefix:** SD · **Rules:** SD1, SD2, SD3 (hash), SD5 (class cross-check), SD6 (the plan's decision table) · **Depends on:** T0. Parallel-safe with T2.

## Goal

The engine's brain with **no database, no clock, no I/O**: what a seed set and record are, how they are registered and
validated, how content is canonicalised and hashed, and — as a pure function — **what applying a set would do given the
current ledger and live fingerprints**. Everything T3 needs to decide is decided here and unit-tested exhaustively.

## Files (all new, `aeon/internal/seed/`)

- `seed.go` — package doc (the SD1 rule in one paragraph; dependency rule below) and the types:
  `Class` (`inert|guard`), `Set`, `Record`, `State` (`applied|removed|diverged|retired|failed|absent`), `Op`
  (`apply|update|skip|restore|retire|adopt`), `OperatorRights{Edit, Remove bool}`.
- `registry.go` — `Registry`, `NewRegistry(sets ...Set) (*Registry, error)` (returns refusals, never panics),
  `DefaultRegistry()` (the package-global set built from `init()`), `mustRegister(Set)`, `Lookup`, `All()` (sorted).
- `canon.go` — `Canonical(v any) ([]byte, error)` (stable JSON: sorted keys, no insignificant whitespace, UTF-8, `\u`
  escapes normalised) and `Hash(content []byte) string` (hex SHA-256 of the canonical bytes).
- `plan.go` — `Plan(set Set, st LedgerState, live LiveState) []Decision` — the pure decision function (below).
- `applier.go` — the `Applier` interface **declared here, implemented per domain**:
  ```go
  type Applier interface {
      Set() string
      GuardAffecting() bool                     // SD5 cross-check
      Operator() OperatorRights                 // SD6: what an operator may do to a system row
      Fingerprint(tx Tx, key string) (hash string, present bool, err error)   // hash of the LIVE row's canonical content
      Upsert(tx Tx, r Record, adopt bool) error // write the row (origin='system'); adopt=true fills an existing stub
      Retire(tx Tx, key string) error           // flag a row whose record left the code (row kept)
  }
  type Tx interface{ Exec(query string, args ...any) (Result, error); Query(...) ... } // the minimal seam, no sql import
  ```
- `*_test.go` — tests below.

**Dependency rule (asserted):** `internal/seed` imports the standard library only — no `internal/store`, `database/sql`,
`internal/handler`, `internal/policy`, `internal/mcp`, `internal/daemon`, `internal/protocol`. Domains import `seed`, never
the reverse (the `internal/records` precedent: pure data both sides can depend on).

## Declaration rules (every one a refusal `NewRegistry` returns and `mustRegister` panics on)

1. `Set.ID` grammar `^[a-z][a-z0-9]*(\.[a-z][a-zA-Z0-9]*)+$`, 3–64 bytes; unique.
2. `Class` is `inert` or `guard`.
3. `Version ≥ 1`; each `Record.Version ≥ 1` and `≤ Set.Version`.
4. `Records()` non-nil; every `Key` non-empty, ≤ 128 bytes, unique within the set, no control characters.
5. `Content` is valid JSON ≤ 1 MiB.
6. **Class/Applier cross-check (SD5):** a set registered `inert` whose Applier reports `GuardAffecting()==true` is refused,
   naming both ("this set widens a guard and cannot be applied unasked").
7. Every set has exactly one Applier (looked up by `Set.ID` through `RegisterApplier`); a set with none is refused at
   `Validate` time, not at apply time.

## `Plan` — the decision table (pure, total, one function)

Input per record: the ledger row (or none), the live fingerprint (or "row absent"), the record's version/hash.

| Ledger | Live row | vs record | State → Decision |
| --- | --- | --- | --- |
| none | absent | — | `apply` (create) |
| none | **present** | — | `adopt` if the Applier says the row is an adoptable stub (`Fingerprint` returns `present` and `Operator`/`Upsert(adopt)` accepted) else **conflict** → `skip`, reason names the conflict (a user row with the same key — never overwritten, SD9) |
| applied | present, hash == `applied_hash` | record version > applied | `update` |
| applied | present, hash == `applied_hash` | record version == applied | `skip` ("up to date") |
| applied | present, hash == `applied_hash` | record version < applied | **refuse**, named ("a lower version than applied — a downgrade is never silent") |
| applied | present, hash ≠ `applied_hash` | any | state `diverged` → `skip`, reason carries both versions |
| applied | absent | any | state `removed` → `skip`, reason "removed by an operator; `seed.restore` re-applies" |
| removed / diverged | any | any | `skip` (until `restore`) |
| applied | present | record **missing** from the set | `retire` |
| retired | — | record reappears | `apply` (re-adopt) with a named reason |
| failed | — | any | `apply` retry |

`Decision{Key, Op, State, FromVersion, ToVersion, Reason}`. `Plan` returns decisions **sorted by key**; it never errors —
a refusal is a `Decision` with `Op=skip` and a reason, except the downgrade, which is a `Refusal` field on the result so
T3 can fail the whole apply loudly. `restore` is a separate pure function `PlanRestore(set, key, ledger, live)`.

## Tests

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestSetIDGrammarTable` | ≥ 12 ids valid/invalid | grammar drift |
| `TestRegistryRefusesEachDeclarationRule` | one subtest per rule 1–7, error names the set/key | a bad declaration accepted |
| `TestClassApplierCrossCheck` | inert + guard-affecting Applier refused, naming both | a guard set slips in as inert (SD5) |
| `TestDefaultRegistryHasOnlyDeclaredSets` | in this slice's tests the default registry is empty or contains exactly `agents.firstparty` (T4 flips it) | an undeclared production set |
| `TestCanonicalIsStable` | key order / whitespace / escape variants of one value hash identically; two different values differ | non-canonical hashing |
| `TestHashIsHexSha256` | known vector | wrong digest |
| `TestPlanTable` | **every row above** as a table-driven case, asserting Op, State, reason text | any decision wrong |
| `TestPlanDowngradeIsARefusal` | lower version → `Refusal` set, no decisions applied | silent downgrade |
| `TestPlanNeverOverwritesDivergedOrRemoved` | diverged/removed → skip even when a higher version exists | operator's choice clobbered (SD6) |
| `TestPlanRetiresMissingRecords` | record gone from code → `retire`, not delete | auto-deletion |
| `TestPlanIsDeterministicAndSorted` | shuffled input → identical output | nondeterminism |
| `TestPlanIsPure` | no clock/IO: same inputs, 1000 runs, same output; `go vet` import list stdlib-only | hidden state |
| `TestSeedImportsStdlibOnly` | `go/parser` over the package | the dependency rule broken |
