# T4 · The agents set: schema extension, applier, a lossless source, adoption of S43's stubs

**Prefix:** SD · **Rules:** SD1, SD4, SD7 (what a row must carry), SD8 (steps 1–3, 5), SD9 · **Depends on:** T3.

## Goal

First-party agents become **complete rows**, produced by the seed process. The `agent` table gains what dispatch needs;
the `agents.firstparty` set declares every registered body as a record whose content is **exactly what dispatch reads**;
the agents `Applier` writes/updates/adopts rows; and a round-trip test proves nothing is lost. **Dispatch itself is
still unchanged here (T5)** — this task only fills the table.

## Files

- `aeon/internal/store/migrations/<14-digit>_agent_dispatch_columns.sql` — **new**, after T2's. Plain `ALTER TABLE agent
  ADD COLUMN` statements (SQLite-safe; defaults satisfy CHECKs). **The column list is what T0 item 4.6's field table
  proved necessary**; the expected shape:
  ```sql
  -- S43-extra T4: the agent columns first-party dispatch needs (tools allow-list, temperature, handoff schema, the policy-agent link, the body hash) plus origin, so a system row is distinguishable from a user/imported one. internal<=>origin='system' is asserted by a test; S43's internal flag and its refusals are untouched.
  ALTER TABLE agent ADD COLUMN tools        TEXT    NOT NULL DEFAULT '[]';
  ALTER TABLE agent ADD COLUMN temperature  REAL    NOT NULL DEFAULT 0;
  ALTER TABLE agent ADD COLUMN handoff      TEXT    NOT NULL DEFAULT '{}';
  ALTER TABLE agent ADD COLUMN policy_agent TEXT    NOT NULL DEFAULT '';
  ALTER TABLE agent ADD COLUMN body_hash    TEXT    NOT NULL DEFAULT '';
  ALTER TABLE agent ADD COLUMN origin       TEXT    NOT NULL DEFAULT 'user' CHECK (origin IN ('system','user','import'));
  UPDATE agent SET origin = 'system' WHERE internal = 1;
  UPDATE agent SET origin = 'import' WHERE internal = 0 AND signature <> '';
  ```
  Additional columns only if T0 proved a dispatch-read field has no home; every field otherwise goes in `metadata` JSON
  (`mode`, `variant`, recorded-inert fields) and is listed in Notes.
- `aeon/internal/store/agent.go` — extend `Agent` with the six fields and the scans/inserts; **S43's behaviour unchanged**:
  `CreateAgent`, `EditAgent`, duplicate/delete refusals and `Internal` semantics keep their tests green (edit **adds
  fields**, it does not change a refusal). `Duplicate` copies the new fields and sets `origin='user'`.
- `aeon/internal/agentseed/` — **new package** (domain side of the engine; not in `internal/seed`, which stays
  domain-free): `source.go` (`Source() []seed.Record` from `internal/handler`'s registered bodies), `applier.go`
  (`Applier` over `*sql.Tx`), `decl.go` (`init()` registering the set `agents.firstparty`, class **inert**).
  - **Source** uses `handler.LoadDefinition(name)` for every `handler.RegisteredBodies()` name — i.e. the **existing**
    `parse` + `Verify` + `BuildSchema` guards run, so a bad body still fails at `go test` — and builds `Content` as
    canonical JSON `{slug, name, description, functionality, prompt, tools, temperature, handoff, policy_agent, metadata,
    avatar_type, avatar_color, avatar_mood}`. `slug` comes from S43's `store.Slugify(name)` (the same function S43 used;
    T0 recorded whether S43 keys dispatch by slug or name). `prompt` is `Definition.Body` **byte for byte**. Record
    `Version` = a per-record integer starting at 1 and bumped by a developer when a body's content changes; a
    **`TestSeedVersionsBumpWithContent`** compares each record's `Hash` to a committed `testdata/agents.versions.golden`
    (`key version hash` lines) and fails with "content changed but version did not — bump it" — so a body edit can never
    ship without a version bump. `Set.Version` = max record version.
  - **Applier** `Upsert(tx, r, adopt)`: decode `Content`; `INSERT` a new row (`internal=1, origin='system',
    signed=0`, `signature=''`) or, when `adopt`/update, `UPDATE` **content columns only** (`description, functionality,
    prompt, skills, tools, temperature, handoff, policy_agent, metadata, avatar_*, version, body_hash, updated_at`) —
    **never** `id`, `slug`, `created_at`, `signature`, `signer_certificate`. `Fingerprint` = hash of the canonical content
    columns of the live row (so a hand edit is `diverged`). `GuardAffecting()` = **false** (an agent definition permits
    nothing; permission is policy, S11 "a handler's Policy field is a declaration, never a grant"). `Operator()` =
    `{Edit:false, Remove:false}` (S43 AM1: internal rows refuse edit/delete; duplication is the way).
  - **Adoption** (SD9): a row with the slug, `internal=1`, `version='1'` and empty `prompt` is an adoptable stub; a row
    with the slug and `internal=0` is a **conflict**.
- `aeon/internal/agentseed/*_test.go`, `testdata/agents.versions.golden`.
- `aeon/internal/seed/registry_test.go` — flip `TestDefaultRegistryHasOnlyDeclaredSets` to contain exactly
  `agents.firstparty`.
- `aeon/cmd/aeon/agent_management.go` — **no change**; `agent.migrate` (the S43 stub creator) stays as built and is now
  superseded in practice by the seed (T9 records that the stub path is retained only for non-first-party `plugin_agent`
  rows).

## The lossless round-trip (the slice's core proof)

`TestFirstPartyRoundTripIsLossless` — for **every** registered body: seed into a temp store → read the row →
`handler.Handler{Name, SystemPrompt, Tools, Handoff, PolicyAgent}` built **from the row's columns** (a test-local mapper
T5 later promotes to `handler.FromRow`) → assert equal to the Handler built from the embedded body: `SystemPrompt` byte-equal,
`Tools` equal as ordered lists, `Handoff` deep-equal, `PolicyAgent` equal, `Temperature` equal; and that
`handler.Compile(row-built)` equals `handler.Compile(embedded-built)` for a fixed set of `Section` inputs. **All
registered bodies, not a sample.** Also asserts the slug is unique across the 33 and valid.

## Tests

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestFirstPartyRoundTripIsLossless` | as above, all bodies | a field lost in the row |
| `TestFirstPartyBodiesStillFailAtTestTimeWhenInvalid` | a deliberately broken fixture body makes `Source()` return the loader's refusal | the guards stopped running |
| `TestSeedVersionsBumpWithContent` | golden compare as above | an unversioned body edit |
| `TestEveryFirstPartyRowIsComplete` | after apply: no row has empty `prompt`, `description`, or `tools` where the body declares them (acceptance 1) | stubs remain |
| `TestApplyCreatesRowsWithSystemOrigin` | `internal=1`, `origin='system'`, `signed=0`, `signature=''` | provenance wrong |
| `TestInternalIffSystemOrigin` | over every row: `internal==1 ⇔ origin=='system'` | S43's flag and the new one disagree |
| `TestAdoptStubKeepsIdAndCreatedAt` | a S43-style stub (`version '1'`, empty content) → content filled, `id`/`slug`/`created_at` unchanged, ledger `adopt` | identity rewritten |
| `TestAdoptNeverTouchesAUserAgentWithTheSameSlug` | `internal=0` row with a first-party slug → conflict skip, row untouched | clobbered a custom agent |
| `TestEditedSystemRowIsDivergedNotOverwritten` | write a content column directly → `seed.status` says `diverged`; apply skips | operator/dev edit lost |
| `TestSecondApplyIsANoOp` | zero writes | non-idempotent |
| `TestS43AgentTestsUnchanged` | the existing `internal/store` and `internal/agentmgr` agent tests pass unedited | the new columns broke S43 |
| `TestApplierIsNotGuardAffecting` | `GuardAffecting()==false`; the set registers as `inert` | a guard set slipped in as inert |
| `TestMigrationBackfillsOrigin` | upgrade from the pre-migration vintage: `internal=1` → `system`, signed imports → `import`, others `user` | origin wrong on existing DBs |

## Definition of done

- [ ] Migration adds only the proven-necessary columns + `origin`, backfilled; S43's tests pass unedited.
- [ ] `agents.firstparty` (inert) declared; every registered body is a record; versions guarded by a golden.
- [ ] The lossless round-trip passes for **all** bodies including `Compile`.
- [ ] Adoption keeps identity; user rows are conflicts; edits are `diverged`.
- [ ] No stub first-party row remains after an apply (acceptance 1).

## Do NOT

- Do not change `handler`'s parser, `Verify`, `BuildSchema` or `Compile`.
- Do not make dispatch read the table here (T5).
- Do not change S43's refusal semantics, card format or signature fields; do not edit an S43 test.
- Do not let the Applier write `id`, `slug`, `created_at`, `signature` or `signer_certificate`.
- Do not seed non-first-party agents; do not auto-delete a row whose body left the code.
