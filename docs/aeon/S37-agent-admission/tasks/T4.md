## Steps

1. **Seam field** in `method.go` `Table` (copy the doc style of `Plugins`):
   ```go

   // point builds a closure over internal/plugin (cmd/aeon is the only package allowed to import
   // it — TestNoUnconditionalImportOfPlugin), the protocol layer holds a plain func. nil means
   // half-wired: the create answers ErrNotWired by name, never silently permissive.
   AgentImportPreview func(ctx context.Context, pkgPath string) (preview *AgentImportPreview, refusal string, err error)
   ```
2. **Payload decode + normalise** in `proposals_agent_import.go`:
   ```go
   type agentImportPayload struct{ PkgPath string `json:"pkgPath"` }

   // decodeAgentImportPayload enforces AA2: the payload is ONE field. Unknown fields (a snapshot of the
   // package, a card, a prompt) are refused, never stored.
   func decodeAgentImportPayload(raw json.RawMessage) (agentImportPayload, string) {
       var p agentImportPayload
       dec := json.NewDecoder(bytes.NewReader(raw)); dec.DisallowUnknownFields()
       if err := dec.Decode(&p); err != nil { return p, "refused: agent_import payload is {\"pkgPath\": \"<absolute path>\"} and nothing else — " + err.Error() }
       if strings.TrimSpace(p.PkgPath) == "" { return p, "refused: agent_import needs pkgPath" }
       // A URL is the plugin layer's refusal to word (AP10, N1) — pass it through unchanged so the reason
       // is byte-identical to the CLI's. Anything else must be absolute (AD2, Q3).
       if !strings.Contains(p.PkgPath, "://") && !filepath.IsAbs(p.PkgPath) {
           return p, "refused: pkgPath must be absolute — a relative path resolves against whoever's working directory is running at the time, and create and commit are not guaranteed to be the same process"
       }
       if !strings.Contains(p.PkgPath, "://") { p.PkgPath = filepath.Clean(p.PkgPath) }
       return p, ""
   }
   ```
3. **The validator**:
   ```go
   func (t *Table) validateAgentImport(ctx context.Context, raw json.RawMessage) (*AgentImportPreview, agentImportPayload, string, error) {
       p, refusal := decodeAgentImportPayload(raw)
       if refusal != "" { return nil, p, refusal, nil }
       if t.AgentImportPreview == nil {
           return nil, p, "", ErrNotWired.WithWhat("agent admission is not wired — the daemon started without the entry point's AgentImportPreview seam (cmd/aeon did not set it); `aeon serve` wires it, a hand-built Table does not")
       }
       prev, refusal, err := t.AgentImportPreview(ctx, p.PkgPath)
       return prev, p, refusal, err
   }
   ```
   (`ErrNotWired.WithWhat` is the existing pattern at protocol/agent.go:148.)

**Deviations from the spec (what the task file could not know).**
1. **AA2 enforced by key-count, not `DisallowUnknownFields` (step 2).** The
   spec's step 2 shows `dec.DisallowUnknownFields()`, but
   `TestNothingCallsDisallowUnknownFields` (T3, `types_test.go:82`) forbids any
   decoder in `internal/protocol` from rejecting unknown fields — a decoder that
   refuses them turns every additive change into a breaking one, and this
   package's decoders never do that. The same AA2 refusal is enforced by
   re-reading the payload as a `map[string]json.RawMessage` and refusing any bag
   that is not exactly the one key `pkgPath` (the identical refusal, by the same
   key, in this package's own words); `TestAgentImportPayloadWithExtraFieldsRefused`
   (`{"pkgPath":"/x","card":{...}}`) pins it.
2. **The registry lives in `cmd/aeon`, not `internal/protocol` (step 4).** The
   spec's step 4 anticipates this ("if S35's registry lives in `cmd/aeon` …").
   S35's registry is `proposalValidators` in `cmd/aeon/proposal_validators.go`
   (returns only `error`, TD3); the preview flows separately via the
   `Table.AgentImportPreview` seam, so the `Table` field and the
   daemon/`agent_services.go` wiring ARE needed — the registry entry is a thin
   error-only re-validation (the one function create and commit both re-run), and
   the preview is not in the registry's error path. `TestValidatorRegistry-
   CoversExactlyFourKinds` now covers six, matching `store.ProposalKinds`.
3. **The import-boundary grep test assembles the import path from two halves**
   (`agent_import_boundary_test.go`): `internal/plugin`'s absent test greps the
   whole module (including `_test.go`) for the contiguous import path and reads
   any runtime file that names it as an unconditional importer (AP11); a test
   file that wrote it verbatim would be read as a second, runtime-side import.
   Slicing the token keeps the scanner able to match a real offender while this
   file stays clear of the substring that grep looks for.
