# T3 · The create-time preview, as a `cmd/aeon` function (the three read-only steps, composed)

**Prefix:** AD · **Rules:** AD3 · AA2 · AA4 (preview is advisory) · AA5 · criterion 2 (validator parity) · **Depends on:** T2 · S35 not needed yet (this task touches no S35 code)

## Goal

A new `cmd/aeon` function `agentImportPreviewFor(st)` runs `ReadPackagePreview` → `ReadCarriedPolicies` → `CheckRequests` against the policy set in force now → `RenderConsent`, returning the wire `preview` or the **identical refusal string** `aeon agent import` gives. It writes nothing. T4 plugs it into the socket.

**Why `cmd/aeon` and not `internal/protocol` (this corrects design AD3's sketch).** `TestNoUnconditionalImportOfPlugin` (`aeon/internal/plugin/absent_test.go:81`) fails if any package other than `cmd/aeon` and `internal/plugin` imports `internal/plugin`. So `internal/protocol` cannot call `plugin.ReadPackagePreview` directly. The repo's pattern for this (S15's `Table.Plugins`) is a function seam: the entry point builds a closure over `plugin.*`, the daemon/protocol only hold a plain `func`. This task builds the closure (and the wire structs it returns); T4 adds the seam field. `absent_test.go` stays zero-diff.

   ```go
   // Advisory only (AA4): `aeon proposal commit` re-reads and re-renders.
   type AgentImportPreview struct {
       Agent       string              `json:"agent"`
       Consent     string              `json:"consent"`
       CarriedDeny []AgentImportCarried `json:"carriedDeny"`
   }

   }

   }
   ```
   `carriedDeny` must marshal as `[]` not `null` when empty (initialise with `[]AgentImportCarried{}`). Then create `aeon/cmd/aeon/agent_admission.go` (package `main`; imports `context`, `fmt`, `time`, `plugin`, `policy`, `protocol`, `store`).
2. Add the closure builder, same return shape as `pluginsHandleFor` (agent.go:394): a refusal is the **second** return value, an infrastructure failure the third:
   ```go
   func agentImportPreviewFor(st *store.Store) func(ctx context.Context, pkgPath string) (preview *protocol.AgentImportPreview, refusal string, err error) {
       return func(ctx context.Context, pkgPath string) (*protocol.AgentImportPreview, string, error) {
           if err := wirePluginSeams(st); err != nil { return nil, "", err }   // card verifier + ledger, as the daemon wires them
           a, rj := plugin.ReadPackagePreview(pkgPath)
           if rj != nil { return nil, rj.Error(), nil }
           carried, rj := plugin.ReadCarriedPolicies(pkgPath)
           if rj != nil { return nil, rj.Error(), nil }
           now := time.Now().UTC()
           ps, prj := policy.NewStore(policyRepo(st)).List(ctx, now)
           if prj != nil {
               return nil, fmt.Sprintf("the policy set could not be read (%s) — the check judges against the set in force, and inventing one would judge against nothing", prj.Reason), nil
           }
           if rj := plugin.CheckRequests(a, ps, now); rj != nil { return nil, rj.Error(), nil }
           a.Carried = carried                                   // ImportChecked does this before registering; RenderConsent reads it
           out := &protocol.AgentImportPreview{Agent: a.Name, Consent: plugin.RenderConsent(a, ps).String(), CarriedDeny: []protocol.AgentImportCarried{}}
           for _, p := range carried {
               out.CarriedDeny = append(out.CarriedDeny, protocol.AgentImportCarried{ID: p.ID, Target: protocol.AgentImportTarget{Kind: string(p.Target.Kind), ID: p.Target.ID}})
           }
           return out, "", nil
       }
   }
   ```
   (The policy-set-unreadable string is `agentCtx.set()`'s own text, agent.go:91 — keep them equal. `policyRepo(st)` is the existing helper used at agent.go:408.) The refusal strings are `Reject.Error()` **verbatim** — never wrapped, never prefixed (criterion 2).
3. The function must not call `ImportChecked`, `recordImport`, `StoreCarriedPluginDenial`, `policy.Store.Add`, `Enable`, or write any store row. A comment above it says so and names the commit door (T5).
