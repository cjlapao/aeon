## Steps

1. Build `ProposeImportForm`: a text input (`aria-label="Package path"`, placeholder `/absolute/path/to/agent-package`), a **Propose import** button, and a result area. Local validation is cosmetic only: if the trimmed value does not start with `/` (or a Windows drive letter pattern `^[A-Za-z]:[\\/]`), show *"must be an absolute path"* and do not call — the daemon's refusal stays the authority, so also render any `{ok:false,error}` string **verbatim** (S35 test map #6: never a silent form reset; keep the typed value).
2. On success call `onToast` with S35's exact toast pattern (copy the constant/helper S35 uses — T0 Q9 — do not retype): *"Proposed · commit with `aeon proposal commit 12`"* where the command text is the response's `command` field, not a string the form builds.
3. Under the toast render the preview, labelled **Preview — the commit re-reads the package and shows the authoritative consent**: `preview.agent` as a heading, `preview.consent` in a `<pre>` (whitespace preserved, never summarised — S15 T4), and a list of `preview.carriedDeny` ids with their target kind/id. Every string shown comes from the response; the form never reads a filesystem path (criterion 6). The only action next to the preview is none: no Commit, no Confirm, no keyboard shortcut.
4. Mount the form on the Agents page in its own section titled **Import an agent** with one line of help text: *"Proposes an import; nothing is imported until you run the command shown."*
5. Tests (`ProposeImportForm.test.tsx`; names are the contract):
   ```ts
   it('calls proposal.create with kind agent_import and the typed path')
   it('shows the exact toast built from the response command field')
   it('renders the consent text verbatim inside a pre and labels it a preview')
   it('renders a daemon refusal verbatim and keeps the typed path')
   it('does not call the socket for an empty or relative path')
   it('offers no commit control: no button, link or shortcut whose text matches /commit|confirm|import now/i except the copyable command text')
   it('renders an unwired daemon as the unwired state, not an empty form result')
   it('every rendered string traces to the response or the typed input')   // fake socket returns sentinel strings; assert each appears; assert no fs/path API is imported by the component (grep the source in the test)
   ```
   The "no commit control" test queries `getAllByRole('button')` and asserts the only buttons are *Propose import* (and S35's Discard if the page lists proposals); the toast's command is plain text, not a button.

## Notes

**Built.** `ProposeImportForm.tsx` (NEW, `.../test-bench/pages/`) — one absolute-path field (`aria-label="Package path"`, placeholder `/absolute/path/to/agent-package`), a **Propose import** button, a cosmetic local absolute-path check, a verbatim daemon-refusal line that keeps the typed value, the unwired state, and the labelled advisory preview. The Agents page (`AgentsPage.tsx`) mounts it in one new section, **Import an agent**, with the help line "Proposes an import; nothing is imported until you run the command shown." `ProposalsPage.tsx`, `BENCH_PAGES`, the menu and `SideMenuItem` groups are untouched.

**The form is a proposal, never a commit (criterion 6).** It calls `proposal.create {kind:"agent_import", payload:{pkgPath}}` (through its `create` prop), shows S35's exact toast, and renders the returned preview labelled advisory. No commit / confirm / import-now control anywhere; the preview has no action at all.

**Interface + wiring (the design's `{ create, onToast }` props, adapted to the real S35 mechanism).** The form takes `create: (kind, payload) => Promise<ProposalCreateResult>` and `onToast: (msg) => void`. The Agents page wires `create = (kind, payload) => rpc("proposal.create", { kind, payload })` and `onToast = (msg) => notifications.push({ title: msg, tone: "info", source: "local" })`. The toast text `Proposed · commit with ${result.command}` is built by the form from the response's `command` field (S35's exact pattern — never a command the form invents from the id) and pushed by the page through the same `notifications.push` S35 uses. `ProposalCreateResult` is read off the generated contract (`RpcMethods["proposal.create"]["result"]`, which carries `command` + the optional `preview`), never retyped. The closed-5 `ProposalKind` / `createProposal` helper in `lib/proposals.ts` is deliberately NOT used (it is typed to the 5 kinds and does the toast internally); the form calls `rpc` directly, so no `ProposalKind` change and the exact S35 toast is reused.

**The three states, and the thin-client boundary.** On a transport error the form shows the unwired state (not an empty result); on an rpc error it renders the refusal verbatim and keeps the typed value (no silent reset, S35 test map #6). The local absolute-path check is cosmetic only — it never decides (the daemon's refusal is the authority), and it keeps a clearly-wrong value off the wire. The component source reads no filesystem (`node:fs` / `@tauri-apps/api/fs` absent — asserted in the test).

**Test deviation from the design's list.** The 8 `it`s are the design's eight, by the design's names. "Does not call the socket for an empty or relative path" and "calls proposal.create …" assert against the **real** `rpc` path (the test wires `create` to `rpc` over `installFakeDaemon`), so "does not call the socket" is a real socket-call count (`daemon.calls`), not a prop-spy. The "every rendered string traces to the response" test asserts the sentinel strings appear and greps the component source for a filesystem import. "Existing ProposalsPage tests unedited" is the `git diff` proof (ProposalsPage untouched), not a re-run.
