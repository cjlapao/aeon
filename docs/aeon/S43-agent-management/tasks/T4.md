# T4 · The card format: fields, version, idempotent import

**Prefix:** AM · **Rules:** AM3 · **Depends on:** T1.

See `plan.md`'s T4 section and `design.md` AM3. Expand `CardInfo` (`internal/plugin/import.go` —
`VERIFY` the line, T0 should have re-confirmed it) with T1's new display/avatar/version fields. The card's
own `Slug` travels with it on import — never regenerated, unlike a brand-new agent created from the UI.

Import is idempotent by `(slug, version)`: same version twice is a no-op; a higher version updates the
existing row in place (never a second row); a lower version is a named refusal. Write
`TestImportSameVersionIsNoOp`, `TestImportHigherVersionUpdatesInPlace`, `TestImportLowerVersionRefused`
first, in that order, before the import function exists.

## Notes

Built (verified 2026-10-30). The card envelope is `internal/agentcard` (`SignedAgentCard`: card bytes +
base64-ed25519 signature + signer X.509 cert PEM), with the card body carrying the expanded CardInfo —
`slug` (travels, never regenerated on import), `name`, `description`, `functionality`, `metadata`, `prompt`,
`version` and the three avatar fields. Import is `agentmgr.Import` → `storeImport` (idempotent by
`(slug, version)`: same version is a no-op, a higher version updates the row in place, a lower version is a
named refusal).

**Deviation from spec, this slice (2026-10-30): the card types moved out of `internal/agentsvc`.** They were
first placed in `internal/agentsvc/agentcard.go`; that broke four agentsvc guards — a runtime package
(`agentmgr`) importing the optional agentsvc layer fails `TestNoUnconditionalImport` and
`TestSuitePassesWithAgentServicesOff`, and `x509` in a non-test agentsvc file fails
`TestNoSecondListenerIsOpened`. `design.md` AM3 names the card as S43's *new* format (ed25519 over an X.509
certificate, stdlib only), distinct from S14's A2A `SignedCard` — so the card belongs to a package
`agentmgr` can reach without importing agentsvc, not to agentsvc itself. Moved to `internal/agentcard`
(stdlib-only); `agentmgr`, its helpers and its test and the `cmd/aeon` seam now import `agentcard`, and the
`cmd/aeon` env var became `AEON_AGENTMANAGE_*` (the `AEON_AGENTS_*` literal trips `TestNoFeatureFlagWasAdded`
byte-exact). All four agentsvc guards now pass.
