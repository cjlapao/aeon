# T6 · Duplication and deletion

**Prefix:** AM · **Rules:** AM1, AM2, AM4 · **Depends on:** T1, T2, T3.

See `plan.md`'s T6 section. Duplicate: every field copied into a new row, new GUID, a slug freshly
generated from the **copy's** name (never the original's slug) — refused if it collides with an existing
one (AM2, locked: refuse, never silent-suffix). `internal` forced `false` on the copy regardless of the
source row. Edit: refused on `internal = true` rows, named reason; `slug` and `id` are never writable after
creation. Delete: refused if any blueprint **or any policy row** references the slug (locked, `brief.md`
§5) — name every referencing blueprint and policy row in the refusal. Use T3's blueprint check and T2's
`PolicyListAll`-backed policy check; this task is the caller that wires both into one delete path.

Write the "duplicate a locked system agent produces an editable, non-internal row" test first — it's the
operator's own example and the one AM1 exists to make possible.
