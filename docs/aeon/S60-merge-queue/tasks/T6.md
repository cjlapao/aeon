# T6 · The forge actions, `forge.land`, the merge-rule seam and the grant seam

**Prefix:** MQ · **Rules:** MQ8 (forge half), MQ11, MQ12, MQ13 · **Depends on:** T5; **S56** (grant) and **S57** (`ListStatuses`, `MergeRule`) contracts — seams **fail closed** until those merge.

## Goal

Open the landing PR and land it, one guard family generalised, the irreversible action reachable only through the same gates every merge goes through — plus the `queue.enqueue` code action.

## Files

- `internal/forge/forge.go` — `PR` gains `HeadSHA string` (T0 §1.6 confirms it is absent); `GitHub.ReadPR` maps `head.sha`; `Fake` seeds/returns it; **no** other interface method changes. Golden/fixture for the GitHub mapping in `forge/testdata/`.
- `internal/action/forge_actions.go`:
  - `OpenLandingPR` (action `forge.openLandingPR`, **outward**): head = the item's integration branch (must exist on the remote, else `BlockedError{head-missing}` as `OpenPR`), base = the item's base; find-or-open keyed on head ref (reuse as `OpenPR`); title/body from a fixed template (ids, base, branch, queue position) + the loop's summary **marked as prose by declaration**; evidence `pr_number`, `pr_head_sha`.
  - `Land` (action `forge.land`, **irreversible**): MQ12 steps 1–5 verbatim: ReadPR → head and base asserted against the item → `mergeGate` (**reused unchanged**) → `MergeRule` seam → `verified_sha` check (`pr.HeadSHA == args.VerifiedSHA == integration_sha`, else `KindRefused` `head-moved`) → `Forge.MergePR(n, method)` (method = config `land_method`) → fetch → `IsAncestor(mergeSHA, origin/<base>)` else `PhantomMergeError`. Already merged ⇒ success with the recorded SHA (never merge twice). Protection refusal ⇒ honest failure, **no retry with another method** (N4).
  - **`forge.merge`'s code, guard, tests and evidence are untouched.**
  - `type MergeRule interface{ Allow(ctx, MergeFacts) (RuleVerdict, error) }` (a seam on `ForgeActions`, default `nil`): `nil` ⇒ only `mergeGate` applies and `RuleVerdict` evidence records `merge_rule: "none-configured"`; an `error` ⇒ **refuse** (unverifiable is not green before something irreversible). `MergeFacts` = PR, reviews, statuses (nil when unreported), threads, `verified_sha`, repository, base. S57 implements it.
- `internal/action/class.go`, `registry.go` (+ strategies) — `forge.openLandingPR` outward, `forge.land` irreversible, `queue.enqueue` local; schemas `Source: "code"|"evidence"` only; `BuildAsk` gains the `forge.land` case (repository, PR number, base, queue position, verified SHA, behind/ahead, gate summary — built from ids/enums/numbers) and `forge.openLandingPR` (head, base, title).
- `internal/action/queue_actions.go` — **new**: `Enqueue` (action `queue.enqueue`): resolves the loop's pinned feature branch + base (T4), refuses with MQ15's sentence when no base is known, calls `mergequeue.ValidateEnqueue` then the service (T3) with actor `{blueprint, <loop slug>}`, `attended` read from the loop pin (`LoopAttended`, NULL ⇒ 0). Natural-idempotent: an existing open item for the branch returns it. Local class. The action gets the queue service through a **narrow interface seam** (`QueueEnqueuer`) so `internal/action` imports no store/mergequeue package.
- `internal/action/class.go` `Resolve` — **no signature change here**. T6 adds the **seam** only: `action.Grants` interface `{MergeAllowed(componentRoot string) (bool, policyRev string)}` consulted **only** for `forge.land`; `nil` ⇒ deny-leaning (no grant). The S56 contract widens `Resolve`; until it merges, `forge.land` unattended **denies with the existing sentence verbatim** and attended asks — i.e. G14 unchanged. Tests prove `allowOutward` still never grants `irreversible`.
- `internal/loop/execute.go` — pass `verified_sha`, `integration_sha`, `item` (from the loop's `With`/evidence) into `Args`; no other change.
- Registry-count tests — **+3** (total 15), dated.

## Behaviour (each a test; real-git fixture + `Fake` forge)

1. Happy path: openLandingPR → (approve review seeded) → land: merged, ancestor of base, evidence complete.
2. Base mismatch (PR into another branch), head mismatch (PR head ≠ integration branch), `HeadSHA` ≠ `verified_sha`, integration moved after verification: each refused with its own sentence and **no** forge merge call (the `Fake`'s call log proves it).
3. No review / request-changes outstanding: `mergeGate` refusal verbatim (reuse proven by the identical text).
4. `MergeRule` seam: `nil` ⇒ evidence says none-configured; returns `Deny` ⇒ refused naming the rule; returns error ⇒ refused (unverifiable).
5. Unattended landing loop, no grant: `forge.land` **denied at once**, exact G14 sentence, zero forge calls; with `allowOutward` true: **still** denied (`… allowOutward does not grant it`). Attended: asks with the full ask text; `approve` runs, `deny` ⇒ `action-denied-by-person`.
6. Already-merged PR ⇒ success, no second merge call. Protection refusal ⇒ `KindRefused` surfaced; **no second method attempted** (call log).
7. `PhantomMergeError` when the fake reports merged but the SHA is not on base.
8. `queue.enqueue`: unknown base ⇒ MQ15 sentence; duplicate ⇒ returns the existing item; `mode=off` still enqueues (OD11); actor and `attended` stamped from the pin, not from args.
