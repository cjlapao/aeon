## Behaviour (each a test)

1. Reads need no authority; writes with a missing/foreign component root are refused with the not-found sentence.
2. `settings --mode auto` returns the `statement`; the UI/CLI must show it before confirming (T10/T11); the daemon applies the change only when `confirm:true`-style param `acknowledged` equals the statement's digest (the S35/S45 confirm shape — read S45's chosen form in T0 §4 and reuse it, never a new one).
3. `reorder` on a non-`queued` item refused; `retry` only from `failed`; `land` only from `ready` with mode `manual` or `auto`; `dequeue` of an in-flight item stops its landing loop first.
4. Actor stamping: params naming an actor are a parse error (`additionalProperties:false` equivalents); every write's event carries the peer.
5. `mergequeue.vocabulary` equals `mergequeue.Describe`/consts (no hand-copied list): adding a status constant changes the result with no handler edit.
