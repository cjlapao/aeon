# T2 · The key registry and typed validation

**Prefix:** CS · **Rules:** CS3, CS4 (env name), CS5, CS6, CS8 (`Sensitive`), CS10 (descriptor shape) ·
**Depends on:** T0. Parallel-safe with T1 — pure Go, no database, no shared file.

## Goal

The closed vocabulary that gives a schema-less table its type safety: what a **declared key** is, what makes a
declaration legal, how a value is parsed to and from its one canonical text form, and how the environment name is
derived. Nothing here touches storage, the network or the clock.

## Files to create / modify

All **new**, in `aeon/internal/config/`. **No existing file in the package is edited** (CS1 — T3 pins this).

- `settings.go` — types, `Registry`, `mustDeclare`, `Declare`, lookup, canonical form.
- `settings_env.go` — `EnvName(key) string`, collision detection helper.
- `settings_errors.go` — the three-part errors used by T2 *and* T3 (defined here so T3 does not edit this file):
  `ErrSettingUnknown`, `ErrSettingInvalidValue`, `ErrSettingNotWritable` (see below). Same shape as
  `creds.go`'s `ErrCredentialInConfig`: wrap `errs.Error`, expose `What()/Why()/Do()`.
- `settings_test.go` — tests below.
- `settings_decl_test.go` — a **test-only** declaration file used by this and later tasks' tests (see "Test
  registry"). It is a `_test.go` file so no production declaration is shipped (CS3).

## The types

```go
type SettingType string
const (
	TypeBool   SettingType = "bool"
	TypeInt    SettingType = "int"
	TypeString SettingType = "string"
	TypeEnum   SettingType = "enum"
)

type Scope string
const ScopeGlobal Scope = "global" // the only member (CS6)

// Setting is one declared key. A declaration is code, reviewed, and refuses at init (mustDeclare) — so a
// bad one never reaches a running daemon.
type Setting struct {
	Key         string      // dotted camelCase, e.g. "agents.allowUnsignedImport"; grammar below
	Area        string      // the grouping the UI shows, e.g. "agents"; defaults to the key's first segment
	Type        SettingType
	Default     string      // canonical text form; MUST parse under Type/bounds
	Description string      // one or two sentences a person reads in Settings; required, non-empty
	Scope       Scope       // ScopeGlobal; the zero value is treated as ScopeGlobal
	Sensitive   bool        // CS8: widens a guard; requires a Description saying what the default protects
	// Type-specific bounds (a bound that does not apply to Type is a declaration error):
	Min, Max    *int        // TypeInt
	MaxLen      int         // TypeString; 0 means the default cap 4096; may not exceed 4096
	EnumValues  []string    // TypeEnum; non-empty, no duplicates, each non-empty, each a legal canonical string
}

type Registry struct{ /* map by key; insertion-order independent; read-only after construction */ }

func NewRegistry(decls ...Setting) (*Registry, error)   // the testable constructor: returns the refusal, never panics
func DefaultRegistry() *Registry                        // the package-global set built from init() declarations
func (r *Registry) Lookup(key string) (Setting, bool)
func (r *Registry) All() []Setting                      // sorted by Area then Key
func (r *Registry) Nearest(key string, n int) []string  // up to n declared keys closest to key (see below)
func mustDeclare(s Setting)                             // package-init helper: panics with the NewRegistry error
func (s Setting) ParseValue(raw string) (canonical string, err error)  // validates + canonicalises
func (s Setting) FormatDefault() string
```

## The declaration rules (every one is a refusal `NewRegistry` returns and `mustDeclare` panics on)

1. **Key grammar**: `^[a-z][A-Za-z0-9]*(\.[A-Za-z][A-Za-z0-9]*)+$`, total length 3–128. At least one dot; no
   empty segment; the first character lowercase. This must be **no looser** than T1's CHECK net (test pins both).
2. **Credential-shaped names are refused** (CS5): `isCredentialName(key)` true → refuse. The error says the key
   name, that a credential never lives in a config store (C4), and the one fix (route it through
   `config.Credential`). Test with `providers.apiKey`, `x.token`, `x.password` — **VERIFY the real predicate's
   word list first** (`creds.go`) and pick test names from it, not from memory.
3. **Duplicate key** refused, naming both declaration sites if a file/line is available (use `runtime.Caller` in
   `mustDeclare`; `NewRegistry` just names the key).
4. **Env-name collision** (CS4): two keys whose `EnvName` is equal are refused, naming both. (`a.bC` and `a.bc`
   both map to `AEON_SETTING_A_BC`.)
5. **`Default` must parse** under the key's own type and bounds — a default that fails its own validation would
   make every read `storedInvalid`.
6. **Bounds apply only to their type**: `Min`/`Max` on a non-int, `MaxLen` on a non-string, `EnumValues` on a
   non-enum are refused. `Min <= Max` when both set. `MaxLen` in `[0,4096]`.
7. **`TypeEnum`**: `EnumValues` non-empty, unique, each non-empty with no whitespace; `Default` must be a member.
8. **`Description` is required** and non-empty after trim. For `Sensitive: true` it must additionally be at least
   40 characters (a one-word description cannot say what a default protects) — a blunt, honest check; the real
   review is human.
9. **`Scope`**: zero or `ScopeGlobal`; anything else is refused ("scoped settings are not built — CS6").
10. **`Area`**: empty → derived from `Key`'s first segment; if given it must be `[a-z][A-Za-z0-9]*`.

## Canonical forms — `ParseValue(raw)`

| Type | Accepted | Canonical output | Refused (examples) |
| --- | --- | --- | --- |
| bool | exactly `true` or `false` | same | `True`, `TRUE`, `1`, `yes`, `on`, `""`, ` true` |
| int | `-?(0|[1-9][0-9]*)` within `Min`/`Max` and `int` range | same | `+1`, `007`, `1.0`, `1e3`, `""`, `-0`, `9999999999999999999` |
| string | any valid UTF-8 up to `MaxLen` bytes, **no NUL byte** | same, byte for byte | invalid UTF-8, a NUL, over length |
| enum | exactly one member, case-sensitive | the member | a near-miss (`Auto` for `auto`) — the error names the members |

One spelling per value, so equality is a string compare (design CS3). `ParseValue` **never trims or fixes**; a
leading/trailing space on a bool is a refusal naming the value with visible quotes. An empty string is legal for
a `TypeString` key only if `Default` is `""` **or** the declaration sets no minimum — keep it simple: empty is
legal for `TypeString` and refused for the other three.

## `EnvName` and `Nearest`

- `EnvName("agents.allowUnsignedImport") == "AEON_SETTING_AGENTS_ALLOWUNSIGNEDIMPORT"`: prefix + upper-case +
  every `.` → `_`. Pure function, no table. (Camel humps are **not** split — deterministic and obvious.)
- `Nearest(key, n)`: up to `n` declared keys, ranked by (1) shared first segment, (2) case-insensitive prefix
  match, (3) small edit distance (Levenshtein ≤ 3, an inline ~15-line implementation — **no new dependency**);
  ties by key order. Returns an empty slice when the registry is empty. This feeds `ErrSettingUnknown`'s `Do`.

## The three errors (`settings_errors.go`)

Three-part (`what` / `why` / `do`), like S23's. They are **domain refusals**, not infrastructure errors (DB19).

- `ErrSettingUnknown{Key, Nearest}` — what: "`<key>` is not a declared setting"; why: "only declared settings can
  be read or written, so a typo cannot create a silent no-op"; do: "use one of: `<nearest…>`" — or, when the
  registry is empty, "no settings are declared yet".
- `ErrSettingInvalidValue{Key, Type, Expected, Got}` — what: "`<key>` cannot be set to `<got>`"; why:
  "expected `<Expected>`"; do: the fix in one line (for an enum, the member list; for an int, the range).
  `Got` is rendered with `%q` and truncated to 80 bytes with a visible `…` so a megabyte of input cannot fill a log.
- `ErrSettingNotWritable{Key, Reason}` — reserved for T3's defensive credential-name re-check (CS5) and any
  future per-key write lock; defined here so T3 adds no file to this error family.

## Test registry — `settings_decl_test.go`

A `testRegistry(t)` helper builds a `*Registry` of representative declarations used by T2, T3, T4 and T5's
tests (T4/T5 are other packages, so they build their own from the same recipe, documented here so the three stay
alike): `test.flag` (bool, default `false`), `test.count` (int, Min 1, Max 10, default `3`), `test.label`
(string, MaxLen 16, default `"x"`), `test.mode` (enum `auto|manual`, default `auto`), `test.guard` (bool,
default `false`, `Sensitive: true`, a 50+ character description). **None of these is declared in package-level
`init()`** — the production `DefaultRegistry()` must remain empty in every build (a test asserts it).
