# T4 · Daemon wiring: the adapter, the one shared instance, and the real-store proof

**Prefix:** CS · **Rules:** CS2, CS7, CS11, CS12 · **Depends on:** T3.

## Goal

Bridge `config.Repo` to the real `*store.Store`, build **one** `*config.Store` at serve time, and prove — against
a real SQLite file, not a fake — the slice's first acceptance criterion: *a value written is read back correctly
on the very next call, same process or a fresh one, with no boot-time caching anywhere in the new path.* Settle
CS12 (the change event) per T0's verdict. Nothing in this task adds a socket method (T5).

## Behaviour

1. **The mapping is total and lossless.** `*string` ↔ `*string` for `OldValue/NewValue` (nil stays nil), `bool`
   ↔ `bool`, strings verbatim. A test round-trips every field.
2. **`NewSettings` is the only constructor** the rest of the program uses. It takes the store, applies the
   production defaults (`config.DefaultRegistry()`, `os.LookupEnv`, UTC clock) unless `opt` overrides them, and
   returns the shared instance. There is **no package-level instance** and no `sync.Once` (a hidden global would
   hide a second instance in a test and defeat "same process or not").
3. **What `actor` the protocol layer will pass** is settled by T0 item 3.3; this task only needs the constant
   or helper that builds it (`actorFor(sess *protocol.Session) string`) if the answer lives in the daemon. If it
   is `Session.ClientName`-only the helper is one line plus an empty-name fallback of `"unknown-client"` (never
   an empty string — T3 refuses empty — and never a fabricated identity; the fallback says what is true).
4. **CS12:** if T0 ruled `setting.changed` **cheap**, add the emission here: on a `changed=true` result from
   `Set`/`Unset`, publish one event `setting.changed` `{ "key": …, "source": … }` through the daemon's existing
   event path (the same function the loop/queue writes use — VERIFY its name; do not open a second emission
   route), after the repo write has returned success and never before. If **not cheap**, write nothing here and
   record the decision in Notes so T5/T8/T9 follow it.

## Tests — `internal/daemon/settings_test.go`

The tests open a **real temp-file store** with the existing daemon/store test helpers (VERIFY how
`daemon_test.go` builds one: `grep -n 'store.Open\|newTestStore\|openStore' aeon/internal/daemon/*_test.go | head`).

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestSettingsRepoMappingRoundTripsEveryField` | `RepoRow`/`RepoEvent` → store → back, field for field, including nil `OldValue`/`NewValue` and `ShadowedBy=="env"` | a field dropped or `nil`↔`""` conflated |
| `TestWriteThroughOneHandleReadThroughAnother` | two `*store.Store` opened on the **same file** (two `*sql.DB`s); `NewSettings` over each; `Set` via A, `Get` via B immediately, no sleep, no reopen | any read-side caching, or WAL/visibility surprise — the headline criterion |
| `TestWriteVisibleToAFreshProcess` | write via a store, close it, **spawn `go run`-free subprocess**: re-exec the test binary (`os.Args[0] -test.run=TestHelperReadSetting`, the standard helper-process idiom) which opens the file and prints `Get`'s value; parent asserts the printed value | state lived only in the writer's memory |
| `TestSettingSurvivesDaemonRestartShape` | close and reopen the store, rebuild `NewSettings`, `Get` still returns the saved value and `Source=database` | persistence not real |
| `TestSetAndEventAreOneTransactionAgainstRealStore` | wrap the real repo in a test double that corrupts `ev.Op` (to a value the CHECK refuses) before delegating to `SettingPut`; `Set` returns an error and `SettingGet` finds **no** row | atomicity only held against the fake |
| `TestEventTrailAgainstRealStore` | Set, Set(changed), Set(same), Unset → `History` returns exactly 3 events (`set`,`set`,`unset`) newest first | no-op writes recorded, or trail missing |
| `TestEnvOverridesRealDatabaseValue` | row `false`, env `true` injected via `Options.LookupEnv` → `Source=environment`, `ShadowedBy` set | precedence only held against the fake |
| `TestStoredInvalidAgainstRealStore` | insert a raw invalid value with the store's own accessor, `Get` flags `StoredInvalid` | the real read path skips validation |
| `TestSettingChangedEventEmittedOnChangeOnly` *(only if T0 ruled cheap)* | one event on a changing Set; none on an identical Set; none when the repo write fails | event before the write / event on no-ops |
| `TestNoPackageLevelSettingsInstance` | `go/parser` over `internal/daemon/settings*.go`: no top-level `var` of type `*config.Store`, no `sync.Once` | a hidden global instance |
