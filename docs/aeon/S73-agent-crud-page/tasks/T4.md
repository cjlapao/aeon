# T4 · The actor reaches every road

**Rules:** AR4. **Depends on:** T3.

## Goal

Each of the nine writing paths lands a ledger row naming its actor, and a path that cannot name one refuses. No path
guesses, and no road takes an identity from params.

## Steps

1. `internal/protocol/agent_management.go`: add the ctx channel `WithAgentActor(ctx, kind, id)` /
   `AgentActor(ctx) (kind, id string, ok bool)` — a copy of `WithMCPActor`/`MCPActor`
   (`internal/protocol/mcp_admin.go:499-515`), and it says so in its comment. Add `agentWriteEdge(ctx, sess, name,
   params) (context.Context, error)`: the identity-key refusal first, then `t.ActorFor` nil-check, then the peer stamp
   (`mcpWriteEdge`, `mcp_admin.go:698-713`, is the model — including the uid-0 and blank refusals). Add the closed set
   of write methods the edge applies to; `agent.view` and the two reads stay outside it (SP6: the line is at the
   acts, `platform_door.go:53-57`).
2. `agentManageCall` stops discarding the `*Session` (`agent_management.go:22`): writes run through `agentWriteEdge`
   and hand the enriched ctx to `t.AgentManage`; reads pass the ctx through untouched. `Options.AgentManage`'s
   signature does not change — that is why the ctx is the channel.
3. Declare `ErrAgentNoActor` in the family's voice beside `ErrAgentRefused`, **measure the free code first** (S61's
   block ends at `-31969`; the expectation is `-31970`) and record the measurement in the comment the way S54 and S61
   recorded theirs. Register it in the code table.
4. `cmd/aeon/agent_management.go`: each write case starts by reading `protocol.AgentActor(ctx)` and refusing with
   `ErrAgentNoActor` naming the method when it is absent — the `cmd/aeon/mcp_admin_writes.go:38-41` shape. Then it
   builds a `store.AgentActor` and passes it to the `agentmgr` method. `agent.view`/`agent.rows`/`agent.changes` read
   nothing and check nothing.
5. Path 7, the CLI direct door: `aeon agent import` reaches `importAgentPackage`; stamp
   `protocol.WithAgentActor(ctx, "cli", "cli")` at that call site, the `mcp_client.go:160` precedent, and say in the
   comment why `cli` is honest here (the process is the person's own shell; the kernel uid is in the socket roads and
   nowhere in this one).
6. Path 8, the desk commit: `seamApplyAgentImport` (`cmd/aeon/proposal.go:705`) reads `desk.CommitActor(ctx)` and
   `desk.ProposalIDFrom(ctx)`. Either missing is a refusal naming the missing half, in `seamApplyMCPServerAdd`'s words
   (`proposal.go:464-472`). The committer is the actor; the summary carries `proposal <id>`. The proposal's **author**
   is not the actor and the comment says so (S56's Decider doc argues the case: conflating them is what the audit
   exists to catch).
7. `importAgentPackage` (`cmd/aeon/agent.go:123`) takes the actor (or reads it from the ctx it is handed — pick one and
   make the compiler enforce it; do not accept both).
8. Road for the seed: `internal/agentseed/applier.go` passes `system:seed-engine` on each of its apply paths — insert,
   update, adopt — and **nothing** on a refusal path. A refused apply mints no row (that is the same law as AR2).
9. The `migrate` stamp is the person's, not `system:migrate` — design deviation 3, with the measurement (`agentmgr.go:349`
   is `MigrateFirstPartyAgents`' only caller) in the code comment where a future reader will find the tempting
   constant.
10. Tests, one per road, in the package that owns the road:
    - `internal/protocol/agent_management_test.go`: the stamp lands for each of the six writes; a nil `ActorFor`, an
      empty id and uid `0` each refuse with `ErrAgentNoActor` and write nothing; `agent.view`/`agent.rows`/
      `agent.changes` answer with no stamp present; an identity key in params is refused naming it.
    - `cmd/aeon/agent_actor_test.go`: path 5 through the socket, path 7 through the direct door, path 8 through a desk
      commit — each asserting the ledger row's `actor_kind`/`actor_id` and, for path 8, `proposal <id>` in the
      summary; path 8 with `CommitActor` withheld refuses and mints nothing (the fail-closed half is a test, not a
      comment).
    - `internal/agentseed`'s apply tests extended: `system:seed-engine` on each apply path, nothing on a refusal.
    - `cmd/aeon/agent_road_guard_test.go`: a source walk asserting no `agentmgr` write method is called anywhere
      without an actor argument derived from one of the four named sources, plus its canary.

## Do not

- Do not accept an actor from params, and do not add one to any params struct — the reflection guard S57/S59 use is
  the shape to copy if a test wants a whole-plane negative.
- Do not fall back to a placeholder actor anywhere, including in a test helper that a production path could reach.
- Do not stamp the proposal's author as the committer.
