# T1 · `internal/paging`, and the convention written down

**Rules:** PG1, PG2, PG3, PG4, PG5. **Depends on:** none. **Changes no daemon behaviour** — this task ships a package,
its tests and a document; nothing calls it yet.

## Goal

There is one implementation of paging and one text that says what the daemon's paged reads look like, so that "every
endpoint does it" becomes a claim a reader can check rather than an intention.

## Steps

1. Create `internal/paging/paging.go` with exactly the surface design §PG2 lists: `Request`, `Bounds`, `Normalise`,
   `Offset`, `Column`, `Like`, `Answer`. Pure Go, stdlib only, no database import. A file that needs no store is a file
   that can be tested exhaustively — keep it that way, and keep it under 300 lines.
2. `Normalise` takes the clamp and the defaults from `Bounds` and returns a refusal naming the offending key for a
   wrong JSON type or an unknown `dir`. `Offset` is `(page-1)*pageSize` on the normalised values.
3. `Column` is the only bridge from a wire word to a SQL word: it looks the key up in `Bounds.Sorts`, whose values are
   column literals, and returns an error naming the key when the key is absent. Write its doc comment so a reader
   cannot miss that this is where injection dies.
4. `Like` escapes `\` → `\\`, `%` → `\%`, `_` → `\_` and wraps in `%…%`; document that the SQL must carry `ESCAPE '\'`
   and that the escape runs **before** the count so `total` matches what the table shows.
5. `Answer` is the echo block: `Page`, `PageSize`, `Total`, with a `Pages()` helper for nothing but the UI's sake — if
   nothing needs it, delete it before committing (do not ship a helper with no caller).
6. Write `internal/paging/paging_test.go` covering: the clamp (0, negative, 1, 100, 500, non-integer types), the
   defaults, `dir` refusals, `Offset` at page 1 and page 7, `Column` for every key of a sample map plus an unknown key
   (the error names it) plus a hostile key (`slug;DROP TABLE agent--`), and `Like` against `%`, `_`, `\` and an empty
   `q`.
7. Write `docs/aeon/PAGING.md`: the four keys and their defaults, the answer's echo, the end-of-data rule, the
   allow-list rule, the adoption checklist, and the prior art it does not pretend away — the 34 fixtures with
   `limit`/`cursor`/`pageSize` in three shapes (`limit` alone: `mcp.changes`, `inbox.list`; `limit`+`nextCursor`:
   `retro.list`, `charter.revisions`; `hasOlder`/`hasNewer`: `loop.transcript`), zero fixtures with `page`, and a
   sentence on why a table needs the page window. Close with the adoption table: `agent.rows` (T2), `agent.changes`
   (T5), and everyone else, per slice.

## Definition of done

- `go build ./internal/paging/` and `go test ./internal/paging/` pass; `go vet ./internal/paging/` clean.
- Every property in §PG2–§PG4 has a test with a name that says which one it is.
- `docs/aeon/PAGING.md` names both S73 adopters and the prior art, and links back to this slice.
- `wc -l` on every new file, recorded in Notes. Nothing near 1000.

## Do not

- Do not wire the package into a store or a method — T2 and T5 do that, so the convention is proven by two adopters
  rather than by one convenient one.
- Do not touch the three shipped cursor shapes. They are prior art, not broken things.
- Do not add a cursor implementation "for completeness". One shape, adopted per endpoint, is the claim.

`TestBoundsThatContradictThemselvesClampDown` (a `Bounds` whose default exceeds its own cap: the smaller wins —

safe reading of a mistake is the restrictive one) · `TestZeroBoundsStillPageAtTheConventionDefaults` ·
`TestPageBelowOneBecomesOne` · `TestDirRefusesAnythingButAscOrDesc` · `TestQueryIsTrimmedAndCapped` ·
`TestOffsetIsWhatThePageMeans` · `TestColumnResolvesOnlyThroughTheMap` · `TestNoCallerStringReachesTheOrderBy` ·

`TestLikeEscapesTheMetacharacters` (+ `TestLikeEmptyIsNotMatchEverything`, `TestAnswerEchoesTheAppliedRequest`).

**Two things the task's sketch did not settle, settled in code.** `Bounds` carries `MaxQuery` (the sketch named the cap
but not its owner), and contradictory bounds resolve downward — recorded above because a reader of the design alone
would guess the other way. `pagedReadRefusedKeys` deliberately does **not** live here: the refused vocabulary is a
property of a paged read's parameters, and the door owns parameters (`cmd/aeon/agent_rows.go:84`); the package holding
it would be a package with an opinion about a wire it does not see.
