# T3 — the doors

## Why this exists

The family deliberately has **no start verb**: a worker is a registered
Go function, and a socket door that started "workers" by name with
caller payloads is a remote-execution door wearing a friendly face.
Starting belongs to the owning service's own method — `graph.build`
became the pattern: it decodes, resolves the absolute root and
`StartView`s a `graph.build` worker, answering
`{workerId, state, started}` in milliseconds instead of holding a socket
open for ten minutes. `started:false` is its own honest answer ("one was
already flying"), not a rejection.
