# T5 — the app

## Why this exists

The reopen-mid-build promise is a UI promise: open the page, the mount
read asks the ledger ("this type, this root — anything?"), and whatever
is live appears without a blocking call anywhere. `useAsyncWorkers` is
that read plus the event paint: the six `asyncworker.*` kinds merge
payload-Views by `workerId` while connected; rows stay truth, events
stay paint. The ledger page keeps `interrupted` visually its own (amber,
its own sentence, "nothing restarted it on purpose") — P31 says the
daemon dying and the work refusing are different instructions, and the
DOM must not flatten them. Progress the runner never reported renders
as *unknown*, never a confident 0%. The page cannot start work and says
so; GraphPage got the live-row banner (state, note, %, cancel) for its
root, and its status line re-reads itself when the last live row lands.
