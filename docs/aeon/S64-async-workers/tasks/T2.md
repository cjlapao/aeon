# T2 — the manager

## Why this exists

The user's "manager that takes an interface" is this package: services
`Register` a Go function once at wiring time and `Start` fire-and-forget.
Everything a background worker must be honest about lives here — the
state machine (queued → running → finished|failed|cancelled|interrupted,
each with its own reason string), the classification (deadline → failed
"timed out after %s"; cancel → cancelled; panic → failed "panic: %v",
never escaping the goroutine), and the race every worker has with its
own death: the **guarded** terminal write means whoever reaches the row
first (runner, canceller, or shutdown sweep) wins, the event published
matches the row that survived, and a late write onto an interrupted row
is silent because the row already told the truth.
