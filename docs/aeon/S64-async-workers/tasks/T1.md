# T1 — the ledger

## Why this exists

The reopen-mid-build promise is only as real as the row behind it. This
task makes the database — not a manager's memory — the truth about what
is live: the partial unique index `async_worker_flight` on
`(worker_type, dedupe_key) WHERE state IN ('queued','running')` means
two simultaneous starts for one unit of work cannot both win, whoever
reaches the table first owns the flight, and a restart cannot lose the
fact that work was on foot.
