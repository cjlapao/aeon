# T10 — The demo runs from the app: "Full ladder (S17)"

## Why this exists

**A slice is done when someone else can follow `DEMO.md` and watch it work** — and since the 2026-10-25
amendments (the bench demo-runner spec, exercised by S14's T12, S15's T10 and S16's T13), *watch it work*
includes **in the app**. The Test bench → Demos tab gains the seventh feature panel: **Full ladder (S17)**.

Three ways this panel can appear to pass while lying — the S14/S15/S16 pattern, sharpened by what S17 is
(the method itself, whose gates and send-backs are the things a click-through would corrupt):

**An approve button in disguise, twice over.** The plan gate is the **one** human decision the method is
built around, and its answer set is `[approve, revise, abort]` — `abort` is a first-class outcome, not a
failure. A demo-tab button that answers the plan gate (or an escalation) turns the method into a wizard that
approves itself. **The panel reads gates and never answers them** — the prompt renders verbatim with all
three options as *text*, and the operator's `aeon answer <loopId> …` rides the row.

**A fabricated merge.** No fake daemon merged anything, and a fabricated merge fabricates *a feature that
exists nowhere*. Every success-shaped row is **labeled REPLAY** citing the Go test that proves its envelope;
the model-call and GitHub halves of §1–§7 were **OWED** on the T9 walk (the standing ruling: no provider
credential, no token on this box) and the panel's owed rows say `owed`, never `met`.

**A counters fiction.** D2's whole claim — task 3 keeps its own budget — must render **from the
daemon's `loop.show` data**, not from the page's imagination, and `unverified` must render as the third
state it is, never a green tick (I5 applies to pixels too).

**Read first:** `tasks/T9.md` (the walked DEMO, findings, the owed ledger); `DEMO.md` §8; the S16 panel
(`DemosPage.tsx`'s git-forge panel) and `ui/test/bench-gitforge-s16.test.tsx` for the fake-daemon discipline
— including the two known traps: a refusal must be **thrown as the JSON-string wire form** (a plain `Error`
loses `code` through `toRpcError`), and **every Go test name cited on the page must exist** (grep-verified —
the S16 T13 audit caught three that did not, and the panel now asserts a citation regex on every replay
row for exactly that reason).
