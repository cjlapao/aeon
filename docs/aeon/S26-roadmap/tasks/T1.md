## Why this exists

Everything else in this slice writes rows here. Find the current highest migration number at the time this
task starts — do not hardcode one.

## Scope

**`roadmap_item`**: `id` (PK), `project_root` (`NOT NULL`, FK), `title` (`TEXT NOT NULL`), `epic` (`TEXT`,
nullable — R2: a tag, not a row), `status` (`TEXT NOT NULL CHECK (status IN ('idea','ideating',
'brief-agreed','planned','ready','running','done','cancelled'))` — R1's eight values, no ninth),
`priority_state` (`TEXT NOT NULL DEFAULT 'unknown' CHECK (priority_state IN ('known','assumed','unknown'))`
— D2, matching `S29-triage/brief.md`'s own expected shape), `priority_label` (`TEXT`, nullable, meaningful
only when `priority_state != 'unknown'`), `estimate_min`, `estimate_max` (`INTEGER`, nullable), `estimate_basis`
(`TEXT`, nullable — D3, never populated alone without both bounds), `provenance` (`TEXT NOT NULL CHECK
(provenance IN ('authored','triggered','triaged'))` — D5), `brief_path`, `plan_path` (`TEXT`, nullable —
D9: pointers, never content), `loop_slug` (`TEXT`, nullable, FK to `loop(project_root, slug)` — absent
until materialized, the same "no sentinel, the column is simply unset" discipline S24's T1 used),
`created_at`, `updated_at`.
