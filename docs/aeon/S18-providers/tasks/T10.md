## Why this exists

P34: *a capability that is not reachable through the daemon surface is not finished* — and T3's `routes.probe`
is not *used* until a human can fire it where humans look. The test bench is that place ("test what we need in
the place where it is consumed"), and its ProvidersPage already owns the route-config surface, credential-free.

This is also the slice's demo going in-app: the bench demo runner already walks S13's DEMO from the app; S18's
journey — configure a local route, probe it, watch a step that needs tools get **refused as data** — gets the
same treatment. The legs that need live provider keys are marked **not runnable here** with their remedy, the
established discipline: never a silent skip, never a fake pass.

## Scope

### protocol.ts — the types first

`RouteView` gains `wireCapabilities?: string[]` and `capabilityStates?: Record<string, ProbeResultView>`
(each: `state: "declared" | "verified" | "contradicted"`, `detail`, `probedModel`, `probedAt` — **all present or
the pill is not rendered**); `SetRouteParams` gains `noPrice?: boolean`; a `RoutesProbeResult` type for the
`routes.probe` response. Types mirror the Go shapes exactly — a UI type that drifts from the wire is a second
truth.

### ProvidersPage — the states and the one button

- Each route row shows its wire capabilities as **pills in three visual states** — `declared` (neutral),
  `verified` (confirmed, carrying the probe's timestamp and probed model in the tooltip/summary line),
  `contradicted` (loud, carrying `detail`). Three states, no fourth; absence of a probe is `declared`, never
  assumed-true.
- One **Probe** button per route → `rpc("routes.probe", {route})`. It is the page's only probe affordance:
  **no probe on load, on save, on refresh** (M32 — the same lock `mcp.check` carries). Disabled while a probe is
  in flight for that route. Its result arrives through a `routes.list` refresh, not a second private state —
  one source of facts.
- A probe refusal (contradiction included) renders the daemon's sentence **verbatim** — the daemon wrote it,
  the page does not re-case it.
- The `noPrice` checkbox beside prices (T2's explicit declaration), same empty-means-keep discipline as the key
  and `reasoningEffort`.

### DemosPage — the S18 run

A new demo in the runner (same `DemoStep`/`Verdict` shapes, `demo-` prefixed slugs where loops start):

| Row | Verdict states it can reach |
| --- | --- |
| `routes.list` carries wire capabilities for the local route | met / unavailable ("no local route configured — add one on the Providers tab") |
| `routes.probe` on the local route | met (states arrive with timestamps) / refused-as-data (daemon's sentence verbatim) |
| A step needing `tools` on a route declaring none | refused-as-data — **this is M29's refusal rendered where it will be seen**, including "no model call was made" |
| Unmetered route cost | met reading `unknown` **with its reason**; the literal `$0.00` appearing is an error-state row |
| A→B→A round trip | **not runnable here** — cites the Go test that proves it (`TestSuspendOnAnthropicResumeOnOpenAIResumeOnAnthropic`) |

No row may contact a live provider: the test asserts only `rpc()` over the socket leaves the page (the
bench-demos discipline), and rows needing credentials say so with their remedy.
