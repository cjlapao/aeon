`ANTHROPIC_API_KEY`/`OPENAI_API_KEY` genuinely absent from the environment (env count 0) and a

gates (`runtime/crossprovider_test.go`, `daemon.TestStoreUnmodifiedAtEveryPoint`,
`adapters/crossprovider_wire_test.go`), and CAPABILITIES.md names the same gap. The live claims
measured: `cost unknown (no-price-for-route)` on every renderer with `$0.00` nowhere (D9); the
probe's one-request manners **and** its failure sentence — `nothing was contradicted — every
capability keeps its declaration and its 'declared' state` — twice, one of them by the walker's own
timeout; and `refused: step requires capability 'tools'; route 'local-notools' does not have it (no
model call was made)` with zero requests sent (M29).

**The walk caught a real defect in T8's own plumbing (F-9).** The deferred route switch was applied
only on the step's `done` branch — a step that **suspended** after a steered switch lost it forever
(the steer had drained once), which made the refusal's promised "takes effect at the next step" a
lie exactly on the round trip's middle leg. Fixed in this slice: `applyPendingRoute` now runs at
**every hand-back** (advance + continue, all branches — suspension is exit, P2), with
`loop.TestDeferredRouteSurvivesASuspendingStep` as the gate.

**The DEMO is rewritten to verbs that exist (F-6).** The planning draft named `aeon route
add/probe/show`, `aeon loop route`, `aeon debug last-request`, `aeon step show --dropped` and
`--costs` — none built. Reality: `aeon routes set/probe/list`, a `step.steer` whose switch lands as
`loop.route.applied`, adapter gates for the wire checks, `loop show` printing the ledger
unconditionally. Nine findings (F-1..F-9) are in the slice DEMO's table — CLI flags-after-prompt
swallowed into the task (F-1), `--tools ""` meaning the **default** grant (F-3), `qwen3.5:latest`
unable to finish a probe inside the fixed 30-second `ProbeTimeout` making `verified`/`contradicted`
unreachable on this box (F-4, improvement recorded not fixed), flaky small-model handoffs honestly
recorded (F-5), `initialize`-first with an **int** `protocolVersion` for raw-socket probes (F-7).

**QA suite: amended, never rewritten.** QAM-35..46 continue the numbering (the pre-existing
duplicate `QAM-31` heading is left as found); every case names its real Go gates. The README row
reports what is true — **T1–T9 built & walked, T10 bench outstanding, §3 live legs owed** — rather
than a bare "specified". **M13 survived the slice and the walk says so plainly**: no third adapter
file was ever needed; `TestNoThirdAdapterFile` + `TestEveryDifferenceIsAFlagOrAFinding` are the
guards, and the one claim no machine here could falsify (a foreign provider's reaction to a
transcript it did not produce) is recorded as an open observation.
