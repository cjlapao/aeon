# T6 — No telemetry, asserted

## Why this exists

C11: **no telemetry.** *"The product reads source code and runs commands. Trust is the whole basis of installing it."*

**And a claim like that is worth nothing unstated** (C19). This task turns a sentence in a README into a test that fails when
it stops being true.

## Scope

### The assertion (C19, D13, I6)

A test that runs **a full loop with tools and a forge action** and asserts **no connection except to configured routes and
forges.**

**A full loop, not a single step** (O8). *The connection nobody expects appears on the path nobody exercised* — a version
check on first run, a crash reporter on an error path, a dependency's own analytics on a code path only a real loop reaches.

Implementation: a test harness that observes outbound connections — an HTTP transport wrapper for Go-level calls plus a
process-level check for anything below it. **Both**, because a dependency making its own connection would not go through the
wrapper, and that is exactly the case worth catching.

### What is allowed

| Allowed | Because |
| --- | --- |
| Configured model routes | The user configured them |
| The configured forge | The user configured it |
| A configured embedding route (S22) | Same |
| An `openai-compatible` base URL | Same |

**Nothing else.** No analytics host, no crash reporter, **no version check** — a version check is telemetry with a friendly
name: it reports that this machine is running this version at this time.

### Not opt-in, not anonymised, not for crashes (N1)

**Permanent.** Not a flag, not a first-run question, not "help us improve".

The reason is not privacy in the abstract: **the product reads your source code, holds a forge token, and runs commands you
did not type.** A tool in that position that phones home has spent the only asset it has.

Worth a comment in the code saying it is permanent, because the next person to want it will look for the flag first.

### `PRIVACY.md`

What leaves the machine, in one page: **your prompts and code go to the provider you configured, and nothing goes anywhere
else.** Plus what Aeon stores locally and where.

That page is part of the five minutes — someone deciding whether to install this reads it before running anything.

### In CI (D13)

The trace runs in CI. **A network assertion nobody runs is a network assertion that stops being true** — the same reasoning
S22's O1 applied to its deletability build.
