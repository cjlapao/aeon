# T7 — The README and the four-step path

## Why this exists

**The README is the first thing a stranger reads**, and it is inside the five-minute budget.

Every sentence it contains is time spent. So the question is not *"what should someone know about Aeon?"* — it is **"what is
the shortest true path to a running loop, and what must someone know to walk it?"**

## Scope

### The path is four steps (D1's shape)

```
1. install       one binary
2. aeon init     pick a provider, paste a key
3. cd <a repo>
4. aeon step "…"   or   aeon loop start "…"
```

**Anything a tester has to do beyond those four is time this slice spent badly.** If the README needs a fifth step, the
fifth step is a finding about whichever slice made it necessary — not something to document more clearly.

### No step requires reading another document (D-check)

A path whose step three says *"see CONFIGURATION.md"* is a path that takes twenty minutes.

Links belong **after** the path, for the reader who wants more — never inside it. `QUICKSTART.md` exists for the same reason
and holds the same four steps with slightly more detail, so the README can stay short without the detail being lost.

### Every command in it works, verbatim (D-check)

Asserted by a test that extracts every fenced command from the README and runs the runnable ones.

**A README command that does not work is worse than an absent one**, because someone types it and then distrusts everything
after it. And a README drifts silently — nothing else in a repository is so often edited by someone not running it.

### What the README says about what this is

Short, and honest about the shape:

- **What it is**: a coding platform that runs a declared sequence of model steps against a repository, with a human at the
  gates.
- **What is different**: the method is data, not prose. The loop asks rather than guessing. Costs are reported honestly,
  including when unknown.
- **What it needs**: one binary, one API key. A local model works with no key at all (S18).
- **What it does not do**: no telemetry, no account, no auto-update (T6, N2, N3).

**The last one belongs in the README** rather than only in `PRIVACY.md`, because a stranger deciding whether to install a
thing that reads their source code is deciding about that.

### Not the design

The README links `docs/aeon/` for anyone who wants seventeen slices of reasoning. **It does not summarise them.** A README
that explains the architecture is a README that a stranger reads instead of running the thing.

### Not in scope

`doctor` (T8) and the measurement (T9). This task produces the path; T9 measures whether it works.

someone who did not run what they wrote, and a broken first command costs all the trust the rest of it was building.
