# T5 · Human-door writes, with candidate validation, audit, before/after, and agent-delete protection

**Prefix:** MG · **Rules:** MG1, MG5 (writes), MG6, MG7, MG13 · **Depends on:** T3.

## Goal

A person can add, update, remove, enable/disable servers; declare/revoke grants; narrow an agent's core set — over the socket,
as the human door. **Every** write validates the **whole candidate config** with the one validator, commits rows + audit in one
transaction, and returns the updated view plus the before/after **grants** for each affected agent. Also: deleting an agent that
MCP still references is refused **by name** (an adaptation of S43's merged delete path, S46's own change).

## Files

- `aeon/cmd/aeon/mcp_admin.go` (extend T3's) — the write operations: for each, `rows := currentRows; cand := rows.With(change)` (T2) →
  `mcp.Assemble(cand, IncludeDisabled:true)` (**the validator**; refusal sentence verbatim) → **before**: `GrantView` for every agent the
  change touches (via the registry built from the *current* enabled config) → one `McpWithTx` writing the rows + one `mcp_change`
  row → **after**: same, from the new rows → return. A failed validation writes nothing and no audit row.
- `aeon/internal/protocol/mcp_admin.go` (extend) — params/results and the eight handlers' write half:
  - `mcp.server.add {name, tier, agent?, transport{type,command,args[],env[],url}, tools[{name,rerun,effect}], enabled?}` — `agent` is a **slug** (required for `private`, forbidden for `public`); `env` entries are **names**; `enabled` defaults **true** for a user-added server (config presence = enabled today, MC3); the result carries `warnings` (e.g. unclassified tools: "N tools are UNCLASSIFIED and will be refused until classified (MC6)").
  - `mcp.server.update {name, transport?, tools?}` — whole-field replacement of the provided sections (no partial tool patches); renaming is **not** a thing (name = identity; to rename, add + remove); a system row refuses (MG10: edit refused; duplicate by `add`).
  - `mcp.server.remove {name, cascadeDeclares?: bool}` — refuses while any agent declares one of its tools, naming them, unless `cascadeDeclares:true` (then each revoke is listed in the result and audited as one `grant_revoke`).
  - `mcp.server.setEnabled {name, enabled}`.
  - `mcp.grant.declare {agent, qualified}` / `mcp.grant.revoke {agent, qualified}` — declare validates `qualified ∈` an existing **public** tool or the agent's own private tool (the validator's `validateDeclares`); revoke of an undeclared pair is `changed:false`.
  - `mcp.core.set {agent, core: string[]|null}` — `null` = the whole core set (MC distinct from `[]`); `validateCoreGrant`.
  Every result: `{ server?: ServerView, grants: [{agent, before: GrantView[], after: GrantView[]}], changed: bool, warnings: string[] }`.
  **Params never carry `actor`, `origin`, `id` or timestamps** (`DisallowUnknownFields`); the actor is `table.ActorFor` (unresolvable ⇒ `ErrMcpNoActor`, nothing written).
- `aeon/internal/protocol/method.go` — eight consts after T3's block; `RequiresInitialize`, not `Debug`, conditional on `Table.MCPAdmin`.
- `aeon/internal/protocol/errors.go` — `ErrMcpRefused` (carries the validator's sentence verbatim), `ErrMcpNoActor`, `ErrMcpInUse` (names the declaring agents).
- **Agent-delete protection (adapts S43's merged code — listed in Notes):** `internal/agentmgr`'s delete path (`DeleteAgentBySlug`, S43 AM4) gains MCP references to the set of things that block deletion — implemented as **one added accessor** `Store.McpReferencesFor(slug) ([]McpRef, error)` (T1) that `agentmgr` consults beside its existing blueprint/policy checks, and the refusal names every `mcp_server`/`mcp_declare`/`mcp_agent` reference. **No S43 behaviour changes** other than refusing in one more case; S43's tests pass unedited, with new tests in this slice's files.
- Contract chain: conformance cases, handshake block "S46 writes", fixtures (success + each refusal), `make protogen`.

## Behaviour notes

1. **Public means available, never granted-to-all (MC5):** adding a public server grants nothing; the result's `grants` for every agent is unchanged. A test asserts it.
2. **Private is invisible to peers (MC2):** adding a private server under agent A changes only A's `before/after`; no other agent's view changes (asserted for all agents).
3. **MG7 two-step:** `declare` does **not** author a policy allow; the result's `grants` shows the tool `unavailable` (MC10 sentence) until an allow exists — and the response's `warnings` says so in the validator-adjacent fixed wording. The UI offers the policy step (S45) separately.
4. **Atomicity:** rows + `mcp_change` in one transaction; **no audit row** for a refusal, a no-op (`changed:false`), a read or a dry-run.
5. **Live:** the next step offer and `mcp.status` reflect the write (T3).
6. **Summaries** are fixed templates from names/slugs only (`"added public server %s (stdio, %d tools)"`), never raw user text (SEC-033) and never an env value.

## Notes

Built. The engine is `cmd/aeon/mcp_admin_writes.go` (router `mcpWrite` →
per-door judges → `runWrite`, the ONE place MG5's pipeline lives:
`rows.With(change)` + `mcp.Assemble(IncludeDisabled)` as the pre-Tx gate
with the validator's sentence VERBATIM, one `McpWithTx` for rows+audit,
before/after `GrantView`s, nothing written on refusal or no-op). The
protocol half (`internal/protocol/mcp_admin.go`) adds the seven typed
params/results, `RegisterMCPWrites()` (registered iff `MCPAdmin` is wired),
and `mcpWriteEdge` (identity-key refusal → decode → actor stamp: nil or
uid-0 ActorFor refuses with ErrMcpNoActor before the seam is reached).
`method.go` carries the seven names; the daemon calls
`table.RegisterMCPWrites()` beside `RegisterMCPImportFile()`; the CLI
router's seven cases share `mcpWrite`. Fixtures: seven success contracts
(conformance/mcp/server-add-ok … core-set-ok) + the handshake's exact set
grew +7; `make protogen && make check-protogen` clean.

Deviations, all deliberate:

1. **Identity params**: the protocol package's law forbids
   `DisallowUnknownFields` (types_test asserts nothing may call it), so
   instead of a decode-time shape error the edge runs
   `rejectMCPIdentityKeys` — sixteen named keys (actor/actorKind/actorId/
   origin/id/status/createdBy/acceptedBy/…_at family) refuse with
   ErrBadParams quoting the key (MG5). `rejectIdentityKeys` (S45's list)
   is NOT extended — its sentence serves proposals, whose params
   legitimately carry `id`. "New name ⇒ shape error" is satisfied the
   structural way: the update params have NO rename field, so identity
   churn cannot be expressed (the test pins the name never moves; rename
   remains add + remove).
2. **Transport type pre-check** (`stdio`/`http`, closed vocabulary) runs
   before the validator's candidate gate — the validator checks the
   transport's grammar, not its type; its sentences still answer verbatim
   for everything else.
3. **Remove's candidate gate** validates the CASCADE shape
   (`With(RemoveServer{Cascade:true})`) because `With`'s non-cascade
   refuses-with-declares would pre-empt this door's TYPED ErrMcpInUse —
   the spec's refusal (naming every declaring agent, pass
   cascadeDeclares:true to mean it) is enforced HERE; silent revoke stays
   impossible both ways.
4. **Before/after views run over the include-disabled candidate** (T2's
   law: the filtered view is not New-able; `mcp.New` re-validates). MG4's
   drop from the OFFER stays at the dial seam — so a disable write's
   after-view still lists the declarations' truth, which is exactly
   "declarations STAND"; the step seam filters at offer time (T6/T9).
5. **Agent deletion**: `McpReferencesFor` (T1, pinned) reports the agent's
   own `mcp_agent` row unconditionally, but a BARE row (core NULL = the
   whole-core default) is not a live reference — it leaves with the agent
   via the new `store.McpAgentDeleteTx`; a real narrowing (core NOT NULL),
   owned servers and held declarations all refuse and are named. S43's
   AM4 halves are untouched; `TestS43AgentTestsUnchanged` is honored by
   running `./internal/agentmgr/` and the store's agent suites UNEDITED
   and green (their own files are the test).
6. **Unclassified tools vanish from the grant view** — T3's capability-
   list law (unclassified never reach `ToolsFor`); MC6's named refusal is
   the call door's. The test pins not-available, and the add result
   carries the fixed UNCLASSIFIED warning.
7. **Audit times** render through `mcpStamp` (RFC3339 UTC from the
   admin's clock) — one clock format across the MCP tables, shared with
   the importer.

agentmgr each green; the spec's `-race Mcp|Agent` five-package subset
green; the write/import tests pass under `-count=2` (per-test
