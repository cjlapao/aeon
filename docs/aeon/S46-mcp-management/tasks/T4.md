# T4 · Adopting the legacy file, and `mcp.importFile`

**Prefix:** MG · **Rules:** MG3, MG2, MG13 · **Depends on:** T3.

## Goal

An existing `mcp.json` is carried into the database **once, automatically, all-or-nothing, never silently** (MG3, a flagged product
call), and the explicit human-door `mcp.importFile` can re-import deliberately. After adoption the file is ignored at runtime and never
modified or deleted.

## Files

- `aeon/cmd/aeon/mcp_import.go` — **new**: `adoptLegacy(ctx, st, path) (AdoptResult, error)`:
  1. `path := paths.MCPConfigFile()`; absent ⇒ `no-file`, nothing to do.
  2. Read bytes; `sha := sha256`; `st.McpImportByHash(sha)` exists ⇒ `already-imported`, nothing to do (idempotent).
  3. Tables **non-empty** ⇒ `skipped: the database already has MCP configuration` + a `doctor` note (never merged silently).
  4. `mcp.LoadConfigFile`-equivalent parse + **`Validate`** (the one validator). Failure ⇒ `refused`: write **one** `mcp_import` row
     (`result='refused'`, `detail` = the validator's sentence incl. file path and field, ≤ 1024) and **nothing else**; the daemon starts at
     **level-0** and the sentence is logged and surfaced by `doctor`.
  5. Map each `Agents` key through `mapKey` (T3). **Any unresolvable agent refuses the whole import** (S43 T2's all-or-nothing), naming every
     unresolved key; rows are not partially written.
  6. One transaction: `Disassemble` → rows (`origin='import'`, `enabled=1`), one `mcp_import` row (`imported`, counts), one `mcp_change`
     row per server and one for declarations (`op='import'`, actor `{system,startup}` at start / `{user,<uid>}` via the method, summaries ids-only).
  The legacy file is **never written, renamed or deleted**.
- `aeon/cmd/aeon/serve.go` — call `adoptLegacy` at the point T0 recorded (after migrations and agent seeding, **before** loops are
  accepted), logging one line: `mcp: adopted N servers from <path>` / `mcp: legacy file refused — <sentence>` / nothing for `no-file`.
- `aeon/internal/protocol/mcp_admin.go` (extend) — `mcp.importFile {path?, mode}` (**human door**): `mode ∈ ("dry-run","replace")`; `dry-run` returns
  the diff (servers/tools/declares added/removed vs the current rows, env **names** only) and writes nothing; `replace` replaces **all**
  `mcp_*` rows (never a merge) in one transaction with before/after grants for every agent affected, an `mcp_import` row and `mcp_change` row;
  default `path` = the legacy path; any path must be absolute and a regular file (`ErrBadParams` otherwise); the actor comes from `table.ActorFor`.
- `aeon/cmd/aeon/doctor.go` — one `mcp` line: `mcp: database authoritative (N servers)` / `legacy file differs from what was imported (aeon mcp import-config --dry-run)` /
  `legacy file refused at <date>: <sentence>` / `no MCP configuration (level-0)`. Never prints an env value.
- Tests beside, fixtures from S12's `testdata`.

## Behaviour notes

- A file edited **after** adoption is reported by `doctor`, **not** re-imported (the database is authoritative); only `mcp.importFile replace` re-imports.
- The adoption path and `mcp.importFile` share **one** function; the startup path calls it with actor `system:startup` and `mode:replace` only when the tables are empty.
- No credential: the file's `env` entries are names (validated); if a parse yields a value-shaped entry the validator refuses the whole file.

## Definition of done

- [x] A valid file is adopted once at start (audited, slug-mapped); invalid/unresolvable refuses everything, named, level-0, never silent.
- [x] The file is never modified (inode/mtime/bytes pinned); `doctor` reports drift without re-importing; `mcp.importFile` dry-run writes nothing, replace is one transaction or none.
- [x] Behaviour identical before/after (seeded-rows vs adopted-file status byte-identical); fixtures +2, handshake exact-set +6, `contract.ts` regenerated (`make protogen && make check-protogen` clean).

## Do NOT

- Do not merge into existing rows; do not partially import; do not rename/delete/edit the file; do not accept an actor or origin in params.
- Do not start with a silently empty config when the file is invalid; do not print an env value.
