# T1 · The MCP tables, the audit and import ledger, and the store's SQL half

**Prefix:** MG · **Rules:** MG1, MG2, MG3 (ledger), MG13 · **Depends on:** T0 (FK feasibility, trigger parsing, error block). Parallel-safe with T2.

## Goal

Persist the MCP configuration as rows, an append-only audit, and an import ledger — SQL only in `internal/store` (I2). The database is
a **net beneath** `Config.Validate`, never the validator.

## Files

- `aeon/internal/store/migrations/<14-digit>_mcp_tables.sql` — **new** (timestamp from `date +%Y%m%d%H%M%S`, after the newest file; no `schema.go` edit).
  ```sql
  -- S46 T1: MCP configuration as records (design MG1). The existing mcp.Config.Validate stays THE validator (run on the assembled candidate before every write); these constraints are the net beneath it. Agents are referenced by slug (S43). env holds variable NAMES only (C17). mcp_change is append-only by trigger; mcp_import is the adoption ledger for the legacy JSON file (MG3).
  CREATE TABLE mcp_server (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    name           TEXT NOT NULL CHECK (length(name) BETWEEN 1 AND 64 AND name NOT GLOB '*[^a-z0-9_-]*' AND name GLOB '[a-z]*'),
    tier           TEXT NOT NULL CHECK (tier IN ('public','private')),
    agent_slug     TEXT REFERENCES agent (slug) ON DELETE RESTRICT,
    transport_type TEXT NOT NULL CHECK (transport_type IN ('stdio','http')),
    command        TEXT NOT NULL DEFAULT '',
    args           TEXT NOT NULL DEFAULT '[]' CHECK (json_valid(args)),
    env            TEXT NOT NULL DEFAULT '[]' CHECK (json_valid(env)),
    url            TEXT NOT NULL DEFAULT '',
    enabled        INTEGER NOT NULL DEFAULT 1 CHECK (enabled IN (0,1)),
    origin         TEXT NOT NULL DEFAULT 'user' CHECK (origin IN ('system','user','import')),
    created_at     TEXT NOT NULL,
    updated_at     TEXT NOT NULL,
    CHECK ((tier = 'public') = (agent_slug IS NULL))
  );
  CREATE UNIQUE INDEX idx_mcp_server_name ON mcp_server (name);
  CREATE INDEX idx_mcp_server_agent ON mcp_server (agent_slug);
  CREATE TABLE mcp_server_tool (
    server_id INTEGER NOT NULL REFERENCES mcp_server (id) ON DELETE CASCADE,
    name      TEXT NOT NULL CHECK (length(name) BETWEEN 1 AND 128),
    rerun     TEXT NOT NULL DEFAULT '',
    effect    TEXT NOT NULL DEFAULT '',
    PRIMARY KEY (server_id, name)
  );
  CREATE TABLE mcp_agent (
    agent_slug TEXT PRIMARY KEY REFERENCES agent (slug) ON DELETE RESTRICT,
    core       TEXT CHECK (core IS NULL OR json_valid(core))   -- NULL = the whole core set; '[]' = none (distinct facts)
  );
  CREATE TABLE mcp_declare (
    agent_slug TEXT NOT NULL REFERENCES agent (slug) ON DELETE RESTRICT,
    qualified  TEXT NOT NULL CHECK (instr(qualified, '.') > 1),
    PRIMARY KEY (agent_slug, qualified)
  );
  CREATE TABLE mcp_change (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    op          TEXT NOT NULL CHECK (op IN ('server_add','server_update','server_remove','server_enable','server_disable','grant_declare','grant_revoke','core_set','import','seed')),
    server      TEXT, agent_slug TEXT, qualified TEXT,
    summary     TEXT NOT NULL CHECK (length(summary) BETWEEN 1 AND 1024),
    actor_kind  TEXT NOT NULL CHECK (actor_kind IN ('user','cli','system')),
    actor_id    TEXT NOT NULL CHECK (length(actor_id) BETWEEN 1 AND 256),
    occurred_at TEXT NOT NULL
  );
  CREATE INDEX idx_mcp_change_server ON mcp_change (server, id);
  CREATE TRIGGER mcp_change_no_update BEFORE UPDATE ON mcp_change BEGIN SELECT RAISE(ABORT, 'mcp_change is append-only (S46 MG1)'); END;
  CREATE TRIGGER mcp_change_no_delete BEFORE DELETE ON mcp_change BEGIN SELECT RAISE(ABORT, 'mcp_change is append-only (S46 MG1)'); END;
  CREATE TABLE mcp_import (
    id INTEGER PRIMARY KEY AUTOINCREMENT, path TEXT NOT NULL, sha256 TEXT NOT NULL CHECK (length(sha256) = 64),
    result TEXT NOT NULL CHECK (result IN ('imported','refused')), detail TEXT NOT NULL CHECK (length(detail) <= 1024),
    servers INTEGER NOT NULL DEFAULT 0, imported_at TEXT NOT NULL
  );
  CREATE UNIQUE INDEX idx_mcp_import_hash ON mcp_import (sha256) WHERE result = 'imported';
  ```
  Notes the SQL cannot say: the names match `Config.Validate`'s grammars *or are looser by design* (a test pins "SQL accepts ⊇ validator accepts"); a
  `mcp_server_tool` row with empty `rerun`/`effect` is **UNCLASSIFIED** (MC6) — stored as `''`, never defaulted to a safe-looking class;
  `agent` FKs are `RESTRICT` so deleting a referenced agent fails (T5 makes the refusal **named**); no FK from `mcp_change` to anything (history outlives rows).
  Fallbacks if T0 found: FK to a unique index unsupported ⇒ trigger-enforced reference with the same refusals; trigger bodies unsupported ⇒ S44 T1's no-update/delete-accessor + grep test.
- `aeon/internal/store/mcp.go` — **new**, SQL only, parameterised; plain structs (`McpServerRow`, `McpToolRow`, `McpAgentRow`, `McpDeclareRow`, `McpChange`, `McpImport`):
  `McpRows(ctx) (McpAll, error)` (everything in one consistent read tx), `McpServerGet`, `McpAddServerTx/UpdateServerTx/RemoveServerTx`, `McpSetEnabledTx`,
  `McpDeclareTx/RevokeTx`, `McpCoreSetTx`, `McpChangeInsertTx`, `McpChangeList(ctx, server, agent, limit)` (newest first, clamp [1,500], default 50),
  `McpImportInsertTx`, `McpImportByHash`, `McpIsEmpty(ctx) (bool, error)`, `McpWithTx(ctx, fn)` (the store's existing read-then-write idiom — VERIFY, do not invent another).
- `aeon/internal/store/mcp_test.go`.

**Deviation, recorded (T1.md's own rule — a test the spec named demanded it).** `args`/`env` carry `CHECK (json_valid(…) AND json_type(…) = 'array')` and `core` `CHECK (core IS NULL OR (json_valid(core) AND json_type(core) = 'array'))` — the spec SQL had `json_valid` alone, which accepts an object; `TestMcpEnvIsJSONArrayOfNamesOnly` ("a non-array refused") cannot pass without `json_type`, and a JSON object in `env` is shape the validator could only refuse later, which is exactly what the net beneath it is for. Looseness is preserved the other way: `TestMcpServerNameChecksAreNoStricterThanValidator` inserts 12 names `serverNameRE` accepts (up to 64 chars) — the net accepts every one.
