3. **Adoption drill** — a real S12 fixture `mcp.json` with private + public servers → first start adopts it; `mcp list`/`mcp.status`/`tools.grants` equal the file-era goldens; restart ⇒ no second import; edit the file ⇒ `doctor` drift line, no re-import.
4. **Refusal drills** — an invalid file; a file naming an agent that does not exist → both start at level-0 with the named sentence, zero `mcp_*` rows.
