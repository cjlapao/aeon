# T8 · Agent tools: own-view reads and narrowing-only proposals

**Prefix:** MG · **Rules:** MG8, MG9, MG13 · standing rule 2 · S38 OL2/OL3/OL10 · MC2 · **Depends on:** T3, T7. Parallel-safe with T9–T11.

## Goal

Agents can **see their own MCP situation** and **propose to narrow it** — nothing else. Five catalog specs (one definition, two doors); every read is
**scoped to the calling agent** by construction (MC2: private is invisible to peers, so even error text must not reveal another agent's servers); the
two writes only create inert proposals that can only reduce. Registered, granted to no one by default.

## The five specs (`internal/records/catalog.go`, additive; families `mcp`)

| Tool | Socket twin | Class | Mutates | Scope / what it does |
| --- | --- | --- | --- | --- |
| `mcp_servers` | `mcp.mine.servers` (new) | safe | no | The servers **this agent** may use: its private servers + the public servers it declares tools from; transport summary (env **names**), tools with classes |
| `mcp_grants` | `mcp.mine.grants` (new) | safe | no | **This agent's** grant view: each tool's S12 state (`available/unavailable/refused/ask`) with the reason sentence |
| `mcp_status` | `mcp.mine.status` (new) | safe | no | Reachability of **this agent's** servers from the **cached** probe; never triggers a probe |
| `mcp_propose_remove_server` | `mcp.mine.proposeRemove` (new) | detectable | **yes** | Create an **inert** proposal to remove a server **this agent can see** (kind `mcp_server_remove`); reason required |
| `mcp_propose_revoke_grant` | `mcp.mine.proposeRevoke` (new) | detectable | **yes** | Create an **inert** proposal to revoke **a grant this agent holds** (kind `mcp_grant_revoke`); reason required |

The socket twins are namespaced `mcp.mine.*` so a grep and the T7 guards can tell the **agent-scoped** doors from the person's unscoped `mcp.servers/grants`.

## Rules (each a test)

1. **Identity is stamped, never named.** Schemas are `additionalProperties:false` and contain **no** `agent`, `agent_slug`, `actor`, `source`, `status`, `kind` field; the
   daemon resolves "self" from the stamped agent identity (OL3). A param naming another agent is a **parse error**.
2. **MC2 by construction:** handlers call `Registry.ToolsFor(self)` / `GrantView(self)` / `Availability(self, …)`; they never call the unscoped assembly. A test plants a private server
   `secret-b` for agent B and asserts **A's every response, error and audit row byte-excludes** `secret-b`, its tools and any count that would reveal it (including "N servers" totals and
   "unknown server" suggestions — nearest-name hints are drawn from **A's view only**).
3. **Proposals narrow only:** `mcp_propose_remove_server` is valid only for a server in A's own view (a public server A declares, or A's private); proposing removal of an invisible server is
   refused as "no such server" (not "not yours" — that would confirm existence). `mcp_propose_revoke_grant` requires the pair to be currently declared **by A**. Neither can name a different
   agent. Payloads go through `desk.Validate` (T6) — the same function create and commit use. A per-agent limit of **20 open proposals** (named constant) and ≤ 8 KiB.
4. **No tool adds, declares, enables, imports, edits or commits.** (T7 asserts the registry and catalog; this task adds the positive list.)
5. **No probe from a tool**: `mcp_status` reads the cache the person's `mcp.status` reads; it spawns nothing (spy).
6. **Env values never appear** (names only); descriptions ≥ 40 chars; counted `TestRegistryExactNames` bump (**+5**, from T0's recorded count; dated comment); **not** in `DefaultGrant()`.

## Definition of done

- [ ] Five specs with twins; parity green; schemas identity-free.
- [ ] MC2 proven on every output path including errors, hints and counts; narrowing-only proposals, inert, limited.
- [ ] No tool writes config; not granted by default; registry bump counted; T7's guards green with the new specs.

## Do NOT

- Do not add a param naming an agent; do not add a tool that adds/declares/enables/imports/commits; do not probe from a tool.
- Do not draw hints, counts or errors from outside the caller's own view; do not echo an env value.
- Do not add the five to `DefaultGrant()`; do not give `internal/records` an import.
