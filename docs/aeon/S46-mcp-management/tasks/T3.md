# T3 · The admin seam; every reader switches from file to rows, byte-identically; the read methods

**Prefix:** MG · **Rules:** MG2, MG4, MG5 (reads), MG11, MG12, MG13 · MC11 · **Depends on:** T1, T2.

## Goal

The database becomes the source of truth **for every existing reader**, with output **byte-identical** to the file-based behaviour, and
the five new read methods exist. Done **characterization-first** (T0's reader inventory is the work order). `internal/daemon` and
`internal/protocol` still import no `internal/mcp`; `cmd/aeon` remains the only importer.

## Phase A — characterize (commit first, green on untouched code)

`aeon/cmd/aeon/mcp_golden_test.go` + `testdata/mcpgolden/*`: for each S12/S34/S36 fixture config, with the config supplied **as a file**,
record exactly: `aeon mcp list` (and `--agent`, `--include-refused`), `mcp.status`, `mcp.check` against a stub server, `tools.grants`
per agent, and the step-offer bundle (`MCPBundle`/`MCPWithheld`) for each agent. Record the Phase A commit in Notes.

## Phase B — the change

- `aeon/cmd/aeon/mcp_admin.go` — **new** (the one `internal/mcp` importer; extends the existing seam files):
  `type mcpAdmin struct{ st *store.Store; mapKey func(slug string)(string,bool); now func() time.Time; … }` with
  `currentConfig(ctx, includeDisabled bool) (mcp.Config, error)` = `store.McpRows` → slug→key mapping → `mcp.Assemble`.
  **Every** existing reader in T0's inventory (`loadMCPConfig`, `loadCurrentMCPConfig`, the `mcp_seam.go`/`mcp_services.go` sites,
  `proposal.go`'s effect inputs) calls `currentConfig` — **no remaining read of the file** outside T4's importer (a grep test).
  When the tables are empty it returns `mcp.ErrNoConfig`-equivalent so the **level-0 words** (`mcpAbsentLines`) print unchanged.
- **Registry lifecycle (MG12):** if T0 found `mcp.New` runs once, change **when** it runs: per step offer (cheap — it is a pure
  function over an assembled config) or on a monotonically bumped `mcp_version` read at each offer. Characterized first; the choice is recorded.
- `aeon/internal/protocol/mcp_admin.go` — **new**: the func seam `Table.MCPAdmin func(ctx, method string, params json.RawMessage) (any, string, error)`
  (the `Table.MCP` pattern: dispatch by method name bound at **registration**; `ErrNotWired` when nil, V13: methods absent when nil),
  params/result types, handlers. **Reads in this task:**
  - `mcp.servers {tier?, agent?, enabled?, origin?}` → `{servers: ServerView[]}`; `ServerView{name, tier, agent, transport{type, command, args, url, envNames[]}, tools[{name, rerun, effect, classified}], enabled, origin, declaredBy int, status?, updatedAt}`. `status` is joined from the **same probe cache** `mcp.status` reads (never triggers a probe); absent ⇒ `"unprobed"` (a distinct state).
  - `mcp.server {name}` → `{server: ServerView, declaredBy: [agent…], changes: […last 20]}`; unknown ⇒ typed refusal naming the nearest names.
  - `mcp.grants {agent}` → `{agent, core: string[]|null, declares: string[], grants: GrantView[]}` — **S12's `GrantView` verbatim** for any agent (the person's view, MG8), unknown agent ⇒ named refusal.
  - `mcp.vocabulary {}` → transports, `rerun`/`effect` vocabularies (taken from `mcp`'s constants and `internal/tools`' re-run classes, **not restated**), grammars as regexp **strings** from the validator's own variables.
  - `mcp.changes {server?, agent?, limit?}` → `{changes, statement?}` (`statement` = "no MCP configuration changes recorded." only when empty).
  `mcp.status`/`mcp.check`/`tools.grants` keep their shapes and now read rows.
- `aeon/internal/protocol/method.go` — the five consts + a labelled block, `RequiresInitialize`, not `Debug`, conditional on `Table.MCPAdmin`.
- `aeon/internal/protocol/errors.go` — `ErrMcpUnknown` (+ block from T0); contract chain: conformance cases, handshake block "S46 reads", fixtures (success + `mcp-unknown`), `make protogen`.
- **MC2 note for the person's reads:** these are human-door reads (unscoped by design). The agent-scoped reads are T8's tools and are a **different code path** (`ToolsFor(self)`); a test asserts no tool handler calls these.
