## Behaviour

**Servers tab.** `mcp.servers` (filters sent as params, daemon-side). Row: name, tier pill (`public`/`private` + owner via the picker's display), transport summary (`stdio: command args…` / `http: url`, **env names** as chips — never values), tools with `rerun`/`effect` pills and an **UNCLASSIFIED** warning chip (MC6: "refused until classified"), `enabled` switch, `origin` badge (`System`/`User`/`Import`), live status dot from `status` (`unprobed` is its own grey state), **Probe** button = `mcp.check` for that server (single-flight per S34 TB8 is the daemon's; the button disables while busy). Empty store ⇒ `EmptyState` with the level-0 sentence the daemon sends ("no MCP servers configured. tools available: the core nine only (S11)") — **the daemon's text, not UI prose**.
**Drawer** (`mcp.server`): full transport, every tool with classes, who declares what, audit for the server (`mcp.changes {server}`), actions: Edit, Remove, Duplicate (system rows: Edit hidden — "to change a shipped server, duplicate it", daemon-sent), Enable/Disable.
**Form** (add/edit) built from `mcp.vocabulary`: transport select, command/args (stdio) or URL (http), **env names** input (each entry validated against the daemon-sent grammar; an entry containing `=` or whitespace is refused client-side with the line "enter the variable's name — values come from the daemon's environment"), tool rows (name + `rerun` select + `effect` select, **no default** — an empty class is shown as UNCLASSIFIED, never preselected to a "safe" value, MC6), tier + owner (`AgentPicker`, required for private). Submit ⇒ `mcp.server.add/update`; a refusal shows the validator's sentence **verbatim** under the form and **keeps the draft**.
**Remove:** confirm naming the server, its declaring agents (from `mcp.server`) and the before/after grants; if declared, the confirm offers `cascadeDeclares` as an explicit second checkbox (default off); result shows the `grants` before/after verbatim.

**Grants tab.** Pick an agent (`AgentPicker`) ⇒ `mcp.grants`: core set (`null` rendered as "whole core set" — distinct from "none"), the declared list, and the S12 `GrantView` list — each tool a row with the state pill (`available/ask/unavailable/refused`) and the **reason sentence verbatim** (MC10's "no allow" sentence included). **The two-step grant flow (MG7):** *Declare* (`mcp.grant.declare`, confirm showing before/after) → the response's grants usually shows `unavailable (no allow)`; the UI then offers **"Allow in policy…"**, which opens S45's authoring form **prefilled** (`tool_access`, target = the agent, tool = qualified name, action `allow`, source `operator`) and goes through S45's own confirmation — **never a hidden combined call**. *Revoke* (`mcp.grant.revoke`) with confirm. *Core set* editor (`mcp.core.set`; "use the whole core set" ↔ `null`).

**Proposals tab.** S45's proposals desk filtered to kinds `mcp_server_add`, `mcp_server_remove`, `mcp_grant_revoke`: preview, the "proposed by an agent" badge, commit/reject via S45's generic methods with the before/after confirm; reject needs a reason.

**Audit tab.** `mcp.changes` newest first; fixed-template summaries; no free text rendered as HTML.

**Import tab.** Legacy file status from `mcp.changes`/`doctor`-equivalent data (`mcp.importFile {mode:"dry-run"}` shows the diff: servers/tools/declares added/removed, env **names** only); **Replace** requires a confirm that names the counts and says "replaces all MCP configuration"; result shown. A `refused` adoption (T4) is shown as a warning with the daemon's sentence.

**Cross-cutting.** `live.state !== 'current'` ⇒ writes disabled with the kit affordance; reads show last data; after any write the affected rows/cells are replaced from the **response**, never optimistically; no `localStorage` for MCP data; no `fetch`; i18n parity; no new dependency.
