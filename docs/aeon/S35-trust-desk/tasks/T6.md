## Reality finding — TD10(b)'s "scan handler files for `Exec(`/`INSERT INTO`/`UPDATE`" would find nothing,
because `internal/protocol` never contains SQL

Verified this session (and by T3/T4's own task files, written earlier in this slice): `internal/protocol`
handlers never execute SQL directly. They call through package-local interfaces (`ProposalStore`,
`StepStore`, `QuestionStore` — the pattern `internal/daemon` wires with small adapters like `stepStore`) or
through `daemon.Options` func-seams (`Table.Agents`, `Table.AgentTransition`, S34's `Table.MCP`). The actual
`INSERT`/`UPDATE` text lives in `internal/store/*.go` and in `cmd/aeon`'s seam implementations — **not** in
any file a "scan `internal/protocol/` for `Exec(`" pass would ever touch. Scanning for that pattern there
would pass trivially and prove nothing — a false sense of coverage is worse than an honest gap.

**The real, checkable version of "the only socket-reachable write is on `proposal`"**: enumerate every
**write** method in the registered table (`RequiresInitialize: true`, not read-only, not `Debug` —
`VERIFY` how reads are currently distinguished: S34/S35's new reads may need a `ReadOnly`-style marker if
`Method` doesn't already carry one cleanly, since `agentServicesCall`'s entries use `ReadOnly: true` on
`AgentServiceMethod`, a *different* struct from `protocol.Method` itself — confirm which one the dispatcher
actually gates on before writing the scan), then grep each write method's handler body / seam-implementation
file for calls into write-shaped functions, and assert that set is exactly:

```
{ CreateProposal, DiscardProposal,            // T1/T3 — this slice's own table
  moveVerb (or its extracted core), plugin.Revoke,   // T4 — pre-existing, unwidened
  SaveConfig }                                       // T4 — this slice's one new config writer, CLI-reachable only via T5
```

`DecideProposal`, the corpus-insert functions, and any raw `mcp.json` write **must not** appear reachable
from any *socket* handler — they are reachable only from `cmd/aeon/proposal.go`'s `commit`/`reject` (T5),
which is not socket code at all. Write this amendment plan into `../design.md` TD10 in this task's commit,
replacing the "`Exec(`/`INSERT INTO`" scan with the enumerate-and-allow-list approach above.
