## Goal

## Do NOT

- Do not add this method to the narrow surface (`internal/narrow/actions.go` is a closed action set, S19): `loop.message`/`loop.run`/`loop.close` are socket-only human doors. If a narrow-surface test enumerating methods fails, the method was registered there by mistake.
- Do not hand-register a method the catalog already projects (outcome B) — it panics.
- Do not return a Go error for a domain refusal (not-idle, requires-unmet, invalid blueprint, unknown link): they are `refused` data so the app can render the daemon's own words.
- Do not start a run when `requires:` is unmet, and never create the `loop_run` row before the check.
- Do not wrap `loop.run` in an `ask`: a human peer is the confirmation (CR4); the `ask` belongs to the agent tool (T10).
- Do not change `loop.start`'s behavior or fixtures; do not set `loop.attended`.
- Do not bump `PROTOCOL_VERSION` (new methods, new optional fields, new event kind).
