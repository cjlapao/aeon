# T8 · Engine: `StartRun` — a second blueprint in an idle loop

**Prefix:** CR · **Rules:** CR2, CR6, CR7 · D4, D7 · **Depends on:** T2, T4, T7 · **Contract:** [`../brief.md`](../brief.md) · [`../design.md`](../design.md)

## Goal

Add `loop.StartRun`: from an `idle` loop, validate and pin a blueprint as run N+1, write the run's first message, and set the loop `running` — atomically and without touching attendedness. Steps created during a run are tagged with its `run_seq`. No socket method yet (T9).

- Read `aeon/internal/loop/pin.go` lines 30-127 (`Start`) and `continue.go` lines 12-26 (`MarkStepStarted`).

## Steps

1. Refactor `pin.go` with no behavior change. Cut everything in `Start` from `path, err := blueprint.Resolve(name)` down to and including the `futureHandlerRefusal` check into:
   ```go
   // pinSource resolves, loads and validates a blueprint exactly as loop start does, and returns its parsed form and raw bytes.
   func pinSource(name, mode string) (blueprint.Blueprint, []byte, error)
   ```
   (it uses `mode` where `Start` used `in.Mode`). `Start` becomes: `bp, raw, err := pinSource(name, in.Mode)`; then the rest unchanged (`initial := InitialState(bp)` …). Run `go test ./internal/loop/...` — it must pass **before** you continue (`pin_test.go` pins every refusal).
2. Add to `pin.go`:
   ```go
   // PreviewBlueprint validates a blueprint for a run without pinning it (requires checks, the run options list).
   func PreviewBlueprint(name, mode string) (blueprint.Blueprint, error) { bp, _, err := pinSource(name, mode); return bp, err }
   ```
3. `store/runs.go`: add `func (s *Store) SetRunKickoff(loopID string, runSeq int, messageID int64) error` — `UPDATE loop_run SET kickoff_message_id=? WHERE loop_id=? AND run_seq=?`; zero rows → `ErrNotFound`. Test `TestSetRunKickoffLinksTheMessage`.
4. `loop/continue.go`, `MarkStepStarted`: immediately before the final `return save(dep, st)` insert
   ```go
   if run, err := dep.Store.CurrentRun(id); err == nil {
       if err := dep.Store.SetStepRun(stepID, run.RunSeq); err != nil { return err }
   } else if !errors.Is(err, store.ErrNotFound) {
       return err
   }
   ```
   (add `errors` and `store` imports as needed). A loop with no run row (old fixtures) keeps working.
5. Create `loop/run.go`:
   ```go
   type RunRequest struct {
       LoopID, Blueprint string
       StartedByKind, StartedByID string // user | agent | trigger
       GoalID string; GoalVersion int; TaskID string
       With  map[string]string
       Typed string                // a first message a person typed; "" = use the template/default
       Data  blueprint.KickoffData // what the template may name
       Route string                // "" = inherit the loop's current route
   }
   type RunStarted struct {
       Run     store.Run
       Kickoff store.ChatMessage // zero when the run has no first message
   }
   func StartRun(ctx context.Context, s *store.Store, req RunRequest) (RunStarted, error)
   ```
   Body, in this order — **claim before write**:
   1. `pin, err := s.ReadPinnedLoop(req.LoopID)`; if `pin.Loop.Status != StatusIdle` return `fmt.Errorf("loop %s is %s: %w", req.LoopID, pin.Loop.Status, store.ErrLoopNotIdle)`.
   2. `bp, raw, err := pinSource(req.Blueprint, pin.Loop.Mode)`; return the error as is (`PinRefusal` keeps its kind).
   3. `prev, err := FromPinned(pin)`; `initial := InitialState(bp)`; `initial.Route = orDefault(req.Route, prev.Route)` (write a 3-line local `orDefault`); copy `req.With` into `initial.With`.
   4. `text, source, err := KickoffFor(&bp, req.Data, req.Typed)`; `initial.Kickoff = text`.
   5. `state, err := (LoopState{RuntimeState: initial}).RuntimeJSON()`.
   6. `run, err := s.BeginRun(req.LoopID, store.NewRun{Blueprint: bp.ID, Version: bp.Version, Content: string(raw), StartedByKind: req.StartedByKind, StartedByID: req.StartedByID, GoalID: req.GoalID, GoalVersion: req.GoalVersion, TaskID: req.TaskID}, state)`.
   7. If `text != ""`: `sc := store.Scope{LoopSlug: pin.Loop.Slug, ProjectRoot: pin.Loop.ProjectRoot}`; `msg, err := s.Note(sc, store.NewChatMessage{Author: KickoffAuthor(source), Kind: "note", Body: text, Source: source})`; then `s.SetRunKickoff(req.LoopID, run.RunSeq, msg.ID)`. A failure here returns the error **but the run already exists** — the saved state carries the text, so the run still works; document this in the function comment.
   8. Return `RunStarted{Run: run, Kickoff: msg}`.
   It must never write `loop.attended` and never call `CreatePinnedLoop`.
6. Nothing starts the runner here; the caller does (`d.loopRunner.Start`, T9).
