# T4 · Engine: the resting state (`idle`) and `loop.close`

**Prefix:** CR · **Rules:** CR1, CR9, CR10 · D1, D9, D11 · **Depends on:** T2, T3 · **Contract:** [`../brief.md`](../brief.md) · [`../design.md`](../design.md)

## Goal

A blueprint with `after: converse` ends its run with the loop `idle` (no `loop.finished`, one `loop.run.finished`); every other blueprint ends `done` exactly as today. `loop.close` moves `idle` to `done`. Recovery and startup leave an idle loop alone.

2. Create `loop/rest.go`:
   ```go
   package loop

   import (
       "errors"
       "github.com/cjlapao/aeon/internal/blueprint"
       "github.com/cjlapao/aeon/internal/store"
   )

   const StatusIdle = "idle"

   // endStatus is what a walk that has run out of lanes writes. An abort stays terminal (CR1);
   // after: converse rests; everything else is today's `done`.
   func endStatus(bp *blueprint.Blueprint, aborted bool) string {
       switch {
       case aborted:
           return "aborted"
       case bp != nil && bp.After == blueprint.AfterConverse:
           return StatusIdle
       default:
           return "done"
       }
   }

   // runStateFor maps the loop's final state to the loop_run state.
   func runStateFor(st LoopState) string {
       switch {
       case st.Status == "aborted":
           return "cancelled"
       case st.Flags["run-failed"]:
           return "failed"
       default:
           return "done"
       }
   }

   // emitIfOver settles the run row and publishes the end-of-walk event. Call it AFTER save(). It is a no-op
   // unless st.Status is done, aborted or idle. Absent run rows (old fixtures) and an already-ended run are ignored.
   func emitIfOver(dep Deps, st LoopState, id string) error { ... }
   ```
   `emitIfOver` body, in order: (a) `switch st.Status { case "done","aborted","idle": default: return nil }`; (b) `raw, err := st.RuntimeJSON()`; (c) `run, err := dep.Store.CurrentRun(id)` — `errors.Is(err, store.ErrNotFound)` means skip the run bookkeeping, other errors return; (d) `err = dep.Store.EndRun(id, run.RunSeq, runStateFor(st), raw)` — ignore `store.ErrRunNotRunning`, return others; (e) if `st.Status == StatusIdle`: `cost, _ := dep.Store.RunCost(id, run.RunSeq)` and `emit(dep, "loop.run.finished", map[string]any{"loopId": id, "runSeq": run.RunSeq, "outcome": runStateFor(st), "status": StatusIdle, "cost": cost})`; else `emit(dep, "loop.finished", map[string]any{"loopId": id, "status": st.Status})` — **this payload must stay byte-for-byte what the code emits today** (`{"loopId","status"}`).
