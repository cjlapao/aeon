## Steps

1. `types.go`: add to `Blueprint` (after `OnAbort`):
   ```go
   // After says what a finished run leaves behind (S39 CR1). "" and "finish" are today's behavior: the loop is done.
   // "converse" leaves the loop idle with the conversation open.
   After    string `yaml:"after,omitempty" json:"after,omitempty"`
   // Converse names the agent that answers messages once a run has ended; empty takes the daemon default (CR3).
   Converse string `yaml:"converse,omitempty" json:"converse,omitempty"`
   // Kickoff is a text/template rendered into the run's first message (CR6).
   Kickoff  string `yaml:"kickoff,omitempty" json:"kickoff,omitempty"`
   ```
   and `const ( AfterFinish = "finish"; AfterConverse = "converse" )`. The loader refuses unknown keys by itself (`KnownFields(true)`); a new tag needs no loader code.
2. Create `kickoff.go`:
   ```go
   package blueprint

   import "text/template"

   // KickoffData is everything a kickoff template may name. Unknown fields are refused at validation.
   type KickoffData struct {
       Goal, Task, Component, Project string
       Params                         map[string]string
   }

   // ParseKickoff parses a kickoff template. missingkey=zero: an absent Params entry renders empty.
   func ParseKickoff(src string) (*template.Template, error) {
       return template.New("kickoff").Option("missingkey=zero").Parse(src)
   }
   ```
   (`T7` adds `RenderKickoff` to this file. Do not add it now.)
3. `validate.go`, in `Validate`, immediately after the `if b.OnAbort != "" { … }` block, add (use the local `add` closure and `r.ValidCount++` exactly as the neighbors do):
   ```go
   switch b.After {
   case "", AfterFinish, AfterConverse:
       if b.After != "" { r.ValidCount++ }
   default:
       add(Invalid, "after-value", "after", fmt.Sprintf("after must be %q or %q, got %q", AfterConverse, AfterFinish, b.After), "")
   }
   if b.Converse != "" {
       if b.After != AfterConverse {
           add(Invalid, "converse-without-after", "converse", "converse names the agent that talks after a run; it needs after: converse", "")
       }
       switch {
       case contains(opts.Agents, b.Converse):
           r.ValidCount++
       case contains(futureAgents, b.Converse):
           add(Unverifiable, "agent-registry", "converse", "agent body not shipped — S13 named it a follow-up (no body file in the registry)", "S13")
       default:
           add(Invalid, "unknown-agent", "converse", fmt.Sprintf("unknown agent %q", b.Converse), "")
       }
   }
   if b.Kickoff != "" {
       if tpl, err := ParseKickoff(b.Kickoff); err != nil {
           add(Invalid, "kickoff-template", "kickoff", err.Error(), "")
       } else if err := tpl.Execute(io.Discard, KickoffData{}); err != nil {
           add(Invalid, "kickoff-field", "kickoff", err.Error(), "")
       } else {
           r.ValidCount++
       }
   }
   ```
   Add `"io"` to the imports. A resolver name (`by-tech-tag`) is NOT a valid `converse:` value — the code above deliberately does not check `opts.Resolvers`.
4. Write the docs subsection (step 1 of Files), 6-10 lines: the three keys, the defaults, "an older daemon refuses a blueprint that uses them (unknown key)".
5. No shipped blueprint changes, so no `version:` bump and no `pristineUpgrades` entry. Do NOT add the keys to any file in `internal/blueprint/blueprints/`.
