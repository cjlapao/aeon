# T6 · `loop.message` and the conversation turn

## Goal

A message sent to an `idle` loop starts a conversation turn: one model step by the loop's conversation agent, streamed, steerable and recoverable like any step; a message while a step is running is refused with the `step.steer` remedy. The shipped `brainstorm` blueprint now rests after its run, so the whole path can be walked.
