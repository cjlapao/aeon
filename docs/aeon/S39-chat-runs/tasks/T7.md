# T7 · Kickoff renderer and the run's first message

**Prefix:** CR · **Rules:** CR6 · D7 · **Depends on:** T6 · **Contract:** [`../brief.md`](../brief.md) · [`../design.md`](../design.md)

## Goal

A blueprint's `kickoff:` template renders from goal/task/component/project/params into a run's first message, and that text — whether typed by a person or rendered — becomes the `Goal:` line the model sees. Typed and templated starts give byte-identical model input.

- Read `aeon/internal/loop/advance.go` lines 420-470 (`modelPrompt`) and `loop/state.go` lines 1-60 (`RuntimeState`).

## Steps

1. Write the golden test FIRST (before editing `modelPrompt`): in `loop/kickoff_test.go`, `TestModelPromptGoldenForALoopWithNoKickoff` builds `st := LoopState{Goal: "G", Position: Position{Lane: "only"}, RuntimeState: RuntimeState{...}}` and a `blueprint.Step{ID:"only", Kind: blueprint.ModelStep, Agent:"default", Produces: blueprint.Paths{"OUT.md"}}`, then `got := modelPrompt(st, step)`. Run it once with `want := ""`, copy the actual output into a `const wantPrompt = "…"`, and commit that constant. It must pass **before and after** your edit.
2. `blueprint/kickoff.go`: add (imports `strings`):
   ```go
   // RenderKickoff renders a kickoff template. An empty source renders as "" (no kickoff). The result is trimmed.
   func RenderKickoff(src string, d KickoffData) (string, error) {
       if strings.TrimSpace(src) == "" { return "", nil }
       tpl, err := ParseKickoff(src)
       if err != nil { return "", err }
       var b strings.Builder
       if err := tpl.Execute(&b, d); err != nil { return "", err }
       return strings.TrimSpace(b.String()), nil
   }
   ```
3. `loop/state.go`: add to `RuntimeState`, beside `With`: `Kickoff string \`json:"kickoff,omitempty"\`` with the comment "the current run's first message; empty for a run that was not given one — modelPrompt then uses Goal exactly as before".
4. `loop/kickoff.go`:
   ```go
   package loop

   // KickoffFor picks the run's first message and says where it came from (store.ChatMessage.Source values).
   //  1. typed (a person wrote it)            -> (typed, "user")
   //  2. the blueprint's kickoff: template    -> (rendered, "template")
   //  3. no template: the goal and/or task body -> (body, "template")
   //  4. nothing to say                        -> ("", "")
   func KickoffFor(bp *blueprint.Blueprint, d blueprint.KickoffData, typed string) (text, source string, err error)

   func goalText(st LoopState) string { if st.Kickoff != "" { return st.Kickoff }; return st.Goal }
   ```
   Case 3 body: `strings.TrimSpace(d.Goal + "\n\n" + d.Task)`; when only one is set, just that one trimmed.
5. `advance.go` `modelPrompt`: replace `b.WriteString(st.Goal)` (the line right after `b.WriteString("Goal: ")`) with `b.WriteString(goalText(st))`. Nothing else in the function changes.
6. Helper for who wrote it (used by T8): add to `loop/kickoff.go`
   ```go
   // KickoffAuthor maps a source to a chat_message author: a person's typed or templated start is theirs; automation is the system's.
   func KickoffAuthor(source string) string { if source == "automation" || source == "blueprint" { return "system" }; return "human" }
   ```
