### Revised panel model — 2026-10-30

The user replaced the original list-carousel model with separate temporary pickers and persistent context panels. The implementation now uses `picker?: ChatPanel` for a singular overlay, and `panels?: readonly ChatPersistentPanel[]` for compact expandable context. Up to two persistent panels render directly; three or more use an expandable StackCarousel. The single task slot remains independent. The historical implementation notes below describe the first version only.

`ChatComposer` now exposes `specialKeys` (default `/`, `@`, `$`) and `onSpecialKeyChange({ key, query, start, end } | null)`. The host supplies results. Escape and whitespace dismiss; Escape suppresses the current token until the user moves to another token. IME completion, pasted text, custom keys, and cursor movement are handled. `AgentChat.onPickerDismiss` supports explicit close and Escape within the dock. The demo maps keys to skills/prompts, files, and agents, filters queries, and exposes persistent goal/queued-message/context examples.
