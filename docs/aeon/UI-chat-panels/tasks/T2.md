# T2 — Loop human-interaction index API

Provide a loop-level rail for all durable human interactions: initial goals, messages, steers, answers, approvals/rejections, commands, and other host-defined actions. Index metadata must not require retaining full loop history in memory. This task builds presentation and host-loader APIs only, with no daemon/database changes.

## Notes — 2026-10-31

Implemented `ui/src/components/agent-chat/MessageIndex.tsx`, `messageIndex.css`, and `useMessageIndex.ts`, integrated through optional `AgentChat.messageIndex` / `ChatStream.messageIndex` and exported from the public index. README documents types, lifecycle, host integration, and backend work still needed.

Opaque loop-scoped anchors and optional target ChatItem IDs keep human chat-message IDs distinct from agent transcript cursors. The host supplies human-only metadata, kind labels, and optional cached response excerpts. Marker pagination is independent of ChatItems. Hover/focus cards perform no fetch. Buttons expose accessible names/current state and tooltip descriptions. An agent-filtered view omits the loop-wide rail; read-only loop history retains it.

Loaded targets scroll locally and highlight. Missing targets call `onRequestJump` with configurable before/after counts (20 each by default, each clamped 0–100) and AbortSignal. The host replaces its bounded items/cursors and resolves a rendered target ID. The stream waits for DOM availability, with a 10-second unavailable-target error. New jumps, loop changes, and unmount abort old work; stale completions are ignored. Hosts must also honor the signal before committing their own controlled items.

Indexed navigation suppresses live following and automatic older-history loads. Return to latest restores the host's tail through `onRequestLatest`, waits for its rendered target, and resumes following. A local-only index can omit loaders. Remote history without a latest loader produces an explicit error rather than silently treating an old window as the live tail. Continuous adjacent-window paging and backend/live-history merging remain host-owned.

Added `ui/message-index-demo.html` and `ui/src/demos/message-index.tsx`. Fixture: 108 conversation records, 36 human markers; initial live tail 24 records and first metadata page 12 markers. Loaders simulate bounded ranges and cancellation, not RPCs. No workspace/backend integration was added. Existing loop.transcript reads step_message rows and is not a unified human-interaction index; a future backend integration needs a durable human index and anchored conversation-window read.
