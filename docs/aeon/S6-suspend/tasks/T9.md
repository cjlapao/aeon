## Context

Every test in this slice runs in one process against a fake client. T6 does the most any test can — a fresh object
graph — and it is still one process. **Nothing automated has waited an hour, or survived a daemon restart while
waiting.**

Which is why this walk has two requirements the others did not:

- **Answer a suspension after restarting the daemon.**
- **Answer one after at least an hour**, having done something else in between.

Both are recorded. The first proves nothing is held in the daemon's memory; the second proves nothing is held in a
timer or a lease that quietly expires.

**§1's `pgrep` check is the one a walker will skim**, and it is the whole difference between Aeon and every tool
that keeps a session in a process. If anything is running after a suspension, the slice has not landed regardless
of what else works.

**§6 demonstrates compaction by what it records**, because the thing it prevents is a failure you never see. The
three checks inside it — head sections intact, cost increased, signature unchanged — are what make it a
demonstration rather than a claim, and they are the parts most likely to be skipped for flow.

**Read first:** `DEMO.md` in full; both suites as they stand; the brief's §2.
