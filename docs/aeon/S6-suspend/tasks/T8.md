# T8 — The CLI: `aeon answer`, suspension display, `--compactions`

**File(s):** `aeon/cmd/aeon/answer.go`, `aeon/cmd/aeon/step.go`, `aeon/cmd/aeon/answer_test.go`
**Engineer:** golang-engineer-loop · **Tech:** go · **Depends on:** T7 · **Est. changed lines:** ~250

## Context

The part a person touches, and its job is to make a suspension look like a **normal resting state** rather than a
failure.

A step that stops and prints nothing useful reads as a hang. So a suspension prints the question, the options if
there are any, and **the exact command to answer it** — because the person reading it has just watched their
terminal stop and needs to know that is correct.

**`--compactions` exists because compaction is otherwise invisible.** The thing it prevents is a failure nobody
sees, so the only way to demonstrate it is to show what it recorded: the replaced range, the estimate before and
after, and the summary the model wrote.

**The resumed cost line must include the resume and any compaction.** A step that cost more than its visible model
calls, with no explanation, reads as a billing bug. Showing the compaction as a line is what O2 recorded the usage
separately for.

**Read first:** `cmd/aeon/step.go` (S5 T11); `internal/protocol/answer.go` (T7); S3's cost-line renderings, which
this extends rather than replaces.

## What to do

**1. Suspension display** in `step.go`. When the step suspends:

```
  ▸ question  Which approach?  [in-place | new-table]

suspended · waiting for you
  answer with:  aeon answer 8b1e4c
```

The step id, verbatim and copy-pasteable. Not "see `aeon step list`".

**2. `answer.go`** — `aeon answer <stepId> <answer>`. When the question had options, **validate the choice** and
list them again on a mismatch rather than passing an invalid value through: the model asked for one of a set, and
a value outside it is a question answered with something else.

An **empty** answer is valid (O5) — `aeon answer <id> ""` passes through. Make that possible rather than treating
an empty argument as a usage error.

**3. On resume**, stream the continuation as `step` does, and display the **changed-file note** when there is one:

```
step 8b1e4c  ·  resumed
  ⚠ README.md changed while this step was waiting
```

**4. The cost line** on a resumed step names the resume and any compaction:

```
cost  $0.0043 (known) · 1 resume · 1 compaction (+$0.00062)
```

**5. `step show --compactions`** — the replaced range, the estimate before and after, and the summary text.

**6. Errors in three parts**, so "answering twice" says what happened, what it means and what to do.

**7. Tests against a real in-process daemon on a temp store.** Assert the copy-pasteable command by capturing
stdout and checking it contains the literal step id.
