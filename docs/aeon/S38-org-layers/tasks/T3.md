## Steps

1. `gopls rename` the exported protocol/daemon identifiers (`ProjectStore`→`ComponentStore`, …) the same way as T2 step 2; then do JSON tags `projectRoot`→`componentRoot` with `sed` **restricted to the files listed**.
2. **Component methods**: constants `MethodComponentCreate = "component.create"`, `…Update`, `…List`; handlers are the old project handlers renamed (decode → validate → store → view). `ComponentView` adds `projectId`, `shortDescription`, `description`, `defaultBranch`, `branchPrefix`.
3. **Group methods**: `project.create {name, shortDescription?, description?, iconEmoji?, iconImage?}`, `project.update {id, …}`, `project.list {}` → `{projects: ProjectView[]}`, `project.show {id}` → `{project, components: ComponentView[]}`. Errors: reuse `ErrBadParams`, `ErrStoreUnavailable.WithWhat(...)`; an unknown id is a domain refusal the way `project.update` refuses today (copy it).
4. Register all in `NewTable` (method.go ~:485) — `register` panics on duplicates, so remove the old three first.
5. Write fixtures (hand-written JSON, shape `{"description","method","request","response"}`), **one success fixture per new method**; put every optional field in at least one fixture (protogen derives `?:` from absence).
6. Add the `case` lines to `paramsTypeFor`/`resultTypeFor`.
7. Bump the version constants and fix the tests/fixtures that pin `1`.
8. `make protogen` (from `aeon/`) → commit `ui/src/proto/contract.ts`. `make check-protogen` must pass.
