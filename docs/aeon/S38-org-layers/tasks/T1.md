## Steps

1. **List the tables that carry the scope column.** Against a fresh store run:
   `SELECT m.name FROM sqlite_master m JOIN pragma_table_info(m.name) p WHERE m.type='table' AND p.name='project_root' ORDER BY 1;`
   (in a throwaway Go test or `sqlite3` on `$XDG_STATE_HOME/aeon/state.db`). Paste the list as a comment above `migration0035`; the `ALTER` lines in step 3 must cover **exactly** that list.
2. **Rename the group tables** (rename, never DROP — a DROP of a referenced parent fires `ON DELETE CASCADE`, see `TestTheNaiveDropParentWouldHaveDestroyedTheChildren`, schema_test.go:1584):
   ```sql
   ALTER TABLE project RENAME TO component;
   ALTER TABLE project_root RENAME TO component_root;
   ALTER TABLE component_root RENAME COLUMN project_id TO component_id;
   DROP INDEX idx_project_remote_key;  CREATE INDEX idx_component_remote_key ON component (remote_key);
   DROP INDEX idx_project_repo_key;    CREATE INDEX idx_component_repo_key   ON component (repo_key);
   DROP INDEX idx_project_root_project; CREATE INDEX idx_component_root_component ON component_root (component_id);
   ```
3. **Rename the scope column** on every table from step 1, plus the roots table's own key column:
   `ALTER TABLE component_root RENAME COLUMN project_root TO component_root;` then one `ALTER TABLE <t> RENAME COLUMN project_root TO component_root;` per table. (SQLite rewrites the composite FKs `(project_root, loop_slug) REFERENCES loop(project_root, slug)` and the indexes; the test in step 8 proves it.)
4. **Component gains the spec's fields:**
   ```sql
   ALTER TABLE component ADD COLUMN short_description TEXT NOT NULL DEFAULT '';
   ALTER TABLE component ADD COLUMN description       TEXT NOT NULL DEFAULT '';
   ALTER TABLE component ADD COLUMN default_branch    TEXT NOT NULL DEFAULT '';
   ALTER TABLE component ADD COLUMN branch_prefix     TEXT NOT NULL DEFAULT '';
   ```
5. **Create the new group tier:**
   ```sql
   CREATE TABLE project (
     id TEXT PRIMARY KEY, name TEXT NOT NULL,
     short_description TEXT NOT NULL DEFAULT '', description TEXT NOT NULL DEFAULT '',
     icon_emoji TEXT, icon_image TEXT,
     implicit INTEGER NOT NULL DEFAULT 0 CHECK (implicit IN (0,1)),
     created_at TEXT NOT NULL, updated_at TEXT NOT NULL,
     CHECK (icon_emoji IS NULL OR icon_image IS NULL)
   );
   ALTER TABLE component ADD COLUMN project_id TEXT REFERENCES project (id);
   INSERT INTO project (id, name, implicit, created_at, updated_at)
     SELECT 'prj-' || id, name, 1, created_at, updated_at FROM component;
   UPDATE component SET project_id = 'prj-' || id;
   ```
   (`project_id` stays nullable at the SQL level — SQLite cannot `ADD COLUMN … NOT NULL REFERENCES`. The store forbids NULL; T2 enforces it. T0-Q7's verdict on a later `NOT NULL` rebuild goes in Notes.)
6. Add the `{35, …}` list entry and the `migration0035` const.
7. Bump **all** the count assertions listed under *Files* (grep to confirm none was missed: `grep -rn '!= 34\|== 34' internal cmd --include=*_test.go`).
8. Write `org_layers_test.go` (below). Use the older-store recipe: `g, closeDB := rawGorm(t, path)`; `applyMigrations(t, g, Migrations()[:34])`; seed rows with `g.Exec`; `closeDB()`; `Open(Options{Dir: dir, Clock: fixedClock(), Env: emptyEnv})`.
