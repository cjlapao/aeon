# T13 · Start from a goal or task: GoalID, TaskID and requires

**Prefix:** OL · **Rules:** OL9 · criteria 10, 11 · **Depends on:** T11, T7, T6

## Goal

Let `loop.start` take an optional `goalId` and/or `taskId`, enforce the blueprint's `requires:` with a sentence, pin the goal version, link the loop, and seed the prompt from the goal. No `requires:` and no ids = today.

## Steps

1. **Evaluator (pure):**
   ```go
   type Candidate struct{ Kind, ID, Title, State string }
   type RequiresResult struct{ OK bool; Sentence string; Candidates []Candidate; Goal *store.Goal; Task *store.Task }
   func CheckRequires(bp *blueprint.Blueprint, goal *store.Goal, task *store.Task, offer func() []Candidate) RequiresResult
   ```
   Semantics: each `Requirement` is an `any_of`; ALL requirements must hold (AND of ORs). A goal satisfies `{goal, approved}` iff `ReviewState=="approved"`; a task satisfies `{task, approved}` iff `Manual && ApprovalState=="approved"`. Unmet → `Sentence` = `blueprint %q needs <terms joined by " or "> — none was given` and `Candidates = offer()` (approved goals/tasks in scope; bounded to 20).
2. **Daemon closure:** if `p.GoalID != ""` → `store.GetGoal`; refuse an unknown id with a sentence. If `p.TaskID != ""` → `store.GetTaskByID` (add a thin reader). Build `offer` from `store.ListGoals{ReviewState:"approved"}` + `store.ListTaskRows{Manual:true, ApprovalState approved}` filtered to the workspace's component/project.
3. On `!OK`: **no loop row is created**; return the sentence **and** the candidates in the error's data (use the existing domain-refusal shape, VERIFY with `errors.go`; the S39 dialogue reads this).
4. On OK with a goal: `links.GoalVersion = goal.Version`; `CreatePinnedLoop` writes `loop.goal_id`, `goal_version`; the prompt (`Goal`) is seeded from `goal.Title + "\n\n" + attached body` when `p.Goal == ""`, else `p.Goal` wins (the person typed something).
5. With a task: after the loop row exists call `LinkTaskToLoop(task.ID, scope, "worker")`.
6. Fixtures `loop-start-goal.json` (success), `loop-start-requires-unmet.json` (error with candidates); `make protogen`.

## Notes (2026-10-27)

* **No row before the check, in either direction:** unknown ids
  (`ErrStartLinkUnknown` -31613, naming the id) and unmet requires
  (`ErrRequiresUnmet` -31612, carrying the evaluator's sentence verbatim in
  `what` and the bounded candidates in `todo`) both refuse before any loop

  component (goals via its project, manual approved tasks via its id,
