## Steps

1. **CLI:** rename the flag to `--component` (help text `main.go:192`; default stays cwd). The flag means the component root path. `go build ./cmd/... && go test ./cmd/aeon/... -count=1`.
2. **UI compile-driven rename:** run `make -C ui typecheck` after step 3 and fix errors file by file. Wire field `projectRoot`→`componentRoot`; method `project.*`→`component.*` where a repo is meant.
3. **UI information architecture:** `features/projects/ProjectsScreen.tsx` lists **projects** (`project.list`); a project row opens its components (`project.show`). 5. Update `README.md` in `ui/src` and `UI-QA-DEMO.md`.
6. Tests: update existing; add `visibleLayers.test.ts` (below).
