# T7 · The socket surface and the human-door guard amendment

**Prefix:** CN · **Rules:** CN2, CN15, CN16, CN18, CN19 · P4 · P34 · **Depends on:** T5. Parallel-safe with T6 (the `stopAll` method waits for S55).

## Goal

The daemon's socket carries every scheduler operation — four reads and the human-door controls — each stamped with the peer, each absent from every
surface an agent or a remote caller can reach, and each guarded by **sibling** tests with canaries (S45 T6's method: add beside, never edit).

## Methods (`internal/protocol/continuous.go`, new; constants in `method.go`; registered with `t.register`)

Reads: `scheduler.status`, `scheduler.preview`, `scheduler.decisions`, `scheduler.attention`. Controls: `scheduler.enable`, `scheduler.disable`,
`scheduler.pause`, `scheduler.resume`, `scheduler.root.set`, `scheduler.root.disable`, `scheduler.enableTree`, `scheduler.stopAll` (T6). Roadmap edges:
`roadmap.depend`/`undepend` (T3). Local-interface seam `ContinuousAPI` on the `Table` (nil ⇒ every method absent, V13); params/views as CN18 and CN22:

- `scheduler.status` → `{enabled, paused, pausedReason?, settings: [{key, value, source}], slots: {used, cap}, nextTickAt, repos: [{componentRoot, rootId?,
  enabled, template{blueprint, tech?, with?}, window?, minPriority, lastStartAt?, state{kind, reason?, detail?}}], attention: {open: N}, statement,
  descriptor{priorityStates[], reasons[], windowGrammar, blueprintsFrom: "blueprint.list"}}` — **the descriptor is where forms get their vocabulary** (rule 4).
- `scheduler.root.set` validates CN5 at the door (blueprint exists/validates/ends, window pair, zone, `minPriority`) with the validator's own sentences verbatim;
  an invalid template is a typed refusal, never a stored row.
- One error block (≥ 4 contiguous from T0): `ErrSchedulerRefused` (reason in `what`, three-part `data`), `ErrSchedulerDisabled` (a control needing the master),
  plus the reads reuse `ErrStoreUnavailable`. Conformance fixtures per method, per refusal family.
- `table.ActorFor` supplies the actor for **every** control; params carry none (a test posts `actor` and expects a parse error).

## The guard amendment (P4)

`cmd/aeon/continuous_guard_test.go` — **new siblings, no existing body edited** (S45 T6 / S35 T6 method; if S45's `policy_amend_test.go` has merged, follow its helpers):

   methods is registered, each `RequiresInitialize`, **none** `Debug`, and with the service nil each is absent and `Dispatch` answers `ErrUnknownMethod`.
2. `TestSchedulerWritesNeverReachOtherSurfaces`, one subtest per door so a failure names which: `narrow.Actions()` names none of the sixteen; `narrow.BoundaryStatement()`
   lists none; `protocol.AgentServiceMethods()` none; `tools.Registry()` has no name matching `/scheduler_(enable|disable|pause|resume|root|stop)/`; `records.Catalog()` has

   non-test file under `internal/narrow`, `internal/agentsvc`, `internal/tools`, `internal/records`. Walks assert **≥ 50 files seen**.
3. `TestSchedulerGuardsHaveTeeth` — the canary: feed each negative predicate a synthetic violation (a fake `Action` projecting `scheduler.enable`; a fake `Spec` named
   `scheduler_enable`; a temp file under a fake `internal/tools` dir containing `"scheduler.pause"`) and assert each is reported.
4. `TestSchedulerRowsHaveNoNonPersonWriter` — the AU1 sibling: every write to `scheduler_state`/`scheduler_root` goes through `store.SetSchedulerState`/`UpsertSchedulerRoot`,
   whose only callers are the daemon's control handlers (call-graph walk), and no seed engine, trigger, event dispatcher or agent path calls them (S40 AU1 lock 3, extended).
5. `TestOnlyTheWorkerStartsWork` — the daemon's scheduler start function is the only writer of `scheduler_start`.
6. `aeon/AGENTS.md` §4 — **one row**: "The scheduler is an authority record (S27 CN2): controls are human-door socket methods, absent from the narrow surface, agent services, the tool registry and the records catalog (reads only); it is default-off, never seeded, and never inherits authority down the tree." Linked to the guards by name.
7. `docs/aeon/S40-automation/design.md` — **annotate, do not rewrite**, under AU1: *"Extended 2026-10-30 by S27 CN2: the scheduler's rows are authority records under the same three locks. See S27-continuous/design.md."* (A built slice's planning contract; **no S43/S44 file**.)
