## Behaviour (each a test)

1. An item with no edges is ready exactly when it is today (property test over T1's `IsReady` table).
2. An open dependency (any status but `done`) makes `planned→ready` and `roadmap.materialize` refuse with the sentence naming it.
3. A `cancelled` dependency makes the item **not ready with its own sentence**; the item is never silently stuck (the preview and the board read the same sentence).
4. A dependency completing (`done`) makes the item eligible on the next tick — **no** reactor writes a status for it (derived at the pick, D4: never cached).
5. Edges are same-repository only; a cycle of any length is refused naming the closure; self and duplicate refused.
6. An edge on a `done`/`cancelled` item is refused (history is not rewritten).
7. Removing an edge on a `running` item is allowed (it records intent only); the loop is untouched.
