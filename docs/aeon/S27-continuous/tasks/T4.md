# T4 · `internal/continuous`: the pure core, the preview, the property tests

**Prefix:** CN · **Rules:** CN1, CN5, CN6, CN8–CN12, CN15, CN26 · **Depends on:** T2 (types only). Parallel-safe with T3.

## Goal

Selection as a **pure function** — no SQL, no clock, no goroutine, no daemon import — so that every scheduling rule is a table-driven test and the
**preview is the tick**. This task ends with a package that, given a snapshot, returns the decisions a tick would make and the first failing reason
for every unit it did not start.

## Files (`aeon/internal/continuous/`, new package; imports `internal/trigger` for `StillGoing` and `Schedule.InWindow`, `internal/queue` and
`internal/roadmap` for status vocabularies — **nothing else internal**)

- `types.go` — `Snapshot{Now, Master{Enabled,Paused}, Settings{MaxSlots, MaxStartsPerRootPerHour, AgingHours}, Repos []Repo}`; `Repo{Root, RootID,
  Enabled, Template, Window, MinPriority, Occupying []LoopRef, QueueLive int, QueueHead *QueueUnit, Ready []RoadmapUnit, LastStart time.Time, StartsInHour
  []time.Time, Weight int, FirstDeferral map[SubjectKey]time.Time}`; `QueueUnit{ID, Attended *bool, AutonomyCap, ReadyRow…}`; `RoadmapUnit{ID, Priority,
  OpenDeps []Dep, AutonomyCap, Claimed bool}`; `Slots{Used}`; `Decision{Root, Subject, Verdict (start|defer|skip|refuse), Reason, Detail, Weight}`.
- `reasons.go` — the **closed reason vocabulary** of CN15 as typed constants with `Sentence(Detail) string` (ids and enums only) and `Reasons() []Reason`;
  a test asserts the doc table, the constants and the sentences agree.
- `plan.go` — `Plan(s Snapshot) []Decision`:
  1. master off / paused ⇒ every repository `skip` with `master-off`/`paused`; **nothing else is evaluated**.
  2. per repository: not enabled ⇒ `repo-off`; **occupied** (`trigger.StillGoing` over `Occupying`) ⇒ `repo-occupied` naming the loop and state (CN8);
     window closed ⇒ `window-closed` with the next open instant (CN10).
  3. candidate (CN6): queue head (skip if `Attended` is true ⇒ `attended-item`; if `AutonomyCap`… carried), else roadmap only when `QueueLive == 0`
     (else `queue-live`); roadmap eligibility: priority state ≥ `MinPriority` (`unknown` ⇒ `priority-unknown`, never "low"), not claimed
     (`already-claimed`), no open dependency (`dependency-open`/`dependency-cancelled`), `IsReady` facts present (`not-ready` with the missing facts).
  4. cross-repository order (CN11): aged first, then best priority state, then oldest `LastStart`, then `Root`.
  5. admission in that order (CN9): `Used + Weight ≤ MaxSlots` ⇒ `start` and `Used += Weight`; else `defer` `capacity`; `Weight > MaxSlots` ⇒ `refuse`
     `weight-exceeds-cap` (once — the caller de-dupes through the log); rate (`StartsInHour ≥ MaxStartsPerRootPerHour` ⇒ `defer` `rate-limit` with the
     instant the oldest start leaves).
  6. **one start per repository per tick** (a repository that started is not considered again).
  The seams the daemon fills (budget, grant) appear as snapshot **facts** (`BudgetOK bool, BudgetReason string`, `GrantAbsent bool`) computed by the
  adapter before `Plan` — keeping `Plan` pure; they yield `budget-exhausted` / `grant-absent` at step 3.
- `preview.go` — `Preview(s Snapshot) Report`: `Plan` plus, for every ready unit not started, its first failing reason (the **same** reason strings); a
  `WouldStart` list equal to `Plan`'s starts by construction.
- `window.go` — `Window` value → `trigger.Schedule{WindowStart, WindowEnd, WindowDays}` + `LoadZone` → `InWindow`; `NextOpen(now)` computed by stepping
  to the next window start (DST honesty comes from the same zone code).
- `clock.go` — `Clock`, `SystemClock` — **the only `time.Now` in the package** (counted by `TestNoTimeNowOutsideTheSystemClock`, the `trigger` precedent).
- `seams.go` — `Reader`, `Starter`, `Grants`, `Budgets`, `Stopper`, `Settings` interfaces (CN24) with doc comments naming the owning slice; **no
  implementation here**.
- `worker.go` — **T5** (kept out of the pure files so the purity tests can assert imports).

## Tests (`internal/continuous/*_test.go`; table-driven, deterministic, no I/O)

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestPlanTruthTable` | a ~60-row table over (master, paused, repo, occupancy state, window, queue head, attended, roadmap priority, deps, claimed, capacity, rate) → verdict + reason | any rule moves |
| `TestUnknownPriorityNeverStarts` (property, random snapshots) | no `start` for a unit with priority `unknown`, and it is **reported** `priority-unknown` | the silent-never-run failure S29 exists to prevent |
| `TestBlockedOrWaitingRepoNeverHasACandidate` (property) | any `blocked`/`waiting`/`running` occupant ⇒ no start for that repository | a blocked item restarted (brief §8) |
| `TestAtMostOneStartPerRepoPerTick` (property) | ≤ 1 | concurrent starts into one repository |
| `TestAttendedQueueItemIsSkippedNotStarted` | `attended=1` ⇒ `attended-item`; `attended=0` and `NULL` start (NULL = never declared ⇒ unattended is the scheduler's own pin) — **T0 confirms NULL's meaning in S24 D5/D6 before this row is final** | an attended declaration silently overridden |
| `TestRoadmapOnlyIntoADrainedRepository` | live queue rows ⇒ `queue-live`; occupied ⇒ `repo-occupied` | flooding or double work |
| `TestCapacityAdmissionOrderIsFairAndDeterministic` | the CN11 order across 5 repositories; identical for identical snapshots; aged first | starvation or nondeterminism |
| `TestWeightExceedsCapRefusedOnce` | `refuse` with the setting named | a forever-queued impossible unit |
| `TestRateBackstop` | the Nth+1 start in an hour defers with the leave-instant | an unbounded start rate |
| `TestWindowParityWithTrigger` | `Window` vs `trigger.Schedule.InWindow` over the same truth table incl. midnight span, weekday list, a DST transition | two windows |
| `TestPreviewIsPlan` | `Preview().WouldStart == Plan().starts`; every non-start has a reason | a preview that lies |
| `TestReasonVocabularyIsClosed` | each constant has a sentence, appears in design CN15's list (read from the doc fixture), and no sentence embeds free text | vocabulary drift or user text in a decision |
| `TestPackageIsPure` | `go/parser`: imports ⊆ {stdlib, `internal/trigger`, `internal/queue`, `internal/roadmap`}; no `database/sql`, no `time.Now` outside `SystemClock`, no `go ` statements | a core that cannot be tested |

## Commands

P10, `./internal/continuous/ -count=1 -race -v`; `go vet ./internal/continuous/`.

## Definition of done

- [ ] Pure core, closed reasons, preview equals plan; every property test green over ≥ 1,000 generated snapshots.
- [ ] Purity test enforced; one `time.Now`.

## Do NOT

- Do not import `internal/store`, `internal/daemon` or `internal/protocol`. Do not read a clock or a random source (properties use a seeded generator). Do not
  interpret a `BlockedReason.Kind` — the core never sees one. Do not give `Plan` a way to produce a start for a non-`ready` unit.

**Deviations (all deliberate, all mine):**

1. **Below-minPriority renders as `not-ready` with a detail sentence** ("priority assumed is below this repository\'s minPriority known"). CN15\'s vocabulary is closed at eighteen ids and none of them is "priority-low"; `priority-unknown` is reserved for genuinely-unknown (OD4\'s own words demand the distinction), and inventing a nineteenth id would break `TestReasonVocabularyIsClosed` against the doc line. The sentence still names both states, which is what OD4 asks a person to see.
2. **Seam facts refuse before admission:** budget-exhausted/grant-absent are step-3 facts about the candidate; capacity/rate are step-5 admissions. A repo whose candidate a seam refuses therefore never reaches the slot arithmetic — the spec\'s ordering (step 3 "yield at step 3" preceding step 5) read literally.
3. **Eligible-but-not-chosen units get no `Plan` row** (CN6\'s one-candidate rule makes a per-unit verdict undefined); `Report.Failing` derives their first failing reason — the repository blocker row if one exists, else repo-occupied naming the chosen subject when it starts, else the candidate\'s own deferral/refusal. `TestPreviewIsPlan` walks every ready unit of 1,200 generated snapshots and fails on silence.
4. **The `queue-live` row is emitted at repository level also when the queue head itself was skipped** (attended, non-ready, or seam-refused) while `QueueLive > 0` and roadmap units are waiting — otherwise those units would inherit the head\'s personal reason, which is not their own blocker.
5. **The seam interface is `SettingsReader`, not `Settings`** — `Settings{MaxSlots,…}` is the snapshot struct the spec names in the same package; Go allows one. The doc comment records the spec name.
6. **`NextOpen` scans each day at five-minute resolution** (≤ 9 days) instead of stepping start-to-start: when the DST transition *eats* the nominal start (spring-forward through 02:15, say), arithmetic on the wall clock names an instant that does not exist; the scan names the first instant that is really inside the window — the transition itself. `TestNextOpenNamesTheRealInstant` pins exactly that 2026-03-08 America/New_York case.
7. **Truth table is 46 rows, not ~60** — every dimension the spec\'s column list names (master, paused, repo, five occupancy states, window, head, attended ×3, priority ×3, deps claimed/missing, capacity, weight, rate ×2, aging ×2, round-robin, tie, determinism ×20-runs, silence) is covered; row count differs, coverage does not.
