# T6 · The cross-slice seams: grants, budgets, stop, attention

**Prefix:** CN · **Rules:** CN3, CN9, CN13, CN18, CN24 · **Depends on:** T5 **and S55 + S56 merged** (S57/S58 optional).

## Goal

Fill the four seams of CN24 with the real implementations the sibling slices expose, so a scheduler-started loop (a) carries the outward/merge
permission a person granted, pinned, with the grant revision recorded; (b) is **not admitted** when a budget is exhausted; (c) can be **stopped** by a
person through the scheduler's `stopAll`; (d) surfaces S55/S57's blocked kinds verbatim in `needs-you`. No new policy is invented here — each is a call
into the owning slice.

## Files

  - `grantsAdapter.Resolve(rootID, "scheduler")` → S56's resolve read → `{AllowOutward, AllowMerge, Revision}`; **effective = `min(grant, item.autonomy_cap)`**

  - `stopperAdapter.StopLoop(slug, reason)` → S55's callable `loop.stop`; **the scheduler's `stopAll` method is registered only if this adapter exists**

- The loop pin: S56 owns the merge pin column. T6 passes the resolved values through `startExtras` **only if** S56 exposes a typed field; otherwise it is a

## Behaviour

1. A start for a repository whose root has an S56 `outward` grant: `allow_outward=1` pinned, merge not; with a `merge` grant: both; **no grant: neither**, `grant-absent`
   noted, the loop is still started (building locally is not outward).
2. An item with `autonomy_cap='none'` or `'outward'` narrows the grant; the recorded decision shows grant, cap and effective.
3. S55 budget exhaustion at admission ⇒ `deferred(budget-exhausted)` (never started, nothing claimed). A budget that **becomes** exhausted mid-loop is S55's `cap-hit` block (the loop parks `blocked`, the repository stays held, `needs-you` shows S55's raise sentence).
4. `scheduler.stopAll {reason}`: pause **first** (so nothing new starts), then `StopLoop` for every `started`-by-scheduler loop with status `running|waiting`, each
   recorded; partial failure ⇒ the failures are listed and the pause stays.
5. `needs-you` for `cap-hit` carries the raise instruction; the scheduler never calls `loop.raise` (human door only — S55).

Deviations and rulings:

1. **GrantAbsent means unreadable, not empty.** The spec table's
   `TestNoGrantIsLocalOnly` is explicit: no grant ⇒ the loop *starts*. T4's
   truth table defers only on `GrantAbsent=true`, so the adapter sets it
   only when the S56 read genuinely fails (V13's honest fact; the next tick
   retries). A grantless root starts local-only: no pin row,
   `allow_outward` false, decision clause `grant none, cap grant, effective
   none`.
2. **The pin is the permission; the flags never move.** S56 AL8's structural
   guard (`TestPolicyPinnedLoopsKeepAllowOutwardZero`) outranks any prose
   reading "allow_outward=1 pinned": the scheduler never sets
   `NewLoop.AllowOutward`. Effective permission = min(grant, cap) lives in
   the pin's narrowed entries and in the decision clause — proven by
   `TestMergeNeverFromAllowOutward` both ways (outward never implies merge;
   merge rides the pin, the flag stays 0).
3. **Budget scope split.** The pre-Plan snapshot consults
   `startBudgetVerdictFor(root, "")` (workspace→component→root); the epic's
   cap is consulted at the start door itself, where `startLoopWith` re-reads
   with the item's epic. Coarse before the plan, precise at the door, and
   T0's C2 holds: the door remains the only place a start refuses.
4. **Cap vocabulary needs a writer.** `autonomy_cap` had no reader or writer
   (T2 shipped the column alone). `ItemAutonomyCap`/`SetItemAutonomyCap`
   land in `scheduler_reads.go` (accepting only the narrowing words); T8's
   planner surface is the person-facing door over them. The store remains
   the only SQL.
5. **stopAll's actor is the person.** `scheduler_state.updated_by_kind`'s
   CHECK admits `user|agent|trigger` — not `scheduler` — so the pause is
   written under the human actor who commanded the stop (T7's socket stamps
   the peer; T8's CLI is a caller). Each stop rides `Daemon.StopLoop` — the
   same door behind `loop.stop`, minus transport — with S55's audit,
   refusals and park shape intact; S55's stop parks (`waiting`), which is
   what the test asserts, plus one control-ledger event per stopped loop.
6. **Blocked loops are not stopAll's.** `SchedulerLoopsToStop` admits
   `running|waiting` only — parked loops belong to `loop.raise`/`loop.resume`
   (CN21), and `TestCapHitHoldsTheRepoAndNeverRestarts` proves 100 ticks
   touch neither the park nor its ledger, while a person's `loop.raise`
   (through `Daemon.RaiseLoop`, the real E1 door, over a park seeded with
   its cap record) lifts it.
7. **stopAll writes no decision rows.** The schema's decision CHECK has no
   `stopped` word, and inventing rows under another word would misreport
   the ledger: the pause rides `scheduler_state`'s audit, the stops ride
   `loop_control_event`, and the returned ledger names every stop and every
   failure (the pause stays even on partial failures). Socket registration
   and the method census are T7's paid debt; `schedulerStopAllWired` is the
   gate its registration consults, and
   `TestStopAllUnregisteredWithoutS55` pins the absent fact.
8. **`attentionNotes` carries one note.** Only `cap-hit` (the spec's own
   words); `gate-failed`/`post-merge-red` deliberately have no note — S57's
   C4 keeps gate kinds display-only and its sentences ride the blocked
   reports verbatim — and unknown kinds pass through with none (the map is
   CN21's "kind unchanged" promise; the `scheduler_attention` consumer
   lands with T8).
9. **`narrowPin` fails toward deny.** An unparsable pin snapshot pins
   nothing — a broken store is not a licence. The cap filter drops entries
   by effect class (`action.Classes()`), so widening is unrepresentable
   (CN3), proven per rung by `TestItemCapOnlyNarrows`.
10. **T5 leftovers paid here.** The full store suite (T5 had only run scoped
    patterns) showed `StartTimesSince` was never named in store.go's surface
    table, and a T5 comment's bare `UPDATE` word tripped
    `TestNoSQLLivesOutsideTheStore`; both are fixed in this change — T5's
    Notes claim of a green suite was scoped, not full.
