## Why this exists

V10 requires embedding cost to report through the three-state `Cost`, because *"indexing a large repository costs real
money, and it must be visible on the same path as everything else."*

S18 already built that path. **So V16 makes an embedding model a route** (M12) rather than a parallel provider integration
— which means the cost states, the unmetered case, the provenance and the capability model are all inherited rather than
rewritten.

## Scope

### It is a route (V16, M12)

**Answer Q5 first**: does S18's route type accommodate an embedding model, or does it assume a chat model?

**If it assumes chat, say so** — the fix is to generalise the route, not to build a second provider path (I8, N9). A
parallel path would mean two places computing cost, two places holding a key, and two notions of what a provider is.

```
aeon route add openai-small --kind openai --model text-embedding-3-small --price-per-million 0.02
aeon route add local-embed  --kind openai-compatible --base-url http://127.0.0.1:11434/v1 \
                            --model nomic-embed-text --no-price
```

### Cost, inherited (V10, D11)

Three states, from S18. And **an unmetered embedding route is `unknown` with a reason** (M30) — a local embedding model has
no price Aeon knows, and `$0.00` would be a claim.

The indexing summary reports it on the same path as everything else, which is V10's whole point.

### Dimension and model id are recorded (V6)

Stored **in the index**, so T8 can detect a mismatch. Recording them is this task's; refusing on mismatch is T8's.

### A failure mid-index does not restart it (O5)

**The indexed portion stands**, the failure is recorded per chunk, and a retry **resumes**.

*A large index that must restart on any failure is one that never completes on a flaky connection* — and an embedding pass
over a large repository is exactly where a flaky connection shows up.

### Batching

Embedding calls are batched, because per-chunk calls over thirty thousand chunks is a rate-limit problem and a cost
problem. A partial batch failure records per chunk, per O5.

### Not in scope

Reindex triggering and asynchrony (T8). Mismatch refusal (T8). The corpora (T4, T5).
