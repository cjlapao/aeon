# T9 — Walk the demo, amend the QA suite

## Why this exists

A slice is not done when its tests pass. It is done when someone who did not build it can follow `DEMO.md` and watch the
thing work (§14).

**And this demo begins by taking the slice away**, which is unusual and deliberate.

## Scope

### Walk every section, starting with §1

**§1 removes the slice before showing what it does.**

```
make build TAGS=noretrieval
make test
aeon tools list
```

**`make test` must pass** — not "pass with skips" — and `search` must be **absent from the tool list.**

That ordering is the point. **An empty result is a claim about the repository.** A handler that searches for *"where is the
retry policy"* and gets nothing reasonably concludes there isn't one and moves on. A handler with no `search` reaches for
`grep`, which is what V5 wanted anyway.

**If `search` exists and returns empty, the slice is not done** — that is a capability answering unhelpfully, which is worse
than one that is legibly not there.

**§2's `transcripts SKIPPED` line must appear**, and it is not an apology. `step_message` holds **tool output no redaction
pass has seen.** Confirm the reasoning is legible to whoever walks it: the rule is *what stood between the content and the
index*, not sensitivity in the abstract.

**§3 is the differentiator, and its second half is what matters.** A manifest showing `retrieved` with its query and score
is useful. **Suspending and resuming and getting an identical manifest** is what proves K13's freeze survived contact with
retrieval — and if a resumed step re-resolved, it could get a different context from the one that suspended.

**§5 must refuse and price, not answer or spend.** Both halves: answering across two embedding spaces gives *"plausible,
wrong results — the worst failure a retrieval system has"*, and reindexing unasked spends real money.

**§6 measures step timings with a reindex running.** Unchanged, and staleness reported **per corpus**.

### Amend the QA suite

**Never rewrite. Amend.** `docs/test_suites/aeon-retrieval.md` — **check its numbering first**, and read it.

Expect its existing cases to have been written when the extension was a `.so` on the user's machine. Anything about
**loading an extension, or an `extension-missing` state, is now impossible** — S4's DB18 statically links it. Mark those
cases corrected, naming S25, rather than deleting them: someone arriving from the earlier design will look for the load
step.
