# T2 · Pure helpers: `Describe`, the vocabulary, the next-fires wrapper, the match tester, the health composer

**Prefix:** AN · **Rules:** AN7, AN8, AN11, AN13 (vocabulary) · **Depends on:** T0 (next-fire/matcher entry points). Parallel-safe with T1.

## Goal

The pure logic every read needs, with no I/O: **one formatter** for a trigger's description, the **vocabulary** the forms render from, thin **wrappers** that expose the engines' own next-fire and match functions (no behaviour change), and a **health composer** that
turns reads of other domains into an honest verdict.

## Files (new, `aeon/internal/automationview/` — a pure package; imports `internal/trigger` and `internal/automation` *types/functions only*, **never the store**)

- `describe.go` — `Describe(v View) string` with fixed templates, values `%q`-quoted, canonical match key order (AU6): schedule ("every day at 03:00 in `Europe/Lisbon`; working hours Mon–Fri 09:00–18:00; starts blueprint `dev-loop` in `/path` with goal `…`" — common cron shapes rendered in words by a small, exhaustive, tested table; any other expression printed raw), webhook ("on a signed POST; secret from env `NAME`; starts blueprint `…`"), event ("when `goal.approved` (goal_type in feature, bug) in component `C` starts blueprint `B`; at most N runs/hour, ≤ $M/day"). Archived/disabled/paused are state words appended, not template changes. Control characters never reach a sentence (a `%q`-escaped, length-capped render).
- `vocabulary.go` — `Vocabulary() VocabularyView`: events (4) with the **match keys applicable to each** (AU6's rules, *derived by calling the validator's own applicability table*, not restated), task types (S38's list from its constant), outcome words with one-line meanings, limits (min/max), window grammar, the timezone list (from `time` via the zone names the validator accepts — a curated list of canonical IANA zones, T0 decides which source), and `AuthorityStatement` (the fixed sentence the UI shows on every authority-granting confirm: *"This starts agents with no one present. Outward actions are denied. It will run: <description>."* with `<description>` a placeholder the caller fills from `Describe`).
- `nextfires.go` — `NextFires(s ScheduleSpec, from time.Time, n int) ([]FireInstant, error)`: **wraps the scheduler's own next-fire function** (T0 item 6; if none is exported, add a *thin exported wrapper in `internal/trigger`* that the clock itself calls — a pure extraction with the clock's tests green and unedited, listed in Notes). Each `FireInstant{At, Note}` notes a rule that moved it ("skipped: 02:30 does not exist on this date (DST)", "fires once: 01:30 occurs twice", "moved into the working-hours window"). `n ≤ 20`.
- `matchtest.go` — `TestMatch(match Match, sample Event) MatchResult{Matches bool, PerKey []KeyResult}` using **the real matcher** (AU6) and adding only the per-key explanation (value, allowed set, ✓/✗); validates the match first and returns the validator's sentence verbatim on error.
- `health.go` — `ComposeHealth(in HealthInputs) Health` where `HealthInputs` are **already-read facts** (blueprint state from S48, env presence bool, workspace exists, scope exists, enabled/archived/paused): `BlueprintState ∈ ok|missing|invalid|unverifiable` (+ report counts), `CanFire` = all ok ∧ enabled ∧ ¬archived ∧ ¬paused; a reason list. Pure; the daemon supplies the inputs (T3).
- `*_test.go`.

## Rules (each a test)

1. **Describe is total and safe:** a table over every schedule/webhook/event shape incl. archived/disabled/paused and hostile values (newlines, ANSI, BiDi controls in names/goals/workspaces) — output is a single line with the escapes visible, ≤ 400 chars.
2. **Vocabulary is derived:** the applicability table equals the validator's own (mutating the validator's table in a test seam changes the vocabulary); task types equal S38's constant.
3. **`NextFires` equals the engine:** a differential test drives the **real clock** (injected time) over a year of instants for fixture schedules (daily, weekly, DST gap/overlap zones such as `Europe/Lisbon`, `America/New_York`, `Australia/Lord_Howe`, with and without a window) and compares to `NextFires` — identical instants, same skip/once semantics.
4. **`TestMatch` equals the matcher:** fuzz 500 (match, sample) pairs; the verdict equals the production matcher's; invalid matches return the validator's sentence verbatim.
5. **Health is a pure function of its inputs** and never reads the environment/clock/filesystem itself.
6. **No store import** (`go/parser`), no new dependency; existing `internal/trigger`/`internal/automation` suites unedited and green.
