# T1 · Provenance, archive, audit, and the unified fire view — migration and store

**Prefix:** AN · **Rules:** AN3 (lock 3), AN4, AN5, AN6 · **Depends on:** T0 (state columns, outcome mapping, trigger-body support, error block). Parallel-safe with T2.

## Goal

The storage for the management slice: a **creator** on schedules (the third AU1 lock), **archive** columns on both families, an append-only **`automation_change`** audit, and a read-only **`automation_fire_view`**. SQL only in `internal/store`. **No engine table is rebuilt.**

  ```sql
  -- S49 T1: automation management storage (design AN3-AN6). trigger_schedule gains the creator S40's event_trigger already has (lock 3 of AU1: only a person authors a trigger) — pre-existing rows get created_by_id '' meaning "predates provenance", never a fabricated id.   CREATE TABLE automation_change (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source TEXT NOT NULL CHECK (source IN ('schedule','webhook','event')),
    trigger_id TEXT NOT NULL CHECK (length(trigger_id) BETWEEN 1 AND 128),
    op TEXT NOT NULL CHECK (op IN ('create','update','enable','disable','pause','resume','fire_now','archive','unarchive')),
    summary TEXT NOT NULL CHECK (length(summary) BETWEEN 1 AND 1024),
    actor_kind TEXT NOT NULL CHECK (actor_kind IN ('user','cli')),
    actor_id TEXT NOT NULL CHECK (length(actor_id) BETWEEN 1 AND 256),
    occurred_at TEXT NOT NULL
  );
  CREATE INDEX idx_automation_change_trigger ON automation_change (source, trigger_id, id);
  CREATE TRIGGER automation_change_no_update BEFORE UPDATE ON automation_change BEGIN SELECT RAISE(ABORT, 'automation_change is append-only (S49 AN4)'); END;
  CREATE TRIGGER automation_change_no_delete BEFORE DELETE ON automation_change BEGIN SELECT RAISE(ABORT, 'automation_change is append-only (S49 AN4)'); END;
  CREATE VIEW automation_fire_view AS
    SELECT … FROM trigger_fire f JOIN trigger_schedule s ON s.id = f.schedule_id …   -- exact columns/mapping from T0 item 5
    UNION ALL
    SELECT 'event' AS source, f.trigger_id, … FROM event_trigger_fire f;
  ```
