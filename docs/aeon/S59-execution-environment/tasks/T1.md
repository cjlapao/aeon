# T1 · Characterization goldens: bash, git, terminal, MCP environments, and the sink-scan harness

**Prefix:** EV · **Shape:** P2 (Phase A) · **Rules:** EV5, EV8, EV10 · **Depends on:** T0.

## Goal

Pin today's behaviour **on the untouched code**, so T5's refactor of `Spawn` and its environment change prove what
changed and what did not — and build the **sentinel sink scanner** T4 and T12 use to prove a secret never appears
anywhere. The one thing pinned that T5 will **flip on purpose** is "a daemon-environment sentinel is visible to a
`bash` child": it is recorded as *current behaviour to be removed*, with its header naming T5.

## Files to create

- `aeon/internal/tools/spawn_golden_test.go` — table of commands through `Spawn` with a verdict token: exit codes
  (0, 1, 127), stdin is `/dev/null` (`read x` returns immediately), stdout/stderr truncation with true sizes at the 64 KiB
  caps, timeout (`TimedOut`, `Signal`, group killed — a grandchild holding a port dies), OOM heuristic (`exit 137`),
  `renderRun` bytes for each. Deterministic (short sleeps, fixed seeds).
- `aeon/internal/tools/bash_golden_test.go` — the same through `runBash` (the model-visible `Result` bytes incl. `Summary`).
- `aeon/internal/tools/spawn_env_current_test.go` — **characterization of the leak**: set a sentinel
  (`AEON_SENTINEL_ENV=…` and a fake `ANTHROPIC_API_KEY`) in the test process, run `env` through `Spawn`, assert both
  are visible. Header: *"pins the CURRENT inherit behaviour (S59 EV1). T5 inverts this test; it must not be deleted,
  it must change its assertion."*
- `aeon/internal/git/env_golden_test.go` — `git.Client` with a recording `Exec`: the exact argument lists for every
  method (so T5's `Env` addition changes no argv) and, with the real exec, that `GIT_DIR` set in the environment is
  honoured today (documenting the ambient-state hole `workspace/git.go` already closes).
- `aeon/internal/workspace/git_env_golden_test.go` — `gitEnv()` output keys with a sentinel set: `GIT_*` stripped,
  hardening keys added, everything else inherited (including the sentinel).
- `aeon/internal/terminal/env_golden_test.go` — `terminalEnv`: `TERM` replaced, rest inherited. Header: *"the ONE
  deliberate inherit (LW8); S59 EV10 pins it, does not change it."*
- `aeon/internal/mcp/env_golden_test.go` — `newStdioTransport`'s environment: `PATH`, `HOME`, named variables only.
- `aeon/internal/execenv/envtest/sinkscan.go` — **new test-support package** (only `_test.go` files may import it; T6
  adds the guard). `Scan(t, Sinks{Store: st, LogBuf: *bytes.Buffer, Events: []protocol.Event, Responses: [][]byte,
  Files: []string}, sentinels ...string)` reads: every text column of every table via `sqlite_master` (so a *new*
  table is covered automatically), the raw `state.db` and `state.db-wal` bytes, the captured logger buffer, event
  payloads, and the given response bodies; fails naming **sink, table/column and byte offset** for any sentinel or its
  base64/hex/percent forms. A self-test plants a sentinel in a throwaway table and asserts the scanner finds it.
- `aeon/internal/daemon/exec_golden_test.go` — end-to-end through a test daemon: a granted `bash` step runs `echo hi`;
  record the tool-result bytes, the stored transcript rows and the events (the shapes T5 must keep).

## Rules

- Each golden names the **later task** expected to change it and how, in a header comment (T5 flips only the leak
  test; everything else must stay byte-identical).
- No test depends on a real container runtime or the network.

### Machine preamble (recorded because a bare `go` command fails misleadingly here)

Per `aeon/AGENTS.md` §6, plus two facts this box added: `sqlite-vec.h` needs `<sqlite3.h>` and there is no system
copy (the header is copied from the driver to `.tmp/cgo-shim/sqlite3.h`); `go-tree-sitter`'s yaml grammar invokes
`g++`, which exists here only as `g++-16` (a `.tmp/bin/g++ → g++-16` symlink on `PATH`). `GOCACHE` must be
redirected to the gitignored `.tmp/gocache` when the home cache is mounted read-only. Miss any of the three and the
failure is a C `fatal error: sqlite3.h: No such file or directory` in a package nobody edited.
