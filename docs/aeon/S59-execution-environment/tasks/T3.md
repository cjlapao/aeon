# T3 · `internal/execenv` core: spec, validation, allow/deny, `ChildEnv`, `Restricts`, capabilities, `Resolve`

**Prefix:** EV · **Rules:** EV1, EV3, EV4, EV5, EV6, EV16 · **Depends on:** T0. Parallel-safe with T2.

## Goal

The **pure** heart of the slice: no store, no `os`, no `tools` import — standard library only (a test asserts the
import list, the `records` catalog precedent). Everything the other tasks call to *decide* something lives here and
is table-tested without a daemon.

## Files (new package `aeon/internal/execenv/`)

- `spec.go` — `Spec` and its members (EV4); `ParseSpec([]byte) (Spec, error)` (closed shape: unknown keys refused,
  `additionalProperties:false` semantics via `json.Decoder.DisallowUnknownFields`); `Canonical(Spec) []byte`
  (stable ordering — the audit stores it and `Restricts` compares it).
- `vocab.go` — **data**: `Backends()` (`host-inherit`, `host-scrubbed`, `container`, `vm`) with strength order,
  `Capabilities(backend)` (EV3 table), `DefaultPassthrough()`, `Deny()` (words, prefixes, exact names, loader/shell
  variables), `ProxyWarnPatterns()`, `EgressModes()`, `SourceKinds()`, and the two sentences `Honesty` and
  `RedactionLimits` (EV1, EV8). `Vocabulary()` returns all of it for `environment.vocabulary`.
- `validate.go` — `Validate(spec Spec, backend string, opts ValidateOpts) []Refusal` returning **every** problem (not
  the first), each a three-part sentence: unknown/unsupported backend (`vm` with no registered driver — `opts.Drivers`),
  a capability the backend cannot enforce (memory on a host; `egress.allow`; non-null `preview`; `home: scratch` on
  `host-scrubbed`), a denied name in `passthrough`/`set`/secret `inject_as` (the sentence names the variable, says why,
  and points to secret references), credential-shaped `set` name, invalid variable name (`^[A-Za-z_][A-Za-z0-9_]*$`,
  ≤ 128), `set` limits (≤ 64 entries, value ≤ 1 KiB), `limits` ranges (wall 1–`BashTimeout` s; memory ≥ 64 MiB;
  cpus 0.1–64), image required for `container`, services only on container, duplicate names. **Warnings** (non-fatal)
  returned separately: `*PROXY*` names, floating image tag, `memoryMiB` absent on a container.
- `childenv.go` — `type ChildEnv struct{ vars []Var; legacy bool; built bool }` (unexported fields);
  `Build(spec Spec, daemonEnv func(string) string, injected []Injection) (ChildEnv, error)` — passthrough copied by
  name and `PREFIX_*` pattern from `daemonEnv`, then `set`, then injected secrets (a secret **replaces** a same-named
  variable and the replacement is recorded), output sorted; `LegacyInherit() ChildEnv` (marks `legacy`); `Env() []string`
  (the only place values leave, used by the executor); `Names() []Var{Name, Source}` (no values — for the step record
  and the preview); `IsZero()`; `Legacy() bool`. The zero value is **inert** (`built == false`): `Env()` on it panics
  in tests and returns an error in production wiring, and `Spawn` refuses it (T5).
- `gitenv.go` — `GitEnv(daemonEnv, spec-less)`: the base allowlist + `SSH_AUTH_SOCK` + `GIT_TERMINAL_PROMPT=0` +
  the hardening the UI's `gitEnv()` already adds (EV10, D9).
- `restrict.go` — `Restricts(old, new Spec, oldBackend, newBackend string) []Widening`: empty ⇒ restrictive (EV16's
  axes); each `Widening` names the axis and the offending member; pure and total.
- `resolve.go` — `Resolve(in ResolveInput) (Resolution, *Refusal)` — `ResolveInput{ComponentBinding,
  RootBinding, WorkspaceBinding *BoundEnv; Attended *bool; ScrubbedSystem *BoundEnv}`; applies EV2's order and EV6's
  downgrade (`Resolution{Env BoundEnv, Source, Downgraded bool, Reason string}`); refusals `environment-unbound`
  (no binding) and `environment-unavailable` (downgrade needed, `ScrubbedSystem` nil).

### Deviations, and the fact that forced each one

1. **`DaemonEnv` is `struct{Lookup func(string) string; Names func() []string}`, not `func(string) string`.**
   The spec's signature cannot answer the second half of passthrough: a getter cannot discover that the daemon
   holds `LC_ALL` and `LC_CTYPE`, and `LC_*` is in the default allowlist. Rather than make patterns work only
   when a caller happens to pass more, `Build` **refuses** a pattern whose `Names` is nil
   (`environment-unavailable`, naming the reason) — a locale that quietly stops being passed is an ASCII shell
   discovered by a user three hours later. The daemon reads `os.Environ` OUTSIDE the package and hands both
   closures in (T5's wiring).
2. **The type is `DenyList` and the served set is `VocabularySet`.** The task names the functions `Deny()` and
   `Vocabulary()`, and Go will not hold both under one identifier. The functions keep the names clients and
   `environment.vocabulary` use.
3. **`DenyList.Exempt = ["AEON_SERVICE_"]` added.** EV14 has the daemon derive `AEON_SERVICE_<NAME>_HOST` and
   `_PORT`, and `AEON_` is a denied prefix — so without an exemption the package refuses to inject the names it
   builds itself. The exemption escapes `Prefixes` **only**: `Words` still fire inside it, so a service named
   `token` is still refused. Pinned by `TestNamespacedServiceVarsAreBuildableNames`.
4. **A sixth `Refusal.Kind`, `spec-invalid`, for validation-time refusals.** EV11's five are what a step record
   can carry; "your spec has three problems" is not a step that was refused. It is a constant beside the five so
   every three-part sentence in the slice is one type with one renderer, and it never reaches a step record.
5. **`ChildEnv.Env()` panics on the inert value; `TryEnv()` answers it with a refusal.** The task asks for both
   "panics in tests" and "errors in production". One method cannot do both honestly: `Spawn` (T5) calls
   `TryEnv` and refuses, so the panic is unreachable in a wired path and remains what a unit test sees when a
   caller forgot to resolve.
6. **Beyond the task's file list:** `validate.go` is its own file rather than living inside `spec.go` (SIZE1 and
   one concern each), and `restrict.go`'s transitivity case runs over 220 generated specs — the reflexive and
   transitive properties are asserted pairwise over the generated set, which is the only way the third-element
   bug shows up.

### Not verified, and what would verify it

- **Nothing outside the package has run this code.** `Spawn`'s fifth parameter, the `tools.CommandExecutor`
  and the daemon's `StepExecResolver` are T5; until they exist, "a command runs in a built environment" is a
  claim about tests only.
- **The `PREFIX_*` pattern against a REAL daemon environment** is unexercised: the tests hand in a map, which
  is the point, but it means the `os.Environ`-reading adapter does not exist yet (T5) and has never been run.
- **The deny list versus the daemon's actual variable set** is argued from `internal/config/creds.go` and
  `internal/forge`'s token names by reading, not by enumeration: `TestCredentialWordsSupersetOfConfigMarks`
  pins config's marks only. A daemon that holds a credential under a name config does not mark (and execenv
  does not either) would pass every test here. T4's resolver is where the daemon's own names get enumerated.
