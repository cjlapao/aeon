## W2-10 — found, not fixed, and it is the sharpest thing this walk surfaced

`provision.go:260` `reusable()` selects a container to hand to a step from `ProvisionsFor(componentRoot, loopSlug)`

the step would execute in the database container rather than the workspace one, with that service's mounts and
network. Reproduce-by-reading is enough to see it; the fix is a predicate on the row's owner, plus a test that a
`service:` row is never returned to a loop — and, since `reusable` also checks the engine, an assertion that the
handle it returns belongs to the loop's own container. Recorded here rather than silently left, because the next
person to touch `reusable()` should meet this sentence before the code.
