## The migration drill (one migration)

1. **Fresh apply:** `tool` table + index exist; a fresh daemon start seeds one row per system tool (`origin='system'`, `created_at` set).
2. **Upgrade from the pre-S47 vintage:** open an existing store with the new binary → the migration applies; the start seeds the rows; unrelated tables (`agent`, `policy`, `proposal`) unchanged (row counts).
3. **Idempotent re-open/re-start:** no second migration; a second apply writes nothing.
4. **Drift drill:** edit a row's `description` directly with `sqlite3` → `tools.status` reports `differs{description}`; the runtime's model-facing spec for that tool is **unchanged** (TC2); `seed.apply` does not repair it silently (no version bump ⇒ reported `diverged`).
5. **Retirement drill:** build a test binary with a tool removed from the registry → its row stays, `tools.status` reports `retired`.
6. **Forward-only:** no rollback; recorded.
