### Findings the goldens surfaced

1. **F-T1-1 (handed to T9): `doctor` never reports its own daemon as reachable.**
   `cmd/aeon/doctor.go:44` dials with the literal version `1`; since S38 T2 the protocol floor is
   2, so the daemon refuses the handshake with `-31002 protocol version not supported` before any
   method. Measured live: `daemon socket unreachable: aeon -31002: protocol version not supported`
   with a healthy daemon listening. Pinned as-is in `TestDoctorGoldenUp` so the fix is a visible
   golden change; T9 edits this verb (the BK15 lines) and owns the one-word fix.
2. **`Claim()` never binds** (`internal/endpoint/claim.go:43`): free state → returns nil and
   creates NOTHING (the bind is the daemon's `localrpc` Init); stale state → removes the file;
   live state → refuses. Claim's entire observable mutation set is the stale-file removal —
   which is exactly the one line T7's `Probe` stops doing. The free-state golden asserts the
   non-creation.
3. **After a clean Open+Close the state dir holds exactly `state.db`** — the `-wal`/`-shm`
   sidecars exist only while a connection is open (clean close checkpoints and removes them).
   That is the baseline "no sidecars" means.
4. **A behind-vintage `db upgrade --dry-run` prints byte-identical output to a fresh one**: the
   open applies the pending migrations first (DB8), so the dry-run reports nothing pending; the
   "was pending a moment ago" text is the parenthetical (F19). The vintage path is therefore
   pinned at the store level (`TestOpenMigratesAnOldStoreWithoutAnyCopy`), and the CLI golden
   carries the note.
5. **Doctor's seed lines differ by daemon state** (deterministic on a fresh dir): down =
   `agents.firstParty 33 behind` / `watchdog.default 5 behind`; up = `29 behind` (the daemon
   seeded 4 firstParty agents at boot) / `watchdog.default up to date (1/1 applied)`.
