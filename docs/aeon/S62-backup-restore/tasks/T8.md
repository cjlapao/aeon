# T8 · Export of managed records: registry, allow-list reads, `export.*`, `aeon export`

**Prefix:** BK · **Shape:** P5, P6, P8-adjacent · **Rules:** BK14, BK12, BK13 · **Depends on:** T1. Its daemon methods extend T6's
guards (listed below); otherwise parallel-safe with T4–T7.

## Goal

A person can write a **read-only, deterministic, secret-free text snapshot** of the managed records to a directory and put it
in git. It reports record sets whose slice is not built as *unavailable*, never as empty. It has no importer.

## Files

- `aeon/internal/export/` — **new** (no SQL, no network):
  - `registry.go` — `Exporter{Name, Description, Tables []string, Optional bool, Read func(ctx, Reader) ([]File, error)}` and
    `Register`/`All()`; names are a closed set per build (a test asserts the registry equals the documented list).
  - `file.go` — `File{Path, Bytes}` with stable JSON encoding (sorted keys, 2-space indent, LF, trailing newline), path
    hygiene (relative, no `..`, no absolute), size cap per file (4 MiB — over ⇒ the exporter splits or refuses, recorded).
  - `exporters_core.go` — the sets of BK14 present today: `agents`, `policies`, `routes`, `components`, `triggers`, `goals`,
    `settings` (when `setting` exists), `memory` (**opt-in**). Each names its **columns** (allow-list) and its sort key; each
    states in `Description` what it deliberately omits.
  - `run.go` — `Run(ctx, deps, opts)`: resolves requested sets (default = all non-optional available), refuses a `DIR`
    that is relative, exists non-empty, or is a symlink; creates 0700/0600; writes `export.json` (generated_at, aeon version,
    schema count, per-set `{state, files, rows}`) and `README.md`; writes each set to `<set>/<id-or-slug>.json`.
- `aeon/internal/store/export.go` — **new**: `ExportRows(ctx, spec TableSpec) ([]map[string]any, error)` where `TableSpec{Table
  string; Columns []string; OrderBy string; Where Predicate?}` — every identifier is checked against a **Go constant

  exist is `unavailable`, not an error); values come back as JSON-safe scalars; `TableExists(name) bool`. Components read
  through the **S44-extra tree accessors** when merged (T0 records which); until then through the single `component` table
  plus its roots — the exporter has a branch-free shape because `parent_id` is simply "absent ⇒ null".
- `aeon/internal/protocol/export.go`, `method.go` — `export.run {sets[], dir, includeMemory?}` (human socket) and `export.sets {}`
  (read, open), `BackupStore`-style `ExportStore` interface, `Table.Export`; V13 absence when nil; fixtures; `ErrBackupRefused`
  reused for refusals (reason in `what`).
- `aeon/internal/daemon/export_service.go` — the implementation over `export.Run`; `dir` must be absolute and satisfy the
  rules above; actor stamped from the door; one `backup_run` row (`kind=export`).
- `aeon/internal/records/catalog.go` — `export_sets` spec (twin `export.sets`), `Mutates:false`; `toolset_test.go` **+1** (T6's

## Behaviour (each a test)

1. **Deterministic:** exporting the same store twice yields byte-identical trees (compare file lists and bytes); only
   `export.json`'s `generated_at` may differ (test strips it explicitly and asserts it is the **only** difference).
2. **Allow-list, not deny-list:** every exporter's selected columns are exactly its declared list (a test queries the tracer
   log or the `TableSpec`s and compares); a column added to a table later is **not** exported until declared (a fixture adds
   a column and asserts it is absent from the output).
3. **No credential in output:** seed credential-looking strings (`sk-…`, `ghp_…`, `Bearer …`, a PEM header) into **every**
   free-text column any exporter reads and into forbidden columns (`api_key`-like names on a synthetic table); assert the
   forbidden columns are never selected and that declared *content* fields are copied verbatim (the content is the record —
   an agent card's prompt may legitimately contain text; the test documents that export is a content copy, not a scrubber, and
   the README says so).
4. **Unavailable is not empty:** drop/omit the `setting` table (S44 not merged) ⇒ set `settings` reported
   `unavailable (slice not built)` with rows `null`; an existing-but-empty table ⇒ `available`, 0 rows, **different state**.
5. **Directory rules:** relative ⇒ refused; existing non-empty ⇒ refused; symlink ⇒ refused; mode 0700/0600 on Unix;
   a failure mid-way removes the partially written tree it created (the export's own dir only, through the fenced remover's
   export variant — added to T4's documented exception list).
6. **Read-only:** the store is byte-identical before/after (hash of the snapshot of tables); the direct door opens with
   `SkipMigrations` and **never migrates** (spy).
7. **Memory opt-in:** learnings are absent unless `--include-memory`; `export.sets` lists `memory` as `available (opt-in)`.
8. **Daemon/CLI parity (P5)** both directions; `export_sets` equals `export.sets`.
9. **Components set** round-trips the tree shape (a store with a root, two children and archived node ⇒ files carry `parentId`,
   `archivedAt`, effective-setting sources are **not** exported (derived), `roots`) — or, before S44-extra, the flat shape; the
   test is parameterised on the merge state T0 recorded.
10. **Size cap** splits/refuses an oversized agent prompt deterministically.

### Decisions recorded here

- **Error resolution (locked):** every export refusal rides the family's refusal voice — `ErrBackupRefused` (-31863, the S62
  block's code), the closed-set engine kind in `data.kind`, the person's sentence in `data.what`; **-31864 stays reserved**.
- **The prefix is the door's, not the wire's.** The engine's sentences carry an `export: ` prefix (its own voice). The
  protocol handler renders `export <verb> refused: <detail>` — so the DAEMON service strips the prefix before handing the
  detail over (`strings.TrimPrefix(runErr.What, "export: ")`), or the wire would carry it twice. The CLI's DIRECT door keeps
  the prefix: it has no handler to re-voice the sentence, and its error goes to the person verbatim. The conformance fixture
  `conformance/export/run-refused.json` carries the stripped form. The asymmetry is documented in both places.
- **`export.sets` is open.** It says nothing an uninitialised daemon could not already say (the registry plus this schema),
  so it is `RequiresInitialize` false — the export family's one open door, asserted separately from the gated list.
- **Parity is asserted on the wire answer and the tree, not on stdout.** The human rendering includes the ledger line, which
  is a door fact ("the run is in the ledger" vs "the run is not in the ledger (direct door)"), so the test compares the
  `--json` wire results (typed) and the on-disk bytes, file by file.
