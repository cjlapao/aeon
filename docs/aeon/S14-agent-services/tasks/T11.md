## Why this exists

**AS1 as a test rather than a promise.**

> An agent with no card, no skills and no tools is markdown and a prompt — and the ladder runs on it
> unchanged.

That is the adoption story: **a company with only MCP servers writes agents pointed at public tools; a
company with none keeps markdown agents. Same system, two depths.** Nobody buys the whole model to start.

**And it decays the ordinary way.** A test somewhere gains a card because that was convenient, and six
months later removing agent services breaks forty tests for reasons unrelated to agent services. S22
earned this discipline for retrieval and S12 reused it; this is the third time.

**Read first:** S22's deletability tests and S12's `absent_test.go` for the pattern; AS1, AS11.

## Scope

**1. Run the whole suite with agent services off.** Not this package's tests — **everything else.** It must
pass.

**2. One of S13's 25 bodies dispatches unchanged.** Pick one, run it, assert the result matches S13's
expectation. **This is the concrete form of "the 25 bodies need no change."**

**3. No package imports `agentsvc` unconditionally.** Assert by grep — an unconditional import is how
"optional" quietly stops being true.

**4. No feature flag.** Deletability means *absent configuration works*, not *a switch exists*. A flag is a
second state to test and a thing that gets set wrong.

**5. The absence is reported where it matters.** A lane targeting a skill when no agent services are
configured gets a structured refusal, not a nil dereference.
