## Why this exists

**This is the slice's keystone, and the place it can go quietly wrong.**

> An async Task is a **suspension**, not a concurrency model (AS4).

The step fires the Task and **exits.** S6's machinery exactly (P2). The loop resumes cold when the Task
completes.

**The failure mode is a goroutine that waits.** It satisfies every informal description — *"the step is
waiting for the task"* — and it destroys P2 completely, because **a blocked step cannot survive a
restart.** It will pass a casual test. It will fail the first daemon crash, in production, as a loop that
never resumes and has no record of why.

**So the test is the absence of a goroutine**, not the presence of a result.

**And nothing spawns** (AS5). A Task is a row. No child process, no orphans, no abort semantics — A1's
correct half, kept.

**Read first:** S6's suspend-by-exiting and S7's cold resume — **reuse them, do not reimplement**; S4's
`step.status`; AS4, AS5, AS13.

## Scope

**1. A Task is a row**, in a table this task adds to S4's schema via a numbered migration following S4's
discipline exactly (one transaction, one number, ledger-recorded).

**2. Two paths, chosen at invocation:**

| | |
| --- | --- |
| **sync** | the step waits; the Task completes within the step |
| **async** | **the step exits.** The step row is `suspended`; a completion resumes the loop cold |

**3. No promotion.** A sync Task that takes too long does **not** become async. A step whose transcript
changes shape on a timeout has a gap nothing explains.

**4. A Task carries the policy set it was created under** (AS13). S7's replay discipline applied to
delegation: otherwise a Task created under one policy completes under another and the record cannot say
which governed it.

**5. Answer Q4, and state it either way.** A skill whose agent needs an `ask` is a Task that suspends —
which **composes**, because suspension is already a row. The question is whether the **caller's** step must
also suspend. **Probably yes**; whichever way, write it down, because the alternative is a caller blocked
on a human it cannot see.

**6. Recovery.** S7 must be able to resume a Task it did not create. The chain row is how (T5); this task
makes the Task row sufficient to find it.
