  is a planner asking a specialist (a path of ONE ask) or a specialist asking one more (TWO). Four lets
  that shape breathe twice before refusing, and stays small enough to be a backstop and not what the
  spec calls the failure mode — "a cycle detector that takes longer to fire". The cycle check runs FIRST
  and on its own terms; the bound exists for chains of DISTINCT agents (no repeat), which no cycle check
  can catch and which only a number can refuse.
- **Two refusals, two sentences, each forbidden the other's diagnosis:** the cycle refusal names the path
  in order from the agent making the refused ask (`reddit-agent → planner → reddit-agent` — measured:
  the first test expectation named it from the OTHER end and the refusal was the correct one), calls it
  a structural mistake, and says the fix is the graph; it may mention cost only to DISCLAIM it. The

  the fix a graph fix too but for the runaway reason. The tests forbid the misdiagnosis words
  ("exceeded", "depth", "bound", "raise") in the cycle sentence and require the disclaimer in each —
  an absence assertion is the whole task.
- **The bound measures the WHOLE path, not one direction** (measured, the hard way): the first version
  walked only DOWNWARD from the callee, which lets an infinite chain grow upward, unmeasured. A refusal
  computes `longestTo(caller) + 1 + longestFrom(callee)` — what is already above the caller, the new
  ask, what is already below the callee — over the recorded rows, walking backwards through
  `ChainEdgesToCallee` (the join resolves the caller AGENT from the caller step, which is what makes
  the graph honest: an ask belongs to the agent whose step recorded it, not to whoever claimed it).
- **Refusal BEFORE everything** — the cycle check runs after legality (card, skill) and before the edge
  AND the Task: an illegal ask leaves no trace (the test counts edges and finds none), and a refusal
  after creation would leave "a Task nobody will complete" (the spec's words). The boundary is exact:
  four asks allowed (test builds exactly four), the fifth refused as depth.
- **Reads, not memory:** `TestChainSurvivesRestart` closes the store handle, reopens the same directory,
  and the fresh Invoker refuses the same cycle with the same named path — the graph is rows, which is
  what makes T6's rollup and S7's resume-of-a-Task-it-did-not-create possible. A store that cannot
  answer refuses the invocation (fail closed, quoting the store's words) rather than certifying
  "no cycle" from rows nobody could count.
- **A diamond is not a cycle** (`TestDiamondIsNotACycle`): two paths rejoining at one specialist is the
  normal shape of a map; the detector flags a repeat ON THE PATH, never a revisit of a busy callee —
  a detector that refused collaboration would be the confident wrong answer again.
- **The caller's identity is now gated at invoke:** an ask filed under another agent's step would be
  attributed to the wrong agent by the cycle walk (every refusal then diagnoses someone else's loop),
  so Invoke reads the caller step and refuses a mismatch naming both agents (`TestInvokeGateRejectsForeignIdentity`).

## Why this exists

A graph admits cycles, and **two different failures need two different diagnoses.**

| | | Fix |
| --- | --- | --- |
| **A cycle** | A asks B asks A | a structural mistake — fix the graph |
| **Depth** | a chain that keeps going | runaway — tune the bound, or fix the graph |

**Conflating them gives the wrong answer confidently.** A cycle that spends money until a `CostCap` fires
reports *"cost exceeded"* — which sends somebody to raise a cap when they have an infinite loop. The cap
was not wrong; it was the only thing that noticed.

**So the cycle is refused on its own terms, and the refusal names the cycle.** `planner → reddit → planner`
is a sentence somebody can act on.

**Read first:** `invoke.go` (T4) for where edges are written; AS6, AS7; S17's two-level counters for the
*other* kind of runaway, which this is not.

## Scope

**1. The chain is rows**, reconstructable after a restart. That is what makes cost rollup possible across a
crash (T6) and what lets S7 resume a Task it did not create.

**2. Cycle detection on the recorded chain**, at invocation time, **before** the Task is created. Refusing
after creation leaves a Task nobody will complete.

**3. The refusal names the path.** Not *"cycle detected"* — the agents, in order.

**4. The depth bound is separate**, and **answer Q1: the number.** Keep it **small** — the shape being
built is a planner asking a specialist, which is two. State the reasoning; a large bound is a cycle
detector that takes longer to fire.

**5. Refused at the boundary**, not one past it. A chain of exactly the bound is allowed; one deeper is
refused, and the refusal states both numbers.

**6. Two tests, not one.** A cycle test and a depth test. If one test covers both, the diagnosis cannot be
distinguished, which is this task's whole point.
