## Why this exists

The thing the slice is for: **an agent asking another agent to do something.**

**Why this is not a tool call.** A planner wanting a report from Reddit does not want `reddit.search` — it
wants *"find what people are saying about X and summarise it."* That is a request for **judgement about how
to use tools**, which is the difference between a tool and an agent (AS10).

**Read first:** `task.go` (T3) — this calls it and does not reimplement waiting; S8's step shape; AS4,
AS10.

## Scope

**0. Check the prerequisite first, and stop if it is missing.**

**S8's step must carry `skill:` and `params:`.** A lane cannot target a skill until a step can express one.

**If that amendment has not landed, report this task as blocked.** Do **not** invent a free-text
convention — a convention is a format nobody validated, and it will be load-bearing by the time anybody
notices.

**1. Invocation**: caller, callee, skill id, params, and sync-or-async. Nothing else.

**2. Every invocation records a chain edge** (AS6). T5 owns the chain's properties; this task owns putting
the edge there, and it is written **before** the Task runs — so a crash mid-invocation leaves a recorded
attempt rather than an untraceable cost.

**3. An unknown skill is refused with a structured reason** (A13's shape): the agent, the skill, and the
skills that do exist. Not a suggestion engine — an enumeration.

**4. The caller does not learn the callee's tools.** It gets a result. **If this task exposes the callee's
tool list to the caller, S12's MC2 is being undone** by a different route.
