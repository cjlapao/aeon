## Why this exists

**No new transport** (P25). Aeon already has a socket speaking JSON-RPC 2.0, which is what A2A specifies —
so the work is a method table, not a listener.

**And a second listener would be a third surface.** P25 says one protocol with N enumerated projections;
an agent-services port opened here would be a fourth thing to secure, document and keep narrow — and
nobody asked for it, because every agent in this slice is local. **S21 is where the wire arrives**, with
TLS and a trust store.

**Read first:** S2's method table and `internal/protocol/`; P25; N18's one-table rule in S19 for the
precedent on enumerating in one place.

## Scope

**1. Skill invocation over the existing socket.** Methods added to S2's table, in **one place** — a method
registered in two files is a surface that grows by accident.

**2. No second listener.** Assert by grep: no `Listen`, no bind, no port in this package.

**3. The method table is enumerated**, and every entry states what it cannot do — S19's N12 discipline,
applied here because this is the same kind of list.

**4. Local only.** No host, no URL, no TLS. If a remote address can be configured here, S21's trust-store
work has been pre-empted without its egress policy.
