**Prefix:** AL · **Shape:** P2 (Phase A only), P4 (hash pins) · **Rules:** AL7, AL8, AL9, AL16 · **Depends on:** T0.

## Goal

Pin today's behaviour **on the untouched code** so every later task proves what it changed and what it did not: the whole `Resolve` matrix and sentences, the pinned values of every
loop start path, the narrow surface's behaviour, and the **assertion logic** of the guards this slice must leave alone. All green before any production change.

## Files to create

- `aeon/internal/action/resolve_golden_test.go` — **new**: for **every** registry name (`action.Names()`) × `attended` {true,false} × `allowOutward` {true,false} write `Resolve`'s `(Verdict, Class, Sentence)`
  to `testdata/resolve_matrix.json` (36 rows today). The test regenerates in memory and compares byte-for-byte; a registry addition fails it with "a new action needs a deliberate golden row" (the
  point: a new `irreversible` action must be a conscious decision for AL2).
- `aeon/internal/daemon/pin_golden_test.go` — **new**: drive the real start paths over a temp store and record the pinned row `{attended, allow_outward, started_by, trigger_id}` for: a schedule fire
  (`StartFromTrigger`), a webhook fire, an event fire (`startFromEvent`), a narrow trigger body carrying `attended:true, allowOutward:true`, a socket `loop.start` with and without both fields, a queue
  advance. Expected today: schedule/webhook/event `attended=0, allow_outward=0`; narrow `attended=0` and `allow_outward` = the body's; socket = the body's (NULL when absent). Goldens in `testdata/pin/*.json`.
- `aeon/internal/loop/execute_golden_test.go` — **new**: drive a one-lane blueprint through `forge.openPR` and `forge.merge` with the forge fake as witness for the four attended/allowOutward combos; record
  the block reason / question / fake call log. (These duplicate the spirit of `allowoutward_test.go:103-192`; the golden form makes later byte-diffs trivial.)
- `aeon/cmd/aeon/autonomy_pins_test.go` — **new**: the guard-pin file. For each of the existing tests this slice must not weaken — `TestNoKeyLevelGrantExists` (`narrow/trigger_test.go:205`),
  `TestAttendednessCannotBeInferredFromPolling` (`loop/allowoutward_test.go:344`), `TestClassesAreNotConfigurable` (`action/class_test.go:195`), `TestTriggeredLoopIsUnattended`
  (`loop/allowoutward_test.go:72`), `TestIrreversibleDeniesToo` (`:159`), `TestAllowOutwardIsPerLoop` (`:192`), S40's event-start pin tests (names from T0 item 5) — compute the SHA-256 of the
  **assertion-bearing source** (the function body text, extracted by `go/parser`) and compare with the digests recorded in T0's Notes; the failure message says the pre-amendment logic is the
  contract and a change must be a deliberate, listed amendment (the S45 T6 `TestOriginalGuardsAreByteIdentical` method).

## Rules

- Deterministic: fixed clock (`store.Now` seam), fixed slugs, sorted output.
- Each golden file has a header comment in its **test** (not the JSON) naming the later task expected to change it and how — expected: **none** change `Resolve`'s matrix or the existing pins
  (AL9/AL16 promise byte-identical behaviour); T4 may only **add** rows (new fixtures with a grant) and T5 only adds an `ResolveWithGrant` zero-context equivalence test.
- The hash pins record digests in a constant table **with a comment per row** citing the test's file:line; T7 re-asserts them after the amendments.
