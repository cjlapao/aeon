# T6 · The socket human door: three write methods and a read set

**Prefix:** AL · **Shape:** P4 (registration half), P3 · **Rules:** AL10, AL11, AL14 · **Depends on:** T3, T4, T5.

## Goal

The daemon's socket speaks autonomy: ten methods on the person's 0600 + peer-credential surface, one new error code family, the contract chain regenerated. Writes stamp the **kernel peer**, refuse anything that is not a person, and
carry the audit row; reads answer "what could an unattended loop do here, why not the rest" and "what was this loop pinned with, and is it still live".

## Behaviour (each a test)

1. `autonomy.grant` on a root with `forge.openPR`, `requireBudget` default ⇒ `GrantView` with `active:true`; the audit row exists with `actor_kind='user'` and the peer uid; `autonomy.changes` returns the fixed-template sentence.
2. `autonomy.grant` `forge.merge` without expiry / with `requireGates:false` / with 91 days ⇒ typed refusals with the T2 sentences; `outward` class ⇒ accepted; `irreversible` class ⇒ refused.
3. `autonomy.grant` on a child ⇒ refusal naming the root; `autonomy.deny` on a child ⇒ accepted.
4. `autonomy.revoke` is idempotent (second call: same view, **no** new change row); the result's `affectedLoops` lists running pinned loops.
5. `autonomy.effective` for a root with no grants says nothing is granted and lists every non-local action as `deny`; with `forge.openPR` granted: `openPR` run, `postReview` deny `no grant`, `merge` deny `irreversible — needs its own grant`.
6. `autonomy.effective` ≡ the pin a loop would get (`TestEffectiveEqualsWhatAStartPins`, AL14): same inputs, then actually start via the T4 path and compare snapshot.
7. `autonomy.pinned` on a loop whose grant was since revoked ⇒ that grant `live: revoked`, the covered actions `deny` with the revoked sentence; for a loop with no pin row ⇒ `{pinned:false, statement}`.
8. `autonomy.uses` pairs `begun`/`completed` and reports an unpaired `begun` as `outcome: "unknown — the process stopped before the result was recorded"`.
9. Every write method refuses a connection whose actor kind is not `user`, and **absent when the service is nil** (`Dispatch` ⇒ `ErrUnknownMethod`).
10. No method accepts `actor`, `by`, `createdBy`, `status` or `source` in params (strict decode ⇒ parse error).

### Deviations from the spec, and why

- **Identity keys: key-bag refusal, not strict decode.** T6.md says "strict decode ⇒ parse error"; the protocol's decode is deliberately permissive for unknown fields (T3 — a field from the future is not an error), so the door is a key-bag check over exactly the five identity keys (`checkAutonomyParams`), which answers `ErrBadParams` naming the key — a parse-error-class refusal on exactly the five keys, permissive on everything else. Behaviour 10 (no method accepts the five keys) holds on every method, read or write.
- **The used-event root is the loop's own project root** (`st.ComponentRoot`), not the repository the loop acts on — S31 D1 (a loop's events are appended with the loop row's real root, so a `Filter{ComponentRoot}` subscriber gets one project's uses and not the machine's). Settled by the same evidence as T5's used-event work.
- **`revoke-already.json`** — an extra conformance fixture beyond the listed refusal families: an already-revoked grant is a no-op SUCCESS (Changed false, no new change row, empty affected), not a refusal; the fixture documents that shape.
- **Test split**: the spec's `P10` command runs `-run 'Autonomy'` on both packages; the daemon's six tests are named after the spec's table (`TestEffectiveEqualsWhatAStartPins` etc.) and do not contain the word "Autonomy", so they run by name (or the full package suite, run above). The protocol's do match `-run 'Autonomy'` (plus `DryRun`).
- **Conditions defaulting is whole-object**: absent `conditions` key ⇒ `AutonomyConditions{RequireBudget: true}`; a present object (even `{}`) ⇒ verbatim — the params field is a `*AutonomyConditions` so the absent-vs-present distinction survives to the seam.
- **`effective` origin**: absent ⇒ `"schedule"`; a named origin is validated against the four protocol constants else `ErrBadParams` (no default for a typo — a plausible wrong answer).
- **Daemon `not-a-root`** names the parent root (checked before `ValidateGrant`, whose sentence omits it) — the actionable half the store's sentence also carries.
