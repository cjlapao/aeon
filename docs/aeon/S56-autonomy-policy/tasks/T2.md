# T2 · `internal/autonomy` and `action.ResolveWithGrant`: the pure core

**Prefix:** AL · **Rules:** AL2, AL3, AL4, AL5, AL9, AL14 · **Depends on:** T1. Parallel-safe with T3.

## Goal

All grant logic that needs no database: the vocabulary derived from the registry, strict validation, the pure resolver `Plan`, the condition evaluator and its seams, the sentences, and
`action.ResolveWithGrant`. Nothing here imports `internal/store` (I2) or does I/O; a test greps for both.

## Files to create

- `aeon/internal/autonomy/types.go` — `Subject{Kind, Name}`, `State` (`allow|deny`), `Conditions{RequireGates bool, RequireBudget bool, Labels []string, MaxPerDay int}` (typed, JSON tags `requireGates`,
  `requireBudget`, `labels`, `maxPerDay`; **decoder uses `DisallowUnknownFields`**), `Grant` (the row's logic fields: id, rootId/nodeId, subject, state, conditions, expiresAt, revokedAt), `Origin` (`schedule|webhook|event|scheduler`),
  `Pin{Rev int64, Origin, Labels, Allowed []PinnedGrant}`, `PinnedGrant{GrantID, Subject string, Conditions Conditions}`.
- `aeon/internal/autonomy/vocabulary.go` — `Vocabulary()` built from `action.Names()` and `action.Classes()` (read both through the exported accessors — **never a copy of the names**): subjects (every non-local action
  by name, plus the one class shorthand `outward`), conditions with `{name, type, evaluated: pin|action, forced?}`, limits (`MaxMergeGrantDays = 90`, `MaxLabels = 8`, `MaxLabelLen = 64`), origins, states.
  `ExpandSubject(s) []string` turns `outward` into the **current** outward action names.
- `aeon/internal/autonomy/validate.go` — `ValidateGrant(in, now) *Refusal` (pure; returns the sentence a person reads): unknown action; **local action** ("X is local — it runs without a grant"); class other than
  `outward`; **`irreversible` as a class** ("an irreversible action is granted only by its own name"); `allow` on a non-root is the store's, but `ValidateGrant` takes a `NodeInfo{IsRoot bool, Archived bool}` and refuses it first;
  `forge.merge`/any irreversible: `RequireGates` forced `true` (a request carrying `false` is **refused**, not silently corrected) and `expiresAt` mandatory, ≤ `now + MaxMergeGrantDays`; `maxPerDay ≥ 1`; labels ≤ limits;
  expiry in the past refused; `note` ≤ 512 bytes; a `deny` carries no conditions and no expiry. A single `Refusal{Code, Sentence}` with **closed codes** (`unknown-subject`, `local-subject`, `class-not-grantable`, `condition-forced`, `expiry-required`,
  `expiry-too-far`, `condition-invalid`, `not-a-root`, `node-archived`, `expired`).
- `aeon/internal/autonomy/plan.go` — `Plan(in PlanInput) []ActionPlan`: `PlanInput{Origin, Labels, Grants []Grant (active allows + denies for the root and its component), Now, Conds Conditions evaluator}` →
  per registry action `{Action, Class, Verdict (run|deny), Because (sentence), GrantID, Conditions []ConditionStatus{Name, State met|unmet|cannot-say, Sentence}}`. Rules: local ⇒ run (no grant); vetoed ⇒ deny; allow matched by action or class
  expansion, **label-matched at pin time**, not revoked, not expired; irreversible runs only through its own name. `PinFrom(plan) Pin` produces the snapshot (AL8) — **only the pin-time-evaluable part** (labels) is decided; action-time conditions are carried
  in the pin and evaluated later.
- `aeon/internal/autonomy/conditions.go` — the seams: `type Seams struct { Gates func(ctx, loopID string, pr int) Answer; Budget func(ctx, loopID string) Answer; Uses func(ctx, grantID string, since time.Time) (int, error) }`,
  `Answer{State met|unmet|cannot-say; Sentence string}`; `Evaluate(ctx, c Conditions, loopID string, pr int, s Seams, now) []ConditionStatus` — a **nil seam or error ⇒ `cannot-say`**, never `met` (AL4). The Gates seam sentence is carried verbatim.
- `aeon/internal/autonomy/sentences.go` — every sentence a person can see, as constants/functions: granted-run, vetoed, revoked, expired, condition unmet, condition cannot-say, no-grant. Each names the grant id and (for pinned loops) the pinned revision.
- `aeon/internal/action/grant.go` — **new file, `class.go` untouched**: `GrantContext`, `LiveState`, `ResolveWithGrant` exactly as AL9 rules 1–5. It imports nothing from `internal/autonomy` (the loop package fills the struct); the file must contain **none** of
  `os.Getenv`, `os.LookupEnv`, `SetClass`, `OverrideClass`, `RegisterAction`, `yaml` (including comments) — `TestClassesAreNotConfigurable` walks it.

## Tests (pure, table-driven)

| Test | Asserts | Fails when |
| --- | --- | --- |
| `TestZeroGrantContextEqualsResolve` | for **every** registry action × attended × allowOutward, `ResolveWithGrant(…, GrantContext{})` ≡ `Resolve` (T1's golden rows) | the wrapper changed existing behaviour |
| `TestVetoDeniesUnattendedOutwardEvenWithTheLegacyFlag` | vetoed + `allowOutward` ⇒ deny naming the grant | a veto ignored |
| `TestPinnedCoveredLivePasses` / `…RevokedDenies` / `…ExpiredDenies` / `…ConditionUnmetDenies` / `…ConditionCannotSayDenies` | rules 4–5 each with its sentence | a live failure ran |
| `TestUnattendedIrreversibleRunsOnlyThroughRule5` | with no pin, vetoed, uncovered, or any failing check, `forge.merge` is deny; with pin+covered+live+conditions, run | merge authority leaked |
| `TestOutwardClassDoesNotCoverMerge` | an allow on class `outward` never covers `forge.merge` | merge implied |
| `TestVocabularyEqualsTheRegistry` | subjects == non-local `action.Names()` + `outward`; adding a name to the registry (test double) changes the vocabulary | a hardcoded list |
| `TestValidateRefusals` (table, one row per closed code) | each sentence verbatim, `forge.merge` `requireGates:false` refused, expiry 91 days refused, `irreversible` class refused | a loophole |
| `TestPlanIsPureAndDeterministic` | same input twice ⇒ identical output; no clock read (clock is an input) | hidden state |
| `TestExpandOutwardIsCurrent` | adding an outward name (test double) is covered by an existing `outward` allow | stale expansion |
| `TestConditionsNilSeamIsCannotSay` | every nil seam ⇒ `cannot-say`, verdict deny | silent allow |
| `TestLabelsMatchAtPinTime` | a labelled grant applies only when the start's labels intersect | label bypass |
| `TestPackageIsPure` | `go/parser`: no import of `internal/store`, `database/sql`, `os/exec`, `net`; no `os.Getenv` | I/O in the core |
| `TestClassesAreNotConfigurable` (existing, **run**, unedited) | green with `grant.go` present | banned substring |
