`{activePage === "<id>" && isConnected && (...)}`, and one shared block —
```tsx
{activePage !== "status" && activePage !== "agent-chat" && !isConnected && (
  <Alert tone="amber" title="Not connected" description="…" data-testid="tab-needs-connection" />
)}
```
(`VERIFY: grep -n 'tab-needs-connection' src/features/test-bench/TestBench.tsx`) — already covers **any**
new tab for free. **This task adds no second empty-state mechanism.** The two new pages need nothing
special here; they get the existing disconnected handling by simply existing as ordinary gated branches,
the same as `policy`/`files`/every other tab.
