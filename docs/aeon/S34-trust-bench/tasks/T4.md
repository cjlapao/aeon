# T4 · `Probe(server)` in `internal/mcp`, and `mcp.check`

**Prefix:** TB · **Rules:** TB8 (probe discipline), TB9 (no probe side effects) · **Depends on:** T3 (shares
the `Table.MCP` seam and the probe-cache map). **The one genuinely new daemon behavior in this slice** —
everything else in S34 is exposure of code that already runs.

## Reality finding — there is no per-server configurable timeout to read

Design.md §5 says the bound is *"5 s default, from the config's own timeout field when present."* Verified
this session: `internal/mcp/config.go`'s `ServerConfig`/`TransportConfig` (`VERIFY: grep -n 'type
TransportConfig struct' -A 8 internal/mcp/config.go`) carry `Type, Command, Args, Env, URL` — **no timeout
field exists anywhere in the config schema.** Adding one would be an `internal/mcp` config-schema change,
which is S12's territory, not this bench slice's (brief §7: this slice adds no new verb and no new domain
field — it exposes). **Drop the "from the config's own timeout field" clause.** `Probe` takes one fixed
constant, named and measured the way `S36-mcp-dispatch/design.md` MD4 names `mcpDialBudget`:

```go
// internal/mcp/probe.go
const DefaultProbeTimeout = 5 * time.Second
```

Amend `../design.md` §5 to say this plainly in this task's commit.

## Goal

1. Extract the dial→`initialize`→`tools/list` sequence `cmdMCPList` already runs per server
   (`cmd/aeon/mcp.go`, the loop around its `mcp.Dial(ctx, tg.srv, os.Getenv)` / `c.ListTools(ctx)` /
   `c.Close()` calls — `VERIFY: grep -n 'mcp.Dial(ctx' cmd/aeon/mcp.go`) into one function,
   `mcp.Probe(ctx, srv ServerConfig, getenv func(string) string) (ProbeResult, error)`, and make
   `cmdMCPList` call it too. Its existing tests are the gate (Q1, plan.md): if they still pass unmodified
   after the refactor, the extraction was mechanical, which is the point — no new behavior, one fewer
   implementation to audit.
2. Wire `mcp.check {server}` onto the `Table.MCP` seam T3 introduced (same func, new `case "mcp.check":` in
   `mcpHandleFor`'s switch — **do not add a second seam field**), with: single-flight per server name,
   `DefaultProbeTimeout` bound, result cached into T3's `probeResult` map with `CheckedAt`, and **the probe
   builds no `tools/call` request — ever**, asserted against a fake transport, not asserted in prose.

## Files to create / modify

- `internal/mcp/probe.go` — **new file.**
  ```go
  const DefaultProbeTimeout = 5 * time.Second

  type ProbeTool struct { Name, Class string } // Class from the registry's own classification, not re-derived
  type ProbeResult struct {
      OK    bool
      Tools []ProbeTool
      Err   error
      Ms    int64
  }

  // Probe dials srv, completes initialize + tools/list, and returns. It
  // builds no tools/call request anywhere in its body — TestProbeNeverCallsATool
  // asserts this against a fake transport that fails if it ever sees one.
  func Probe(ctx context.Context, srv ServerConfig, getenv func(string) string) ProbeResult {
      start := time.Now()
      c, err := Dial(ctx, srv, getenv)
      if err != nil {
          return ProbeResult{OK: false, Err: err, Ms: time.Since(start).Milliseconds()}
      }
      defer func() { _ = c.Close() }()
      remote, err := c.ListTools(ctx)
      if err != nil {
          return ProbeResult{OK: false, Err: err, Ms: time.Since(start).Milliseconds()}
      }
      tools := make([]ProbeTool, 0, len(remote))
      for _, r := range remote {
          tools = append(tools, ProbeTool{Name: r.Name}) // class filled from classify.go if Q4's raise applies — confirm against ApplyListings
      }
      return ProbeResult{OK: true, Tools: tools, Ms: time.Since(start).Milliseconds()}
  }
  ```
  Treat the sketch above as a starting shape, not a contract — match whatever `cmdMCPList`'s real loop does
  byte-for-byte (its error handling, its exact `Close` ordering) rather than this file's paraphrase of it.
- `cmd/aeon/mcp.go` — replace `cmdMCPList`'s inline per-server dial loop with calls to `mcp.Probe`; its
  existing test file must pass with zero behavioral edits to the test assertions (Q1's gate).
- `cmd/aeon/mcp_services.go` (from T3) — extend `mcpHandleFor`'s switch with `case "mcp.check":`:
  - decode `{server string}`; unknown server name (not in `cfg.Public` or any agent's `Private`) refuses
    naming it, same convention as T2's unknown-agent refusal.
  - **single-flight per server name**: a `map[string]*sync.Once`-shaped guard is wrong (`Once` can't be
    reused for a second check after the first finishes) — use a `map[string]chan struct{}` or a
    `singleflight.Group` (check whether the module already vendors `golang.org/x/sync/singleflight` —
    `VERIFY: grep -rn singleflight go.sum`; if absent, hand-roll with a mutex-guarded
    `map[string]*inFlightProbe{done chan struct{}; result ProbeResult}` rather than adding a dependency for
    one call site).
  - `ctx, cancel := context.WithTimeout(ctx, mcp.DefaultProbeTimeout)`, call `mcp.Probe`, write the result
    into T3's cache map with `CheckedAt: time.Now().UTC().Format(time.RFC3339)`.
  - a context deadline exceeded is `ProbeResult{OK: false, Err: context.DeadlineExceeded}` → renders as the
    honest timeout shape (design.md §2.4's second example), never a bare error dump.
- Conformance fixture `routes/mcp-check.json` (success case) — a second request/response pair or sibling
  file for the failure shape, matching T3's one-fixture-per-state convention.

## Notes

**Built 2026-10-29.** Both pre-written reality findings confirmed: no per-server timeout field exists
(`DefaultProbeTimeout = 5 * time.Second`, one constant); `RemoteTool` carries no "class" (`ProbeTool` is
`Name`/`Description`, the real fields, never design.md's invented classification). `design.md` §5 amendment
deferred to T8, same call every prior task made.

**Q1 answered: the extraction does NOT refactor cleanly, and the plan's own escape hatch applies.**
`cmdMCPList`'s loop calls `reg.ApplyListings`/`reg.AttachClient` and keeps the connection OPEN (the registry
reads through it afterward); `mcp.check`'s probe is deliberately the opposite shape — dial, check, release,
no lingering session from a UI click (brief §3/§5). Making one function serve both would either leak a
connection per Check click or cost `cmdMCPList` the registry it needs. Shipped `mcp.Probe` as its own
function sharing `Dial`/`ListTools` (the one real dial path) with `cmdMCPList`'s loop, independently
orchestrated — the plan's own fallback ("the probe ships as a thin wrapper calling the same internal
functions rather than a rewrite — decided by T4's diff, not in advance"). `cmd/aeon/mcp.go` is UNCHANGED by
this task; there was also no pre-existing `cmd/aeon/mcp_test.go` to keep green (checked — none exists), so
the "zero behavioral edits" gate is trivially satisfied by not touching the file at all.

`internal/mcp/probe_test.go` (new — the fake-transport proof, a local `httptest.Server` rather than the
