## Shared infrastructure this task introduces (used by T7 too)

Neither `Fact<T>` (design.md TB2) nor a reusable "is this an unwired-method error or a real error" classifier
exists yet in the UI codebase (`VERIFY: grep -rn 'type Fact' ../ui/src` — confirm still absent before adding
a second one). Create them once, here, for both pages to share:

- `ui/src/features/test-bench/lib/fact.ts` — **new file**:
  ```ts
  export type Fact<T> =
    | { state: "ok"; value: T }
    | { state: "unwired" }
    | { state: "error"; message: string };

  // A method-not-found RpcError (the daemon doesn't register this method —
  // an old build) is "unwired", distinct from a real failure. VERIFY the
  // exact code/kind RpcError carries for "method not found" against
  // `ui/src/lib/bridge.ts` (grep for -32601 / METHOD_NOT_FOUND) before
  // hard-coding the check below — this sketch assumes it is `code === -32601`.
  export function classify(error: unknown): Fact<never> {
    const e = toRpcError(error);
    if (e.code === -32601) return { state: "unwired" };
    return { state: "error", message: e.message };
  }
  ```
- `useFact<K extends keyof RpcMethods>(method: K, params: RpcMethods[K]["params"]): Fact<RpcMethods[K]["result"]>`
  — a small hook beside `classify`, following `PoliciesPanel`'s exact load/error/busy shape
  (`ui/src/features/test-bench/pages/PolicyPage.tsx`'s `PoliciesPanel` function is the model to copy, not
  reinvent): `useState<Fact<T>>({state: "unwired"})` as the pre-first-load placeholder would be WRONG per
  TB2 (that's inventing a state before anything was asked) — start `null`/"loading" distinctly, resolve to
  exactly one of the three terminal states once the call settles. Export a `refetch` alongside it (design
  §3's `Refresh` is "refetch, not dial" — TB9).
- A small `<FactCell>` presentational component (`ok` renders `children(value)`; `unwired` renders a quiet
  "not wired on this daemon" chip; `error` renders the message in `ErrorPanel`'s style) so every strip in
  both pages renders the three states identically rather than each strip inventing its own.
