## Context

Two shapes that everything else switches on, and both are cheap now and expensive to retrofit.

**`StepResult` ships as a tagged union with a `suspended` variant nothing produces** (K21). S6 fills it in.
Shipping the shape costs a `Kind` field today; adding it at S6 means a mechanical sweep through every switch
written in between. And a test asserts nothing returns `suspended` yet, so the unused variant is honest rather
than aspirational.

**Suspension is not a fifth outcome.** The four — `ok`, `reject`, `blocked`, `failed` — describe *work*.
Suspension describes a *pause*. Adding it to the outcome enum would make `blocked` ambiguous: a caller could no
longer tell "ran out of iterations" from "waiting for a human", and those need opposite responses.

**Every limit lives in one file, labelled a guess** (O4, I6). `MaxIterations`, the deadline, the bash timeout,
the output caps — all derived from prose rather than measurement. Scattered constants become folklore, and the QA
suite is written to change these numbers rather than confirm them. So each carries its provenance in a comment:
where the number came from, and that it is a guess.

**Read first:** `docs/_archive/aeon-v1-horizontal/03-step-runtime/tasks/T1.md` for the TypeScript shape; the plan's Q2 for the
event vocabulary and Q3 for the four numbers with their provenance.

## What to do

**1. `types.go`:**

```go
type Outcome string  // "ok" | "reject" | "blocked" | "failed"
type ResultKind string  // "complete" | "suspended"

type StepResult struct {
    Kind    ResultKind
    Outcome Outcome          // complete only
    Handoff *Handoff         // complete only
    Question *PendingQuestion // suspended only — NEVER SET IN S5 (K21)
    Messages []model.Message
    Manifest ContextManifest
    Usage    model.Usage
    Cost     model.Cost
    Events   []StepEvent
}
```

Plus `StepRequest`, `StepHandler`, `ContextSection`, `ContextManifest`, `Handoff`, `StepEvent`.

`ContextManifest` carries `Files []FileHash`, `IterationsUsed int` and `DeadlineAt time.Time` — **absolute**,
not a remaining duration. A relative deadline cannot survive a suspension that lasts overnight; it would grant
the resumed step its whole budget again.

**2. Extend the event vocabulary** with `step.tool.start` and `step.tool.end`. **Do not rename** the superseded
names — S9 was specced against them.

**3. `limits.go`** — every number, each with a comment naming its provenance and that it is a guess. The bash
timeout's 600 s came from counting `timeout 600` in twenty-one agent bodies; say so.

**4. Write the type tests.** Prove there is no fifth outcome. Prove `Question` is nil across every path —
grep, plus exhausting the fake client's scripts and asserting no result has `Kind == "suspended"`.
