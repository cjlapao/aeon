## Context

Where K3's rule lives: every step gets a **fresh** context built from declared sections, and nothing accumulates
across steps. That is the design's central bet and what makes a step reproducible.

**The manifest is frozen at assembly even though nothing resumes yet** (K23). S6 compares these hashes to tell a
resumed step which files changed while it waited; S7 does the same after a crash. Freezing is cheap today and
**impossible to retrofit** once callers have assumed the context is re-read — and S4 already has the column
waiting for it.

**A missing declared file is a construction error, not an empty section** (D13). An empty section reads to a
model as "this file is empty", which is a different and more damaging claim than "this file is missing" — the
model will reason confidently from the absence.

**Assembly order is part of the contract.** A persona before a task spec before a handoff reads differently from
the reverse, and models are order-sensitive. Do not sort.

**Read first:** `docs/_archive/aeon-v1-horizontal/03-step-runtime/tasks/T2.md`, which this ports; the plan's Q9 for the default
handler's sections; `internal/store`'s `context_manifest` column shape (S4 T5).

## What to do

**1. `context.go`:**

```go
type ContextDeps struct {
    ReadFile func(string) ([]byte, error)
    Hash     func([]byte) string
    Clock    func() time.Time
}

func AssembleContext(specs []SectionSpec, d ContextDeps) AssembleResult
func Rehash(m ContextManifest, d ContextDeps) (changed, missing []string)
```

Dependencies injected (I5) — which is what makes assembly deterministic and testable without a filesystem, and
what will make S6's identity assertion possible.

**2. Assemble in declared order**, hashing every file with a `DeclaredFile`.

**3. `Rehash` returns two lists**, `changed` and `missing`, kept **separate**. They are reported to a model
differently — "this file changed while you waited" and "this file no longer exists" call for different responses
— and merging them loses that. Nothing calls `Rehash` in S5; it exists because the manifest does, and S6 uses
it.

**4. Never mutate the manifest.** `Rehash` compares and reports. Freezing means freezing.

**5. Tests.** Order preserved; a missing declared file returning a construction error; a **second assembly not
re-reading**, asserted with a `ReadFile` spy; no file read outside the declared set; determinism under a fixed
clock, by assembling twice and comparing.
