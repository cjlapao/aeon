## Context

**`aeon/` already exists when this task starts.** It is created by hand, outside the loop: a Go module with
`cmd/`, `internal/`, a `go.mod` requiring `go-backend-scaffolding`, and a `cmd/aeon/main.go` that starts the
API and nothing else.

So this task does not build the skeleton. **It establishes what the skeleton actually is**, and pins it, so
that every task after it is standing on something described rather than something assumed.

**That is worth a task on its own.** Six tasks follow and all of them edit this module. A handshake that
costs twenty minutes now is the difference between "T3 failed" and "T3 failed because `main.go` was not
what T3 believed". The loop cannot see the folder being made; this is where it looks.

**Aeon imports the framework — it does not fork it** (B1). `aeon/` holds Aeon's code and nothing upstream.
If this task finds copied framework source under `aeon/internal/`, that is a **finding to report, not
something to tidy**: it changes P24's extraction story and B1's whole basis, and the person who put it there
had a reason worth hearing.

**`go-backend-scaffolding` is never edited** (N8). It is a different repository and a dependency; this slice
only reads it.

**Read first:** `aeon/go.mod` and `aeon/cmd/aeon/main.go` as they exist; the design's B1, B2 and B8; the
plan's Q7.

## What to do

**1. Record what is there.** Enumerate, in this task's notes: the module path, the Go version, every direct
requirement with its version, and every package under `aeon/internal/`. **An enumeration, not a summary** —
later tasks are matched against this list.

**2. Pin the framework to an exact version** (B2). No `latest`, no branch, no pseudo-version if a tag exists.
`go mod tidy`, and commit `go.sum`.

**3. Write `aeon/UPSTREAM.md`** recording:

- the framework's module path and **the exact pinned version**
- **what Aeon uses from it** — the packages actually imported, enumerated
- **the upgrade procedure**: the commands, that B11's golden-file test must pass afterwards, and that the
  reason for the upgrade is recorded here each time

This file replaces the fork's base-commit record. **The divergence problem is gone; a different one replaces
it** — an upgrade is now one command, so what needs writing down is not *where we diverged* but *why we
moved and what it changed*.

**4. Assert `aeon/` owns no upstream copy** (B1). Grep `aeon/internal/` for the framework's module path and
for its package names. A hit is reported as a finding with the file named, not silently deleted.

**5. Confirm it builds and starts.** `go build ./...`, then run the binary and confirm the API starts and
the process stays up. **A skeleton that arrives already broken cannot be distinguished from a later task
breaking it**, which is the whole reason this task is first.
