# T5 · Agent tools and the `roadmap_idea` proposal kind

**Prefix:** RM · **Rules:** RM8 · **Shape:** P6 · **Depends on:** T4, **S45 T1/T5**.

## Specs (family `roadmap`)

| Tool | Twin | Mutates | What it does |
| --- | --- | --- | --- |
| `roadmap_list` | `roadmap.board` | no | The roadmap with each item's honest status, three-state priority, estimate with basis, readiness and blocker |
| `roadmap_show` | `roadmap.show` | no | One item in full with its history |
| `roadmap_propose_idea` | `roadmap.proposeIdea` (new) | **yes** | Create an **inert proposal** to add an idea (kind `roadmap_idea`); a person commits it; nothing changes until then |

## Files and rules

- Migration `<ts>_proposal_roadmap_idea.sql`: the P6 table rebuild — **read the current `proposal` DDL** (all kinds from S37/S46/S48/S49 if merged), change only the CHECK; Go mirror, lock test, literal count assertions.
- `internal/desk` kind `roadmap_idea` `{componentRoot, title, epic?, note}`: `Validate` = the **same validators `roadmap.add` runs** (component exists, title rules; one function with create/commit parity); `Apply` = `roadmap.add` (provenance `authored`) with the committing person as actor; `AlreadyApplied`: an identical open item exists (same root+title).
- Schemas: no identity/status/provenance fields; per-agent open-proposal limit; registry bump **+3** counted and dated; not in `DefaultGrant()`; no tool updates/cancels/estimates/prioritizes/dispatches (T4 asserts).

## Tests

Catalog/parity; schema carries no identity; invalid refused at create (nothing persisted); valid ⇒ inert proposal by the agent actor with board/list byte-identical; commit via S45's generic commit writes the item with the **committer** as actor and one `roadmap_change`; migration preserves rows/indexes; validators one function; limits; registry counted and not granted; no write tool exists.

## Do NOT

Add a tool or kind that edits, cancels, estimates, prioritizes or dispatches; add provenance values; add a socket method beyond the one twin; copy another slice's kind list.
