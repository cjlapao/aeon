# T4 · Catalog page: category, access, address, and the policy link

**Rules:** TA14. **Depends on:** T1.

## Steps

1. In `features/settings/tools/` (`ToolList.tsx`, `ToolFilters.tsx`, `ToolDrawer.tsx`) add the three columns and a filter each for category and access. The filters send nothing new to the daemon; they filter the list already loaded.
2. The drawer gets "Write a policy for this tool". It opens the Policy page's create form with `toolName` set to the tool's address and the action left for the operator to pick. Use the existing route and search params the S45 "policy for this tool" link already uses; do not invent a second one.
3. Tests: columns render from the fake daemon, the access filter narrows the list, the link carries the address.

## Definition of done

- The Tools page shows the address and filters by category and access.
- The link lands in the policy form with the field filled.

## Do not

- Do not touch the drift banner or the agent matrix.
