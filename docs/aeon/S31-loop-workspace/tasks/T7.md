# T7 · Terminal sessions in the daemon (D9)

**Prefix:** LW · **Contract:** [`../brief.md`](../brief.md) §6 T7 · **Code map:** [`../CODEMAP.md`](../CODEMAP.md) §3 (stepCancels registry pattern), §8 (process-group discipline), §16 (pty dep)

## Context

The daemon owns PTY shell sessions in a registered project root: open, input, resize, attach (bounded scrollback), detach, close, list. Output and exit reach the app as their **own notifications** — `terminal.output` / `terminal.exit` via `localrpc.Notify`, **not** through the `EventLog` (LW7: the log's seq is durable and its ring shared; keystroke-rate output would evict real events). A terminal is not policy-governed (LW8 — the person's own shell under their own uid on a P26 socket) and must never reach the narrow HTTP surface (guard test, I5). Boundeds (LW10): scrollback ring 1 MiB/terminal, ≤8 terminals per project root, output coalesced to one notification per 16 ms or 32 KiB whichever first. Terminals outlive a connection, not the daemon (LW9): detached reaped after 15 min with nobody attached; all killed (process group, matching `tools/spawn.go`'s `Setpgid` mechanism) on daemon shutdown. Windows: `terminal.open` refuses with a named `unsupported` error (LW12), build-tagged so the package compiles everywhere.

## What to do

- New `internal/terminal`: registry owned by the daemon (shape like `stepCancels`), PTY via **`github.com/creack/pty`** (MIT — add to go.mod, record in the Notes here; not UPSTREAM.md, that file is framework-only). Shell: `$SHELL`, fallback `/bin/sh`; `TERM=xterm-256color`; cwd = the project root; own process group, killed as a group.
- One reader goroutine per terminal → ring buffer + coalescer → `localrpc.Notify(connID, "terminal.output", {terminalId, seq, data base64})` per attached connection; exit → `terminal.exit {terminalId, exitCode?, signal?}`, session kept (exited) until closed or reaped.
- Connection close detaches (localrpc's connection lifecycle); reaper per LW9 (test-shortenable interval); `Daemon` shutdown closes all.
- Socket handlers `terminal.open/input/resize/attach/detach/close/list` — `projectRoot` must be registered, refusals named (I4). Input is a UTF-8 string; output base64 (Q3).

  tail-keeping is proven by a wrap test.

  each layer's tests stand where only it can: `internal/terminal` (shell mechanics, bounds,

  `TestTerminalAttachBindsTheCallingConnectionNotAParam`: the seat follows the SESSION, a

  the wire: output base64, `exit 3` → `terminal.exit {exitCode:3}`, resize → `stty size`

  live subscription on the SAME connection that carries the terminal traffic and asserts
  `events.Head()` identical before and after, plus zero `event` notifications added — a
  terminal's whole life spends no durable seq and no ring space. (The wire fake gained a `Raw`
