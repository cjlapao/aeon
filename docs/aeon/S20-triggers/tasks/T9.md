# T9 — Walk the demo, write the QA suite

## Why this exists

**A slice is done when someone else can follow `DEMO.md` and watch it work.**

And this demo has the two steps most likely to be *reasoned about* rather than run:

**§5 — the DST cases.** They need a real transition date in a real zone. **If you compute what should
happen instead of making it happen, the step proves nothing** — and these are the two days a year the
slice exists to get right.

**§3 — the catch-up.** It needs the daemon genuinely down across multiple instants. **If the clock is
advanced while the daemon is up, there is nothing to reconcile.**

**Read first:** `DEMO.md` in full; `docs/test_suites/` for the house format and id convention; S11's note
on asserting **properties, not counts**.

## Notes (what this task actually found, in its own words)

**The walk finished the slice — literally.** Five code bugs shipped-unit-green and were caught only where the
capability is consumed: `trigger add` did not exist (built here — socket method, CLI verb, conformance
fixture, tests; the slice shipped every door but the one that adds); the governance hook matched the
trigger's **kind** instead of its **identity** (a `{"trigger":"schedule"}` row admitted every schedule — and
the daemon fixtures seeded kind-words, mirroring the bug, so units stayed green: `TestKindNamedRowsUnlockNothing`
pins the corrected identity semantics and every fixture was retargeted to real trigger ids); `fire-now`
truncated its instant to the minute, colliding with `UNIQUE(schedule_id, instant)` and hiding the running
loop from the overlap gate's own `<` query (now the exact asked-instant — TR4 honesty and TR5 overlap both
depend on the instant being *true*); a brand-new schedule was **silent forever** (empty frontier parses as
zero time → "unrealistically wide — left untouched"; `Add` now seeds the frontier at registration — T4's
"new triggers start from now" was a rule its own producer never wrote); and the forbidden-word scanner read
`trigger.fireNow` as one token. **Lesson for every T9 after this: a fixture written from the code under test
proves agreement, not correctness — only the consumer's place proves that.**
