## Why this exists

**Two things, and both are about not building a trap.**

**The clock is injectable from the first line.** Every test in this slice is about time — missed fires, DST,
overlap, windows. **A clock retro-fitted for testability has two code paths, and the one the tests do not
use is the one that runs at 3am.** And a suite that sleeps to test a scheduler is a suite nobody runs.

**And the attendedness must not leak.** This is new code calling `loop.start`, and passing *"this is a
scheduled run, treat it as attended"* is a **one-line convenience that destroys G14.** The pin exists so a
verdict is reproducible; a hint would make the verdict depend on who started the loop.

**What this task inherits rather than builds:** the entire safety story. G14 pins attendedness, S11 closed
the inference path, S6 suspends on an outward action. **This task's job is to prove the inheritance still
holds** — not to add a guard.

**Read first:** G14 in [`../../S11-permissions/design.md`](../../S11-permissions/design.md) and its "no
inference path" note; S6's suspension; `schedule.go` (T1); the design's TR2.

## Scope

**1. A clock interface or parameter.** **No `time.Now` inside** — asserted by grep. Every test moves time
explicitly.

**2. The tick** evaluates the window, overlap (T3) and `TriggerAccess` (T7) before starting anything. This
task establishes the order; those tasks fill in the checks.

**3. Start the loop with attendedness pinned unattended** — through the same path a person's loop uses,
with no extra parameter. **Assert that no attendedness hint is passed**, by signature or by grep.

**4. Assert the inherited behaviour end to end**: an unattended scheduled loop reaching an `outward` action
**suspends**. Not aborts, not proceeds. This is the single most important test in the slice, and it tests
code this slice did not write.

**5. `started-by: trigger` is recorded on the loop**, so §1 of the demo can distinguish it. **That is
provenance, not attendedness** — do not let the two share a field, because then "who started it" and "may
it act" become one value and somebody will set it to make a schedule act outwardly.
