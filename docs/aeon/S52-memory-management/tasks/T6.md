**Deviations and measured facts the task file could not know.**

1. **The loop link costs one read.** Rows carry `sourceLoopSlug`, not a loop id, so the panel resolves
   slugs through a `loop.list {all:true}` read (door 8). An unresolved slug renders a plain word —
   never a guessed `/loops/<something>` route.
2. **The desk is reused, not re-implemented** (McpSection's precedent): `<ProposalsDesk
   kinds={MEMORY_PROPOSAL_KINDS} />` — that list is the folder's ONLY proposal-kind literal, and the
   guard allows the five `proposal.*` because the reused desk files carry them.
3. **The reason bound is quoted, not typed.** The label interpolates `vocabulary.limits.reasonMin/Max`;
   while the vocabulary is not loaded the label SAYS the bound is the daemon's without inventing
   numbers (`reasonUnknown`). An early draft hardcoded "1..256" — the guard-adjacent honesty review
   caught it.
4. **`RetractLaw` rides the confirm** (`memory-confirm-law`, byte-equal to the vocabulary fixture —
   asserted) and a `lawMissing` state prints while the vocabulary is unread; no authority sentence is
   DEFINED in UI code (guard, two patterns).
5. **Contract-widening at the read boundary**: `Retraction` fields are absent from the generated
   board/show types because the T2 fixtures predate retractions; Go omits them empty on the wire.
   Widened with the triageModel's documented-cast idiom; the filter params for `board`/`forAgent` are
   cast at the same seam (fixture-narrower than the Go wire).
6. **ICU, not mustache**: the ui-kit parser is single-brace — `{{slug}}` threw
   `IcuParseError` at first run; labels use `{slug}`-style.
7. **`Pill` with `dot` puts an outer `data-testid` on the DOT span** (measured: pill textContent
   empty). Row pills carry no dot (triage's row pills agree) so word and class are assertable —
   LM10's four-provenances-distinct check runs on the rendered class.
8. **Tone functions return literal unions** (`MemoryTone`), not `string` — `npm run lint` is `tsc`
   and `Pill.tone` is a 21-name `TrueColor` union.
9. **The walk quotes its unfakeable lanes** rather than re-enacting them: the agent lane (a person
   socket's peer kind is `user`, never `agent`), the proposal commit, and two-window staleness — each
   step names its tests (see DEMO §S52). `agent.delete` DID walk live over the socket and refused
   naming the count.

10. **A fresh class of bug, found by the FULL suite and named here**: the
    first-run `rowsOf`/`hitsOf` returned a fresh `[]` literal for a malformed
    answer, and the board mirrors rows up through a `useEffect` keyed on that
    value — under `test/product-shell.test.tsx`'s fake daemon the generic `{}`
    fallback for `learnings.board` made that identity new EVERY render, the
    effect re-fired forever, and the whole vitest worker livelocked (CPU pinned,
    timeouts never fire because microtasks never settle — a hung suite, not a
    failing one). Fixed with a shared stable empty constant (`NO_ROWS`/`NO_HITS`,
    comment carries the lesson): a malformed answer is one quiet render. The
    targeted fixture tests could never show this — only the app-shell walk
    through a fake daemon could.
