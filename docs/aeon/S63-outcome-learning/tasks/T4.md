# T4 · `internal/scorecard`: derived cards with sample sizes, states and floors

**Prefix:** RT · **Rules:** RT3, RT7, RT8, RT9 · N8 · P31/P32 · **Depends on:** T1 (fixtures from T2). Parallel-safe with T3.

## Goal

A **pure read package** that turns recorded facts (plus history for coverage) into cards. No writes, no cache, no
stored score. Every metric says how many samples it rests on and refuses to produce a number it cannot support.

## Files

- `aeon/internal/scorecard/` — **new**: `types.go` (`Card`, `Metric{Value *float64, N int, State, Note, Detail}`,
  `State` closed set `ok|too-few|cannot-say|partial`, `Subject`, `Window`, `Coverage`), `compute.go`,
  `agent.go`, `blueprint.go`, `component.go`, `compare.go`, `vocabulary.go` (`Metrics()` with descriptions, `States()`,
  `MinSample = 5`, `Milestones` re-export), `percentile.go` (median/p90, nearest-rank, documented).
  Imports `internal/store` (read functions) and `internal/history` (coverage + `Rollup` rendering) only — **not**
  `loop`, `runtime`, `policy`, `learnings`.
- `aeon/internal/store/retro_read.go` — **new**: the aggregate SQL (all SQL stays in the store, I2): `RetroAggregate(
  Subject, Window)` returning grouped counts/sums, `LatestOutcomePerLoop` query, `RetroWallSamples`.
- `aeon/internal/scorecard/testdata/` — census fixture (T2's recorder over a built store) and goldens.

## Computation rules (each is a test)

1. **Unit = latest `retro_outcome` per `(component_root, loop_slug)` within the window**; "ever blocked" looks at all
   rows of that loop. Backfill rows count toward status/cost metrics only (`partial` with the reason) and are excluded
   from any metric needing NULL columns.
2. `n` is the number of samples the **metric's own denominator** used, not the card's loop count.
3. State: `n == 0` or prerequisite absent ⇒ `cannot-say`; `0 < n < MinSample` ⇒ `too-few`; incomplete rows or floors ⇒
   `partial` (value present, note says why and how many); otherwise `ok`. `value` is `null` for `too-few` and
   `cannot-say`.
4. `costPerCompletedItem`: sum of floors over finished-done loops with any cost data ÷ their count; `Detail` carries
   `unknownSteps`, `partialSteps`, `steps` and the rendered "at least $X (K of N steps unknown)"; if **no** finished loop
   has any known cost ⇒ `cannot-say`, never `0`.
5. `wallPerItem` = median and p90 over `wall_ms` (NULLs excluded; excluded count shown).
6. `firstPassRate` denominator = finished-done loops; numerator = rework total 0 **and** no unverified step **and** not
   ever blocked.
7. `gatePassRate`, `mergedThenRevertedRate`: `cannot-say` with note "needs S57 (gate results)" until the columns/tables
   exist (T0 states which); implemented as a function over an interface that returns `ErrNotRecorded`.
8. Per-agent card from `retro_agent` rows joined to outcomes in the window; `stepsRun` etc.; an agent with only
   `agent_slug_known=0` rows is reported under its name with `note: "name, not slug"`.
9. Component card: roll-up over the node's tree via a `component_root` set resolved through the S44-extra reads
   (`RootOf`/children — T0 confirms the function names); `breakdown` = per-child `{loops, done, blocked}` counts only.
10. Coverage: `loopsInHistory` from `history.Merge` count in the window; `loopsRecorded` distinct loops in
    `retro_outcome`; `recordedSince` = earliest `recorded_at`; the card is returned even when empty.
11. `Compare` = two independent computations with identical rules; no delta is computed or stored (a person reads two
    numbers).
12. **No ranking function exists** (RT11): the package exports no sort-by-score, no "best/worst".

## Tests

| Test | Asserts | Fails when |

| `TestSmallSampleReadsTooFew` | n = 4 ⇒ `too-few`, value null; n = 5 ⇒ `ok` | a rate from two runs |

| `TestCostPerItemIsAFloorWithItsUnknowns` | rendered string equals history's renderer for the same rollup | a total claimed |
| `TestLatestOutcomePerLoopRule` | blocked-then-done loop counts once as done and once in "ever blocked" | double count |
| `TestFirstPassIgnoresBackfill` | backfill rows can't raise `firstPassRate` | inflated rate |
| `TestMedianNotMean` | skewed wall samples ⇒ median/p90 as documented | mean of skew |
| `TestAgentCardIsPerSlug` / `TestUnresolvedNameIsLabelled` | | misattribution |
| `TestComponentRollupIncludesChildren` | tree of root+2 children: roll-up equals the sum of the three nodes; `includeChildren=false` is the node only; breakdown has counts, no scores | tree semantics wrong |
| `TestCoverageOnEveryCard` | `loopsNotRecorded = loopsInHistory − loopsRecorded` | hidden gaps |

2. **Store reads** (`internal/store/retro_read.go`, all SQL in the store, I2): `RetroLatestOutcomes` —
   `ROW_NUMBER() OVER (PARTITION BY component_root, loop_slug ORDER BY id DESC)` keeps the RT7 unit;
   `lastN` = "the last N loops that reached a terminal in the window" (rn=1, id DESC, LIMIT).
   `RetroEverBlockedLoops` deliberately WINDOW-FREE (rule 1: a loop blocked last month was not a first
   pass today). `RetroAgentRowsInWindow` joins agent rows to their outcome's window/roots. Empty roots
   span every component (history.Options' own semantics). All three named in store.go's surface table.
3. **`unverifiedRate` denominator decided**: the fact table (T1, frozen) has NO total-steps column — the
   steps a row KNOWS are the ones a verification verdict reached: `verified_pass + verified_fail +
   unverified_steps`. A row missing any of the three is skipped, never zero-filled (P31).
4. **`firstPassRate`** (rule 6): denominator = finished-done loops the row can JUDGE (`retries` AND
   `unverified_steps` readable); NULL drops the row AND is counted in the note ("N finished-done loop(s)
   unreadable (backfilled or partial)"). Backfill exclusion is STRUCTURAL — backfilled rows carry NULL
   verdict columns by design (RT13), so they can never vote; `TestFirstPassIgnoresBackfill` proves four
   loops with two backfilled rows reads too-few(2), not a rate of four.
5. **`too-few` beats `partial`**: below `MinSample` a metric holds its number (value null) even when
   floors/unknowns are present — a one-sample floor is not a number it can stand behind. `partial`
   promotes a stated value only.
6. **Cost rendering is a CALL, not a copy**: `Detail.rendered = history.Rollup{Total, StepCount,
   UnknownCount, Floor}.Render()` — rule 4's equality test compares against the same renderer invoked in
   the test. No loop with any known cost ⇒ `cannot-say` (never 0 — `TestUnknownIsNeverZero`).
7. **Gate plane**: `GateResults` interface + package var `gateResults` nil (S57's `verify_run` exists per
   T0 but the revert twin does not — the pair wires together or not at all); both metrics answer
   `cannot-say` naming S57. The interface makes future wiring a compile-time event, rule 7.
8. **Subject/roots resolution**: component id → `ReadComponent` → root; an UNREGISTERED id is read as a
   `component_root` verbatim (the honest reading of "the card for this directory"). `includeChildren`
   walks depth two (children + their children); `breakdown` lists DIRECT children as
   `{loops, done, blocked}` ints only — `TestComponentRollupIncludesChildren` reflect-refuses any float
   field (nothing to rank, RT11). Agent/blueprint subjects are workspace-wide; a foreign/unknown agent
   gets an empty cannot-say card, not another agent's numbers.
9. **Coverage** (rule 10): `loopsInHistory` from `history.Merge` — one merge per scoped root, empty scope
   spans all (S25's own semantics); `Since` rides the query, `until` filters the timeline in memory. The
   `last` cap trims the card's METRICS, never the honesty strip — coverage refetches the uncapped distinct
   set when a cap is in force (`TestCoverageOnEveryCard`). Empty subject ⇒ full card of cannot-say +
   statement, not an error.
10. **`Milestones()` re-export is generated, not imported**: importing `internal/retro` from scorecard

    test-only, no cycle: retro never imports scorecard).
11. **N8 + RT11 guards are source scans** (`TestNoWritesNoCache`, `TestNoRankingExported`): banned text
