# T5 · The socket surface, the digest, and the locked-rule guards

**Prefix:** RT · **Rules:** RT3, RT10, RT12, RT13, RT16 · P34 · P4 (guard shape) · **Depends on:** T3, T4.

## Goal

The daemon answers every scorecard, retro and digest question over the socket; the one write-adjacent door
(`retro.backfill`) is human-only; and the **"nothing self-applies" rule is a set of guards that fail when violated** —
with canaries proving they can.

## Behaviour

- Every method except `retro.backfill` is a **read** and classified `read` (S47 table input). `retro.backfill {dryRun?
  (default true), yes?}`: human socket door (peer-credential surface), **absent from** `narrow.Actions()`,
  `BoundaryStatement()`, agent services, the tool registry and the records catalog (P4); dry-run default; writing needs
  `yes:true`; refusal sentence otherwise.
- Results carry `statement` (RT3 sentence), `coverage`, and per-metric `state`; the digest follows RT12's fixed order;
  empty windows return sections with `cannot-say`/0 and a sentence.
- `retro.status` returns: `recordedSince`, `lastWriteAt`, `dropped` (daemon counter), `outcomes`, `learningsWritten`,
  `reconcile` state, `modelRetrospective{enabled, blockedBy?}`.
