### 1. Facts re-walked (F1–F16)

**Same unless a drift line follows.**

1. **`publishLoop`** (`internal/daemon/blueprint.go:498`): the terminal block (`kind == protocol.KindLoopFinished ||
   KindLoopBlocked`) calls five reactors in order — `onQueueTerminal`, `onRoadmapTerminal`, `onTriageTerminal`,
   `onGateTerminal` (S57), `onMergeQueueTerminal` (S60); `onEnvironmentTerminal` runs at the function top (S59). T2
   adds one call in the terminal block — the sixth. All five share the shape
   `(kind protocol.EventKind, componentRoot, loopSlug string, fields map[string]any)` and each hands work to a
   goroutine (V18 — never block the emit path).
2. **Event `seq` is NOT available to reactors** (F2 drift): `publishLoop` receives only `(kind, payload)`; the seq is
   allocated later by `AppendEvent` inside `d.publish` (`store/events.go:86` returns it). **RT2 key decided:**
   `terminal_key = outcome_kind + "@" + loop.updated_at` as re-read in the reactor goroutine via
   `ReadPinnedLoop`. `isoUTC` carries **millisecond precision** (`store/open.go:305`
   `"2006-01-02T15:04:05.000Z"`), so a replay re-reads the same row → same key → `ON CONFLICT DO NOTHING`; two
   genuinely different terminal events for one loop share a key only if same kind, same millisecond — negligible,
   and the collision is dedupe, not corruption. Collision risk named per spec.
3. **Payload fields**: `loop.finished` = `{loopId, status}` with `status ∈ {done, aborted, cancelled}`
   (`internal/loop/rest.go:94`; endStatus: aborted→aborted, converse→idle which emits `loop.run.finished` at :86
   and is NOT a terminal outcome, cancelled via S55 cancel path :47). `loop.blocked` carries `status` + a reason
   that arrives to the queue reactor as **`*loop.BlockedReason{Kind, Detail, Action, Slice}`** (`loop/action.go:21`)
   — the struct, not a string; `queueReason()` already handles both shapes. **RT2 reads `.Kind` directly**; the
   "leading token of the reason string" fallback only matters for the string shape. **Drift: `cancelled` is a fifth
   kind** — the closed set is `done | aborted | cancelled | blocked/<kind> | blocked/other:<kind>` (F2 said
   done|aborted only; S55's cancel writes `cancelled`, and `loop.close` synthesizes `finished/done` for idle loops at
   blueprint.go:415 — S39 CR1).
4. **BlockedReason.Kind inventory, measured** (all emits): `budget-unreadable` (advance.go:313), `cap-hit`
   (advance.go:330/438, continue.go:116), `model-error` (:351), `contract-unverifiable` (contract.go:33),
   `backlog-append` (:505), `exhaustion` (:549), `unresolvable-reject` (:557), `step-<outcome>` (:565,
   continue.go:196), `unit-error` (advance_parallel.go:353), `pin-unparseable` (continue.go:238),
   `escalation-answer` (escalate.go:358), `gate-answer` (runner.go:321), `runner-error` (runner.go:133),
   `action-denied` (execute.go:110/157/206), `action-failed` (execute.go:212); state.go:102 adds
   `action-conflict`, `action-denied-by-person`, `action-refused`; `st.BlockKind` mirrors the last blockTo kind;
   `stuck` arrives via watchdog (`store/watchdog.go:746` `setRuntimeLastReason`). **No closed enum exists** — every
   unmapped value lands `blocked/other:<kind>` ≤ 48 chars per RT2; `stuck` is reachable and maps to `blocked/stuck`.
5. **Blueprint pin + wall**: `store.ReadPinnedLoop(id)` (`store/blueprint.go:212`) →

   started→terminal `updated_at` (NULL if absent).
6. **Escalations**: `escalate.go:115-133` — attended escalation = `CommitGate(id, sc, prompt, ["continue","abort"],
