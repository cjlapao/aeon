# Aeon

A coding platform that runs a declared sequence of model steps against a
repository, with a human at the gates.

## Four steps

1. **Install** — one binary.
2. **`aeon init`** — pick a provider, paste a key.
3. **`cd <a repo>`** — go to the code you want it to work on.
4. **`aeon step "…"`** — or `aeon loop start "…"`.

That is the path. There is no fifth step, because a fifth step is time this
would have spent badly.

## What is different

The method is data, not prose. The loop asks rather than guessing. Costs are
reported honestly, including when they are unknown.

## What it needs

One binary, one API key. A local model works with no key at all.

## What it does not do

No telemetry. No account. No auto-update. A tool that reads your source code
and runs commands is one you install on trust, so this is stated here, not
only in `PRIVACY.md`.

More — seventeen slices of reasoning, the design — is in `docs/aeon/`. This
page is the path, not the architecture.
